# 从模型到行动：自主系统的统一方法

**From Modeling to Action: A Unified Approach to Autonomous Systems**

> 核心主线：**建模（Modeling）→ 估计（Estimation）→ 规划（Planning）→ 控制（Control）→ 执行（Execution）**
>
> **学习（Learning）** 横跨各层，**反馈（Feedback）** 将整个系统连接成闭环。
>
> 机械臂作为贯穿案例，不作为一级知识层级。

## 内容结构

全书共九篇、五十八个章节，附六个附录：

| 篇 | 主题 | 核心问题 |
|---|---|---|
| 第一篇 | 世界与系统 | 什么是系统？自主系统的完整闭环是什么？ |
| 第二篇 | 建模 | 如何从物理规律得到系统的数学描述？ |
| 第三篇 | 估计 | 如何从带噪声的观测中还原系统状态？ |
| 第四篇 | 规划 | 如何从目标出发生成可行运动？ |
| 第五篇 | 控制 | 如何让系统按照期望的方式运行？ |
| 第六篇 | 执行 | 如何把连续理论落到数字计算机与真实硬件？ |
| 第七篇 | 学习 | 当模型不精确时，系统能自己学什么？ |
| 第八篇 | 系统集成 | 模块如何连接，系统如何从零设计？ |
| 第九篇 | 统一视角 | 动力学、概率、优化如何统一于反馈？ |

附录包含数学基础、空间与刚体数学、控制与规划算法速查、软件工具链与配套实验系统。
