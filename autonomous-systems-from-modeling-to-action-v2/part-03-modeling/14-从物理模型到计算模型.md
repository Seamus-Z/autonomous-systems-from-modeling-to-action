物理定律通常以力、力矩、电压、电流和几何约束的形式出现，而估计器、控制器与规划器需要的是能够在计算机中反复求值的状态转移。两者之间并非简单的“把公式写成代码”：必须选择状态、处理高阶导数、确定输入与输出、在工作点附近线性化，并根据采样和保持机制得到离散模型。每一步都会引入假设，也会决定后续算法能看见什么、忽略什么。

本章以一台差速移动操作机器人为贯穿例子。机器人具有左右驱动轮、直流电机、平面底盘和一个两关节机械臂。我们将分别建立电气、机械、移动和操作模型，再把它们组织成适用于仿真、估计、控制与规划的统一计算接口。这里关注的是模型如何形成；模型参数的辨识、闭环设计和实时部署将在后续章节进一步展开。

## 14.1 从物理变量选择状态

状态（state）是在已知未来输入的条件下，足以决定系统未来演化的最小内部信息。连续时间确定性系统通常写成

```math
\dot x(t)=f(x(t),u(t),t),\qquad
y(t)=h(x(t),u(t),t),
```

其中 $`x\in\mathbb R^n`$ 为状态， $`u\in\mathbb R^m`$ 为输入， $`y\in\mathbb R^p`$ 为输出。所谓“足以决定未来”，意味着给定 $`x(t_0)`$ 和 $`t\ge t_0`$ 上的输入 $`u(t)`$ ，模型不再需要 $`t_0`$ 以前的完整历史。这就是状态描述的马尔可夫性。状态不等于全部物理变量，也不等于全部传感器读数；它是模型在所选精度和边界内必须保留的记忆。

选择状态时，最常见的线索是储能元件和运动自由度。质量和转动惯量储存动能，因此位置与速度常成为机械状态；弹簧形变量对应势能；电感电流和电容电压描述电磁储能。对贯穿本章的机器人，可选组合状态

```math
x=
\begin{bmatrix}
x_b&y_b&\theta_b&
\omega_R&\omega_L&
i_R&i_L&
q_1&q_2&
\dot q_1&\dot q_2
\end{bmatrix}^{\mathsf T},
```

其中 $`(x_b,y_b,\theta_b)`$ 是底盘位姿， $`\omega_R,\omega_L`$ 是轮速， $`i_R,i_L`$ 是电机电流， $`q\in\mathbb R^2`$ 是机械臂关节角。若驱动器内部已有远快于机械动态的电流闭环，控制模型可以不保留 $`i_R,i_L`$ ；若要分析电源限制和电流瞬态，则不能删除它们。

工程上应同时检查四件事：

- **充分性**：删去某变量后，当前状态和输入是否仍能唯一确定导数；
- **独立性**：是否把受代数约束限制的变量重复列入状态；
- **可解释性与可估计性**：状态是否便于传感器重建和参数标定；
- **尺度与坐标**：米、弧度、安培等量纲差异是否会造成数值病态。

“状态越多越真实”是常见误区。未建模参数、缓慢漂移和传感器偏置可以扩充为状态，但每增加一个状态都需要动态假设，并可能降低可观测性。反之，状态过少会把真实记忆错误地压缩成瞬时关系，使模型在快速运动、强耦合或瞬态阶段失效。

## 14.2 从高阶微分方程到一阶状态模型

许多物理模型天然以高阶常微分方程出现。例如单自由度机械系统满足

```math
m\ddot q+c\dot q+kq=F,
```

其中 $`q`$ 为位移， $`m>0`$ 为质量， $`c\ge 0`$ 为阻尼系数， $`k\ge 0`$ 为刚度， $`F`$ 为外力。令 $`x_1=q`$ 、 $`x_2=\dot q`$ ，便得到一阶模型

```math
\dot x_1=x_2,\qquad
\dot x_2=-\frac{k}{m}x_1-\frac{c}{m}x_2+\frac{1}{m}F.
```

写成矩阵形式为

```math
\dot x=
\underbrace{\begin{bmatrix}
0&1\\-k/m&-c/m
\end{bmatrix}}_{A}x+
\underbrace{\begin{bmatrix}
0\\1/m
\end{bmatrix}}_{B}F.
```

一般地，标量 $`r`$ 阶方程 $`q^{(r)}=\phi(q,\dot q,\ldots,q^{(r-1)},u,t)`$ 可取

```math
x=\begin{bmatrix}q&\dot q&\cdots&q^{(r-1)}\end{bmatrix}^{\mathsf T},
```

从而形成链式的一阶系统。数值积分器、状态估计器和大多数现代控制算法均以一阶状态转移为基本接口，因此这一改写不是纯粹的记号变化，而是从物理方程进入计算算法的关键步骤。

并非所有方程都能直接化为显式的一阶常微分方程。含理想接触、闭链约束或电路代数关系的模型可能是微分—代数方程（differential-algebraic equation, DAE）

```math
F(\dot x,x,u,t)=0.
```

此时若强行求解 $`\dot x=f(x,u,t)`$ ，可能引入奇异矩阵或破坏约束。工程上可通过选择独立坐标、约束稳定化，或直接采用 DAE 求解器处理。高阶改一阶增加的是变量数量，而不是物理自由度；把同一自由度的位置、速度视为两个独立自由度也是错误的。

## 14.3 机械系统的状态模型

多自由度刚体机械系统通常由

```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f(\dot q)
=S(q)u+J_c(q)^{\mathsf T}\lambda+\tau_{\mathrm{ext}}
```

描述。这里 $`q\in\mathbb R^{n_q}`$ 为广义坐标， $`M(q)\in\mathbb R^{n_q\times n_q}`$ 为对称正定惯性矩阵， $`C\dot q`$ 表示科氏与离心项， $`g`$ 为重力项， $`\tau_f`$ 为摩擦力矩； $`u\in\mathbb R^m`$ 经分配矩阵 $`S\in\mathbb R^{n_q\times m}`$ 作用于系统， $`J_c^{\mathsf T}\lambda`$ 是约束力， $`\tau_{\mathrm{ext}}`$ 是其他外力矩。若没有显式约束且 $`M`$ 可逆，取 $`x=[q^{\mathsf T},v^{\mathsf T}]^{\mathsf T}`$ 、 $`v=\dot q`$ ，则

```math
\dot x=
\begin{bmatrix}
v\\
M(q)^{-1}\!\left[S(q)u-C(q,v)v-g(q)-\tau_f(v)+\tau_{\mathrm{ext}}\right]
\end{bmatrix}.
```

这个形式揭示了计算顺序：先由当前位形构造惯性与力项，再解线性方程 $`M(q)\dot v=b`$ 。实现时通常不显式计算 $`M^{-1}`$ ，而采用 Cholesky 分解或其他线性求解器，以提高稳定性并利用矩阵结构。

贯穿例中的底盘轮系和机械臂都属于机械系统，但约束性质不同。机械臂关节角通常可作为独立广义坐标；理想差速底盘则具有侧向无滑移约束，它限制速度方向，却不能只靠位形约束积分消除，属于非完整约束。轮胎打滑、齿轮间隙和库仑摩擦还会引入非光滑动态。若算法需要导数，常用平滑近似替代 $`\mathrm{sgn}(v)`$ ，但必须记录近似区间，避免把低速附近的数值便利误当成真实物理规律。

机械模型还应明确能量与符号约定。例如执行器机械功率应满足 $`P=u^{\mathsf T}S^{\mathsf T}\dot q`$ 。若坐标方向、减速比或力矩符号不一致，模型即使维度正确也可能产生“负阻尼”。能量平衡是检查机械状态方程的重要手段。

## 14.4 电机的状态模型

对永磁直流电机，忽略磁饱和后，电气与机械方程可写为

```math
L\dot i=V-Ri-k_e\omega,\qquad
J_m\dot\omega=k_t i-b_m\omega-\tau_\ell,
```

其中 $`i`$ 为电枢电流， $`V`$ 为端电压， $`L>0`$ 为电感， $`R>0`$ 为电阻， $`\omega`$ 为转子角速度， $`k_e`$ 为反电动势常数， $`k_t`$ 为力矩常数， $`J_m`$ 为转动惯量， $`b_m`$ 为黏性阻尼， $`\tau_\ell`$ 为负载力矩。取 $`x_m=[i,\omega]^{\mathsf T}`$ ，以 $`V`$ 和 $`\tau_\ell`$ 为输入，有

```math
\dot x_m=
\begin{bmatrix}
-R/L&-k_e/L\\
k_t/J_m&-b_m/J_m
\end{bmatrix}x_m+
\begin{bmatrix}
1/L&0\\
0&-1/J_m
\end{bmatrix}
\begin{bmatrix}V\\\tau_\ell\end{bmatrix}.
```

减速器传动比为 $`N`$ 时，必须统一电机侧与负载侧变量。若采用 $`\omega_m=N\omega_j`$ 的定义，则理想情况下关节输出力矩为 $`\tau_j=N\eta\tau_m`$ ，其中 $`\eta\in(0,1]`$ 为效率。折算惯量和摩擦时也要使用同一侧的坐标，否则容易重复乘除 $`N`$ 。

对机器人驱动轮，脉宽调制（pulse-width modulation, PWM）的占空比 $`d`$ 并不总能直接视为电压。理想平均模型可取 $`V=dV_{\mathrm{dc}}`$ ，但死区、母线压降、电流限幅和开关延迟会改变该关系。若电气时间常数 $`L/R`$ 远小于机械时间尺度，可近似令 $`\dot i=0`$ ，得到

```math
i\approx \frac{V-k_e\omega}{R},\qquad
\tau_m\approx \frac{k_t}{R}(V-k_e\omega).
```

这是时间尺度分离得到的降阶关系，并非在所有频率上成立。研究电流保护、快速力矩控制或电源波动时，必须恢复电流状态；只研究低带宽底盘运动时，降阶模型通常更经济。

## 14.5 移动机器人的状态模型

差速移动机器人在纯滚动、无侧滑假设下，可用平面位姿 $`p_b=[x_b,y_b,\theta_b]^{\mathsf T}`$ 描述。设轮半径为 $`r`$ ，左右轮角速度为 $`\omega_R,\omega_L`$ ，轮距为 $`b`$ ，则车体前向速度与偏航角速度为

```math
v=\frac{r}{2}(\omega_R+\omega_L),\qquad
\Omega=\frac{r}{b}(\omega_R-\omega_L),
```

运动学状态方程为

```math
\begin{bmatrix}
\dot x_b\\ \dot y_b\\ \dot\theta_b
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta_b&0\\
\sin\theta_b&0\\
0&1
\end{bmatrix}
\begin{bmatrix}v\\\Omega\end{bmatrix}.
```

这是一个非线性、多输入多输出（multi-input multi-output, MIMO）模型。它的非线性来自 $`\sin\theta_b`$ 和 $`\cos\theta_b`$ ，而 MIMO 只表示输入或输出不止一个；“非线性”和“MIMO”是两个独立分类，不能混为一谈。

如果轮速不能瞬时跟随命令，应把轮速加入状态。例如采用一阶驱动近似

```math
\dot\omega_R=-\frac{1}{\tau_R}\omega_R+\frac{k_R}{\tau_R}u_R,\qquad
\dot\omega_L=-\frac{1}{\tau_L}\omega_L+\frac{k_L}{\tau_L}u_L,
```

其中 $`u_R,u_L`$ 是驱动命令， $`\tau_R,\tau_L>0`$ 是时间常数。这样，底盘模型从纯运动学模型变为含执行器动态的状态模型。进一步保留电流、轮胎纵向力和车体惯量，则可建立动力学模型。模型层级应由任务速度、地面条件和控制带宽决定。

无侧滑假设是该模型最重要的边界。急转弯、松软地面、轮径误差或载荷变化都会使里程计累积偏差。规划模型可以保留理想非完整约束以降低计算量，而估计模型应通过过程噪声或滑移状态表达不确定性。姿态角还具有周期性： $`\theta_b`$ 与 $`\theta_b+2\pi`$ 表示同一朝向，直接相减可能产生虚假的大误差，应使用角度归一化或群上的误差表示。

## 14.6 机械臂的非线性 MIMO 状态模型

对贯穿例中的两关节机械臂，动力学为

```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f(\dot q)=\tau,
```

其中 $`q,\dot q,\tau\in\mathbb R^2`$ ， $`M(q)\in\mathbb R^{2\times2}`$ 。取

```math
x_a=\begin{bmatrix}q\\\dot q\end{bmatrix}\in\mathbb R^4,\qquad
u_a=\tau\in\mathbb R^2,
```

则

```math
\dot x_a=
f_a(x_a,u_a)=
\begin{bmatrix}
\dot q\\
M(q)^{-1}\!\left[u_a-C(q,\dot q)\dot q-g(q)-\tau_f(\dot q)\right]
\end{bmatrix}.
```

每个关节力矩都可能影响全部关节加速度，因为 $`M(q)`$ 通常不是对角矩阵，科氏项也会产生速度相关耦合。因此，机械臂不能被普遍视为若干互不相关的单输入单输出系统。高减速比和低速运行时，独立关节近似有时有效，但它是局部工程近似，而不是机械结构的基本性质。

若底盘和机械臂同时运动，可定义联合状态

```math
x=\begin{bmatrix}p_b^{\mathsf T}&\omega_R&\omega_L&q^{\mathsf T}&\dot q^{\mathsf T}\end{bmatrix}^{\mathsf T}.
```

轻型机械臂安装在重型底盘上时，常忽略机械臂运动对底盘的反作用；当臂展较大、加速度较高或底盘较轻时，该近似会破坏动量和姿态预测，需要采用完整的浮动基或移动操作器耦合动力学。接触抓取还会增加末端约束力 $`J(q)^{\mathsf T}F_c`$ ，并可能触发自由运动与接触运动之间的模式切换。

状态空间描述天然适合这类非线性 MIMO 系统：同一个 $`f(x,u)`$ 可供仿真器积分、供非线性优化器预测，也可在指定点求导后交给线性控制器。状态空间并不保证模型准确；它只提供了组织内部记忆、输入和输出的统一形式。

## 14.7 输出方程与传感器模型

状态是系统内部描述，输出则是传感器或任务真正提供的信息。一般输出模型写为

```math
y=h(x,u,t)+v,
```

其中 $`y\in\mathbb R^p`$ ， $`v`$ 为测量误差。若模型线性，则

```math
y=Cx+Du+v,
```

其中 $`C\in\mathbb R^{p\times n}`$ 选择或组合状态， $`D\in\mathbb R^{p\times m}`$ 描述输入到输出的直接通道。 $`D\ne0`$ 并不意味着状态被绕过，而表示在模型时间尺度上，输入可即时影响测量。

贯穿例中，编码器可测关节角和轮角，陀螺仪测偏航角速度，相机测地标在图像中的投影。典型模型包括

```math
y_{\mathrm{enc}}=q+b_q+v_q,
```

```math
y_{\mathrm{gyro}}=\Omega+b_g+v_g,
```

```math
z_j=\pi\!\left(T_{CB}(x)P_j\right)+v_j.
```

其中 $`b_q,b_g`$ 是偏置， $`P_j`$ 是三维地标， $`T_{CB}(x)`$ 是由机器人状态决定的坐标变换， $`\pi(\cdot)`$ 是相机投影函数。若偏置随时间缓慢漂移，可令 $`\dot b_g=w_b`$ ，将其作为扩展状态；若始终把偏置并入白噪声，估计器会产生系统性误差。

传感器模型还应包括采样时刻、延迟、量化、饱和、视场和失效条件。例如编码器输出可能是离散计数，相机只在地标可见且曝光有效时产生观测。高斯加性噪声便于推导，但不能表达离群点和遮挡。输出方程的工程意义不仅是“从状态算测量”，还在于明确哪些状态可能被数据区分；仅把变量列入状态，并不意味着它们可被传感器观测。

<a id="ch14-sec8"></a>
## 14.8 从非线性模型到工作点模型

非线性模型精确表达了状态依赖关系，但许多分析和控制方法需要局部线性模型。工作点（operating point）是选定的名义状态与输入 $`(\bar x,\bar u)`$ 。若系统为自治或定常系统，平衡点（equilibrium point）还要求

```math
f(\bar x,\bar u)=0.
```

二者不能等同：沿直线匀速行驶的移动机器人具有随时间变化的位置，因此其名义运动是工作轨迹而不是固定平衡点；机械臂静止保持某姿态时，若 $`\bar u=g(\bar q)`$ ，则 $`(\bar q,\dot{\bar q}=0)`$ 可以是平衡点。

定义小扰动

```math
\delta x=x-\bar x,\qquad
\delta u=u-\bar u,\qquad
\delta y=y-\bar y,
```

其中 $`\bar y=h(\bar x,\bar u)`$ 。在工作点附近忽略二阶及更高阶项，可得

```math
\delta\dot x\approx A\delta x+B\delta u,\qquad
\delta y\approx C\delta x+D\delta u.
```

这里的线性模型描述的是偏差动态，而不是原变量动态。若直接把 $`\delta x`$ 当作 $`x`$ ，却忘记补回重力平衡输入或名义轨迹，控制器会产生稳态偏差甚至错误方向的作用。

局部模型的有效范围取决于非线性曲率、输入幅度和时间跨度。机器人转角很小、关节运动局限于某姿态附近时，单一工作点模型可能足够；大范围机动则需要增益调度、多个局部模型、轨迹线性化或直接使用非线性模型。线性化不是断言原系统“本质上线性”，而是把可接受范围内的变化分成一阶主效应与高阶余项。

<a id="ch14-sec9"></a>
## 14.9 Jacobian 线性化的工程使用

对可微非线性系统

```math
\dot x=f(x,u,t),\qquad y=h(x,u,t),
```

在名义点或名义轨迹 $`(\bar x(t),\bar u(t))`$ 上的 Jacobian（雅可比矩阵）为

```math
A(t)=\left.\frac{\partial f}{\partial x}\right|_{\bar x,\bar u,t},\qquad
B(t)=\left.\frac{\partial f}{\partial u}\right|_{\bar x,\bar u,t},
```

```math
C(t)=\left.\frac{\partial h}{\partial x}\right|_{\bar x,\bar u,t},\qquad
D(t)=\left.\frac{\partial h}{\partial u}\right|_{\bar x,\bar u,t}.
```

其维度分别是 $`A\in\mathbb R^{n\times n}`$ 、 $`B\in\mathbb R^{n\times m}`$ 、 $`C\in\mathbb R^{p\times n}`$ 、 $`D\in\mathbb R^{p\times m}`$ 。若名义轨迹满足 $`\dot{\bar x}=f(\bar x,\bar u,t)`$ ，偏差模型没有额外常数项；否则还会出现残差 $`f(\bar x,\bar u,t)-\dot{\bar x}`$ 。

以差速底盘的输入 $`[v,\Omega]^{\mathsf T}`$ 为例，

```math
f=
\begin{bmatrix}
v\cos\theta_b\\v\sin\theta_b\\\Omega
\end{bmatrix},
```

因而

```math
A=
\begin{bmatrix}
0&0&-\bar v\sin\bar\theta_b\\
0&0& \bar v\cos\bar\theta_b\\
0&0&0
\end{bmatrix},\qquad
B=
\begin{bmatrix}
\cos\bar\theta_b&0\\
\sin\bar\theta_b&0\\
0&1
\end{bmatrix}.
```

该结果清楚地表明：朝向误差会以与名义速度 $`\bar v`$ 成比例的方式转化为横向位置误差。若 $`\bar v=0`$ ，某些局部耦合会消失，这可能改变局部可控性或可观测性分析的结果。

工程实现可采用手工推导、符号微分、自动微分或有限差分。有限差分近似

```math
\frac{\partial f}{\partial x_i}
\approx
\frac{f(x+\epsilon e_i,u)-f(x-\epsilon e_i,u)}{2\epsilon}
```

简单但对步长敏感： $`\epsilon`$ 太大产生截断误差，太小则放大浮点舍入误差。无论采用何种方法，都应通过维度检查、随机方向导数测试以及与非线性模型短时扰动响应对比来验证 Jacobian。饱和、死区、库仑摩擦和接触切换点不可微，不能在这些点机械套用普通 Jacobian。

<a id="ch14-sec10"></a>
## 14.10 LTI 与 LTV 模型

线性时不变（linear time-invariant, LTI）模型为

```math
\dot x=Ax+Bu,\qquad y=Cx+Du,
```

其中 $`A,B,C,D`$ 不随时间变化。它适合固定工作点附近的机械臂姿态保持、恒定载荷下的电机速度调节等任务。LTI 模型允许使用特征值、传递函数、频率响应、可控性矩阵和可观测性矩阵等成熟工具，其计算和验证成本也较低。

线性时变（linear time-varying, LTV）模型为

```math
\delta\dot x=A(t)\delta x+B(t)\delta u,\qquad
\delta y=C(t)\delta x+D(t)\delta u.
```

它常由非线性系统沿名义轨迹线性化得到。例如移动操作机器人一边转弯一边伸臂时，底盘朝向、关节位形和惯性耦合不断变化，对应的 Jacobian 也随时间变化。LTV 不等于非线性：对给定的 $`A(t)`$ 和 $`B(t)`$ ，叠加原理仍对偏差系统成立；区别只在于系统系数随时间变化。

实际系统参数随温度、载荷或电池电压缓慢变化时，也可使用分段 LTI 或增益调度模型。但“变化很慢”需要相对于闭环带宽和预测时域判断。把快速变化的系数冻结为常数，会低估耦合和相位变化；反之，在没有必要时使用 LTV 会增加在线求导、矩阵更新和验证负担。模型类别应服从算法所需精度，而不是追求形式上的复杂。

<a id="ch14-sec11"></a>
## 14.11 连续模型到离散模型

数字计算机在离散时刻 $`t_k`$ 读取传感器并更新命令，因此需要离散状态模型

```math
x_{k+1}=f_d(x_k,u_k,k),\qquad
y_k=h_d(x_k,u_k,k).
```

若采样周期为 $`T_s=t_{k+1}-t_k`$ ，连续非线性系统在区间内的精确离散映射是

```math
x_{k+1}
=
x_k+
\int_{t_k}^{t_{k+1}}
f(x(t),u(t),t)\,dt.
```

该表达式虽然精确，却通常不能闭式求值，因为积分中的 $`x(t)`$ 本身由微分方程决定。离散化的实质是确定输入在采样间隔内如何变化，并求解或近似该流映射。

对 LTI 系统 $`\dot x=Ax+Bu`$ ，若区间内输入按给定规则保持，则离散模型可写为

```math
x_{k+1}=A_dx_k+B_du_k,\qquad
y_k=C_dx_k+D_du_k.
```

这里 $`A_d`$ 是无量纲状态转移矩阵， $`B_d`$ 的量纲包含时间积分效应，不能简单地令 $`A_d=A`$ 、 $`B_d=B`$ 。连续极点与离散极点也位于不同平面；在精确采样下，连续特征值 $`\lambda_i`$ 对应离散特征值 $`z_i=e^{\lambda_iT_s}`$ 。

采样周期不是纯软件参数。它必须足以解析关注的最快动态，同时考虑传感器曝光、通信延迟、计算时间和执行器更新率。过大的 $`T_s`$ 会造成混叠、预测偏差和相位滞后；过小的 $`T_s`$ 则可能放大量化噪声、增加计算负担，并使矩阵差分变得数值敏感。Chapter 33 将进一步讨论数字实现中的这些约束。

<a id="ch14-sec12"></a>
## 14.12 零阶保持

零阶保持（zero-order hold, ZOH）假设在每个采样区间内输入保持常值：

```math
u(t)=u_k,\qquad t\in[t_k,t_{k+1}).
```

这与许多数字执行器的实际行为一致：控制器在 $`t_k`$ 写入一次命令，驱动器在下一次更新前持续使用该命令。对 LTI 系统，ZOH 下的精确离散化为

```math
A_d=e^{AT_s},\qquad
B_d=\int_0^{T_s}e^{A\tau}B\,d\tau,
```

且通常 $`C_d=C`$ 、 $`D_d=D`$ 。当 $`A`$ 可逆时可写成

```math
B_d=A^{-1}(A_d-I)B,
```

但工程实现不应依赖 $`A`$ 可逆。更稳健的计算方法是使用块矩阵指数：

```math
\exp\!\left(
\begin{bmatrix}
A&B\\
0&0
\end{bmatrix}T_s
\right)
=
\begin{bmatrix}
A_d&B_d\\
0&I
\end{bmatrix}.
```

对贯穿例，底盘速度命令常由控制周期 ZOH 保持，而底层电流环可能以更高频率更新。此时对上层模型而言，轮速或力矩命令近似分段常值；对电机模型而言，PWM 开关并非真正的常值电压，而是需要平均化或更细时间尺度的开关模型。这说明保持假设必须对应具体接口，不能脱离执行器层级。

ZOH 也不是唯一选择。轨迹发生器可能在两个采样点间进行线性插值，对应一阶保持；某些驱动器内部带有平滑器或速率限制器，对外表现为额外动态。如果模型假设 ZOH，而硬件实际使用插值和限幅，预测误差会集中出现在快速命令变化阶段。

<a id="ch14-sec13"></a>
## 14.13 数值离散化

非线性系统通常通过数值积分得到离散映射。最简单的前向欧拉法为

```math
x_{k+1}=x_k+T_s f(x_k,u_k,t_k),
```

其局部截断误差为 $`O(T_s^2)`$ ，固定时间区间上的全局误差为 $`O(T_s)`$ 。对变化缓慢、采样足够快的控制模型，它计算便宜且 Jacobian 简单；但对刚性电机动态、强阻尼或较大步长，它可能产生数值不稳定，即使真实连续系统本身稳定。

经典四阶 Runge–Kutta 方法在 ZOH 输入下为

```math
\begin{aligned}
k_1&=f(x_k,u_k,t_k),\\
k_2&=f(x_k+\tfrac{T_s}{2}k_1,u_k,t_k+\tfrac{T_s}{2}),\\
k_3&=f(x_k+\tfrac{T_s}{2}k_2,u_k,t_k+\tfrac{T_s}{2}),\\
k_4&=f(x_k+T_sk_3,u_k,t_k+T_s),\\
x_{k+1}&=x_k+\frac{T_s}{6}(k_1+2k_2+2k_3+k_4).
\end{aligned}
```

它具有四阶全局精度，但每一步需要四次动力学求值。隐式欧拉法

```math
x_{k+1}=x_k+T_s f(x_{k+1},u_k,t_{k+1})
```

需要求解非线性方程，却对刚性系统更稳定。长期机械仿真还可使用辛积分方法，以更好地保持哈密顿结构和能量性质。

必须区分三种概念：连续对象的真实采样、控制器内部的预测离散化，以及高保真仿真的积分步长。控制周期可以是 $`10\ \mathrm{ms}`$ ，仿真器却可能在每个控制周期内执行十个 $`1\ \mathrm{ms}`$ 子步。若把粗糙的欧拉预测模型同时当作“真值仿真器”，闭环测试会人为掩盖离散误差。接触事件、饱和切换和角度归一化还需要事件检测或投影处理，单纯提高积分阶数并不能修复错误的混杂逻辑。

<a id="ch14-sec14"></a>
## 14.14 控制模型、估计模型和规划模型为什么可以不同

同一机器人可以同时拥有多个正确但用途不同的模型。所谓正确，不是逐项相同，而是在指定任务、时间尺度和误差容限内保留了必要机制。统一使用最高保真模型看似稳妥，实际上可能使优化无法实时完成、估计器无法观测全部状态，或控制器对不可靠参数过度敏感。

对贯穿例，可以采用如下分工：

- **控制模型**：保留轮速、底盘位姿和机械臂关节动态，忽略 PWM 开关与结构柔性；强调输入到受控变量的短时响应和在线求导效率。
- **估计模型**：加入陀螺仪偏置、轮径误差或缓慢滑移状态，并配置过程噪声；强调状态转移与传感器输出的一致性。
- **规划模型**：把底盘简化为受速度、曲率和碰撞约束的运动学系统，把机械臂动力学压缩为速度、加速度或力矩边界；强调长时域搜索的可计算性。
- **验证模型**：恢复电流限制、摩擦、延迟、饱和、载荷变化和接触，用于暴露算法对非理想因素的敏感性。

这些模型之间必须建立明确映射。例如规划状态 $`x_p=[x_b,y_b,\theta_b,q^{\mathsf T}]^{\mathsf T}`$ 可由完整状态投影得到

```math
x_p=P(x),
```

而规划命令 $`u_p=[v,\Omega,\dot q_d^{\mathsf T}]^{\mathsf T}`$ 需通过轨迹跟踪器和执行器模型转换为电机电压或关节力矩。若抽象模型给出的命令在完整系统中不可实现，问题不在于“低层控制不够强”，而在于抽象接口缺少加速度、力矩、摩擦或延迟约束。

模型不同不等于模型互相矛盾。应使用一致的坐标、符号、单位、时间戳和参数来源，并通过升阶验证检验简化模型。最危险的误区是让不同模块对同名变量采用不同语义，例如规划器中的 $`v`$ 表示瞬时车体速度，而驱动接口中的 $`v`$ 实际表示归一化占空比。

<a id="ch14-sec15"></a>
## 14.15 模型作为模块之间的统一接口

自主系统中的模型不只是方程集合，也是模块间的契约。一个完整的计算模型至少应明确

```math
\mathcal M=
(\mathcal X,\mathcal U,\mathcal Y,
f_d,h_d,
\mathcal C,
T_s,
\Theta),
```

其中 $`\mathcal X,\mathcal U,\mathcal Y`$ 分别是状态、输入和输出空间， $`f_d`$ 是离散状态转移， $`h_d`$ 是输出函数， $`\mathcal C`$ 表示状态与输入约束， $`T_s`$ 是采样周期， $`\Theta`$ 是参数及其有效范围。对随机模型，还应给出过程噪声与测量噪声接口；对混杂模型，还需定义模式、守卫条件和重置映射。

同一个接口可支持不同模块：

```math
x_{k+1}=f_d(x_k,u_k)
```

供仿真器推进状态，估计器用它生成先验，模型预测控制器用它展开预测，规划器用它检查候选动作的可达性；而

```math
y_k=h_d(x_k,u_k)
```

把内部状态连接到编码器、惯性测量单元和相机观测。若同时提供 Jacobian

```math
A_k=\frac{\partial f_d}{\partial x},\quad
B_k=\frac{\partial f_d}{\partial u},\quad
C_k=\frac{\partial h_d}{\partial x},
```

则线性控制、局部优化和状态估计可共享同一模型实现，减少手工推导不一致。

真正可复用的模型还必须约定坐标系、角度方向、单位、状态排列、时间语义和异常行为。输入是在区间起点生效还是带一个周期延迟，位姿表示的是车体中心还是后轴中心，关节角是电机侧还是输出侧，这些问题往往比公式本身更容易导致系统故障。接口版本变化时，应同时更新仿真、估计、控制和日志工具，而不是依赖调用者猜测。

最终，统一接口并不要求所有模块使用同一复杂度，而是要求模型之间可以投影、提升、线性化、离散化和验证。物理模型给出守恒定律与约束，计算模型给出可执行的状态转移，模块接口则保证这些转移在整个自主系统中具有一致含义。这条链路将为后续章节中的系统分析、状态估计、轨迹优化和反馈控制提供共同基础。

## 本章小结

本章完成了从物理规律到计算接口的转换主线。首先依据系统记忆和储能机制选择状态，将高阶微分方程改写为一阶状态模型；随后分别建立了机械系统、直流电机、差速底盘和两关节机械臂的非线性 MIMO 模型，并通过输出方程把内部状态连接到编码器、惯性传感器和相机。

在计算层面，我们区分了工作点与平衡点，利用 Jacobian 得到局部偏差模型，并说明了 LTI 与 LTV 模型各自适用的范围。连续模型通过采样和保持机制转化为离散状态转移；对 LTI 系统可在 ZOH 下精确离散，对非线性系统则需选择欧拉、Runge–Kutta、隐式或结构保持积分方法。离散化方法、控制周期和仿真步长属于不同设计层次，不能相互替代。

最后，同一物理对象可以拥有不同的控制模型、估计模型、规划模型和验证模型。它们不必复杂度相同，但必须共享清晰的坐标、单位、时间和约束语义，并能通过投影与升阶验证相互连接。下一章将在这些计算模型之上进一步讨论模型性质与系统行为，为后续的估计、规划和控制算法建立可分析的基础。
