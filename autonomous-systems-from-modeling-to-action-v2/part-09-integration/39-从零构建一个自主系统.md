## 39.1 明确任务

构建自主系统的第一步不是选择算法，而是把任务写成可判断成败的闭环问题。以仓储移动操作机器人为例，任务可以表述为：机器人从待机区出发，在有人、货架和其他车辆共存的仓库中定位目标料箱，移动至可操作区域，利用六轴机械臂完成抓取，再把物品运送至指定工位。这里必须同时明确初始条件、目标集合、允许动作、环境变化、完成时限与失败条件，而不能只写“实现自主抓取”。

可将任务形式化为带约束的性能优化问题：
```math
\min_{\pi}\;J(\pi)=\mathbb{E}\!\left[
w_tT+w_eE+w_rR+w_f\mathbf{1}_{\mathrm{fail}}
\right],
\qquad
\text{s.t.}\quad x_k\in\mathcal X,\;u_k\in\mathcal U .
```
其中 $`\pi`$ 是从观测历史到动作的策略， $`T`$ 为完成时间， $`E`$ 为能耗， $`R`$ 为碰撞风险或风险度量， $`\mathbf{1}_{\mathrm{fail}}`$ 为失败指示量， $`x_k\in\mathbb R^n`$ 和 $`u_k\in\mathbb R^m`$ 分别是离散时刻的状态与输入。权重 $`w_t,w_e,w_r,w_f`$ 只有在各项经过尺度归一化并反映业务优先级时才有意义；安全约束通常应作为硬约束，而非仅靠很大的惩罚权重表达。

工程上还要建立验收指标，例如导航到位误差不超过 $`3\,\mathrm{cm}`$ 、末端抓取位姿误差不超过 $`5\,\mathrm{mm}`$ 和 $`2^\circ`$ 、额定负载下单次任务成功率达到规定阈值。指标应附带测试分布：地面摩擦、照明、货物质量和人员流量的范围都要说明。若任务分布未定义，所谓成功率无法复现；若需求彼此冲突，则应先确定优先级和可行域，而不是期待后续控制器自动消解矛盾。

## 39.2 定义系统边界

系统边界规定哪些对象由系统建模和控制，哪些对象作为环境、扰动或外部服务。对仓储机器人，可把移动底盘、六轴机械臂、夹爪、电机驱动器、相机、IMU、计算机和机载网络纳入本体；仓库地图、货架、地面、人员、无线调度系统与充电设施属于外部环境。边界还包括责任边界：任务调度器给出“搬运哪个料箱”，机器人负责生成并执行无碰路径，而紧急停车回路应能独立于高层软件切断危险运动。

统一接口可写成受扰动、带观测的状态空间模型：
```math
x_{k+1}=f(x_k,u_k,w_k),\qquad
y_k=h(x_k,v_k),\qquad
z_k=g(x_k,e_k),
```
其中 $`x_k\in\mathbb R^n`$ 是边界内状态， $`u_k\in\mathbb R^m`$ 是可控输入， $`w_k`$ 是过程扰动， $`y_k\in\mathbb R^p`$ 是机载传感器观测， $`v_k`$ 是测量噪声； $`e_k`$ 表示环境状态， $`z_k`$ 则是机器人与环境交互产生的碰撞距离、接触力或任务事件。若环境自身具有重要动态，例如其他移动机器人按可预测轨迹运动，就应把相应变量加入联合状态，而不能把所有变化都压缩为白噪声。

边界决定故障归属和验证方法。定位服务器中断、网络延迟、夹爪掉电、地面湿滑分别属于外部服务异常、通信异常、内部硬件故障和环境扰动，需要不同的降级策略。系统边界不是永久不变的：原型阶段可以假设仓库地图已知，部署阶段则可能必须纳入地图维护模块。任何边界简化都应附带适用假设；尤其不能在设计时假定人员可完全预测，却在验收时要求机器人处理任意突发横穿。

## 39.3 建立坐标系

坐标系是几何量的类型系统。仓储移动操作机器人至少需要世界坐标系 $`\{W\}`$ 、底盘坐标系 $`\{B\}`$ 、机械臂基座坐标系 $`\{A\}`$ 、各关节连杆坐标系 $`\{L_i\}`$ 、末端工具坐标系 $`\{E\}`$ 、相机坐标系 $`\{C\}`$ 和 IMU 坐标系 $`\{I\}`$ 。应明确轴方向、右手约定、长度单位、角度单位以及时间戳语义。例如 $`\{W\}`$ 可固定在仓库地图原点， $`\{B\}`$ 的 $`x`$ 轴指向车头， $`\{E\}`$ 固定在夹爪抓取中心。

刚体变换用齐次矩阵表示：
```math
{}^{W}T_E=
{}^{W}T_B\,
{}^{B}T_A\,
{}^{A}T_E(q),\qquad
{}^{X}T_Y=
\begin{bmatrix}
{}^{X}R_Y & {}^{X}p_Y\\
0&1
\end{bmatrix}\in SE(3).
```
这里 $`{}^{X}R_Y\in SO(3)`$ 和 $`{}^{X}p_Y\in\mathbb R^3`$ 分别表示坐标系 $`\{Y\}`$ 相对 $`\{X\}`$ 的姿态和平移， $`q\in\mathbb R^6`$ 是六轴机械臂关节角。记号 $`{}^{X}T_Y`$ 必须始终解释为“把 $`Y`$ 系坐标变换到 $`X`$ 系”，否则矩阵乘法虽然维度正确，也可能产生方向相反的隐蔽错误。速度和力还需通过伴随矩阵变换，不能只旋转或平移其中一部分。

工程实现中应维护一棵有向坐标变换树，并区分静态标定变换与动态估计变换。相机外参 $`{}^{B}T_C`$ 、IMU 安装变换 $`{}^{B}T_I`$ 属于静态量，底盘位姿 $`{}^{W}T_B(t)`$ 和末端位姿 $`{}^{A}T_E(q(t))`$ 属于时变量。该表示假设物体可近似为刚体；轮胎形变、机械臂柔性和相机支架振动若不可忽略，就需要增加柔性状态或把它们纳入不确定性。坐标正确而时间不对同样会失败，因此每个变换还必须带时间戳和有效区间。

<a id="ch39-sec4"></a>
## 39.4 选择状态

状态是使未来在给定当前输入后与更早历史条件独立的最小信息，即满足马尔可夫性质的变量集合。仓储机器人可采用组合状态
```math
x=
\begin{bmatrix}
p_B^\top&\theta_B&v_B^\top&q^\top&\dot q^\top&i^\top&b_g^\top&b_a^\top
\end{bmatrix}^{\top},
```
其中 $`p_B\in\mathbb R^2`$ 、 $`\theta_B\in\mathbb R`$ 是平面底盘位姿， $`v_B\in\mathbb R^3`$ 可包含纵向、横向和角速度， $`q,\dot q\in\mathbb R^6`$ 是机械臂关节位置与速度， $`i\in\mathbb R^{n_m}`$ 是所建模电机的电流， $`b_g,b_a\in\mathbb R^3`$ 是 IMU 陀螺仪和加速度计偏置。是否纳入每一项取决于目标时间尺度与可观测性。

状态、输入、观测和参数必须区分。轮端电压是输入，编码器读数是观测，轮半径通常是参数；若轮半径因载荷或磨损缓慢变化并需要在线估计，它也可以扩展为状态。对规划器，常用的简化状态可能只有 $`x_p=[p_x,p_y,\theta]^\top`$ ；对关节力矩控制，必须保留 $`q,\dot q`$ ；对视觉抓取，还要维护目标物体位姿及其协方差。不同模块可以使用不同状态，但接口中必须给出投影关系与不确定度，不能把低维规划状态误认为完整物理状态。

增加状态会提高表达能力，也会增加辨识、估计和计算负担。一个状态如果既不影响预测，也不影响约束或代价，就不应保留；反之，若忽略的变量导致明显的历史相关性，如电机温度导致持续限流，就应把温度或等效能力状态纳入模型。状态选择通常假设选定采样周期内未建模快动态已经衰减。若该时间尺度分离不成立，简化模型只能用于较慢层级，不能直接用于高速闭环。

## 39.5 建立几何模型

几何模型描述机器人各刚体形状、关节连接和运动学约束，是碰撞检测、可达性分析与任务空间控制的基础。六轴机械臂的正运动学可写为
```math
{}^{A}T_E(q)=\prod_{i=1}^{6}{}^{L_{i-1}}T_{L_i}(q_i),
\qquad
\xi_E=J(q)\dot q,
```
其中 $`q\in\mathbb R^6`$ ， $`J(q)\in\mathbb R^{6\times6}`$ 是几何雅可比矩阵， $`\xi_E=[v_E^\top,\omega_E^\top]^\top\in\mathbb R^6`$ 为末端线速度与角速度。底盘若采用差速结构，则理想无侧滑约束使平面速度由左右轮角速度决定；全向轮底盘则具有不同的速度映射和摩擦假设。

碰撞几何不必与可视化网格同样精细。底盘可用若干凸多边形或圆柱近似，机械臂连杆可用胶囊体，货架和料箱可用有向包围盒。对机器人几何体 $`\mathcal R(q)`$ 与障碍物集合 $`\mathcal O`$ ，安全约束可表示为
```math
d(\mathcal R(q),\mathcal O)\ge d_{\mathrm{safe}},
```
其中 $`d(\cdot,\cdot)`$ 是有符号距离， $`d_{\mathrm{safe}}>0`$ 包含定位误差、制动距离和模型偏差。若距离由离散点云近似，点云稀疏处可能高估间隙，因此安全裕度必须与传感器分辨率及估计协方差相关联。

几何模型还要经过尺寸测量、关节零位标定和手眼标定验证。工程上应分别测试正运动学闭环误差、逆运动学多解、关节极限和奇异位形。刚体运动学假设适用于低速、结构刚度充分的操作；搬运重物时若连杆挠曲达到毫米级，单纯提高视觉或控制精度无法消除系统误差。此时应修正负载相关几何模型，或把柔性变形作为状态估计。

## 39.6 建立动力学模型

动力学模型描述力和力矩如何产生加速度。六轴机械臂的经典刚体模型为
```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f(\dot q)=\tau+J^\top(q)F_{\mathrm{ext}},
```
其中 $`M(q)\in\mathbb R^{6\times6}`$ 是正定惯性矩阵， $`C(q,\dot q)\dot q\in\mathbb R^6`$ 为科氏与离心项， $`g(q)\in\mathbb R^6`$ 为重力项， $`\tau_f`$ 是摩擦力矩， $`\tau\in\mathbb R^6`$ 是关节驱动力矩， $`F_{\mathrm{ext}}\in\mathbb R^6`$ 是末端外力旋量。该模型连接几何、控制与执行器，是前馈补偿和接触控制的核心接口。

移动底盘可按用途选择复杂度。低速仓储导航常采用
```math
\dot p_x=v\cos\theta,\qquad
\dot p_y=v\sin\theta,\qquad
\dot\theta=\omega,
```
其中 $`(p_x,p_y,\theta)`$ 是底盘位姿， $`v,\omega`$ 是纵向和角速度；需要分析制动、打滑或载荷转移时，则要加入质量 $`m`$ 、转动惯量 $`I_z`$ 、轮胎纵横向力和电机动态。模型越精细并不必然越好：若参数无法测得或在线计算预算不足，复杂模型可能比经过验证的低阶模型更差。

建立模型后应进行开环检查，包括单位一致性、平衡点、能量变化、可控性和数值稳定性。对连续模型 $`\dot x=f(x,u)`$ ，在工作点 $`(x^\ast,u^\ast)`$ 附近可线性化为 $`\delta\dot x=A\delta x+B\delta u`$ ，其中 $`A\in\mathbb R^{n\times n}`$ 、 $`B\in\mathbb R^{n\times m}`$ 。线性模型只在局部扰动较小、接触模式固定时成立；抓取碰撞、轮胎由粘着转为滑动等混杂事件需要切换模型或互补约束，不能用单一平滑方程覆盖所有工况。

<a id="ch39-sec7"></a>
## 39.7 建立执行器模型

执行器模型把控制器的抽象命令连接到真实的电压、电流、转矩和运动。直流或永磁同步电机在简化坐标下可写成
```math
L\dot i=V-Ri-k_e\omega_m,\qquad
\tau_m=k_t i,\qquad
J_m\dot\omega_m=\tau_m-\tau_L-b\omega_m ,
```
其中 $`i,V`$ 为电流和电压， $`L,R`$ 为电感和电阻， $`k_e,k_t`$ 为反电动势与转矩常数， $`\omega_m`$ 、 $`J_m`$ 是电机角速度和惯量， $`\tau_L`$ 是等效负载转矩。经减速比 $`N`$ 和效率 $`\eta`$ 后，关节输出近似为 $`\tau_j=\eta N\tau_m`$ ，同时转速受到 $`\omega_j=\omega_m/N`$ 限制。

实际驱动器还包含电流环、速度环、死区、饱和、量化、通信延迟、温升限流和抱闸逻辑。可用约束
```math
|\tau_j|\le\tau_{\max}(\omega_j,T_m,V_b),\qquad
|\dot\tau_j|\le r_{\tau}
```
表示转矩能力随关节速度、电机温度 $`T_m`$ 和母线电压 $`V_b`$ 变化，并限制转矩变化率 $`r_\tau`$ 。底盘轮电机在低电量时无法保持额定加速度；机械臂抓取重箱时若忽略持续转矩与峰值转矩的区别，会在轨迹中途触发热保护。

工程上应通过台架试验获得命令到输出的增益、带宽、延迟和饱和曲线，并明确驱动器内部闭环是否可配置。若厂商接口只接受速度目标，高层就不能假设自己直接控制轮端转矩。上述电机模型假设磁路近似线性且参数缓慢变化；强饱和、齿隙、柔性传动或静摩擦主导时，需要分段模型或实验辨识。执行器模型的价值不是追求电磁细节齐全，而是确保控制命令在硬件能力内可实现。

<a id="ch39-sec8"></a>
## 39.8 选择控制模型

控制模型是为在线决策保留的动力学近似，它通常比物理模型低阶，但必须保留与目标和约束直接相关的机制。对仓储底盘，局部轨迹跟踪可使用离散运动学模型
```math
x_{k+1}=
\begin{bmatrix}
p_{x,k}+\Delta t\,v_k\cos\theta_k\\
p_{y,k}+\Delta t\,v_k\sin\theta_k\\
\theta_k+\Delta t\,\omega_k
\end{bmatrix},
```
其中 $`x_k\in\mathbb R^3`$ ， $`u_k=[v_k,\omega_k]^\top\in\mathbb R^2`$ ， $`\Delta t`$ 是控制采样周期。机械臂在中低速自由空间运动时可采用关节双积分模型；高速或重载操作则应保留惯性、重力和转矩约束。

模型选择应由预测时域、计算资源和误差容忍度共同决定。上层任务规划可以使用离散模式状态，中层路径规划使用几何与运动学模型，下层控制使用局部线性化动力学。对模型
```math
x_{k+1}=f_c(x_k,u_k)+w_k,
```
过程项 $`w_k`$ 不只是随机噪声，也代表地面不平、轮滑和模型降阶误差。若假设 $`w_k`$ 有界，则可设计鲁棒约束；若用概率分布描述，则必须验证分布假设，而不能把未知误差默认设成独立高斯量。

一个实用判据是：控制模型应在目标工作域内正确预测输入对受控量的主要方向、幅值和延迟。底盘低速无滑模型不适合湿滑地面急转弯，刚性关节模型不适合长柔性臂高速摆动，平面模型也不适合有坡度和台阶的四足机器人。控制模型可以不完整，但其失效边界必须可检测，并由速度限制、模型切换或安全停车覆盖。

<a id="ch39-sec9"></a>
## 39.9 选择传感器

传感器选择应从“哪些状态和风险必须被观测”反推，而不是简单堆叠设备。仓储机器人可使用轮编码器测量轮角位移，IMU 测量角速度与比力，激光雷达或深度相机观测环境几何，RGB 相机识别标签与目标物体，关节编码器提供机械臂位置，电流传感器间接反映驱动力矩，夹爪力传感器检测接触。不同传感器的视场、量程、精度、更新率和失效模式应互补。

一般测量模型为
```math
y_k=h(x_k)+v_k,\qquad v_k\sim\mathcal N(0,R_k),
```
其中 $`y_k\in\mathbb R^p`$ ， $`R_k\in\mathbb R^{p\times p}`$ 是测量噪声协方差。高斯模型便于估计，但相机误匹配、雷达多径和编码器跳变常产生重尾离群值，需要门限检验、鲁棒损失或混合分布。IMU 的测量还包含偏置和安装误差，例如 $`\tilde\omega=R_{IB}\omega+b_g+n_g`$ ；如果漏掉 $`b_g`$ ，积分姿态会产生持续漂移。

工程上必须同时设计空间标定、时间同步和健康监测。相机与机械臂的手眼外参决定抓取精度，IMU 与编码器的时间偏差会被估计器误认为运动误差。单一前向相机可能在逆光、遮挡或近距离无纹理箱体前失效，因此不能承担唯一的防碰责任。传感器冗余也不是无条件有益：相关误差若被错误当作独立信息，会使协方差过度自信；所有传感器共用同一时钟或电源时，还可能存在共同原因故障。

<a id="ch39-sec10"></a>
## 39.10 建立状态估计

状态估计将模型预测与带噪观测融合，输出控制和规划所需的状态及其不确定度。离散贝叶斯滤波的基本结构为
```math
p(x_k\mid y_{1:k-1})
=\int p(x_k\mid x_{k-1},u_{k-1})p(x_{k-1}\mid y_{1:k-1})\,dx_{k-1},
```
```math
p(x_k\mid y_{1:k})
\propto p(y_k\mid x_k)p(x_k\mid y_{1:k-1}).
```
前式是预测，后式是观测更新。线性高斯系统可用卡尔曼滤波，弱非线性系统可用扩展或无迹卡尔曼滤波，强非线性、多峰定位与数据关联问题则可能需要粒子方法或因子图优化。

仓储底盘可融合轮速、IMU 和激光地图匹配，估计 $`{}^{W}T_B`$ 、速度与 IMU 偏置；机械臂通常由关节编码器获得高频状态，再通过相机修正目标物体和工具外参。估计结果不应只有均值 $`\hat x_k`$ ，还应包含协方差 $`P_k\in\mathbb R^{n\times n}`$ 或等价置信描述。规划安全距离可根据位置不确定度增大，例如
```math
d_{\mathrm{margin}}=d_0+\alpha\sqrt{\lambda_{\max}(P_p)},
```
其中 $`P_p`$ 是位置协方差子块， $`\alpha`$ 与所需置信水平有关。

估计器必须检查可观测性、一致性和异常恢复。机器人静止时，某些 IMU 偏置可以估计；在长直无特征通道中，视觉或激光对纵向位置的约束可能很弱。若初值错误、模型失配或数据关联错误，滤波器可能发散，即使输出数值仍然平滑。高斯单峰估计适用于后验近似单峰的范围；在两个相似货架通道之间无法判别时，应保留多假设或请求主动观测，而不是把两个位置取平均。

<a id="ch39-sec11"></a>
## 39.11 建立路径与轨迹规划

路径是配置空间中的无时间参数曲线，轨迹则为状态和输入赋予时间。底盘路径可写为 $`\gamma(s)`$ ， $`s\in[0,1]`$ ；轨迹写为 $`x(t),u(t)`$ ，并满足动力学和约束。机械臂规划位于关节配置空间 $`\mathcal C\subset\mathbb R^6`$ ，障碍物通过机器人几何映射为配置障碍 $`\mathcal C_{\mathrm{obs}}`$ 。因此末端直线无碰并不保证机械臂肘部无碰，底盘平面无碰也不保证伸出的机械臂不会扫到货架。

轨迹优化可统一表示为
```math
\min_{x_{0:N},u_{0:N-1}}
\Phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k)
```
```math
\text{s.t.}\quad
x_{k+1}=f(x_k,u_k),\;
x_k\in\mathcal X_{\mathrm{free}},\;
u_k\in\mathcal U,\;
x_0=\hat x .
```
这里 $`N`$ 是离散时域长度， $`\ell`$ 可同时惩罚时间、能耗、曲率和控制变化， $`\Phi`$ 是终端代价。采样规划适合高维非凸可行域，图搜索适合栅格和道路网络，数值优化适合产生平滑且动力学可行的轨迹；工程系统常将它们组合，而非寻找唯一“最佳”算法。

在仓储任务中，可先为底盘寻找货架间通道，再选择可抓取的停靠位姿，随后联合检查底盘和机械臂可达性。规划依赖地图、动态障碍预测和状态估计；这些输入具有不确定性，因此轨迹必须保留制动和重规划余量。若人员运动不可可靠预测，长时域最优轨迹并无实际保证，应采用短时预测、保守速度和反应式安全层。规划完整性或最优性结论只在其采样、模型和静态环境等假设下成立。

<a id="ch39-sec12"></a>
## 39.12 选择控制方法

控制方法负责把参考轨迹转化为能够抑制误差和扰动的反馈动作。在线性化模型
```math
\delta x_{k+1}=A_k\delta x_k+B_k\delta u_k
```
上，可使用状态反馈 $`\delta u_k=-K_k\delta x_k`$ ；机械臂关节控制可采用
```math
\tau=M(q)\!\left(\ddot q_d+K_d\dot e+K_pe\right)
+C(q,\dot q)\dot q+g(q),
```
其中 $`e=q_d-q`$ ， $`K_p,K_d\in\mathbb R^{6\times6}`$ 是正定增益。该计算力矩形式在模型准确、状态可得且执行器未饱和时，可把误差动态近似整形成二阶系统。

若约束和多变量耦合重要，可采用模型预测控制，在有限时域内反复求解带状态和输入约束的优化问题；若模型不确定但有界，可使用鲁棒控制；末端与箱体接触时，可选阻抗或导纳控制，使力与位移遵循指定关系。PID 仍适合许多电机速度环和关节位置环，但积分项必须配合抗饱和，否则底盘被障碍物阻挡或关节触限时会积累过大控制量。

选择方法时应比较稳定性条件、模型需求、计算时延、调参成本和故障行为。仓库低速底盘未必需要复杂非线性控制，而重载机械臂高速运动不能只靠低增益位置环。任何稳定性结论都依赖模型范围、采样周期和饱和假设；一旦控制命令被限幅，理想闭环极点不再完整描述实际系统。因此控制器必须与执行器能力、估计质量和安全层共同设计，而不是单独在无约束模型上追求最优。

<a id="ch39-sec13"></a>
## 39.13 设计控制层级

自主系统通常需要按时间尺度与职责分层。仓储机器人可采用任务层、行为层、规划层、轨迹控制层、执行器层和独立安全层：任务层以秒到分钟为尺度决定取放顺序；行为层管理“导航、对接、抓取、撤离”等模式；规划层以数百毫秒到数秒重规划；轨迹控制层以 $`10`$ — $`100\,\mathrm{Hz}`$ 跟踪；电机电流环可运行在 $`1\,\mathrm{kHz}`$ 以上。层级的意义是隔离复杂度，而不是让模块彼此不知道约束。

设高层输出参考 $`r_j`$ ，低层闭环映射为
```math
x_{j+1}=F_{\mathrm{cl}}(x_j,r_j,d_j),
```
其中 $`j`$ 是较慢时间步， $`d_j`$ 为聚合扰动。高层规划使用的可达集合和响应时间应来自低层闭环能力，而不是裸动力学的理想能力。接口需要包含参考值、有效时刻、截止时间、坐标系、约束和状态质量。例如行为层发出的“抓取”命令必须同时携带目标物体标识与位姿置信度，不能只发送一个无上下文布尔量。

层级之间还要定义权限和仲裁。安全层应能覆盖普通轨迹命令，驱动器故障应向上传播，任务层取消命令则需要有受控停车语义。时间尺度分离只有在内层明显快于外层时才成立；若底盘速度环带宽不足，外层轨迹控制会激发振荡。分层也不能掩盖强耦合：狭窄货架前底盘与机械臂可能需要联合规划，而不是先固定底盘再强迫机械臂完成不可达动作。

<a id="ch39-sec14"></a>
## 39.14 将控制量映射到执行器

控制器输出通常是广义速度、加速度、力或力矩，而硬件接口可能接受轮速、关节位置或电流命令，因此需要显式控制分配。差速底盘中，给定纵向速度 $`v`$ 和角速度 $`\omega`$ ，左右轮角速度为
```math
\begin{bmatrix}\omega_R\\\omega_L\end{bmatrix}
=
\begin{bmatrix}
1/r&r_b/(2r)\\
1/r&-r_b/(2r)
\end{bmatrix}
\begin{bmatrix}v\\\omega\end{bmatrix},
```
其中 $`r`$ 是轮半径， $`r_b`$ 是左右轮距。该映射假设纯滚动、两轮半径一致且底盘刚性；轮径误差会同时引入尺度误差和航向漂移。

对机械臂，任务空间期望力旋量 $`F_d\in\mathbb R^6`$ 可映射为关节力矩 $`\tau=J^\top(q)F_d+\tau_{\mathrm{null}}`$ ；期望末端速度则可通过阻尼伪逆求解
```math
\dot q=J^\top(JJ^\top+\lambda^2I)^{-1}\xi_d ,
```
其中 $`\lambda>0`$ 是奇异附近的阻尼参数。阻尼能限制关节速度，却会引入任务误差；它不是消除奇异性的魔法。冗余机器人还可在零空间中处理避限位和避障，但六轴机械臂执行一般六维任务时通常没有连续冗余。

工程映射必须执行单位换算、符号校验、限幅、变化率限制和可行性检查。控制分配可写为带约束最小二乘问题，在多个轮、电机或旋翼间分配所需广义力；无人机尤其依赖该步骤，而差速底盘形式较简单。若所需动作超出能力，应返回“不可实现程度”并让规划层降低速度或修改轨迹，不能静默截断。静默饱和会使控制器认为命令已执行，从而积累误差并破坏稳定性判断。

<a id="ch39-sec15"></a>
## 39.15 建立实时闭环

实时闭环要求感知、估计、规划、控制和执行在规定时限内以一致数据运行。若传感器采样、计算、通信和驱动共同造成延迟 $`\tau_d`$ ，控制器实际使用的是过去状态 $`\hat x(t-\tau_d)`$ 。离散闭环可表示为
```math
x_{k+1}=f\!\left(x_k,\pi(\hat x_{k-d},r_{k-d}),w_k\right),
```
其中 $`d`$ 是以控制周期计的延迟。延迟增加相位滞后，抖动则使模型时变；即使平均计算时间足够短，偶发超时也可能导致危险动作。

工程实现应为各循环规定周期、最坏执行时间、优先级和超时策略。例如 IMU 预积分与底盘状态估计运行在 $`200\,\mathrm{Hz}`$ ，底盘控制在 $`50\,\mathrm{Hz}`$ ，机械臂关节控制在 $`500\,\mathrm{Hz}`$ ，局部规划在 $`10\,\mathrm{Hz}`$ ，任务调度在事件触发下运行。跨频率数据应通过带时间戳缓冲区插值或外推，命令应包含序号与有效期。不能简单使用“最近收到的数据”，因为它可能来自不一致时刻。

实时系统还要设置看门狗、心跳、截止时间监测和安全状态机。若局部规划超时，机器人应执行已验证的短时制动轨迹，而不是无限保持最后一个速度命令。实时性不等于所有模块都必须硬实时：电机与安全回路通常要求硬实时，高层识别可采用软实时，但其迟到结果必须被丢弃。闭环频率只有在传感器带宽、执行器带宽和模型有效范围匹配时才有意义，盲目提高频率可能只会放大量化噪声和总线负载。

<a id="ch39-sec16"></a>
## 39.16 仿真验证

仿真验证用可控、可重复的环境检查模型、算法和接口，但它不是实机安全证明的替代品。应建立多个保真层级：单元测试验证坐标变换和雅可比；运动学仿真验证路径与碰撞；动力学仿真验证控制和执行器饱和；传感器仿真验证估计与感知；系统级仿真验证任务状态机、通信延迟和故障恢复。仓储场景应包括狭窄通道、遮挡货箱、移动人员、不同载荷与地面摩擦。

验证对象可写成性质集合，例如
```math
\Pr\!\left(
d_{\min}\ge d_{\mathrm{safe}},
\;T\le T_{\max},
\;\|e_E\|\le\varepsilon_E
\right)\ge1-\delta ,
```
其中 $`d_{\min}`$ 是任务期间最小间距， $`T_{\max}`$ 是时限， $`e_E`$ 是末端误差， $`\delta`$ 是允许的统计失败概率。蒙特卡洛试验应从明确分布中采样质量、摩擦、传感器噪声、延迟和初始位姿；对安全关键参数，还要做边界扫描和对抗性组合，因为随机采样不容易覆盖稀有危险事件。

应记录成功率之外的内部指标，如创新序列、约束裕度、控制饱和比例、最坏周期和模式切换原因。仿真模型若与控制器使用同一方程，会产生“同模验证”的虚假乐观，因此验证模型应加入参数扰动、未建模延迟和不同接触模型。视觉渲染逼真也不等于动力学真实。仿真结论只对覆盖的模型族成立，未建模的线缆拖拽、齿隙、镜面反射和人员行为仍需通过实机试验暴露。

<a id="ch39-sec17"></a>
## 39.17 实机实验

实机实验应按风险逐级扩大，而不是第一次上电就运行完整自主任务。推荐顺序为：断动力接口检查、单传感器检查、架空单电机测试、低速单关节测试、底盘空载测试、机械臂自由空间测试、固定障碍场景、静态抓取、移动与操作串联，最后才进入有人参与的动态仓库。每一级都应设置可观测的通过条件和回退条件。

实验数据应覆盖状态估计、参考轨迹、原始传感器、执行器命令、电流、电压、温度、故障码和统一时钟。跟踪性能可用
```math
\mathrm{RMSE}=
\sqrt{\frac{1}{N}\sum_{k=1}^{N}\|x_k-x_k^{\mathrm{ref}}\|_W^2}
```
衡量，其中 $`W`$ 是根据单位和任务重要性选择的半正定权重矩阵；同时还要报告最大误差、分位数和约束越界次数。仅报告平均误差会掩盖抓取瞬间或急停时的峰值风险。

现场试验必须具备物理急停、软件急停、速度限制、隔离区域和明确的试验负责人。抓取额定负载前应先验证夹爪保持力与机械臂持续转矩；测试人员不应进入可能的扫掠空间。实验结论依赖测试条件，晴天静态空仓中的成功不能外推到逆光、满载和高人流环境。每次扩大运行域，都应基于前一级证据更新风险评估，而不是把偶然成功视为模型已经正确。

<a id="ch39-sec18"></a>
## 39.18 系统辨识与模型修正

系统辨识利用输入输出数据估计未知参数或动态结构。若模型可写为
```math
y_k=\phi_k^\top\theta+\epsilon_k,
```
其中 $`\phi_k\in\mathbb R^d`$ 是由状态和输入构成的回归向量， $`\theta\in\mathbb R^d`$ 是待估参数， $`\epsilon_k`$ 是残差，则批量最小二乘解为
```math
\hat\theta=(\Phi^\top W\Phi)^{-1}\Phi^\top WY ,
```
前提是 $`\Phi^\top W\Phi`$ 可逆且激励充分。仓储机器人可据此辨识轮半径、轮距、底盘速度响应、电机摩擦、机械臂负载惯量和控制链路延迟。

实验输入必须在安全约束内提供足够频率和方向的持续激励。只让底盘直行无法可靠辨识轮距，只在单一姿态缓慢移动机械臂也难以区分重力参数与摩擦参数。训练数据和验证数据应分离，残差还应按速度、载荷、温度和运动方向分组检查。若残差存在系统相关性，说明模型结构、时间同步或噪声假设仍有问题，而不只是参数数值不准。

模型修正应遵循“最小必要复杂度”：先检查单位、坐标、延迟和标定，再增加非线性摩擦、齿隙或柔性项。在线递推辨识适合参数缓慢漂移，但必须设置参数投影、变化率限制和异常数据门控，避免一次碰撞把轮径估计改坏。辨识得到的是实验工作域内的等效模型；湿滑地面、不同轮胎和超额负载可能改变参数，不能将局部辨识结果无条件外推到所有工况。

<a id="ch39-sec19"></a>
## 39.19 引入学习模块

学习模块适合处理难以显式建模、数据丰富且可定义监督信号的部分，例如料箱检测、抓取候选评分、地面可通行性、动力学残差和任务时间预测。它不应因为“模型不够准”而被直接放到整个闭环外层。更稳妥的结构是保留已知动力学
```math
x_{k+1}=f_{\mathrm{phys}}(x_k,u_k)
+r_\theta(x_k,u_k),
```
其中 $`r_\theta`$ 是参数为 $`\theta`$ 的学习残差，并限制其幅值、平滑性和使用域。这样可把数据用于修正轮滑或关节摩擦，同时保留物理模型提供的结构与基本可解释性。

选择学习位置应对应误差来源：视觉漏检应改进表征和训练数据，机械臂负载变化导致跟踪误差可学习残差动力学，任务分配效率低可学习代价预测；坐标系方向错误、时间戳错位和电机接线反向则不应交给网络补偿。训练集应覆盖部署分布，并划分独立验证集和压力测试集。模型还应输出置信度或域外分数，使系统在不确定时降低速度、请求重观测或回退到保守策略。

学习策略 $`\pi_\theta(o)`$ 若直接输出动作，会面临分布偏移、不可解释饱和和闭环误差累积。安全关键系统可在其后加入动作投影：
```math
u^\ast=\arg\min_{u\in\mathcal U_{\mathrm{safe}}}
\|u-\pi_\theta(o)\|^2 ,
```
其中 $`\mathcal U_{\mathrm{safe}}`$ 由制动、碰撞和执行器约束定义。但安全集合本身仍依赖模型和感知质量，投影不是绝对保证。学习模块上线前必须具备版本管理、数据追溯、回滚机制和运行域监测；只有当它相对基线在独立条件下提供可重复收益时，才应进入主闭环。

<a id="ch39-sec20"></a>
## 39.20 系统级调试与故障定位

系统级故障往往表现于一个模块，却产生于另一个接口。例如末端抓取偏差可能来自相机外参、目标检测、底盘定位、关节零位、结构挠曲或时间同步；底盘蛇形振荡可能来自控制增益，也可能来自轮速符号、延迟或定位跳变。因此调试应沿因果链进行：任务目标 $`\rightarrow`$ 规划参考 $`\rightarrow`$ 状态估计 $`\rightarrow`$ 控制输出 $`\rightarrow`$ 执行器响应 $`\rightarrow`$ 传感器反馈，并在每个接口比较期望量和实测量。

可把残差定义为
```math
r_k=y_k-\hat y_{k|k-1},
```
并检查归一化创新平方
```math
\mathrm{NIS}_k=r_k^\top S_k^{-1}r_k,
```
其中 $`S_k`$ 是预测测量协方差。持续偏大的 NIS 可能意味着噪声低估、模型失配或传感器异常；持续单向残差更像标定偏差；只在加速时出现的误差常与延迟、柔性或惯量有关。故障树、事件时间线、相关性分析和故障注入可以帮助缩小范围，但统计相关不能替代物理因果验证。

有效日志必须包含统一时间、坐标系、单位、软件版本、参数摘要、状态机模式和命令来源。调试时一次只改变一个主要因素，先重现实验，再提出假设，设计能区分竞争解释的试验。例如要区分轮径误差与航向观测偏差，可比较正反向直线和原地旋转数据，而不是盲目调控制增益。对于无法可靠定位或恢复的故障，系统应进入可定义的安全状态。

系统完成并不意味着故障消失，而是故障能够被检测、隔离、降级并复现。仓储机器人应能区分相机暂时遮挡、IMU 数据冻结、电机过温、网络中断和地图不一致，并采取继续低速、重新定位、放下负载或停车等待等不同策略。故障诊断依赖冗余和模型，其保证只覆盖预先定义的故障集合；对未知故障，保守的健康度监测与安全停机仍是必要边界。

## 本章小结

从零构建自主系统是一条贯通任务、模型、估计、规划、控制、执行与验证的闭环主线。首先把仓储搬运任务写成带目标、约束和验收分布的问题，再定义系统边界、坐标系、状态、输入与观测；随后建立几何、动力学和执行器模型，并按不同时间尺度选择适合在线使用的控制模型。传感器与估计器提供带不确定度的状态，规划器生成满足几何和动力学约束的轨迹，控制器通过层级结构和控制分配把轨迹转化为硬件可执行命令。

完整系统还必须处理时间：采样、同步、延迟、截止时间和故障传播都属于闭环的一部分。仿真用于覆盖模型族和边界条件，实机实验用于暴露真实接口与未建模机制，系统辨识用于修正可测参数，学习模块只在误差类型、数据条件和安全边界明确时引入。最终的调试方法不是逐个替换算法，而是沿统一的因果链检查状态、概率、优化、几何和硬件接口。

本章给出的是构建流程，而不是一组无条件有效的配方。每个模型和算法都依赖工作域、时间尺度、噪声、计算资源与硬件能力；系统可靠性来自这些假设被显式表达、在线监测并由降级机制保护。下一章将在此流程之上建立统一知识坐标系，把各类算法放回“对象、信息、目标、约束、模型与计算”的共同位置，以便比较它们解决的问题、依赖的假设以及彼此之间的接口。
