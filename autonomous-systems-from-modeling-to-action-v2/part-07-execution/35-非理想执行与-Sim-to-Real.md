## 35.1 Saturation

饱和是执行器命令受到幅值边界约束的现象。若控制器给出的期望输入为 $`u_c\in\mathbb{R}^m`$ ，真实执行输入可写为
```math
u_i=\mathrm{sat}(u_{c,i};u_i^-,u_i^+)
=\min\!\left(u_i^+,\max(u_i^-,u_{c,i})\right),
```
其中 $`u_i^-`$ 、 $`u_i^+`$ 分别是第 $`i`$ 个通道的下、上限。边界可以来自电机允许电流、逆变器母线电压、机械臂关节最大转矩、移动底盘轮胎附着力，也可能由温度、电池荷电状态或安全策略动态改变。因此，饱和不是控制器之后一个无关紧要的裁剪函数，而是闭环动力学的一部分。

以状态空间模型 $`\dot x=f(x,u)`$ 为例，在线性化模型 $`\dot x=Ax+Bu`$ 上设计的 LQR 通常产生 $`u_c=-Kx`$ 。当 $`-Kx`$ 超出可行输入集合
```math
\mathcal U=\{u\in\mathbb{R}^m\mid u^-\leq u\leq u^+\}
```
时，实际闭环变为 $`\dot x=Ax+B\mathrm{sat}(-Kx)`$ ，原有线性稳定性结论只在不触发饱和的局部区域内直接成立。对仓储移动操作机器人而言，急停后的底盘恢复控制可能同时要求很大的轮端转矩；六轴机械臂携带重物伸展时，重力补偿也可能占用大部分关节转矩余量。此时继续增大反馈增益不会增加实际控制能力，反而可能放大振荡、积分累积和轮胎打滑。

带积分器的控制器尤其需要抗积分饱和。若积分状态满足 $`\dot z=e`$ ，可采用回算机制
```math
\dot z=e+K_{\mathrm{aw}}(u-u_c),
```
其中 $`e\in\mathbb{R}^p`$ 是跟踪误差， $`K_{\mathrm{aw}}\in\mathbb{R}^{p\times m}`$ 是抗饱和增益。另一种做法是条件积分：仅当执行输入未饱和，或误差方向有助于退出饱和时更新积分状态。对于多输入系统，还应通过控制分配求解
```math
\min_{u\in\mathcal U}\ \|Gu-w_d\|_W^2+\lambda\|u-u_{\mathrm{prev}}\|^2,
```
其中 $`w_d`$ 是期望广义作用、 $`G`$ 是执行器到广义作用的映射。上述方法都依赖边界估计基本可信；若电机热降额、负载变化和地面附着没有被纳入边界，所谓“抗饱和”仍可能基于错误的可用控制余量。

## 35.2 Rate Limit

幅值可行并不意味着变化速度可行。速率限制描述执行命令在单位时间内能够改变的最大幅度，连续时间下可写为
```math
\dot u_i\in[\rho_i^-,\rho_i^+],
```
离散时间下则为
```math
\Delta u_k=u_k-u_{k-1},\qquad
\rho^-\Delta t\leq\Delta u_k\leq\rho^+\Delta t.
```
其中 $`\rho^\pm\in\mathbb{R}^m`$ 是上升和下降速率边界， $`\Delta t`$ 是控制周期。电机电流受电气时间常数和电流环带宽限制，液压与气动执行器受流量限制，机械臂轨迹还受到速度、加速度和跃度约束。速率限制因而是执行器动态，而不只是为了让指令曲线“更平滑”。

一种简单模型是在理想命令与被控对象之间加入限速器，
```math
u_k=u_{k-1}+\mathrm{clip}
\left(u_{c,k}-u_{k-1},\rho^-\Delta t,\rho^+\Delta t\right).
```
更完整的做法是将执行输入本身扩展为状态，令 $`\dot u=v`$ ，并把 $`v`$ 作为受约束的新控制量。这样，优化控制器可以同时处理 $`u\in\mathcal U`$ 与 $`v\in\mathcal V`$ ，但系统维度和预测时域计算量也随之增加。若执行器还存在一阶动态，可用 $`\tau_a\dot u+u=u_c`$ 近似；这里 $`\tau_a>0`$ 是执行器时间常数，该近似只适用于工作点附近且没有明显迟滞或死区的情形。

在仓储机器人中，底盘速度命令骤变会造成货物滑移或驱动轮失去附着；机械臂关节转矩跃变会激发减速器和连杆柔性模态；云台相机的快速转动则可能恶化曝光和特征跟踪。工程上应在轨迹规划阶段就保证速度、加速度和跃度可行，而不是依靠驱动器最后限幅。控制器中的参考治理器、输入整形或带 $`\Delta u`$ 约束的模型预测控制可以显式维护可行性，但其有效性假设模型、周期和边界近似准确；面对碰撞、急停等安全事件，速率限制还必须允许由独立安全通道覆盖，不能为了平滑而延迟危险状态下的制动。

## 35.3 Friction

摩擦把相对运动、法向载荷和表面状态映射为阻碍运动的力或力矩。常用的关节摩擦模型为
```math
\tau_f(\dot q)=b\dot q+
\left(\tau_c+(\tau_s-\tau_c)e^{-(|\dot q|/v_s)^\alpha}\right)
\mathrm{sgn}(\dot q),
```
其中 $`q\in\mathbb{R}^n`$ 为关节位置， $`b`$ 是黏性摩擦系数， $`\tau_c`$ 、 $`\tau_s`$ 分别为库仑摩擦和静摩擦幅值， $`v_s`$ 为 Stribeck 特征速度， $`\alpha>0`$ 控制曲线形状。该模型能描述中高速摩擦和低速摩擦下降趋势，但在 $`\dot q=0`$ 处的符号函数不连续，也不能完整表达预滑动位移、温度和润滑变化。

静止阶段更适合用集合值关系表达：当 $`\dot q=0`$ 时，只要外加力矩满足 $`|\tau_{\mathrm{ext}}|\leq\tau_s`$ ，摩擦就可取 $`\tau_f=\tau_{\mathrm{ext}}`$ 以维持静止；超过阈值后系统进入滑动。数值仿真中若直接使用不连续符号函数，固定步长积分器可能在零速附近产生抖振。可使用 $`\tanh(\dot q/\epsilon)`$ 平滑近似，也可采用互补约束或含内部摩擦状态的 LuGre 类模型。平滑化有利于求导和优化，但会引入不存在于真实系统的微小爬行，因此参数 $`\epsilon`$ 不能仅按数值方便任意放大。

仓储机器人底盘的轮地摩擦决定最大牵引力，近似满足 $`|F_t|\leq\mu F_n`$ ，其中 $`\mu`$ 是附着系数、 $`F_n`$ 是法向载荷；灰尘、包装膜和湿滑地面会使 $`\mu`$ 快速变化。六轴机械臂的减速器密封和轴承摩擦则会导致低速跟踪误差、换向误差和电流偏置。摩擦前馈可以使用辨识模型补偿，状态估计器也可把未建模摩擦作为扰动估计，但过度补偿会在速度过零时注入跳变力矩。工程上应区分“用于控制的低阶摩擦模型”和“用于接触安全评估的保守边界”，并承认摩擦参数通常只在有限温度、载荷和速度范围内有效。

## 35.4 Backlash

回差是传动方向反转时，输入端运动不能立即传递到输出端的迟滞现象，常见于齿轮啮合间隙、丝杠螺母间隙和松弛联轴器。设电机侧等效位置为 $`\theta_m`$ ，负载侧位置为 $`\theta_l`$ ，回差宽度为 $`2\delta`$ 。理想游隙模型可把相对位移 $`r=\theta_m-N\theta_l`$ 分为三个区域： $`r=\delta`$ 时接触正向齿面， $`r=-\delta`$ 时接触反向齿面， $`|r|<\delta`$ 时处于自由游隙区，其中 $`N`$ 是传动映射系数。由于输出依赖运动历史，回差不能由单值静态函数完整描述，而应视为具有离散接触模式的迟滞算子。

在接触模式下，可用
```math
\tau_t=k_b(r-s\delta)+d_b(\dot\theta_m-N\dot\theta_l),\qquad s\in\{-1,1\},
```
表示传递力矩，其中 $`k_b`$ 、 $`d_b`$ 是接触刚度和阻尼；在游隙模式下近似取 $`\tau_t=0`$ 。模式切换使系统成为混杂动力学系统。若仿真只用连续平均模型，可能遗漏换向撞击；若使用无限刚度的理想接触，则又容易造成数值刚性和非物理能量注入。合适的模型复杂度取决于任务：高速寿命分析需要接触冲击细节，常规轨迹跟踪可采用可微迟滞近似。

六轴机械臂在货架前执行插取动作时，腕关节反向会使编码器已报告运动而末端暂时不动，随后又出现位置突跳。仅依赖电机侧编码器的状态估计无法观测这一内部间隙；增加负载侧编码器、视觉末端测量或关节力矩传感器可改善可观测性。控制上可通过同方向逼近、预加载机构、回差逆补偿和降低换向增益缓解问题，但逆补偿高度依赖 $`\delta`$ 及负载状态，不能跨越磨损和温度变化无条件使用。涉及人机接触或狭窄货格时，应把残余末端误差纳入碰撞裕量，而非假定软件补偿能够消除机械间隙。

## 35.5 Compliance

柔顺性表示系统在受力后发生可恢复形变的能力。对单个弹性关节，可用电机侧角度 $`\theta`$ 与连杆侧角度 $`q`$ 之间的弹簧阻尼模型
```math
\tau_s=K_s(\theta-q)+D_s(\dot\theta-\dot q),
```
其中 $`K_s,D_s\in\mathbb{R}^{n\times n}`$ 分别为刚度和阻尼矩阵。刚体模型只有 $`q`$ 一组广义坐标，而柔性模型至少增加电机侧状态，使系统出现额外共振模态。串联弹性执行器主动引入可测形变以估计力矩；普通减速器、长连杆、轮胎和安装支架也都具有不可忽略的被动柔性。

柔顺性既是误差来源，也是安全和接触控制资源。机械臂末端小位移满足近似关系 $`F=K_x\Delta x`$ ，其中 $`F\in\mathbb{R}^6`$ 是末端力与力矩， $`\Delta x\in\mathbb{R}^6`$ 是局部位姿误差， $`K_x`$ 是笛卡尔刚度矩阵。阻抗控制常指定
```math
M_d\ddot e+D_d\dot e+K_de=F_{\mathrm{ext}},
```
以塑造末端在外力下的动态响应。该关系基于局部坐标、接触环境和雅可比矩阵近似有效；在奇异位形、大转角或刚性环境高频接触下，离散采样、延迟和未建模结构模态会破坏期望阻抗。

仓储移动操作机器人从货格拉出周转箱时，底盘轮胎、机械臂基座、六个关节和夹具垫片共同构成串联柔性链。若规划器只使用刚体几何，末端在载荷下会偏离目标；若控制器一味提高位置增益，又可能激发机械共振或产生过大的接触力。工程上应通过载荷相关挠度补偿、陷波或模态阻尼、力位混合控制来利用和约束柔性，并在仿真中保留主导低频模态。有限元级细节并非总是必要，但任何被忽略的模态都应显著高于闭环带宽；否则“刚体假设”没有充分依据。

## 35.6 Sensor Delay

传感器延迟是物理状态发生变化到对应测量可被估计器或控制器使用之间的时间差。含延迟的测量模型可写为
```math
y_k=h(x(t_k-\tau_s))+v_k,
```
其中 $`x`$ 是系统状态， $`h(\cdot)`$ 是观测函数， $`\tau_s\geq0`$ 是采集、曝光、处理和排队造成的总延迟， $`v_k`$ 是测量噪声。延迟与低采样率不同：低采样率决定观测间隔，延迟决定观测所对应的过去时刻；两者也都不同于时间戳误差。

相机图像可能经过曝光、传输、去畸变和神经网络推理后才输出目标位姿，而 IMU 通常以更高频率、更低延迟报告角速度和比力。融合时必须根据采样时间而不是到达时间建立测量模型。若延迟已知，可保存状态与协方差历史，在测量对应时刻执行更新，再将结果传播到当前时刻；也可用当前预测
```math
\hat x(t_k)\approx\Phi(\tau_s)\hat x(t_k-\tau_s)
```
进行补偿，其中 $`\Phi`$ 是由动力学模型得到的状态转移映射。非线性系统需要相应的积分传播和协方差更新，不能简单把旧图像当作当前观测。

仓储机器人高速转弯时，延迟 $`100\,\mathrm{ms}`$ 的相机货架位姿可能对应十几厘米前的位置；若直接用于底盘闭环，会造成横向摆动。机械臂视觉伺服同样可能因图像延迟而降低相位裕量。实际系统应统一硬件或软件时钟、记录采样时间和到达时间、测量延迟分布，并在估计接口中显式携带时间戳。预测补偿依赖短时间内模型可信且延迟有界；遇到曝光时间变化、处理队列拥塞或时间戳跳变时，应增大测量不确定度、拒绝过旧数据或降速，而不能假定一个固定延迟参数始终成立。

## 35.7 Communication Delay

通信延迟发生在传感器、计算节点和执行器之间的数据传输过程中，包括总线仲裁、序列化、交换机排队、协议栈和重传时间。离散系统可表示为
```math
x_{k+1}=Ax_k+Bu_{k-d_k}+w_k,
```
其中 $`d_k\in\mathbb{N}`$ 是随时间变化的输入延迟步数， $`w_k`$ 是过程扰动。若数据包丢失，可引入到达变量 $`\gamma_k\in\{0,1\}`$ ，例如执行端采用
```math
u_k=\gamma_k u_{c,k}+(1-\gamma_k)u_{k-1}.
```
保持上一命令只是众多丢包策略之一，对持续速度命令可能合适，对力矩命令或急停命令则可能危险。

通信问题还包括乱序、重复、带宽竞争和时钟不同步。仓储机器人中，相机经以太网传输，IMU 经串行链路或 CAN 总线接入，底盘与六轴机械臂驱动器则可能运行不同周期。应在消息中包含源时间戳、序号、有效期限和坐标系版本，并区分“命令生成时间”“预期执行时间”和“实际确认时间”。周期性控制流量宜使用有界时延的实时通道，日志和大图像数据不应阻塞安全控制；急停、制动和驱动失能应尽可能由独立、可验证的安全链路实现。

延迟会增加闭环相位滞后。对近似固定延迟 $`\tau_c`$ ，频域中对应因子 $`e^{-s\tau_c}`$ ；频率为 $`\omega`$ 时额外相位为 $`-\omega\tau_c`$ ，因此高带宽环路最敏感。可采用时间戳预测、Smith 预测器、延迟状态扩展或网络化模型预测控制，但这些方法依赖延迟上界和对象模型。工程验收不应只测试平均延迟，还应测量高分位延迟、连续丢包长度和重连行为。若通信质量超出设计包络，系统应进入有界速度、局部自主或安全停止模式，而不是继续依赖远端控制器给出及时响应。

<a id="ch35-sec8"></a>
## 35.8 Model Mismatch

模型失配是部署对象的真实动力学与设计、估计或仿真模型之间的差异。可将标称离散模型写为
```math
x_{k+1}=f(x_k,u_k;\bar\theta)+w_k+\Delta(x_k,u_k),
```
其中 $`\bar\theta`$ 是标称参数， $`w_k`$ 表示随机过程扰动， $`\Delta`$ 表示结构性残差。质量、惯量和摩擦系数偏差属于参数失配；遗漏电缆拖曳、轮胎变形和柔性模态属于结构失配；不同货箱、地面和电池状态引起的变化则属于时变失配。把所有差异都归入独立同分布高斯噪声通常不合理，因为许多误差与状态、输入和运行历史相关。

需要特别区分模型误差与数值误差。模型误差即使在积分步长趋近于零时仍然存在；数值误差来自离散积分、碰撞求解容差和浮点计算，通常会随算法或步长改变。若仿真轨迹异常，可通过缩小时间步长、提高求解精度和替换积分器检查数值收敛；若结果收敛却持续偏离实机，则更可能是动力学结构或参数错误。反之，盲目增加模型细节却继续使用不稳定的接触积分，也不能获得可信结果。

工程上可用有界不确定性 $`\theta\in\Theta`$ 、扰动集合 $`w\in\mathcal W`$ 或概率分布 $`p(\theta,w)`$ 表达失配。鲁棒控制关注最坏情形，随机控制关注风险分布，自适应控制在线修正部分参数，扰动观测器则估计总等效扰动。仓储机器人载荷未知时，机械臂重力项和底盘制动距离都会变化；控制系统可使用称重、关节电流和加速度数据更新负载估计，同时保留保守安全边界。任何鲁棒性结论都依赖不确定集覆盖真实对象且模型结构满足假设；若真实状态超出训练、辨识或验证区域，应优先触发监测与降级，而不是把“鲁棒”理解为对任意失配都有效。

<a id="ch35-sec9"></a>
## 35.9 High-Fidelity Simulation

高保真仿真不是细节数量最多的仿真，而是在目标任务和评价指标上具有足够预测能力的仿真。一个移动操作机器人仿真通常包含刚体或柔性多体动力学、电机与驱动器、接触摩擦、传感器生成、通信时序、控制软件和环境几何。统一写成混杂系统可表示为
```math
\dot x=f_{m}(x,u,\theta),\qquad
m^+=g(m^-,x),\qquad
y=h_m(x,\theta_s)+v,
```
其中 $`m`$ 是接触、饱和或故障模式， $`\theta`$ 和 $`\theta_s`$ 分别是动力学与传感器参数。模式切换和多时间尺度使数值求解比单一光滑状态方程困难得多。

保真度应围绕用途分配。评估底盘定位时，轮地滑移、IMU 偏置、相机视场和时间戳比机械臂齿轮微观接触更重要；评估插箱接触时，末端几何、柔顺性、摩擦和控制延迟则必须充分建模。电机电流环可能以数十千赫兹运行，关节控制以千赫兹运行，相机仅几十赫兹，因此仿真需要多速率调度或经过验证的降阶模型。时间步过大会漏掉碰撞和高频模态，时间步过小则显著增加成本，且不能自动修复错误的物理模型。

高保真模型必须通过分层验证建立可信度：先检查单个电机阶跃、电流和转速响应，再检查关节空载与负载运动，随后检查机械臂末端轨迹、底盘制动和整机任务。比较指标可包括稳态误差、上升时间、频率响应、能耗、接触峰值和失败率，而不能只比较一条“看起来相似”的轨迹。仿真输出还应保留能量、约束残差和求解器状态，以识别非物理穿透或能量增长。

高保真仿真仍然不是实机证明。无法准确获得的货物摩擦、地面污染、线缆姿态和碰撞材料参数，会限制其外推能力。因此应同时维护快速低阶模型与较慢验证模型：前者服务规划、优化和大规模试验，后者用于关键工况复核。只有当模型在明确的状态、输入、载荷和环境包络内通过数据验证时，其预测才可用于部署决策。

<a id="ch35-sec10"></a>
## 35.10 Software-in-the-Loop

软件在环（Software-in-the-Loop，SIL）是让待部署控制、估计、规划和任务软件连接到仿真对象运行的测试方式。其关键不是重新实现一套“类似算法”，而是尽量复用实机代码路径、消息定义、参数文件、坐标系和调度接口。仿真器产生传感器消息，软件栈计算命令，仿真对象再根据命令推进，从而形成闭环。

SIL 的时间机制必须显式定义。若仿真时刻为 $`t_k`$ ，软件模块的第 $`i`$ 个任务可抽象为
```math
z_{k+1}^{(i)}=F_i(z_k^{(i)},m_k),\qquad
m_{k+\ell_i}=H_i(z_{k+1}^{(i)}),
```
其中 $`z^{(i)}`$ 是模块内部状态， $`m_k`$ 是输入消息， $`\ell_i`$ 是计算与传输延迟对应的步数。理想同步模式有利于复现和回归测试，实时异步模式则更接近实际调度。若仿真每一步都等待全部模块完成，便可能掩盖实机中的超时、消息竞争和线程抖动；若只追求墙钟实时，又可能牺牲确定性和故障定位能力。

对仓储机器人，SIL 可完整执行“地图定位—货架识别—底盘靠近—机械臂抓取—任务恢复”流程，并注入相机丢帧、IMU 偏置、关节饱和和网络抖动。测试不仅应检查最终是否抓取成功，还应断言速度、碰撞距离、估计协方差、求解器状态和命令有效期等不变量。随机场景必须记录种子、模型版本和参数，以便失败可复现。

SIL 擅长发现软件接口、状态机、坐标变换和极端场景问题，但不能验证真实驱动电气行为、处理器负载、传感器电磁干扰或机械损伤风险。若仿真接口过于理想，例如直接提供无延迟真值位姿，软件会对现实产生错误依赖。因此 SIL 的边界应清楚标注，并与后续硬件在环和受控实机测试共同构成证据链。

<a id="ch35-sec11"></a>
## 35.11 Hardware-in-the-Loop

硬件在环（Hardware-in-the-Loop，HIL）把部分真实硬件接入实时仿真闭环。常见配置是使用真实控制器、计算机、通信总线和驱动接口，而由实时仿真器模拟机器人动力学与传感器；也可以保留真实电机或关节，把其余机构作为虚拟负载。其目标是暴露 SIL 无法覆盖的定时、量化、接口和硬件故障问题，同时避免整机试验的成本与危险。

HIL 的核心约束是实时因果性。若仿真步长为 $`T_s`$ ，每一步的采样、计算和输出必须满足
```math
T_{\mathrm{io}}+T_{\mathrm{solve}}+T_{\mathrm{out}}\leq T_s,
```
其中三项分别是输入采集、模型求解和输出更新时间。超时不能被离线“补算”消除，因为真实控制器已经基于过期信号运行。对电机 HIL，还需正确模拟编码器量化、母线电压、反电动势和电流采样；对相机链路，可使用合成图像或回放数据，但必须保持曝光时间、帧率和时间戳语义一致。

仓储机器人可以先让真实底盘控制器连接虚拟车体与仓库场景，验证 CAN 总线调度、制动逻辑和失联保护；随后把真实机械臂控制柜连接虚拟六轴机构，检查关节限位、奇异位形和急停恢复。如果接入真实电机或力执行器，虚拟环境与物理硬件之间可能因延迟产生非物理能量，导致不稳定。此时应采用功率限制、被动性监测、虚拟耦合阻尼和独立硬件急停，并从低能量工况逐步扩展。

HIL 仍受模拟部分真实性约束。真实控制器通过了虚拟碰撞测试，不代表真实结构能承受相同冲击；真实通信通过了固定注入延迟，也不代表现场网络分布相同。HIL 应用于验证明确的接口和实时属性，并记录最坏执行时间、抖动、丢包恢复和故障响应。涉及安全功能时，还需要独立故障注入和实物验证，不能用 HIL 单独替代系统级安全论证。

<a id="ch35-sec12"></a>
## 35.12 Domain Randomization

域随机化是在仿真训练或测试中主动改变模型参数、传感器特性和环境外观，使策略或算法不依赖单一标称仿真。设随机域参数为 $`\xi\sim p_\phi(\xi)`$ ，策略为 $`\pi_\psi`$ ，常见训练目标是
```math
\min_\psi\ 
\mathbb E_{\xi\sim p_\phi,\ \tau\sim P(\cdot\mid\pi_\psi,\xi)}
[J(\tau)]
+\lambda\,\mathrm{Risk}(J),
```
其中 $`\tau`$ 是轨迹， $`J`$ 是任务代价， $`\phi`$ 描述随机化分布，风险项可采用高分位损失或条件风险价值。随机变量可包括质量、惯量、摩擦、延迟、相机内外参、光照、纹理和传感器噪声。

随机化范围需要由物理知识和数据共同约束。若把机械臂各连杆惯量独立随机化，可能生成不满足刚体几何关系的对象；若独立随机轮地摩擦与制动距离，也会破坏变量间相关性。更合理的方法是先随机货物质量、质心和材料，再由物理关系派生惯量、法向载荷和摩擦边界。相机噪声也不应只叠加独立高斯像素噪声，还应考虑运动模糊、曝光、遮挡和标定漂移，但复杂度应与任务敏感性匹配。

仓储移动操作机器人训练抓取策略时，可随机货箱尺寸、夹具摩擦、机械臂零位偏差和视觉延迟；训练底盘策略时，可随机地面附着、轮径、电池电压及负载质心。验证时应把训练分布内测试和分布外压力测试分开，避免用同一随机分布同时训练和宣称泛化。随机化过窄会过拟合仿真，过宽则可能使策略过度保守，甚至学习利用随机模型中的共同伪影。

域随机化成立的必要条件是随机参数族覆盖现实中的主导差异，且仿真没有被策略利用的系统性漏洞。它不能弥补错误的动作接口、遗漏的安全约束或不真实的接触求解。工程上应分析性能对各参数的敏感度，优先随机主导因素，并把不确定但有界的参数与真正随机的扰动区分开。部署后收集到的新数据应反向更新 $`p_\phi(\xi)`$ ，形成可追踪的仿真分布，而不是永久沿用拍脑袋设定的均匀区间。

<a id="ch35-sec13"></a>
## 35.13 System Identification for Sim-to-Real

面向 Sim-to-Real 的系统辨识，是利用实机输入输出数据估计仿真模型参数、动态结构和不确定性范围。给定数据集
```math
\mathcal D=\{u_k,y_k,t_k\}_{k=0}^{N},
```
灰箱参数辨识可求解
```math
\hat\theta=\arg\min_{\theta\in\Theta}
\sum_{k=0}^{N}
\|y_k-\hat y_k(\theta)\|_{R^{-1}}^2+\lambda r(\theta),
```
其中 $`\hat y_k(\theta)`$ 是模型预测， $`R`$ 是测量噪声协方差， $`r(\theta)`$ 是物理先验或正则项。参数 $`\theta`$ 可包括质量、惯量、电机常数、摩擦、刚度、延迟和传感器偏置。状态不可直接观测时，辨识需要与滤波、平滑或潜状态优化联合进行。

辨识质量首先受可辨识性制约。若机械臂始终低速匀速运动，就难以把惯性项与摩擦项区分；若底盘测试没有足够转向激励，也难以同时估计左右轮径和 IMU 偏置。输入应在安全约束下提供持续激励，例如多正弦、扫频或经过限幅的伪随机序列。实验还需覆盖预期负载、温度和速度区间，但不能为了数学激励越过电机电流、关节行程、地面附着与碰撞安全边界。

仓储机器人可按层级辨识：电机台架估计电阻、电感和转矩常数；单关节试验估计摩擦、传动柔性和延迟；底盘试验估计轮径、轴距、滑移和制动模型；整机携带不同货物时再估计负载相关参数。训练数据与验证数据必须分离，并使用多步预测、频率响应和任务指标验证，而不能只报告单步拟合误差。残差若仍与速度、方向或温度显著相关，说明模型结构尚未捕获关键机制。

并非所有误差都应强行塞入物理参数。可将模型写成
```math
x_{k+1}=f_{\mathrm{phys}}(x_k,u_k;\theta)
+r_\eta(x_k,u_k),
```
其中 $`r_\eta`$ 是数据驱动残差模型。残差学习可提高局部预测精度，但应限制其幅值、平滑性和适用域，并防止它抵消守恒关系或安全边界。辨识结果也不是永久常数：磨损、润滑、轮胎更换和载荷会导致参数漂移。部署流程应包含参数版本、置信区间、变化检测和重新辨识触发条件，为下一章的数据驱动建模提供经过物理约束的数据接口。

<a id="ch35-sec14"></a>
## 35.14 从“理论稳定”到“真实系统可用”

理论稳定通常针对给定模型、无界或理想输入、准确状态以及确定采样条件建立。例如存在 Lyapunov 函数 $`V(x)`$ ，使标称闭环满足
```math
\dot V(x)\leq-\alpha\|x\|^2,
```
即可得到局部或全局渐近稳定结论。但真实系统同时包含饱和、速率限制、摩擦迟滞、回差、柔性、延迟、丢包和模型失配，实际导数更接近
```math
\dot V\leq-\alpha\|x\|^2
+\beta\|d\|^2+\gamma\|\Delta\|^2,
```
其中 $`d`$ 汇总外部扰动， $`\Delta`$ 汇总模型与执行误差。此时工程目标往往从“误差趋于严格零”转变为输入到状态稳定、最终有界、约束不违反和故障后安全退化。

真实可用性需要同时管理性能包络与安全包络。对状态约束集合 $`\mathcal X`$ 、输入集合 $`\mathcal U`$ 和安全集合 $`\mathcal S`$ ，系统至少应保证在规定初始集、负载和环境条件下，闭环轨迹保持在 $`\mathcal S`$ 内，并尽可能满足 $`\mathcal X`$ 与 $`\mathcal U`$ 。仓储机器人靠近货架时，可将最大速度设计为定位协方差、制动距离和通信状态的函数；机械臂伸入货格时，可根据载荷估计、关节转矩余量和视觉新鲜度调整速度。安全监控器应独立检查关节限位、碰撞距离、命令超时和估计可信度，并可覆盖名义控制器。

从仿真到部署应采用逐级扩大能量与场景范围的验证阶梯：

1. 单元与模型测试，检查坐标、单位、约束和数值稳定性；
2. SIL 闭环回归，覆盖任务状态机和随机故障；
3. HIL 实时测试，验证时序、总线、驱动接口和失联行为；
4. 受限实机测试，从低速、轻载、空旷环境开始；
5. 压力与长时测试，覆盖热状态、磨损、网络抖动和任务恢复；
6. 现场部署监测，以日志、告警和回退策略限制未知风险。

每一级都应设定可量化准入条件，例如跟踪误差分位数、最小碰撞距离、最大电流、求解超时率、通信高分位延迟和任务失败后的安全停止时间。通过率不能只由平均性能决定，因为低概率的大冲击、长延迟或估计发散可能主导安全风险。测试场景还应覆盖模型边界附近，而不是只重复标称任务。

最终，真实系统可用并不意味着所有非理想都被精确建模，而是关键非理想已被观测、约束、验证并纳入降级路径。设计者需要明确哪些结论来自证明，哪些来自辨识，哪些只在经验包络内成立；同时让日志保留状态、输入、时间戳、饱和标志、估计不确定度和安全事件。这样，现场数据才能用于更新模型和风险边界，并与下一章的数据驱动建模连接，而不让学习模块替代物理约束、因果检查和系统级验证。

## 本章小结

本章把执行链中的非理想因素统一纳入状态空间、约束、概率和混杂系统框架。饱和与速率限制决定输入可行集；摩擦、回差和柔顺性改变从电机作用到机构运动的动力学；传感器与通信延迟改变信息对应的时间和闭环相位；模型失配则要求控制与估计结论始终附带适用域、不确定集和失效边界。它们不是部署阶段才出现的零散补丁，而应在规划、控制、估计和安全设计时共同考虑。

高保真仿真、SIL 与 HIL 构成逐层增加现实约束的验证链。域随机化扩展测试与训练分布，系统辨识则利用实机数据校正物理参数和不确定性范围。二者必须通过独立验证连接：随机化不能替代模型诊断，拟合精度也不能替代闭环安全测试。真正可部署的系统应具有明确的性能包络、可监测的异常指标、独立安全通道以及从正常运行到降速、停止和恢复的完整路径。

下一章将在这些接口之上讨论数据驱动建模与学习系统。这里形成的数据集不仅包含观测与动作，还应包含时间戳、参数版本、运行域、约束激活、延迟、置信度和失败标签；这里建立的物理模型、残差结构和安全边界，则为选择学习目标、构造损失函数、评估分布外风险和限制学习模块权限提供基础。
