自主系统的控制律通常依赖速度、角速度、负载、接触力或内部偏差等状态，但传感器只能直接测得其中一部分。状态观测的任务，是把模型、已知输入和输出历史结合起来，重建这些无法直接测量的内部变量。本章讨论确定性状态观测：先判断状态是否能够由输出唯一辨识，再构造具有确定误差动力学的观测器。

贯穿本章的例子是一台单关节机器人。关节角编码器给出角度 $`q`$ ，电机电流可换算为控制转矩 $`u`$ ，而角速度 $`\dot q`$ 、负载扰动 $`d`$ 和部分柔性效应不能直接测得。局部线性模型写为

```math
J\ddot q+b\dot q+kq=u+d,
```

其中 $`J>0`$ 为等效转动惯量， $`b\ge 0`$ 为黏性阻尼， $`k\ge 0`$ 为局部等效刚度。若先忽略扰动并令

```math
x=
\begin{bmatrix}
q\\
\dot q
\end{bmatrix},
```

则模型可写为标准状态空间形式

```math
\dot x=Ax+Bu,\qquad y=Cx+Du,
```

其中

```math
A=
\begin{bmatrix}
0&1\\
-k/J&-b/J
\end{bmatrix},
\quad
B=
\begin{bmatrix}
0\\
1/J
\end{bmatrix},
\quad
C=
\begin{bmatrix}
1&0
\end{bmatrix},
\quad D=0.
```

这里 $`x\in\mathbb R^2`$ 、 $`u\in\mathbb R`$ 、 $`y\in\mathbb R`$ 。后续各节将围绕这个模型讨论：只测角度时为什么仍可能获得速度信息、什么时候这种恢复从原理上不可能，以及如何把估计状态送入反馈控制器。

<a id="ch17-sec1"></a>
## 17.1 隐藏状态

状态（state）是这样一组最小内部变量：给定当前状态、未来输入和系统模型，便能够确定系统未来的理想演化。状态不等同于传感器读数，也不等同于所有物理量的罗列。对连续时间确定性系统

```math
\dot x=f(x,u),\qquad y=h(x,u),
```

状态为 $`x(t)\in\mathbb R^n`$ ，输入为 $`u(t)\in\mathbb R^m`$ ，输出为 $`y(t)\in\mathbb R^p`$ 。当状态的某些分量不直接出现在输出中，或者虽然出现在输出中却无法由传感器分别辨识时，这些分量就是隐藏状态。隐藏不表示“不重要”，而只表示“没有被直接、唯一地测量”。

单关节机器人中，编码器输出 $`y=q`$ ，因此角位置是直接测量量，而角速度 $`\dot q`$ 是隐藏状态。最简单的做法似乎是对角度作数值微分，但差分

```math
\dot q(t)\approx \frac{q(t)-q(t-\Delta t)}{\Delta t}
```

会把测量噪声同时放大约 $`1/\Delta t`$ 倍；减小采样周期虽然降低离散化偏差，却可能增大高频噪声。观测器则不把速度视为孤立的导数，而是利用动力学关系、历史测量和已知转矩共同推断速度。因此，“隐藏状态能否估计”首先是一个结构问题，其次才是滤波算法问题。

工程中还应区分状态、参数和外部输入。惯量 $`J`$ 通常是参数，外部碰撞转矩 $`d(t)`$ 通常是扰动输入；只有在为它们指定演化模型后，例如 $`\dot d=0`$ ，才能把它们扩展为状态。把任意未知量都称为状态并不会自动增加信息，反而可能使扩展模型不可观。状态选择还必须与时间尺度匹配：缓慢变化的载荷可近似为常值扩展状态，快速冲击则不能被同一假设准确描述。

<a id="ch17-sec2"></a>
## 17.2 输出中为什么包含状态信息

输出之所以能够携带隐藏状态信息，是因为内部状态会通过动力学传播到可测通道。对线性时不变系统

```math
\dot x=Ax+Bu,\qquad y=Cx+Du,
```

从初始时刻 $`t_0=0`$ 出发，其状态和输出为

```math
x(t)=e^{At}x(0)+\int_0^t e^{A(t-\tau)}Bu(\tau)\,\mathrm d\tau,
```

```math
y(t)=Ce^{At}x(0)
+\int_0^t Ce^{A(t-\tau)}Bu(\tau)\,\mathrm d\tau
+Du(t).
```

如果输入 $`u(t)`$ 已知，那么输出中由输入直接造成的部分可以根据模型计算；剩余项 $`Ce^{At}x(0)`$ 包含初始状态的信息。不同状态经 $`e^{At}`$ 演化后在输出端形成不同时间轨迹，这正是从输出历史反推状态的基础。

在理想光滑条件下，也可以从输出及其导数看出这种信息传播。若 $`D=0`$ ，则

```math
y=Cx,\qquad
\dot y=CAx+CBu,
```

```math
\ddot y=CA^2x+CABu+CB\dot u.
```

对机器人例子， $`y=q`$ ，因而理想情况下 $`\dot y=\dot q`$ 已直接包含隐藏速度。进一步有

```math
\ddot y=-\frac{k}{J}q-\frac{b}{J}\dot q+\frac{1}{J}u.
```

这说明角度输出随时间的变化形状同时受位置、速度和输入影响。观测器利用的不是某个时刻的一次测量，而是输出在时间上的连续约束。

不过，“输出包含信息”并不等于“直接求导就是好方法”。输出导数可能不存在、难以稳定计算，传感器噪声也会使高阶导数极不可靠。理论分析可使用导数揭示结构，工程实现则通常采用动态观测器递推地积累信息。此外，输入必须足够准确地已知；执行器饱和、死区和未建模延迟会使控制命令与实际作用量不同，从而被观测器误认为状态误差或外部扰动。

<a id="ch17-sec3"></a>
## 17.3 可观性（Observability）

可观性（observability）描述能否由有限时间区间内的已知输入和输出，唯一确定系统的初始状态。对连续时间线性时不变系统，如果任意两个不同初始状态 $`x_a(0)\ne x_b(0)`$ 在施加相同输入时都不可能产生完全相同的输出轨迹，则系统对 $`(A,C)`$ 是完全可观的。由于相同输入项会相消，该性质只由 $`A`$ 和 $`C`$ 决定，而与 $`B`$ 和具体输入值无关。

令状态差为 $`\delta x(0)=x_a(0)-x_b(0)`$ 。两个状态不可区分，当且仅当

```math
Ce^{At}\delta x(0)=0,\qquad \forall t\in[0,T].
```

若只有 $`\delta x(0)=0`$ 满足该条件，则初始状态可被唯一辨识。可观性因此是模型与传感器配置的联合性质，不是状态自身的属性。改变传感器位置、测量方向或输出组合，也就是改变 $`C`$ ，可能使同一个动力学模型从不可观变为可观。

非线性系统的可观性更复杂。对

```math
\dot x=f(x,u),\qquad y=h(x),
```

通常研究某个工作点附近的局部弱可观性。其判据涉及 $`h`$ 沿向量场 $`f`$ 的李导数（Lie derivative）：

```math
L_fh(x)=\frac{\partial h}{\partial x}f(x,u),
```

并检查 $`h,L_fh,L_f^2h,\ldots`$ 对状态的梯度是否在局部张成 $`n`$ 维空间。线性化模型可观是重要的局部指标，但不能保证大范围内不存在对称性或多解。例如只测距离的机器人可能在镜像位置产生相同输出，即使某一局部线性化看起来信息充分。

还要区分“可观”和“数值上容易观测”。理论上满秩的系统可能非常接近不可观，使微小噪声和参数误差导致巨大的状态估计误差。因此工程设计不仅要检查是或否，还要检查条件数、可观 Gramian 的特征值以及不同工作点下的变化。

<a id="ch17-sec4"></a>
## 17.4 可观性矩阵

对 $`n`$ 维连续时间线性时不变系统，可观性矩阵定义为

```math
\mathcal O=
\begin{bmatrix}
C\\
CA\\
CA^2\\
\vdots\\
CA^{n-1}
\end{bmatrix}
\in\mathbb R^{np\times n}.
```

系统完全可观的充要条件是

```math
\mathrm{rank}(\mathcal O)=n.
```

该矩阵对应于输出及其前若干阶导数对状态的线性约束。根据 Cayley–Hamilton 定理， $`A`$ 的 $`n`$ 次及更高次幂都可由低阶幂表示，因此检查到 $`CA^{n-1}`$ 已足够。离散时间系统

```math
x_{k+1}=A_dx_k+B_du_k,\qquad y_k=C_dx_k+D_du_k
```

具有同样形式的可观性矩阵，只需把 $`A,C`$ 替换为 $`A_d,C_d`$ 。

对单关节机器人，

```math
\mathcal O=
\begin{bmatrix}
C\\
CA
\end{bmatrix}
=
\begin{bmatrix}
1&0\\
0&1
\end{bmatrix}.
```

因此只测角度也足以观测角度和角速度。注意，这一结论依赖于动态模型中 $`\dot q`$ 对 $`q`$ 的时间变化产生作用。若输出是与某个内部模态完全解耦的量，相应列可能永远无法进入输出导数，可观性矩阵便会降秩。

另一个等价工具是 Popov–Belevitch–Hautus 判据，即对 $`A`$ 的每个特征值 $`\lambda`$ ，都满足

```math
\mathrm{rank}
\begin{bmatrix}
\lambda I-A\\
C
\end{bmatrix}
=n.
```

该判据直接回答某个模态是否能被传感器看到。有限时间可观 Gramian 则定义为

```math
W_o(T)=\int_0^T e^{A^\mathsf Tt}C^\mathsf TC e^{At}\,\mathrm dt.
```

若 $`W_o(T)`$ 正定，则系统在该区间可观，并且状态方向 $`v`$ 在输出中产生的能量为 $`v^\mathsf TW_o(T)v`$ 。很小的最小特征值表示某些状态方向虽然理论可观，但信号极弱。实际计算时不应仅凭浮点矩阵的“精确秩”下结论，还应进行状态量纲缩放，并检查奇异值及其对参数变化的敏感性。

<a id="ch17-sec5"></a>
## 17.5 不可观意味着什么

不可观意味着存在非零状态方向 $`v\ne 0`$ ，使得

```math
CA^kv=0,\qquad k=0,1,\ldots,n-1.
```

沿这个方向改变初始状态不会改变任何理想输出轨迹。此时无论算法多复杂、计算能力多强，都不能仅由现有输入输出唯一恢复该状态；这是信息缺失，而不是优化器或滤波器性能不足。增加采样频率也无法创造原本不存在的状态—输出耦合。

通过相似变换 $`x=T[\;x_o^\mathsfT\;x_u^\mathsfT\;]^\mathsfT`$ ，系统可写成可观分解形式

```math
\begin{bmatrix}
\dot x_o\\
\dot x_u
\end{bmatrix}
=
\begin{bmatrix}
A_o&0\\
A_{21}&A_u
\end{bmatrix}
\begin{bmatrix}
x_o\\
x_u
\end{bmatrix}
+
\begin{bmatrix}
B_o\\
B_u
\end{bmatrix}u,
\qquad
y=
\begin{bmatrix}
C_o&0
\end{bmatrix}
\begin{bmatrix}
x_o\\
x_u
\end{bmatrix}.
```

其中 $`x_o`$ 为可观部分， $`x_u`$ 为不可观部分。输出完全不依赖 $`x_u`$ ，因此任何基于输出残差的校正都无法修正其初值误差。若 $`A_u`$ 的全部模态稳定，则系统称为可检测（detectable）：不可观状态不能精确重建，但其误差会自行衰减，仍可构造渐近稳定观测器。若不可观模态不稳定，则估计误差可能无限增长。

机器人上的典型误区是同时估计多个具有相同输出效应的未知量。例如在静态或低加速度阶段，未知重力参数、常值负载转矩和电流零偏都可能表现为同一个等效转矩。仅凭关节角和电流，三者通常不能被分别辨识；观测器最多估计它们的组合。解决办法不是盲目提高观测器增益，而是增加独立传感器、改变运动以产生可区分的动态特征、减少扩展状态数量，或为部分未知量引入可靠先验。

不可观还可能只出现在特定工作点。例如机械臂处于某些几何奇异姿态时，不同关节运动在末端传感器上产生相同瞬时效果。因而传感器配置与轨迹设计需要覆盖实际运行区域，而不能只在单个标称点检查秩。

<a id="ch17-sec6"></a>
## 17.6 Luenberger Observer

Luenberger 观测器（Luenberger observer）是线性确定性状态观测的基本结构。对

```math
\dot x=Ax+Bu,\qquad y=Cx+Du,
```

构造

```math
\dot{\hat x}
=A\hat x+Bu
+L\bigl(y-C\hat x-Du\bigr),
```

其中 $`\hat x\in\mathbb R^n`$ 为状态估计， $`L\in\mathbb R^{n\times p}`$ 为观测器增益，括号中的量

```math
r_y=y-\hat y=y-C\hat x-Du
```

称为输出残差或创新残差。模型预测项 $`A\hat x+Bu`$ 根据动力学推进估计，校正项 $`Lr_y`$ 则用实际输出修正预测。若残差为零，观测器按模型自由演化；若残差不为零，修正方向和强度由 $`L`$ 决定。

单关节机器人只测角度时，可令

```math
L=
\begin{bmatrix}
l_1\\
l_2
\end{bmatrix}.
```

观测器方程为

```math
\dot{\hat q}
=\widehat{\dot q}+l_1(q-\hat q),
```

```math
\widehat{\ddot q}
=-\frac{k}{J}\hat q-\frac{b}{J}\widehat{\dot q}
+\frac{1}{J}u+l_2(q-\hat q).
```

第一式利用角度误差校正位置估计，第二式把同一残差注入速度动力学。与直接差分相比，它显式使用了惯量、阻尼、刚度和输入转矩的信息，并允许通过 $`l_1,l_2`$ 调整收敛速度。

离散实现不能简单忽略采样。若采用精确离散模型

```math
x_{k+1}=A_dx_k+B_du_k,
```

则常用预测—校正形式为

```math
\hat x_{k+1}
=A_d\hat x_k+B_du_k
+L_d(y_k-C_d\hat x_k-D_du_k).
```

$`L_d`$ 的单位和数值不能直接照搬连续时间增益。还应明确测量、控制和状态更新时间戳；一个采样周期的延迟会改变误差动力学，严重时可使原本稳定的观测器失稳。

<a id="ch17-sec7"></a>
## 17.7 估计误差动力学

定义估计误差

```math
e=x-\hat x.
```

将被观测系统与 Luenberger 观测器相减，可得理想误差动力学

```math
\dot e=(A-LC)e.
```

因此，只要矩阵 $`A-LC`$ 是 Hurwitz 矩阵，即全部特征值实部严格为负，估计误差就会渐近收敛到零。这个结论与具体输入 $`u`$ 无关，因为真实系统和观测器使用相同的已知输入，输入项在相减时抵消。

实际系统可写为

```math
\dot x=Ax+Bu+Ew,\qquad
y=Cx+Du+v,
```

其中 $`w\in\mathbb R^r`$ 表示过程扰动和模型误差， $`E\in\mathbb R^{n\times r}`$ 为其作用矩阵， $`v\in\mathbb R^p`$ 为测量噪声。此时

```math
\dot e=(A-LC)e+Ew-Lv.
```

增大 $`L`$ 往往能提高初始误差和低频模型偏差的衰减速度，却会通过 $`-Lv`$ 更强地注入测量噪声。这是确定性观测器中的核心折中：快速不等于准确，高带宽也不等于高质量。

若存在正定矩阵 $`P=P^\mathsf T>0`$ 和 $`Q=Q^\mathsf T>0`$ ，满足

```math
(A-LC)^\mathsf TP+P(A-LC)=-Q,
```

则以 $`V=e^\mathsf TPe`$ 为 Lyapunov 函数，可以证明无扰动时误差指数收敛；有界 $`w,v`$ 存在时，误差收敛到与扰动幅值和增益有关的有界邻域。该结论提醒我们，观测器并不会消除噪声，只会塑造噪声到估计误差的传递特性。

残差也不应被误读为纯传感器噪声。模型参数错误、执行器未实现的命令、时间同步偏差、外部碰撞和传感器故障都可能进入残差。残差长期非零通常意味着模型—系统不一致，但单个残差信号未必足以区分其来源。

<a id="ch17-sec8"></a>
## 17.8 观测器极点配置

当 $`(A,C)`$ 完全可观时，可以任意配置 $`A-LC`$ 的特征值。该问题与状态反馈极点配置互为对偶： $`(A,C)`$ 可观等价于 $`(A^\mathsf T,C^\mathsf T)`$ 可控，因此可先为对偶系统计算反馈增益，再取转置得到 $`L`$ 。若系统仅可检测，则只能配置可观部分的极点，而不可观稳定模态保持不变。

考虑近似模型

```math
A=
\begin{bmatrix}
0&1\\
0&-a
\end{bmatrix},
\qquad
C=
\begin{bmatrix}
1&0
\end{bmatrix},
\qquad
L=
\begin{bmatrix}
l_1\\
l_2
\end{bmatrix},
```

其中 $`a=b/J\ge 0`$ 。误差矩阵为

```math
A-LC=
\begin{bmatrix}
-l_1&1\\
-l_2&-a
\end{bmatrix},
```

其特征多项式为

```math
s^2+(a+l_1)s+(al_1+l_2).
```

若期望观测器极点为 $`-p_1,-p_2`$ ，其中 $`p_1,p_2>0`$ ，则令

```math
l_1=p_1+p_2-a,
\qquad
l_2=p_1p_2-al_1.
```

这给出了极点位置与残差注入增益之间的直接关系。

常见经验是让观测器带宽高于闭环控制带宽，但不能机械地规定“快若干倍”。极点过慢会使状态反馈长期使用错误状态；极点过快则会放大编码器量化、结构振动和未建模高频动态。机器人存在柔性模态时，刚体观测器带宽若超过第一个未建模共振频率，估计速度可能包含明显振荡，进而经控制器放大。

离散时间极点必须位于单位圆内。连续极点 $`\lambda_c`$ 在零阶保持、采样周期 $`T_s`$ 下大致映射为

```math
\lambda_d=e^{\lambda_cT_s}.
```

直接把连续极点数值用作离散极点是错误的。极点配置完成后，还应在噪声、参数摄动、采样抖动和执行器饱和条件下验证，而不能只检查名义特征值。

<a id="ch17-sec9"></a>
## 17.9 Disturbance Observer

扰动观测器（disturbance observer，DOB）用于估计作用在系统输入端或等效输入端的未知扰动。设单输入单输出名义对象为 $`P_n(s)`$ ，实际输出近似满足

```math
y(s)=P_n(s)\bigl(u(s)+d(s)\bigr),
```

其中 $`d(s)`$ 是输入等效扰动。若 $`P_n^{-1}(s)`$ 可实现，则形式上有

```math
d(s)=P_n^{-1}(s)y(s)-u(s).
```

经典 DOB 通过低通滤波器 $`Q(s)`$ 构造

```math
\hat d(s)=Q(s)\left[P_n^{-1}(s)y(s)-u(s)\right].
```

$`Q(s)`$ 在低频区域接近 $`1`$ ，使缓慢扰动能够被恢复；在高频区域衰减，以避免逆模型放大噪声和未建模动态。控制器可使用补偿 $`u=u_c-\hat d`$ ，从而在名义带宽内抵消扰动。

在单关节机器人中，可把摩擦、负载变化和接触力矩合并为等效扰动 $`d`$ 。由动力学

```math
d=J\ddot q+b\dot q+kq-u
```

可见，直接计算需要速度和加速度，而这两者对噪声敏感。DOB 的本质不是无代价地求得真实扰动，而是利用名义动力学和带宽受限的逆模型，获得某个频段内的等效扰动估计。它适合碰撞检测、摩擦补偿和负载抑制，但估计量通常不能被直接解释为唯一的物理来源。

DOB 的边界来自逆模型。若名义对象含非最小相位零点、纯延迟或相对阶次过高，其精确逆可能不稳定或不适定，必须采用稳定近似逆，并由 $`Q`$ 限制带宽。模型不确定性也会被映射为“扰动”；因此 DOB 能增强鲁棒性，却不能证明估计出的每一牛顿米都来自外部接触。传感器噪声、控制输入时间戳错误和执行器死区同样会污染 $`\hat d`$ 。

<a id="ch17-sec10"></a>
## 17.10 Extended State Observer

扩张状态观测器（extended state observer，ESO）把未知内部动力学、参数误差和外部扰动合并为“总扰动”，并把它作为附加状态在线估计。对单关节机器人，可在局部写成

```math
\ddot q=b_0u+f,
```

其中 $`b_0`$ 是已知的名义输入增益，单位为 $`(\mathrm{rad/s^2})/(\mathrm{N\,m})`$ ；总扰动

```math
f=
-\frac{k}{J}q-\frac{b}{J}\dot q
+\left(\frac{1}{J}-b_0\right)u
+\frac{d}{J}
```

合并了已知结构、参数误差和外部扰动。令

```math
x_1=q,\qquad x_2=\dot q,\qquad x_3=f,
```

并假设 $`\dot f`$ 有界，则扩张模型为

```math
\dot x_1=x_2,\qquad
\dot x_2=x_3+b_0u,\qquad
\dot x_3=\dot f,\qquad
y=x_1.
```

一个三阶线性 ESO 可写为

```math
\dot z_1=z_2+\beta_1(y-z_1),
```

```math
\dot z_2=z_3+b_0u+\beta_2(y-z_1),
```

```math
\dot z_3=\beta_3(y-z_1),
```

其中 $`z_1,z_2,z_3`$ 分别估计位置、速度和总扰动。若希望名义误差特征多项式为 $`(s+\omega_o)^3`$ ，则可选

```math
\beta_1=3\omega_o,\qquad
\beta_2=3\omega_o^2,\qquad
\beta_3=\omega_o^3,
```

其中 $`\omega_o>0`$ 为观测器带宽。估计到 $`z_3`$ 后，可使用

```math
u=\frac{u_0-z_3}{b_0}
```

进行总扰动补偿，其中 $`u_0`$ 是由期望闭环动力学产生的名义控制量。

ESO 与经典 DOB 相关但不能混为一类。DOB 通常从名义输入—输出对象及其滤波逆出发，强调某一频带内的等效输入扰动；ESO 则显式增加状态，并通过输出误差同时估计原状态和总扰动。两者都依赖模型、带宽和扰动正则性，不是“无模型”方法。

ESO 的关键假设是总扰动在观测器时间尺度内足够平滑，至少其导数有界。冲击、剧烈摩擦切换和高频柔性振动会破坏该假设。增大 $`\omega_o`$ 可缩短跟踪滞后，却会迅速放大测量噪声，因为各增益分别按 $`\omega_o,\omega_o^2,\omega_o^3`$ 增长。此外，若 $`b_0`$ 符号错误或接近零，补偿方向可能错误；若执行器饱和而观测器仍使用未饱和命令，ESO 还会把输入实现误差吸收到总扰动中，造成估计偏置甚至补偿振荡。

<a id="ch17-sec11"></a>
## 17.11 状态观测如何连接状态反馈

状态反馈控制器通常假定完整状态可用，例如

```math
u=-Kx+Nr,
```

其中 $`K\in\mathbb R^{m\times n}`$ 为反馈增益， $`r`$ 为参考输入， $`N`$ 为参考前馈矩阵。实际系统只能使用估计状态，于是实现为

```math
u=-K\hat x+Nr.
```

由于 $`\hat x=x-e`$ ，控制输入也可写为

```math
u=-Kx+Ke+Nr.
```

因此估计误差通过 $`Ke`$ 进入控制通道。状态估计不是控制器之外的附属模块，而是闭环系统的一部分：噪声引起的速度估计抖动会转化为转矩抖动，扰动估计偏差会转化为补偿误差。

忽略参考项时，闭环系统与观测误差的联合动力学为

```math
\begin{bmatrix}
\dot x\\
\dot e
\end{bmatrix}
=
\begin{bmatrix}
A-BK&BK\\
0&A-LC
\end{bmatrix}
\begin{bmatrix}
x\\
e
\end{bmatrix}.
```

该矩阵为分块上三角矩阵，其特征值等于 $`A-BK`$ 与 $`A-LC`$ 的特征值并集。这就是线性系统的分离原理（separation principle）：若 $`(A,B)`$ 可控或至少可稳定，且 $`(A,C)`$ 可观或至少可检测，则可以分别设计状态反馈增益 $`K`$ 和观测器增益 $`L`$ ，名义组合系统仍然稳定。

分离原理不意味着控制器和观测器可以在工程上互不关心。它依赖线性、模型一致、无饱和等理想条件；当存在执行器限幅、时延、非线性、增益调度和强噪声时，两者的动态会通过非理想环节耦合。对机器人而言，观测器过快可能把编码器噪声送入大反馈增益，观测器过慢又可能使控制器在快速运动中使用滞后的速度。设计时应同时检查估计带宽、控制带宽、结构共振、采样频率和执行器能力。

贯穿本章的单关节机器人可以形成一条完整实现链：编码器测量 $`q`$ ，Luenberger 观测器估计 $`\dot q`$ ，状态反馈产生名义转矩；若负载变化显著，再由 DOB 或 ESO 估计等效扰动并作带宽受限的补偿。每增加一个估计量，都应重新检查可观性、噪声敏感度和闭环稳定裕度，而不是把观测器输出无条件视为真实状态。

## 本章小结

本章从隐藏状态出发，说明了输出历史为什么能够携带内部状态信息。可观性回答“能否唯一恢复”的结构问题；可观性矩阵、PBH 判据和可观 Gramian分别提供秩、模态和数值强弱三个视角。不可观不是算法不够复杂，而是现有模型与传感器不能区分某些状态方向；若不可观模态稳定，系统仍可能可检测。

在结构条件满足后，Luenberger 观测器通过“模型预测加输出残差校正”构造状态估计，其核心是误差动力学

```math
\dot e=(A-LC)e.
```

观测器极点决定名义收敛速度，但增益越大，测量噪声和未建模高频动态的影响通常也越强。扰动存在时，误差动力学变为

```math
\dot e=(A-LC)e+Ew-Lv,
```

因此实际设计必须在收敛、噪声、模型不确定性和采样约束之间折中。

DOB 与 ESO 都能估计等效扰动，但前者通常基于名义对象的滤波逆，后者通过扩张状态估计总扰动。两者都不能凭空区分具有相同输出效应的物理来源。最后，估计状态通过状态反馈进入控制系统；在线性名义条件下，分离原理允许分别配置控制器和观测器极点，但真实自主系统仍需进行联合带宽与鲁棒性验证。下一章将在这里建立的确定性观测框架上，进一步处理噪声、不确定性以及估计可信度的定量表达。
