状态估计要回答的不是“传感器读到了什么”，而是“结合动力学、历史信息与当前观测，系统状态最可能是什么，以及这个判断有多可靠”。在概率语言中，目标是递推计算后验分布：

```math
p(x_k\mid z_{1:k},u_{0:k-1}),
```

其中 $`x_k\in\mathbb R^n`$ 是时刻 $`k`$ 的状态， $`z_{1:k}`$ 表示截至当前的全部观测， $`u_{0:k-1}`$ 表示已执行的控制输入。卡尔曼滤波（Kalman Filter, KF）在线性 Gaussian 条件下给出这一分布的精确递推；扩展卡尔曼滤波、无迹卡尔曼滤波和粒子滤波则以不同方式处理非线性或非 Gaussian 情形。

本章贯穿使用一台仓储移动机器人作为例子。机器人依靠轮速计和运动模型预测自身运动，并融合 UWB、相机或激光雷达观测来估计位置、速度和朝向。这个例子会从二维匀速线性模型逐步扩展到非线性运动、距离—方位观测、多峰定位假设，从而说明不同估计方法并不是彼此替代的“算法菜单”，而是建立在不同假设上的概率近似。

<a id="ch19-sec1"></a>
## 19.1 线性 Gaussian 状态空间模型

离散线性 Gaussian 状态空间模型写成：

```math
x_k=F_{k-1}x_{k-1}+B_{k-1}u_{k-1}+G_{k-1}w_{k-1},
```

```math
z_k=H_kx_k+v_k.
```

其中 $`F_{k-1}\in\mathbb R^{n\times n}`$ 是状态转移矩阵， $`B_{k-1}\in\mathbb R^{n\times m}`$ 将控制输入 $`u_{k-1}\in\mathbb R^m`$ 映射到状态， $`G_{k-1}\in\mathbb R^{n\times q}`$ 将过程噪声 $`w_{k-1}\in\mathbb R^q`$ 映射到状态空间， $`H_k\in\mathbb R^{r\times n}`$ 将状态映射为 $`r`$ 维观测。标准假设为：

```math
w_{k-1}\sim\mathcal N(0,Q_{k-1}),\qquad
v_k\sim\mathcal N(0,R_k),
```

并且过程噪声、测量噪声和初始状态误差相互独立。这里 $`Q_{k-1}\in\mathbb R^{q\times q}`$ 、 $`R_k\in\mathbb R^{r\times r}`$ 均为半正定协方差矩阵；若直接把状态空间噪声写成 $`x_k=F x_{k-1}+Bu+w_k`$ ，则 $`G=I`$ 且 $`Q`$ 为 $`n\times n`$ 。

对移动机器人采用状态

```math
x_k=
\begin{bmatrix}
p_{x,k}&v_{x,k}&p_{y,k}&v_{y,k}
\end{bmatrix}^T\in\mathbb R^4,
```

在采样周期 $`\Delta t`$ 内使用二维匀速模型：

```math
F=
\begin{bmatrix}
1&\Delta t&0&0\\
0&1&0&0\\
0&0&1&\Delta t\\
0&0&0&1
\end{bmatrix}.
```

若 UWB 直接给出平面位置 $`z_k=[z_{x,k},z_{y,k}]^T`$ ，则

```math
H=
\begin{bmatrix}
1&0&0&0\\
0&0&1&0
\end{bmatrix}.
```

模型称为“线性 Gaussian”，是因为状态转移和测量函数对状态为线性映射，所有不确定性均由 Gaussian 分布表示。在这些假设下，只需维护均值与协方差，就能完整表示后验分布：

```math
p(x_k\mid z_{1:k})=\mathcal N(\hat x_{k|k},P_{k|k}).
```

需要注意，“传感器误差直方图看起来近似钟形”并不足以保证整个模型成立。未建模偏置、时间延迟、坐标系错误、数据关联错误和离群点，都可能使噪声具有非零均值、时间相关性或重尾特征。卡尔曼滤波的递推公式不会因此停止运行，但输出的协方差可能不再具有可信的概率含义。

## 19.2 状态预测

状态预测把上一时刻的后验均值推进到当前时刻，形成测量到达前的先验均值：

```math
\hat x_{k|k-1}
=
F_{k-1}\hat x_{k-1|k-1}
+
B_{k-1}u_{k-1}.
```

下标 $`k|k-1`$ 表示“使用截至 $`k-1`$ 时刻的信息估计 $`k`$ 时刻状态”，而 $`k|k`$ 表示融合当前测量后的后验估计。由于假设过程噪声均值为零， $`G_{k-1}w_{k-1}`$ 不直接出现在均值预测中；它的影响进入协方差传播。

对仓储机器人而言，匀速预测为：

```math
\hat p_{x,k|k-1}
=
\hat p_{x,k-1|k-1}
+
\Delta t\,\hat v_{x,k-1|k-1},
```

```math
\hat v_{x,k|k-1}=\hat v_{x,k-1|k-1},
```

$`y`$ 方向同理。若控制器给出已知加速度 $`a_x,a_y`$ ，则可加入

```math
B=
\begin{bmatrix}
\frac12\Delta t^2&0\\
\Delta t&0\\
0&\frac12\Delta t^2\\
0&\Delta t
\end{bmatrix},
\qquad
u=
\begin{bmatrix}a_x\\a_y\end{bmatrix}.
```

这里“已知输入”与“过程噪声”必须区分：前者是滤波器可获得的命令或测量，后者表示未被输入和模型解释的随机变化。

预测不是简单地把上一帧数值复制到下一帧。它编码了系统对时间的理解，因此采样周期、输入时间戳和离散化方式都属于模型的一部分。若传感器以不同频率异步工作，预测应推进到每条观测自己的时间戳，而不是假定所有数据同时到达。高动态系统中，使用错误的 $`\Delta t`$ 往往会被误判为“噪声参数没有调好”。

另一个常见误区是把控制命令视为机器人实际执行的运动。轮胎打滑、电机饱和、地面碰撞等都会造成命令与真实运动不一致。工程上应把这类不确定性反映到过程模型和 $`Q`$ 中，必要时将轮速比例因子、陀螺仪偏置等慢变量增广为状态，而不是强迫状态预测完全跟随命令。

<a id="ch19-sec3"></a>
## 19.3 协方差传播

预测均值描述状态中心如何移动，协方差传播则描述不确定性如何随动力学变化。线性模型下：

```math
P_{k|k-1}
=
F_{k-1}P_{k-1|k-1}F_{k-1}^T
+
G_{k-1}Q_{k-1}G_{k-1}^T.
```

其中 $`P_{k|k-1}\in\mathbb R^{n\times n}`$ 。第一项把已有不确定性经过动力学映射到下一时刻，第二项加入本时间段新产生的过程不确定性。即使均值预测完全确定，未知扰动仍会使预测分布逐渐扩散。

协方差的非对角元素同样重要。以一维状态 $`[p,v]^T`$ 为例，位置由速度积分得到，因此经过预测后，位置误差与速度误差通常相关：

```math
P=
\begin{bmatrix}
\sigma_p^2&\operatorname{cov}(p,v)\\
\operatorname{cov}(v,p)&\sigma_v^2
\end{bmatrix}.
```

一次位置测量不仅会修正位置，也可能通过这一相关性修正速度。若人为把非对角元素清零，滤波器就丢失了这种跨状态的信息传递能力。

假设每个采样区间内存在方差为 $`\sigma_a^2`$ 的随机常加速度，则一维过程噪声协方差可写为：

```math
Q_{\text{state}}
=
\sigma_a^2
\begin{bmatrix}
\frac{\Delta t^4}{4}&\frac{\Delta t^3}{2}\\
\frac{\Delta t^3}{2}&\Delta t^2
\end{bmatrix}.
```

二维情况下可对 $`x`$ 、 $`y`$ 方向构造相应块矩阵。这一公式对应“区间内随机加速度保持不变”的离散假设；若从连续时间白噪声严格离散化，矩阵中的时间幂系数会不同。工程实现不能只复制矩阵形式而忽略其噪声模型和单位。

有限精度计算可能使 $`P`$ 逐渐失去对称性，通常可在必要时执行 $`P\leftarrow(P+P^T)/2`$ 。但若出现明显负特征值，不能只靠截断掩盖问题，还应检查离散化、矩阵维度、更新公式和数值条件。平方根滤波通过传播协方差的 Cholesky 因子提高数值稳定性，适合状态尺度差异大或运行时间很长的系统。

<a id="ch19-sec4"></a>
## 19.4 Innovation

测量到达后，首先比较实际测量与预测测量。二者之差称为新息（Innovation）或测量残差：

```math
\tilde y_k
=
z_k-H_k\hat x_{k|k-1}.
```

它不是“测量减去上一时刻状态”，而是“当前测量减去当前预测测量”。对于非线性角度观测，新息还必须映射回正确的角度区间，例如将方位角残差归一化到 $`(-\pi,\pi]`$ 。

新息协方差为：

```math
S_k
=
H_kP_{k|k-1}H_k^T+R_k,
```

其中 $`S_k\in\mathbb R^{r\times r}`$ 。第一项表示由状态不确定性造成的预测测量不确定性，第二项表示传感器自身噪声。因此同样大小的残差，在高精度测量中可能异常，在高噪声测量中则可能完全合理。

归一化新息平方（Normalized Innovation Squared, NIS）定义为：

```math
\epsilon_k
=
\tilde y_k^TS_k^{-1}\tilde y_k.
```

若模型正确且测量维度为 $`r`$ ，则 $`\epsilon_k`$ 服从自由度为 $`r`$ 的卡方分布。工程上可依据卡方阈值进行创新门控（innovation gating）：若某次 UWB 测量与预测严重不一致，则暂不更新、采用鲁棒似然，或触发数据关联检查。门控不能被理解为“凡是不喜欢的测量都删掉”；连续拒绝测量也可能意味着机器人已被碰撞移动、滤波器初始化错误或模型发生切换。

新息序列还是诊断滤波器的重要信号。理想情况下，其均值应接近零，并且除模型允许的相关性外不应长期呈现结构化趋势。持续同号残差常指向偏置或坐标变换错误；周期性残差可能来自时间同步问题；新息明显大于 $`S_k`$ 所预测的范围，则说明 $`Q`$ 、 $`R`$ 或动力学模型过于乐观。

## 19.5 Kalman Gain

卡尔曼增益（Kalman Gain）决定新息应以多大比例反馈到状态：

```math
K_k
=
P_{k|k-1}H_k^TS_k^{-1}.
```

其维度为 $`K_k\in\mathbb R^{n\times r}`$ ，将 $`r`$ 维测量残差映射为 $`n`$ 维状态修正。矩阵 $`P_{k|k-1}H_k^T`$ 是状态误差与预测测量误差之间的交叉协方差，因此卡尔曼增益并非简单的标量“滤波系数”，而是描述每个测量分量应如何影响每个状态分量。

从最小均方误差角度看，设更新采用线性形式

```math
\hat x_{k|k}
=
\hat x_{k|k-1}+K_k\tilde y_k,
```

选择使后验误差协方差迹最小的 $`K_k`$ ，即可得到上述公式。它也等价于在线性 Gaussian 条件下对先验与测量似然进行精确 Bayesian 融合。 $`P`$ 较大而 $`R`$ 较小时，增益通常更偏向测量； $`P`$ 较小而 $`R`$ 较大时，滤波器更依赖预测。但在多维情况下，这种直觉必须结合方向和相关性理解，不能逐元素比较两个矩阵。

对仓储机器人，UWB 只直接测量位置，但 $`K_k`$ 的速度行通常并不为零。原因是预测协方差中已经形成位置—速度相关性，所以位置新息可以修正速度估计。反之，某个状态方向若既不被 $`H`$ 直接观测，也未通过动力学与可观测状态建立相关性，则对应增益长期接近零；这反映的是可观性问题，不能通过盲目增大增益解决。

实现时不应显式计算 $`S_k^{-1}`$ 。更稳定的做法是通过 Cholesky 分解或线性方程求解计算 $`K_kS_k=P_{k|k-1}H_k^T`$ 。若 $`S_k`$ 奇异或病态，应检查是否加入了重复测量、 $`R_k`$ 是否不合理地设为零，以及观测维度之间是否存在线性依赖。

## 19.6 Measurement Update

测量更新（Measurement Update）使用卡尔曼增益修正先验均值：

```math
\hat x_{k|k}
=
\hat x_{k|k-1}
+
K_k\tilde y_k.
```

对应的理想协方差更新可写为：

```math
P_{k|k}
=
(I-K_kH_k)P_{k|k-1}.
```

更新后的协方差通常不大于预测协方差，表示有效观测减少了不确定性。但这里的“减少”是半正定意义上的方向性收缩，不意味着每个矩阵元素都必须数值下降。

有限精度计算中，更推荐 Joseph 形式：

```math
P_{k|k}
=
(I-K_kH_k)P_{k|k-1}(I-K_kH_k)^T
+
K_kR_kK_k^T.
```

它与理想公式在精确算术下等价，但更容易保持对称性和半正定性。如果测量噪声与预测状态误差相关，则上述标准公式不再直接成立，必须在交叉协方差中显式包含相关项；简单地把相关传感器当作独立测量连续更新，会导致重复计算信息和协方差过度收缩。

完整的卡尔曼滤波循环可概括为：

1. 根据动力学计算 $`\hat x_{k|k-1}`$ ；
2. 传播 $`P_{k|k-1}`$ ；
3. 计算新息 $`\tilde y_k`$ 和新息协方差 $`S_k`$ ；
4. 进行门控或数据有效性检查；
5. 计算 $`K_k`$ ；
6. 更新 $`\hat x_{k|k}`$ 与 $`P_{k|k}`$ 。

多传感器异步融合时，每条测量可在其时间戳处独立执行更新。若测量延迟到达，则需要保存历史状态并重放后续预测，或采用固定滞后平滑等方法。把迟到的测量直接应用到“现在”的状态上，会造成时间不一致，而这种错误通常无法通过调整 $`R`$ 修复。

滤波（filtering）只利用当前及过去信息，平滑（smoothing）则允许未来观测修正历史状态。在线控制通常需要滤波结果，离线建图、标定和轨迹重建则常从平滑中获益。二者不可混用：一个利用未来数据得到的平滑轨迹，不能作为实时算法性能的证据。

<a id="ch19-sec7"></a>
## 19.7 Q 与 R

$`Q`$ 与 $`R`$ 不是两个抽象的“调参旋钮”。 $`Q`$ 描述模型在一个传播区间内遗漏了多少随机变化， $`R`$ 描述测量在给定真实状态时具有多少不确定性。它们的元素具有具体单位：若位置以米表示，则位置方差单位为 $`\mathrm m^2`$ ；速度方差单位为 $`\mathrm m^2/\mathrm s^2`$ ；位置—速度协方差单位为 $`\mathrm m^2/\mathrm s`$ 。忽略量纲会产生表面可运行、实际不可解释的参数。

$`R`$ 可通过静态或受控实验估计。传感器在已知真值附近重复采样时，可计算误差样本协方差：

```math
\hat R
=
\frac{1}{N-1}
\sum_{i=1}^{N}
(e_i-\bar e)(e_i-\bar e)^T.
```

但静态噪声不一定代表动态场景：UWB 会受遮挡和多径影响，相机误差取决于纹理和特征几何，激光匹配误差也可能随环境退化。因此实际系统常使用随测量质量变化的 $`R_k`$ ，但这个变化必须有传感器质量指标或统计模型支撑。

$`Q`$ 往往更难直接测量，因为它包含未建模加速度、参数误差、执行器扰动和离散化误差。可先从物理扰动模型构造，再通过新息统计验证。若实际新息长期大于预测范围，可能需要增大 $`Q`$ 或 $`R`$ ，但二者含义不同：增大 $`Q`$ 表示降低对动力学预测的信任，增大 $`R`$ 表示降低对测量的信任。只观察轨迹“平不平滑”无法唯一判断应修改哪一个。

参数设置还应遵守以下边界：

- 不应把未知常值偏置仅当作白噪声处理；更合理的方式通常是增广偏置状态，例如 $`b_{k+1}=b_k+\eta_k`$ 。
- 不能为了让输出更平滑而任意减小 $`Q`$ 。这样会使滤波器协方差过小，在真实机动发生时反应迟缓。
- 不能为了强迫状态贴合测量而把 $`R`$ 设得接近零。数据关联错误或单次离群点会因此造成灾难性跳变。
- 若噪声随时间相关，白噪声假设被破坏；可以建立有色噪声模型、增广状态，或采用更适合的鲁棒估计方法。

有真值数据时，可使用归一化估计误差平方（Normalized Estimation Error Squared, NEES）：

```math
\xi_k
=
(x_k-\hat x_{k|k})^TP_{k|k}^{-1}(x_k-\hat x_{k|k})
```

检验一致性。NIS 不需要真实状态，适合在线监测；NEES 需要真值，适合仿真和标定。二者检验的是“误差是否与滤波器宣称的不确定性一致”，而不仅是均方误差是否较小。

<a id="ch19-sec8"></a>
## 19.8 Extended Kalman Filter

扩展卡尔曼滤波（Extended Kalman Filter, EKF）处理非线性状态空间模型：

```math
x_k=f(x_{k-1},u_{k-1})+w_{k-1},
```

```math
z_k=h(x_k)+v_k.
```

对加性零均值噪声，均值预测直接通过非线性函数：

```math
\hat x_{k|k-1}
=
f(\hat x_{k-1|k-1},u_{k-1}),
```

然后在当前估计附近计算 Jacobian：

```math
F_{k-1}
=
\left.
\frac{\partial f}{\partial x}
\right|_{\hat x_{k-1|k-1},u_{k-1}},
\qquad
H_k
=
\left.
\frac{\partial h}{\partial x}
\right|_{\hat x_{k|k-1}}.
```

协方差、增益与更新公式保持与线性滤波器相同的结构，只是使用局部线性化矩阵：

```math
P_{k|k-1}=F_{k-1}P_{k-1|k-1}F_{k-1}^T+Q_{k-1},
```

```math
\tilde y_k=z_k-h(\hat x_{k|k-1}),
\qquad
S_k=H_kP_{k|k-1}H_k^T+R_k.
```

若噪声以非加性形式进入模型，例如 $`x_k=f(x_{k-1},u_{k-1},w_{k-1})`$ ，还需计算噪声 Jacobian $`L=\partial f/\partial w`$ ，并使用 $`LQL^T`$ ；测量端同理使用 $`M=\partial h/\partial v`$ 和 $`MRM^T`$ 。

对差速移动机器人，可采用状态

```math
x=
\begin{bmatrix}
p_x&p_y&\theta&v&\omega
\end{bmatrix}^T,
```

其离散运动模型可近似为：

```math
f(x)=
\begin{bmatrix}
p_x+v\Delta t\cos\theta\\
p_y+v\Delta t\sin\theta\\
\theta+\omega\Delta t\\
v\\
\omega
\end{bmatrix}.
```

这已不是线性模型，因为位置增量包含 $`\sin\theta`$ 和 $`\cos\theta`$ 。若机器人观测已知地标 $`\ell=[\ell_x,\ell_y]^T`$ 的距离和方位，则

```math
h(x)=
\begin{bmatrix}
\sqrt{(\ell_x-p_x)^2+(\ell_y-p_y)^2}\\
\operatorname{atan2}(\ell_y-p_y,\ell_x-p_x)-\theta
\end{bmatrix}.
```

EKF 的核心近似是：后验仍用单个 Gaussian 表示，非线性函数只在当前均值附近保留一阶项。因此它适合不确定性较小、函数局部平滑、初始化合理的情况。若机器人朝向误差很大，或者观测模型产生多个可能位置，均值附近的线性化可能不能代表真实分布，滤波器甚至会产生过度自信。EKF“公式能算出来”不等于近似有效。

姿态状态还涉及流形结构。二维角度更新后应进行归一化，三维姿态则不能把旋转矩阵的九个元素当作任意 Euclidean 向量直接更新。工程上常采用误差状态 EKF：名义姿态在旋转群上演化，小误差在局部切空间中用三维向量表示。这能避免破坏旋转约束，但仍需正确处理重置 Jacobian 和坐标约定。

<a id="ch19-sec9"></a>
## 19.9 Jacobian 在 EKF 中为什么再次出现

Jacobian 在 EKF 中出现，是因为协方差描述的是估计点附近的小扰动，而非线性函数对小扰动的一阶传播由 Jacobian 给出。若

```math
x=\hat x+\delta x,
```

则在 $`\hat x`$ 附近：

```math
f(\hat x+\delta x)
\approx
f(\hat x)+F\delta x,
\qquad
F=\left.\frac{\partial f}{\partial x}\right|_{\hat x}.
```

因此输出误差近似为 $`\delta x^+\approx F\delta x`$ ，协方差自然满足

```math
P^+
=
\mathbb E[\delta x^+(\delta x^+)^T]
\approx
FPF^T.
```

Jacobain 不是为了把非线性函数永久变成线性函数，而是在每次递推时建立当前局部误差的线性映射。

对上一节的移动机器人模型，其状态 Jacobian 为：

```math
F=
\begin{bmatrix}
1&0&-v\Delta t\sin\theta&\Delta t\cos\theta&0\\
0&1& v\Delta t\cos\theta&\Delta t\sin\theta&0\\
0&0&1&0&\Delta t\\
0&0&0&1&0\\
0&0&0&0&1
\end{bmatrix}.
```

矩阵中的 $`-v\Delta t\sin\theta`$ 和 $`v\Delta t\cos\theta`$ 表明，朝向误差会传播成位置误差。机器人运动得越快、预测时间越长，这种耦合越强。因此朝向协方差即使不直接出现在位置对角项中，也会通过 $`FPF^T`$ 增大位置不确定性。

令 $`d_x=\ell_x-p_x`$ 、 $`d_y=\ell_y-p_y`$ 、 $`r=\sqrt{d_x^2+d_y^2}`$ ，距离—方位测量 Jacobian 为：

```math
H=
\begin{bmatrix}
-\dfrac{d_x}{r}&-\dfrac{d_y}{r}&0&0&0\\[6pt]
\dfrac{d_y}{r^2}&-\dfrac{d_x}{r^2}&-1&0&0
\end{bmatrix}.
```

它揭示了测量的方向性：单个地标的距离主要约束径向误差，方位主要约束切向位置与朝向的组合。当 $`r\to0`$ 时，该参数化变得奇异；这不是“数值上加一个很小的数”就能完全解决的问题，而是观测坐标选择本身失效。

Jacobian 错误是 EKF 工程失败的常见来源。可用有限差分或自动微分核对解析导数，但有限差分步长过大产生截断误差，过小又受浮点误差影响。更重要的是统一扰动定义：姿态误差在左侧还是右侧注入、坐标量在世界系还是机体系表达，会改变 Jacobian。导数数值看似接近，并不保证几何约定一致。

<a id="ch19-sec10"></a>
## 19.10 Unscented Kalman Filter

无迹卡尔曼滤波（Unscented Kalman Filter, UKF）不显式计算状态函数的 Jacobian，而是选择一组确定性 Sigma 点，使这些点的样本均值和协方差与当前 Gaussian 分布一致，再把每个点通过真实非线性函数传播。它近似的是“随机变量经过非线性变换后的统计量”，而不是先对函数做一阶展开。

对 $`n`$ 维状态，定义

```math
\lambda=\alpha^2(n+\kappa)-n.
```

给定均值 $`\hat x`$ 和协方差 $`P`$ ，构造 $`2n+1`$ 个 Sigma 点：

```math
\chi_0=\hat x,
```

```math
\chi_i=\hat x+\left[\sqrt{(n+\lambda)P}\right]_i,
\qquad i=1,\ldots,n,
```

```math
\chi_{i+n}=\hat x-\left[\sqrt{(n+\lambda)P}\right]_i.
```

其中矩阵平方根通常由 Cholesky 分解获得， $`[\cdot]_i`$ 表示第 $`i`$ 列。常用权重为：

```math
W_0^{(m)}=\frac{\lambda}{n+\lambda},
```

```math
W_0^{(c)}
=
\frac{\lambda}{n+\lambda}
+
(1-\alpha^2+\beta),
```

```math
W_i^{(m)}=W_i^{(c)}
=
\frac{1}{2(n+\lambda)},
\qquad i=1,\ldots,2n.
```

$`\alpha`$ 控制 Sigma 点展开范围， $`\beta=2`$ 常用于 Gaussian 先验， $`\kappa`$ 是附加缩放参数。

预测时传播每个点：

```math
\chi_{i,k|k-1}=f(\chi_{i,k-1|k-1},u_{k-1}),
```

再重构均值和协方差：

```math
\hat x_{k|k-1}
=
\sum_iW_i^{(m)}\chi_{i,k|k-1},
```

```math
P_{k|k-1}
=
\sum_iW_i^{(c)}
(\chi_i-\hat x)(\chi_i-\hat x)^T+Q.
```

测量端令 $`\zeta_i=h(\chi_i)`$ ，由这些点计算预测测量均值、测量协方差和状态—测量交叉协方差 $`P_{xz}`$ ，然后使用

```math
K=P_{xz}S^{-1}
```

完成更新。与 EKF 相比，UKF 避免了解析 Jacobian，并通常能更好地捕获均值和协方差经过平滑非线性函数后的变化。

UKF 仍然只维护一个 Gaussian，因此不能自然表达机器人可能位于两个对称走廊中的双峰分布。它也不是“无需模型”：仍需提供可计算的 $`f`$ 、 $`h`$ 、 $`Q`$ 和 $`R`$ 。状态维度增大时，每次预测和测量至少传播 $`2n+1`$ 个点，函数计算成本明显高于 EKF；若采用增广状态同时表示过程噪声和测量噪声，Sigma 点数量还会增加。

角度和姿态也不能直接用普通加权平均。例如 $`179^\circ`$ 与 $`-179^\circ`$ 的算术平均接近 $`0^\circ`$ ，但真实平均方向应接近 $`\pi`$ 。因此移动机器人 UKF 应使用圆周均值并对角度残差归一化；三维姿态则需要流形上的 Sigma 点构造与均值计算。UKF 消除了显式 Jacobian，并没有消除状态空间几何。

<a id="ch19-sec11"></a>
## 19.11 Particle Filter

粒子滤波（Particle Filter, PF）使用一组带权样本近似任意形状的后验分布：

```math
p(x_k\mid z_{1:k})
\approx
\sum_{i=1}^{N}
w_k^{(i)}
\delta(x_k-x_k^{(i)}),
```

其中 $`x_k^{(i)}`$ 是第 $`i`$ 个粒子， $`w_k^{(i)}\ge0`$ 且 $`\sum_iw_k^{(i)}=1`$ ， $`\delta(\cdot)`$ 为 Dirac 脉冲。与 KF、EKF 和 UKF 不同，粒子集合可以表达偏斜、重尾和多峰分布。

最基本的 Bootstrap 粒子滤波先从运动模型采样：

```math
x_k^{(i)}
\sim
p(x_k\mid x_{k-1}^{(i)},u_{k-1}),
```

再根据测量似然更新权重：

```math
\tilde w_k^{(i)}
=
w_{k-1}^{(i)}
p(z_k\mid x_k^{(i)}),
\qquad
w_k^{(i)}
=
\frac{\tilde w_k^{(i)}}{\sum_j\tilde w_k^{(j)}}.
```

若机器人初始位置未知，可在仓库地图多个可能区域放置粒子。地标或激光观测到来后，与观测相符区域的粒子权重增加。只要各个模式仍有足够粒子，滤波器便可暂时保留多个定位假设，而不必过早压缩成一个均值。

经过多次更新，权重往往集中到少数粒子，称为权重退化。有效样本数可估计为：

```math
N_{\mathrm{eff}}
=
\frac{1}{\sum_{i=1}^{N}(w_k^{(i)})^2}.
```

当 $`N_{\mathrm{eff}}`$ 低于阈值时执行重采样，从高权重粒子复制更多样本并淘汰低权重粒子。系统重采样或分层重采样通常比朴素多项式重采样方差更低。重采样并不创造新信息，频繁重采样还会造成粒子贫化，使多样性过早丢失；可通过更好的提议分布、适度粗化或 MCMC 移动步骤改善。

粒子滤波的主要边界是维数灾难。状态维度升高后，要覆盖有效概率区域所需的粒子数可能急剧增长。对完整机器人状态、多个偏置和大规模地图同时采样通常代价过高，因此实际系统常进行结构分解，例如只对机器人位姿采样，而对每个粒子条件下的线性子状态使用卡尔曼滤波。粒子滤波也不是“粒子越多必然越正确”：错误的运动模型、似然函数或坐标变换会让大量粒子稳定地逼近错误后验。

<a id="ch19-sec12"></a>
## 19.12 不同估计方法的假设与边界

不同方法的主要差异不在公式外观，而在它们如何表示概率分布、如何传播非线性，以及为此支付多少计算成本：

| 方法 | 分布表示 | 模型要求 | 非线性处理 | 主要优势 | 主要边界 |
|---|---|---|---|---|---|
| KF | 单个 Gaussian | 线性、Gaussian | 无需近似 | 线性 Gaussian 下精确且高效 | 无法表达非线性和多峰 |
| EKF | 单个 Gaussian | 可微非线性模型 | 一阶 Taylor 线性化 | 计算高效、工程成熟 | 依赖 Jacobian、初始化和局部近似 |
| UKF | 单个 Gaussian | 可传播 Sigma 点 | 确定性采样 | 避免显式 Jacobian，统计传播通常更准确 | 成本较高，仍不能表达多峰 |
| PF | 加权粒子集合 | 可采样转移并计算似然 | Monte Carlo 传播 | 可表达强非线性与多峰 | 维数灾难、退化和实时成本 |

“线性还是非线性”并不是唯一选择标准。若系统虽非线性但工作区间很小，EKF 可能足够；若非线性较强、导数难以获得而状态维度适中，UKF 可能更方便；若全局定位存在多个离散假设，单 Gaussian 方法原则上就不合适，粒子滤波或多假设方法更自然。反过来，在高维且近似线性的系统中，为了“更高级”而使用粒子滤波通常只会增加计算负担。

所有方法都依赖若干共同前提。首先，状态必须包含足以预测未来和解释观测的信息；若遗漏关键偏置或接触模式，算法只能在错误模型中求解。其次，系统必须具有足够可观性。没有绝对位置或外部几何信息时，移动机器人仅依靠轮速积分，其全局位置误差必然随时间增长；任何滤波器都不能从不存在的信息中恢复绝对位置。最后，数据关联必须可靠：把墙角 A 的观测错误地匹配到墙角 B，产生的是错误似然而非普通 Gaussian 噪声。

工程系统还需处理理想递推之外的问题：

- **初始化**：初始均值错误但协方差过小，会使 EKF 和 UKF 拒绝正确测量；全局不确定时应使用较宽先验或多假设初始化。
- **离群点**：Gaussian 似然对大残差十分敏感，应结合门控、鲁棒损失、混合噪声模型或故障检测。
- **延迟与乱序**：状态与测量必须在同一时间基准下比较，必要时回滚并重放历史。
- **模式切换**：打滑、腾空、碰撞和传感器失效会改变动力学或观测模型，可使用多模型估计而非单一固定 $`Q`$ 。
- **一致性**：均方误差小不代表协方差可信；面向规划和控制时，低估不确定性往往比适度保守更危险。

估计器最终输出的不应只有 $`\hat x_k`$ 。规划器和控制器还需要知道哪些方向可靠、哪些方向仍然不确定，因此应同时传递协方差、置信区域、模式概率或粒子集合的摘要。在线性系统满足可控、可观等条件时，估计器与反馈控制器可以在分离原则下分别设计，但控制器实际使用的是估计状态而非真实状态。对于非线性、约束、主动感知或风险敏感系统，估计与行动会更紧密地耦合：机器人的运动本身会改变未来能获得什么观测。

## 本章小结

本章从线性 Gaussian 状态空间模型出发，建立了“预测—比较—修正”的递推主线。状态预测利用动力学推进均值，协方差传播描述不确定性如何扩散；新息衡量观测与预测的差异，新息协方差给出差异应有的尺度；卡尔曼增益利用状态与测量之间的相关性，把测量信息分配到各个状态方向；测量更新则形成新的后验均值和协方差。

当动力学和观测为非线性时，EKF 使用 Jacobian 传播局部误差，UKF 使用 Sigma 点传播均值和协方差，粒子滤波则用加权样本近似更一般的后验。三者不是按“新旧程度”排序，而是分别对应局部 Gaussian 线性化、确定性统计近似和 Monte Carlo 分布表示。选择方法之前，必须先判断非线性强度、后验是否多峰、状态维度、实时预算以及模型是否可微。

贯穿本章的移动机器人例子也说明，滤波器无法替代建模、同步、标定、数据关联和可观性分析。可信的状态估计不仅要给出一个平滑轨迹，还要使实际误差与其宣称的不确定性相一致。下一章将承接这一接口，把估计得到的状态与不确定性送入自主系统后续的决策、规划或控制环节，讨论系统如何从“我认为自己在哪里”进一步走向“接下来应该做什么”。
