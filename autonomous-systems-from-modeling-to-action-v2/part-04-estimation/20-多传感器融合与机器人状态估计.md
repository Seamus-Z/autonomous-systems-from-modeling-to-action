自主系统很少能够直接测得控制与规划所需的完整状态。相机输出像素，惯性测量单元输出角速度与比力，编码器输出轮轴转角，全球导航卫星系统输出天线位置；而控制器真正需要的通常是机器人位姿、速度、角速度、传感器偏置以及这些量的不确定性。状态估计的任务，就是把不同时间、不同坐标系、不同误差结构下的测量，转换为一个动态一致、带置信度的状态表示。

本章以一台室外轮式巡检机器人为贯穿实例。机器人装备轮速编码器、惯性测量单元（Inertial Measurement Unit, IMU）、全球导航卫星系统（Global Navigation Satellite System, GNSS）、双目相机与三维激光雷达。它既要在空旷道路上利用 GNSS 获得全局位置，也要在树荫、建筑物附近和室内依赖视觉、激光与惯性信息连续运行。这个例子将说明：融合不是简单平均，而是在统一时间、统一几何和统一概率模型下，对互补信息进行动态推断。

## 20.1 为什么需要多传感器

设机器人状态为

```math
x=
\left(
p_{WB},R_{WB},v_W,b_g,b_a,\ldots
\right),
```

其中 $`p_{WB}\in\mathbb{R}^3`$ 是机体坐标系 $`B`$ 原点在世界坐标系 $`W`$ 中的位置， $`R_{WB}\in SO(3)`$ 把 $`B`$ 中的向量旋转到 $`W`$ ， $`v_W\in\mathbb{R}^3`$ 是世界系速度， $`b_g,b_a\in\mathbb{R}^3`$ 分别是陀螺仪与加速度计偏置。第 $`i`$ 个传感器的测量可统一写成

```math
z_i(t_i)=h_i\!\left(x(t_i),\theta_i\right)+n_i,
```

其中 $`h_i`$ 是测量模型， $`\theta_i`$ 包含外参、比例因子和时间偏移等标定参数， $`n_i`$ 是测量误差。传感器测到的是 $`z_i`$ ，而规划与控制消费的是状态估计 $`\hat x`$ 及其不确定性 $`P`$ 。

多传感器的必要性首先来自**可观性互补**。单个 IMU 能以高频率传播姿态和速度，却无法阻止偏置积分造成的长期漂移；轮速编码器在平坦且不打滑的地面上能稳定约束前向速度，但不能直接给出绝对位置；GNSS 能提供全局位置，却可能低频、跳变或暂时失锁；视觉和激光能相对环境约束运动，但会受纹理、照明、雨雾、动态物体与几何退化影响。只有当测量对不同状态方向提供互补约束时，融合才可能同时获得短期平滑性与长期有界误差。

融合也不能被理解为“传感器越多越好”。若两个算法使用了同一相机图像或同一轮速信息，却在融合时被当成独立测量，信息会被重复计算，使协方差虚假缩小。若未处理时间延迟、坐标外参或系统性偏置，滤波器可能把一致的模型误差误判成高置信度信息。工程上应先回答四个问题：

1. 每项测量约束状态的哪些自由度，在哪些运动条件下会退化？
2. 测量时间属于采样时刻、曝光中点、扫描时刻，还是消息到达时刻？
3. 测量位于哪个坐标系，传感器相对机体的外参是否可信？
4. 误差是近似白噪声、缓慢偏置、离群点，还是与其他测量相关？

在贯穿实例中，机器人以 IMU 作为高频传播源，以轮速约束地面运动，以视觉和激光提供局部相对位姿，以 GNSS 提供全局锚定。核心并非让所有传感器在任何时刻都参与，而是让每种传感器在自身有效域内提供恰当约束，并在失效时被检测、降权或隔离。

## 20.2 时间同步

动态系统中的测量必须与状态处于同一物理时刻。设传感器记录的时间戳为 $`t_s`$ ，统一时钟中的真实采样时刻为

```math
t=t_s+\delta t+\epsilon_t,
```

其中 $`\delta t`$ 是近似恒定的时钟偏移， $`\epsilon_t`$ 是抖动。消息抵达计算机的时刻还包含通信和排队延迟，通常不能代替采样时刻。对相机而言应区分曝光开始、曝光中点和读出结束；对旋转激光雷达而言，一帧点云中的各点甚至具有不同采样时刻。

时间误差会直接转化为空间误差。若机器人线速度为 $`v`$ 、角速度为 $`\omega`$ ，时间偏移 $`\Delta t`$ 在一阶近似下导致

```math
\|\Delta p\|\approx \|v\|\,|\Delta t|,
\qquad
\|\Delta \phi\|\approx \|\omega\|\,|\Delta t|.
```

例如巡检机器人以 $`5\,\mathrm{m/s}`$ 行驶时， $`20\,\mathrm{ms}`$ 的错位就对应约 $`0.1\,\mathrm{m}`$ 的平移误差；转弯时还会产生方向误差和明显的点云重影。滤波器可能把这种确定性的时间错位吸收到 IMU 偏置、轮胎尺度或外参中，形成“静止时正常、运动时失真”的典型故障。

工程上优先采用硬件触发、脉冲每秒信号或精密时间协议建立共同时间基准。若只能软件同步，应保留原始设备时间戳，估计时钟偏移和漂移，而不是按消息到达顺序粗略对齐。对于低频测量，可将状态传播到测量时刻再更新；对于点云和滚动快门图像，则需要利用 IMU 轨迹进行去畸变。线性插值适用于位置等欧氏量，姿态应使用球面插值或 $`SO(3)`$ 上的指数映射，不能直接对欧拉角逐分量插值。

时间偏移也可作为标定变量 $`\delta t_i`$ 联合估计，此时测量模型变为

```math
z_i=h_i\!\left(x(t_i+\delta t_i),\theta_i\right)+n_i.
```

但只有在运动具有足够激励时，时间偏移才容易与外参、偏置区分。机器人长时间静止或匀速直行时，某些时间参数不可辨识。因而在线估计必须设置合理先验和边界；不能期待滤波器自动修复任意大的时钟错误。

## 20.3 坐标系对齐

多传感器融合首先是一项几何工作。定义齐次变换

```math
T_{AB}=
\begin{bmatrix}
R_{AB} & p_{AB}\\
0 & 1
\end{bmatrix}\in SE(3),
```

它把坐标系 $`B`$ 中的点变换到坐标系 $`A`$ ：

```math
{}^A q=R_{AB}\,{}^B q+p_{AB}.
```

对巡检机器人，至少应明确世界系 $`W`$ 、局部导航系 $`L`$ 、机体系 $`B`$ 、IMU 系 $`I`$ 、相机系 $`C`$ 、激光雷达系 $`L_d`$ 和 GNSS 天线系 $`G`$ 。若 $`T_{WB}`$ 是待估计机体位姿， $`T_{BC}`$ 是固定相机外参，则相机位姿为

```math
T_{WC}=T_{WB}T_{BC}.
```

这里的乘法顺序取决于“下标表示从后者到前者”的约定；项目中必须固定约定并通过单元测试验证。

坐标对齐包含旋转外参和平移外参。平移尤其不能忽略：机器人转动时，离机体原点有杆臂 $`p_{BG}`$ 的 GNSS 天线位置为

```math
p_{WG}=p_{WB}+R_{WB}p_{BG}.
```

若直接把 GNSS 天线位置当作机体中心位置，原地转向时也会出现看似平移的轨迹。相机—IMU、雷达—IMU外参误差则会在转弯和颠簸时形成系统性残差。外参既可离线标定，也可作为慢变量在线修正，但在线估计要求足够丰富的平移和转动激励。

还应区分右手系、轴方向和局部地理坐标约定。机器人软件常使用前—左—上，部分相机模型使用右—下—前，导航系统可能使用东—北—天或北—东—地。仅靠变量名无法避免符号错误，工程接口应显式记录坐标系名称、单位、变换方向和时间戳。对速度、角速度和协方差进行坐标变换时，也不能只变换均值；例如欧氏向量协方差满足

```math
P_A=R_{AB}P_B R_{AB}^{\mathsf T}.
```

位姿扰动的协方差则需要使用 $`SE(3)`$ 的伴随映射，具体形式取决于采用左扰动还是右扰动。混用扰动定义会使雅可比和协方差即使维度正确，也在几何上错误。

## 20.4 IMU 状态传播

IMU 通常以数百赫兹输出三轴角速度和三轴比力。测量模型为

```math
\omega_m=\omega+b_g+n_g,
\qquad
a_m=R_{WB}^{\mathsf T}(a_W-g_W)+b_a+n_a,
```

其中 $`\omega_m,a_m\in\mathbb{R}^3`$ ， $`\omega`$ 是机体相对世界的真实角速度并以机体系表达， $`a_W`$ 是世界系线加速度， $`g_W`$ 是重力向量， $`b_g,b_a`$ 为偏置， $`n_g,n_a`$ 为近似白噪声。加速度计测量的是**比力**，静止平放时其输出并非零，而是与重力方向相反的支撑比力；把加速度计输出直接当作世界系加速度是常见错误。

在忽略地球自转且世界系可视为局部惯性系时，连续时间传播模型为

```math
\begin{aligned}
\dot R_{WB} &= R_{WB}(\omega_m-b_g-n_g)^\wedge,\\
\dot v_W &= g_W+R_{WB}(a_m-b_a-n_a),\\
\dot p_{WB} &= v_W,\\
\dot b_g &= n_{wg},\\
\dot b_a &= n_{wa},
\end{aligned}
```

其中 $`(\cdot)^\wedge`$ 把三维向量映射为反对称矩阵，满足 $`\phi^\wedge q=\phi\times q`$ ； $`n_{wg},n_{wa}`$ 描述偏置随机游走。对时间间隔 $`\Delta t`$ ，一种常用离散近似是

```math
\begin{aligned}
R_{k+1} &= R_k\mathrm{Exp}\!\left((\omega_{m,k}-\hat b_{g,k})\Delta t\right),\\
v_{k+1} &= v_k+\left[g+R_k(a_{m,k}-\hat b_{a,k})\right]\Delta t,\\
p_{k+1} &= p_k+v_k\Delta t+
\frac{1}{2}\left[g+R_k(a_{m,k}-\hat b_{a,k})\right]\Delta t^2.
\end{aligned}
```

高动态场景应使用中点积分、圆锥与划桨补偿，或对一段 IMU 测量进行预积分，而不是依赖低阶欧拉积分。

状态均值传播之外，还要传播误差协方差。对小误差状态

```math
\delta x=
[\delta p^\mathsf T,\delta v^\mathsf T,\delta\theta^\mathsf T,
\delta b_g^\mathsf T,\delta b_a^\mathsf T]^\mathsf T
\in\mathbb{R}^{15},
```

线性化后有

```math
\delta x_{k+1}=F_k\delta x_k+G_k w_k,
\qquad
P_{k+1}=F_kP_kF_k^\mathsf T+G_kQ_kG_k^\mathsf T.
```

$`Q_k`$ 必须由连续噪声密度按采样周期正确离散化，不能把数据手册中的 $`\mathrm{unit}/\sqrt{\mathrm{Hz}}`$ 数值直接当成每采样方差。IMU 提供的是高频、低延迟但会漂移的相对运动骨架；其偏置必须依赖静止约束、轮速、视觉、激光或 GNSS 等外部信息才能被持续校正。

## 20.5 编码器与里程计

轮式机器人的编码器测量轮轴增量或转速。对轮半径为 $`r`$ 、轮距为 $`b`$ 的差速机器人，左右轮角速度为 $`\dot\phi_L,\dot\phi_R`$ 时，理想平面运动满足

```math
v_x=\frac{r}{2}(\dot\phi_R+\dot\phi_L),
\qquad
\omega_z=\frac{r}{b}(\dot\phi_R-\dot\phi_L),
\qquad
v_y=0.
```

在采样周期 $`\Delta t`$ 内，可由轮角增量得到平面位姿增量。直行附近可用小角度近似；一般情况下应按圆弧积分，避免在高曲率运动中产生系统误差。编码器量化噪声随低速时更明显，而轮半径误差会形成距离尺度偏差，轮距误差则主要影响航向变化。

轮式里程计的关键假设不是“编码器准确”，而是轮—地接触满足近似无滑动约束。泥地、砂石、湿滑坡面、越障和急加速都会破坏这一假设。工程上可将轮速作为速度测量

```math
z_{\text{wheel}}=
\begin{bmatrix}
v_x\\
\omega_z
\end{bmatrix}
=
h_{\text{wheel}}(x)+n_{\text{wheel}},
```

也可把横向速度与竖直速度的非完整约束写为伪测量

```math
z_{\text{nhc}}=
\begin{bmatrix}
0\\0
\end{bmatrix}
=
\begin{bmatrix}
e_y^\mathsf T R_{WB}^\mathsf T v_W\\
e_z^\mathsf T R_{WB}^\mathsf T v_W
\end{bmatrix}
+n_{\text{nhc}}.
```

这里 $`e_y,e_z`$ 是机体系基向量。伪测量的协方差不能设为零，否则机器人一旦侧滑，估计器会以过高置信度拒绝真实运动。

巡检机器人可以通过比较轮速预测、IMU 比力、视觉速度和电机电流来检测打滑。一旦残差持续增大，应增大轮速测量协方差，或引入滑移率状态，而不是继续强制无滑动模型。还应避免把由轮编码器积分得到的里程计位姿和原始轮速同时作为彼此独立的观测，否则同一信息会被重复融合。

## 20.6 GNSS

GNSS 接收机可输出位置、速度、时间以及原始伪距和载波相位。对于普通状态估计器，最常用的是地理坐标转换后的局部位置和速度测量。若以局部世界系 $`W`$ 表示，天线位置模型为

```math
z_p=p_{WB}+R_{WB}p_{BG}+n_p,
```

速度模型为

```math
z_v=v_W+R_{WB}\left(\omega_B\times p_{BG}\right)+n_v,
```

其中 $`p_{BG}`$ 是机体原点到天线的杆臂，第二式中的附加项表示刚体旋转导致的天线速度。低速小型机器人有时可忽略该项，但在快速转向或长杆臂安装下不能忽略。

GNSS 的优势是提供不随行程累计漂移的全局约束，但其误差通常并非理想高斯白噪声。建筑物反射会产生多路径误差，树冠会降低卫星几何质量，差分或实时动态定位解可能在固定解、浮点解和单点解之间切换。接收机报告的协方差和解状态应进入融合逻辑；突然跳变的测量不能仅因“来自 GNSS”就被无条件接受。常用门限基于创新

```math
r=z-h(\hat x^-),\qquad
S=HP^-H^\mathsf T+R,
```

以及归一化创新平方

```math
d^2=r^\mathsf T S^{-1}r.
```

若 $`d^2`$ 超过按测量维度设定的统计门限，可拒绝、降权或进入故障确认流程。

GNSS 位置通常不能单独观测机器人的航向；只有在持续运动、具备速度方向信息，或使用双天线基线时，航向才可能被约束。静止时由连续位置差分计算航向尤其不可靠。另一个边界是全局坐标转换：经纬高位于曲面坐标中，局部任务应转换到明确原点和轴约定的切平面坐标系，跨越较大区域时则需考虑地球曲率和所用大地基准。地图坐标、GNSS 坐标与机器人局部连续坐标之间不应被含糊地视为同一个“world”。

<a id="ch20-sec7"></a>
## 20.7 视觉与激光测量

相机通过环境特征的投影关系约束运动。针孔模型中，空间点 $`{}^C P=(X,Y,Z)^\mathsf T`$ 的理想像素坐标满足

```math
\begin{bmatrix}u\\v\end{bmatrix}
=
\begin{bmatrix}
f_x X/Z+c_x\\
f_y Y/Z+c_y
\end{bmatrix},
```

实际模型还需包含镜头畸变、曝光与滚动快门效应。视觉前端可输出特征重投影残差、相邻帧相对位姿，或经过局部优化的视觉里程计结果。单目视觉天然缺少绝对尺度；双目、深度相机、已知物体尺度或 IMU 激励可提供尺度约束，但退化运动仍可能造成尺度和偏置耦合。

激光雷达测量点到环境几何结构的距离。扫描匹配常最小化点到平面代价

```math
J(T)=\sum_i \rho\!\left(
\frac{\left[n_i^\mathsf(Tp_i-q_i)\right]^2}{\sigma_i^2}
\right),
```

其中 $`p_i`$ 是当前扫描点， $`q_i`$ 与 $`n_i`$ 分别是地图中对应平面上的点和法向量， $`T\in SE(3)`$ 是待估计变换， $`\rho`$ 是抑制离群点的鲁棒损失。长直走廊、单一平面或稀疏结构会使某些自由度弱可观；雨雾、玻璃与动态车辆也会破坏对应关系。匹配算法应输出与局部曲率或海森矩阵相一致的协方差，而不是为所有场景使用固定噪声。

视觉和激光可作为两类接口进入后端：一类是直接使用原始残差，例如像素重投影和点到平面距离；另一类是把前端结果压缩成相对位姿测量

```math
z_{ij}\approx T_i^{-1}T_j.
```

前者保留的信息更多，但计算和数据关联更复杂；后者模块边界清晰，却必须携带合理协方差，并注意前端估计与后端状态之间的相关性。若视觉里程计内部已经使用 IMU，再把其位姿输出与同一 IMU 在外部滤波器中独立融合，会造成隐蔽的信息重复。

在巡检机器人上，相机可在结构丰富区域提供精细角度和语义信息，激光可在光照变化下保持几何稳定。二者都应进行运动畸变校正、动态物体剔除和匹配质量评估。匹配数量多不等于几何约束强；真正重要的是残差对状态各自由度的敏感性及其条件数。

<a id="ch20-sec8"></a>
## 20.8 多速率融合

多传感器系统天然是多速率的：IMU 可能为 $`400\,\mathrm{Hz}`$ ，轮速为 $`100\,\mathrm{Hz}`$ ，相机为 $`20\,\mathrm{Hz}`$ ，激光为 $`10\,\mathrm{Hz}`$ ，GNSS 仅为 $`1`$ 至 $`10\,\mathrm{Hz}`$ 。标准处理方式是事件驱动：每到一条 IMU 测量就传播状态；每当其他测量到达，就先将状态精确传播到其采样时刻，再执行测量更新

```math
\begin{aligned}
r_k &= z_k-h(\hat x_k^-),\\
S_k &= H_kP_k^-H_k^\mathsf T+R_k,\\
K_k &= P_k^-H_k^\mathsf T S_k^{-1},\\
\delta \hat x_k &= K_k r_k.
\end{aligned}
```

误差状态经适当流形注入后，协方差可用 Joseph 形式更新：

```math
P_k^+=(I-K_kH_k)P_k^-(I-K_kH_k)^\mathsf T
+K_kR_kK_k^\mathsf T,
```

它比简化式更能保持数值对称性和半正定性。

低频测量常会延迟到达。例如视觉前端完成特征匹配时，估计器已传播到更晚时刻。若直接在“当前状态”上融合旧测量，会引入时间错误。常见方案是保留固定长度的状态、协方差和 IMU 缓冲区：回到测量时刻更新，再重放后续输入。这称为乱序测量（out-of-sequence measurement）处理。滑动窗口优化则可把窗口内多个时刻同时调整，代价是更高计算量和边缘化管理。

不同测量不能仅按频率分配权重，权重应来自信息质量。测量协方差 $`R_k`$ 可以随卫星解状态、图像模糊、激光匹配退化和轮胎滑移自适应变化，但不能为了让轨迹“看起来平滑”而任意调参。过小的 $`R_k`$ 会使估计器追随离群测量，过大的过程噪声会掩盖模型错误，过小的过程噪声则导致创新长期偏大。应联合检查创新均值、创新协方差、状态误差和故障场景，而不是只观察一条轨迹。

实时系统还需明确估计输出的时间语义。最准确的后验状态可能落后几十毫秒，而控制器需要当前状态。常见做法是后端维护延迟优化结果，前端用最新 IMU 将其外推到控制时刻，并同时报告状态时间戳与外推不确定性。没有时间戳的“当前位置”在高速闭环中没有明确意义。

<a id="ch20-sec9"></a>
## 20.9 SE(3) 上的位姿估计

三维位姿属于特殊欧氏群

```math
SE(3)=
\left\{
\begin{bmatrix}R&p\\0&1\end{bmatrix}
\mid R\in SO(3),\ p\in\mathbb{R}^3
\right\},
```

而不是普通六维向量空间。旋转矩阵必须满足 $`R^\mathsf TR=I`$ 和 $`\det R=1`$ 。直接对旋转矩阵元素做加法更新会破坏这些约束；欧拉角虽然只有三个参数，却存在奇异性、轴序依赖和角度环绕问题。四元数适合数值存储，但仍需单位长度约束，并存在 $`q`$ 与 $`-q`$ 表示同一旋转的双覆盖性质。

状态估计通常在李代数切空间中表示小误差。令

```math
\xi=
\begin{bmatrix}\rho\\\phi\end{bmatrix}\in\mathbb{R}^6,
\qquad
\xi^\wedge=
\begin{bmatrix}
\phi^\wedge & \rho\\
0&0
\end{bmatrix},
```

其中 $`\rho\in\mathbb{R}^3`$ 是平移扰动坐标， $`\phi\in\mathbb{R}^3`$ 是旋转扰动坐标。采用右扰动时，

```math
T=\hat T\mathrm{Exp}(\delta\xi^\wedge);
```

采用左扰动时，

```math
T=\mathrm{Exp}(\delta\xi^\wedge)\hat T.
```

两者分别在不同坐标系中解释误差，雅可比、协方差和注入公式不能混用。协方差 $`P_{\xi}\in\mathbb{R}^{6\times6}`$ 描述的是局部切空间中的小扰动，而不是齐次矩阵元素的协方差。

对相对位姿测量 $`Z_{ij}`$ ，一种几何一致的残差是

```math
r_{ij}
=
\mathrm{Log}\!\left(
Z_{ij}^{-1}T_i^{-1}T_j
\right)^\vee
\in\mathbb{R}^6,
```

其中 $`\mathrm{Log}:SE(3)\rightarrow\mathfrak{se}(3)`$ ， $`(\cdot)^\vee`$ 是 $`(\cdot)^\wedge`$ 的逆映射。该残差在测量完全满足时为零，并能在局部线性化后用于误差状态滤波或非线性最小二乘。旋转误差接近 $`\pi`$ 时，对数映射和线性化需要谨慎；大初始误差应通过粗配准、全局初始化或分阶段优化解决，不能依赖一次局部更新。

位姿协方差在坐标变换下应使用伴随矩阵。若扰动定义发生坐标变换，其一般形式为

```math
P'=\mathrm{Ad}_{T}P\mathrm{Ad}_{T}^{\mathsf T}.
```

因此，报告“位置标准差和姿态标准差”时必须同时说明参考坐标系和扰动约定。忽略这一点，在远离坐标原点或存在长杆臂时会严重低估平移—旋转耦合。

<a id="ch20-sec10"></a>
## 20.10 状态估计与定位

定位回答“机器人在哪里”，状态估计则回答更广的问题：机器人当前位姿、速度、传感器偏置、尺度、接触或环境扰动分别是多少，以及这些量有多不确定。定位通常是状态估计的一个子问题。对巡检机器人，控制接口至少需要

```math
\hat x_c=
(\hat p_{WB},\hat R_{WB},\hat v_W,\hat\omega_B),
```

而估计器内部还可能维护 $`b_g,b_a`$ 、轮径尺度、时间偏移、重力方向和传感器外参。内部状态不必全部暴露给控制器，但必须参与正确传播。

工程系统常同时维护三个概念不同的坐标系：全局地图系、局部连续里程计系和机体系。局部里程计系要求短时连续，适合控制；全局地图系允许通过 GNSS 或回环检测消除长期漂移，但校正可能产生位置跳变。可将两者关系写为

```math
T_{MB}=T_{MO}T_{OB},
```

其中 $`M`$ 是地图系， $`O`$ 是连续里程计系。高频局部估计输出 $`T_{OB}`$ ，全局模块缓慢或离散地修正 $`T_{MO}`$ 。这样，控制器不必直接承受全局重定位导致的瞬时跳变，任务规划仍可使用全局一致位置。

状态估计器还必须报告“有效性”，而不只是数值。有效性至少包括时间戳、协方差、初始化状态、当前使用的传感器、故障标志和坐标系标识。协方差小不一定代表估计正确：模型遗漏、相关性忽略和错误标定都可能使滤波器过度自信。应通过一致性检验、独立基准、重复路线和故障注入验证估计误差是否与报告的不确定性相符。

初始化是定位系统的明确阶段，而不是实现细节。静止 IMU 可估计横滚、俯仰和初始偏置，但不能仅凭重力确定航向；单目系统需要尺度来源；地图定位需要足够好的初始区域或全局重定位机制。初始化条件不足时，应维持“未就绪”状态，而不是输出高置信度但任意的位姿。

<a id="ch20-sec11"></a>
## 20.11 SLAM 的接口

同步定位与建图（Simultaneous Localization and Mapping, SLAM）在估计机器人轨迹的同时估计环境地图。状态估计与 SLAM 的边界可按时间尺度和变量范围划分：高频估计器负责当前导航状态与偏置，SLAM 后端维护关键帧、地图特征、回环约束和长期全局一致性。两者不是替代关系，而是局部动态估计与全局结构估计的接口关系。

因子图形式可将联合问题写为最大后验估计：

```math
X^\star
=
\arg\min_X
\sum_k
\left\|r_k(X)\right\|_{\Sigma_k^{-1}}^2,
\qquad
\|r\|_{\Sigma^{-1}}^2=r^\mathsf T\Sigma^{-1}r,
```

其中 $`X`$ 可包含关键帧位姿、速度、IMU 偏置和地图变量； $`r_k`$ 可以是 IMU 预积分、轮速、视觉重投影、激光匹配、GNSS 或回环残差。滤波器倾向于按时间递推并边缘化旧状态，图优化则保留一段或全部历史变量进行重线性化。两者的概率基础相通，差别主要在计算结构和保留信息的方式。

接口设计应避免重复计算信息。若 SLAM 后端接收了 IMU 预积分和视觉特征，其输出关键帧位姿与前端 IMU 状态高度相关；把该位姿当作独立绝对测量再次送回同一滤波器，会产生相关性闭环。较安全的方式包括：明确由一个后端统一融合；或只把全局校正表示为 $`T_{MO}`$ ；或在可计算时传递交叉协方差。模块化不能以概率独立性的错误假设为代价。

回环检测会将当前地点与历史地点关联，从而修正长期漂移，但也可能产生错误闭环。几何验证、鲁棒核、开关变量和多假设验证可以降低风险。即使闭环正确，全局轨迹也可能发生较大调整，因此地图更新不应直接造成底层控制坐标跳变。巡检机器人可继续在连续里程计系中执行短时轨迹，同时由地图系变换吸收全局校正，并由规划层重新解释任务目标。

地图本身也有边界。视觉特征地图、稠密点云地图、占据栅格和语义地图服务于不同任务；不能把用于定位的稀疏特征直接视为可靠避障几何。动态环境中还需区分长期静态结构与短期移动对象。SLAM 提供的是状态估计的长期空间约束接口，而不是对环境永恒不变的承诺。

<a id="ch20-sec12"></a>
## 20.12 估计误差怎样进入控制闭环

控制器根据估计状态而不是真实状态计算输入。设真实系统为

```math
x_{k+1}=f(x_k,u_k,w_k),
\qquad
u_k=\pi(\hat x_k,r_k),
```

其中 $`r_k`$ 是参考目标， $`\hat x_k=x_k+e_k`$ 在局部坐标中表示估计值， $`e_k`$ 是估计误差。在线性工作点附近，若控制律为 $`u=-K\hat x`$ ，则

```math
u=-Kx-Ke.
```

因此估计误差通过 $`-Ke`$ 直接变成执行器命令。高增益控制虽然能快速抑制真实偏差，也会放大位置噪声、速度噪声和姿态抖动。所谓“控制器不稳定”有时实际是估计延迟、状态跳变或噪声带宽与控制增益不匹配。

对移动机器人，横向位置误差与航向误差会进入转向闭环。若估计延迟为 $`\tau`$ ，控制器使用的近似是过去状态 $`x(t-\tau)`$ ；在快速运动时，这相当于增加相位滞后并降低稳定裕度。可用最新输入和 IMU 将估计预测到执行时刻：

```math
\hat x(t_{\mathrm{act}})
=
\Phi\!\left(
\hat x(t_{\mathrm{est}}),
u_{[t_{\mathrm{est}},t_{\mathrm{act}}]}
\right),
```

其中 $`\Phi`$ 是状态传播算子。预测必须同时传播协方差，因为外推时间越长，状态可信度越低。

全局定位跳变尤其危险。若 GNSS 恢复或 SLAM 回环使地图位姿瞬间改变，直接使用地图系误差的底层控制器可能产生大幅转向命令。解决方式不是禁止全局校正，而是分离连续控制坐标与全局任务坐标，对 $`T_{MO}`$ 的变化进行明确管理，并在必要时重新规划。滤波器也不应为了视觉平滑而隐瞒真实的不确定性；连续性和全局一致性是两个不同需求，应通过坐标层次处理。

估计协方差还能主动进入决策与控制。若位置误差协方差为 $`P_p`$ ，障碍物安全距离可按方向 $`n`$ 扩张为

```math
d_{\text{safe}}
=
d_0+\kappa\sqrt{n^\mathsf T P_p n},
```

其中 $`d_0`$ 是名义安全距离， $`\kappa`$ 对应所需置信水平。类似地，当航向不确定性、定位创新或传感器健康指标超过阈值时，系统可降低速度、增大跟踪容差、切换传感器组合或进入安全停车。协方差不是装饰性输出，而是把感知可信度连接到行动风险的接口。

最后，估计器与控制器之间应形成可验证契约：状态定义和坐标系一致；时间戳与预测时刻明确；速度和角速度的表达坐标明确；协方差与有效性可用；重定位、失锁和初始化状态具有确定行为。Chapter 21 及后续关于决策、规划与控制的机制只有在这一接口可靠时，才能把模型中的稳定性和性能落实到真实机器人上。

## 本章小结

多传感器融合的主线可以概括为：先统一时间与坐标，再用动力学传播状态，最后依据每项测量的误差结构和可观方向进行概率更新。IMU 提供高频运动骨架，但偏置积分会漂移；编码器约束地面速度，但受滑移影响；GNSS 提供全局锚定，但会低频、跳变和失锁；视觉与激光提供环境相对约束，但存在数据关联、运动畸变和几何退化。融合的价值来自互补性，而不是传感器数量本身。

三维位姿必须在 $`SE(3)`$ 上表示和更新，不确定性则位于相应切空间。多速率、延迟测量、外参杆臂、测量相关性和异常值不是外围细节，而是决定系统能否在真实环境中工作的核心机制。状态估计还应与定位和 SLAM 分层：连续里程计服务高频控制，全局地图约束长期一致性，二者通过明确的坐标变换接口连接。

最重要的是，估计误差最终会进入行动闭环。噪声会被控制增益放大，延迟会侵蚀稳定裕度，位姿跳变会触发错误动作，不确定性则应影响速度、安全距离和降级策略。下一章将以本章输出的 $`\hat x`$ 、协方差、时间戳和健康状态为接口，进一步讨论自主系统如何在不完整且不确定的状态信息上形成可靠行动。
