## 30.1 从“稳定”到“最优”

稳定控制回答的是“系统能否回到或保持在目标附近”，最优控制进一步回答“在多种可行控制行为中，哪一种最好”。对于仓储移动操作机器人，使底盘最终停在货架前只是稳定性要求；减少到达时间、避免急转、降低轮毂电机发热，并让机械臂末端平稳接近货物，则需要在多个目标之间作定量权衡。因而，“最优”不是控制器固有的绝对属性，而是相对于给定模型、目标函数、时域、信息和约束而言的。

设状态为 $`x(t)\in\mathbb{R}^n`$ ，控制为 $`u(t)\in\mathbb{R}^m`$ 。连续时间最优控制的一般形式是

```math
\min_{u(\cdot)} J
=
\Phi(x(T))
+
\int_{0}^{T} \ell(x(t),u(t),t)\,dt,
\qquad
\dot{x}=f(x,u,t),
```

其中 $`\ell`$ 是运行代价， $`\Phi`$ 是终端代价， $`T`$ 是终止时刻。稳定性关注闭环轨迹的渐近性质，而目标函数还可编码能耗、时间、精度和动作平滑性。一个代价更低的控制器未必拥有更大的稳定裕度；反过来，一个稳定控制器也未必在执行时间或能量上合理。

工程上必须区分“数学最优”和“任务可接受”。若模型忽略地面摩擦变化、电机饱和、相机延迟或货物质量误差，计算出的最优输入只对名义模型最优。最优控制也不自动保证约束满足、鲁棒性或安全性。其适用前提包括模型在工作域内足够准确、状态或其估计可用、代价确实反映任务偏好；必要边界则由执行器能力、碰撞约束、实时算力和未建模动态共同确定。

<a id="ch30-sec2"></a>
## 30.2 动态系统 + 目标函数

最优控制问题由两个不可分割的部分组成：动态系统规定“哪些轨迹能够发生”，目标函数规定“如何比较这些轨迹”。离散时间形式与数字控制器最直接对应：

```math
x_{k+1}=f_k(x_k,u_k),\qquad
J=\phi(x_N)+\sum_{k=0}^{N-1}\ell_k(x_k,u_k),
```

其中 $`x_k\in\mathbb{R}^n`$ 、 $`u_k\in\mathbb{R}^m`$ ， $`k`$ 表示采样时刻， $`N`$ 为时域长度。若存在状态和输入限制，还要满足 $`x_k\in\mathcal X_k`$ 、 $`u_k\in\mathcal U_k`$ 。这些约束不会因为写入代价而自动严格满足：软惩罚允许违反，硬约束才定义可行集合。

仓储机器人的联合状态可包含底盘位姿与速度、六轴机械臂关节角与角速度以及电机内部状态，例如

```math
x=
\begin{bmatrix}
p_b^\top & \theta_b & v_b^\top &
q^\top & \dot q^\top & i^\top
\end{bmatrix}^{\top},
```

其中 $`p_b\in\mathbb{R}^2`$ 是底盘平面位置， $`\theta_b\in\mathbb{R}`$ 是航向角， $`q,\dot q\in\mathbb{R}^6`$ 是机械臂关节状态， $`i`$ 可表示电机电流。控制 $`u`$ 可以是轮端转矩与六个关节转矩，也可以是下层伺服器接收的速度或位置指令。控制层级不同，模型、代价权重和有效带宽也不同。

状态通常不是无误差可知的。相机、编码器和 IMU 经估计器融合得到 $`\hat x_k`$ 及其不确定性，再由控制器计算 $`u_k`$ 。本章主要先讨论确定性、全状态可用的名义问题，即用 $`\hat x_k`$ 近似 $`x_k`$ ；若估计误差显著，确定性最优解不再等同于随机意义下的最优解。模型离散化还应与采样周期一致，过大的周期会使线性化和二次近似失效。

<a id="ch30-sec3"></a>
## 30.3 状态代价与控制代价

最常用的局部目标是二次型。围绕参考状态 $`x_k^{\mathrm{ref}}`$ 和参考输入 $`u_k^{\mathrm{ref}}`$ ，定义误差 $`e_k=x_k-x_k^{\mathrm{ref}}`$ 、 $`\delta u_k=u_k-u_k^{\mathrm{ref}}`$ ，代价可写为

```math
J=
\frac{1}{2}e_N^\top Q_f e_N
+
\frac{1}{2}\sum_{k=0}^{N-1}
\left(
e_k^\top Q_k e_k+
\delta u_k^\top R_k\delta u_k
\right),
```

其中 $`Q_k,Q_f\in\mathbb{R}^{n\times n}`$ 为状态权重， $`R_k\in\mathbb{R}^{m\times m}`$ 为控制权重。通常要求 $`Q_k,Q_f\succeq0`$ 、 $`R_k\succ0`$ ，以保证控制方向上的局部最小化有唯一解。若加入交叉项 $`2e_k^\top S_k\delta u_k`$ ，还需检查整体块矩阵的半正定性。

$`Q`$ 决定“偏离目标有多贵”， $`R`$ 决定“控制动作有多贵”。底盘横向误差可赋较高权重以避免擦碰货架；机械臂末端位置误差可通过任务函数 $`r(q)`$ 写成 $`\|r(q)-r^\mathrm{ref}\|_W^2`$ ；电机转矩、电流或功率可分别用于近似动作强度、热负荷或能耗。为抑制指令跳变，还可加入

```math
\ell_{\Delta u}=
(u_k-u_{k-1})^\top R_\Delta(u_k-u_{k-1}),
```

这要求把上一时刻输入并入增广状态，或在优化变量之间保留耦合。

权重不能只凭数值大小比较，因为位置、角度、速度和转矩的单位不同。常用做法是按可接受误差归一化，例如令 $`Q_{ii}=1/e_{i,\max}^2`$ ，再根据任务风险调整。二次代价在参考附近平滑、易优化，但它不会天然表达碰撞的不可接受性，也可能对大误差给出不符合任务语义的权衡。障碍物、视野边界和关节极限需要硬约束、障碍函数或分段代价，并明确这些替代方式各自只提供何种保证。

<a id="ch30-sec4"></a>
## 30.4 有限时域与无限时域

有限时域问题在 $`k=0,\ldots,N`$ 上优化，允许模型、参考和权重随时间变化，并通过终端代价 $`\phi(x_N)`$ 表达任务结束时的要求。仓储机器人从通道进入取货位、机械臂在两秒内完成接近动作，均具有自然的有限时域。终端状态也可受约束，例如 $`x_N\in\mathcal X_f`$ ；若只加入有限权重的终端代价，则通常只能鼓励而不能强制精确到达。

无限时域问题考虑

```math
J_\infty=\sum_{k=0}^{\infty}\ell(x_k,u_k)
```

或连续时间积分，适合调节到固定平衡点并长期保持。在线性、时不变、二次代价和适当可控性条件下，无限时域解收敛到常数反馈增益，因而实现简单、适用于底盘速度保持或机械臂关节定点调节。若没有折扣因子，只有当闭环状态和输入足够快地趋于零时，总代价才有限。

有限与无限时域并非单纯的计算长度差异。有限时域控制器一般是时变的，并受终端条件强烈影响；无限时域解依赖系统可稳定性以及不可观测模态不会被代价遗漏等条件。对于持续变化的仓储任务，无限时域定点 LQR 不能直接替代轨迹优化；对于有电机饱和和碰撞限制的问题，两者也都不能仅凭无约束解保证安全。下一章的滚动时域方法将有限时域优化反复在线求解，使当前状态和约束持续进入决策。

## 30.5 变分法的基本思想

变分法不直接枚举所有控制序列，而是研究一条候选轨迹受到无穷小扰动后，目标函数如何变化。若候选控制为 $`u(t)`$ ，取扰动 $`u_\epsilon(t)=u(t)+\epsilon\eta(t)`$ ，其中 $`\eta(t)`$ 是允许的变化方向，则局部最优解必须满足一阶变分

```math
\delta J
=
\left.\frac{d}{d\epsilon}J[u_\epsilon]\right|_{\epsilon=0}
=0
```

对所有可行的 $`\eta`$ 成立；二阶变分非负则提供局部极小的进一步条件。与普通多元微积分相比，优化变量从有限维向量变成了随时间变化的函数。

动态约束使状态变化 $`\delta x`$ 与控制变化 $`\delta u`$ 不能独立选择。在线性化意义下，

```math
\delta\dot x
=
f_x(x,u,t)\delta x+
f_u(x,u,t)\delta u,
```

其中 $`f_x\in\mathbb{R}^{n\times n}`$ 、 $`f_u\in\mathbb{R}^{n\times m}`$ 是 Jacobian。引入伴随变量后，可以把所有 $`\delta x`$ 项消去，将代价变化表示成关于 $`\delta u`$ 的梯度。这一思想产生 PMP，也在离散形式中演化为反向传播、伴随法和轨迹优化的反向递推。

工程上，变分法解释了为何需要模型导数，以及为何导数质量直接影响优化方向。对六轴机械臂，刚体动力学、摩擦模型和接触切换都可能使导数不连续；对带角度的底盘状态，直接相减还可能跨越 $`2\pi`$ 分支。变分结论是局部必要条件，不保证全局最优；它通常假设动力学和代价在所研究区域内可微，并要求扰动不破坏未被显式处理的硬约束。

## 30.6 Pontryagin Minimum Principle

Pontryagin 最小值原理（PMP）为受动态约束的连续时间最优控制给出必要条件。定义 Hamiltonian

```math
H(x,u,\lambda,t)
=
\ell(x,u,t)+\lambda^\top f(x,u,t),
```

其中协态 $`\lambda(t)\in\mathbb{R}^n`$ 衡量状态变化对未来最优代价的边际影响。对无路径约束、终止时刻固定且函数可微的问题，最优轨迹满足

```math
\dot x^\star=H_\lambda=f(x^\star,u^\star,t),\qquad
\dot\lambda^\star=-H_x,
```

```math
u^\star(t)\in\arg\min_u H(x^\star,u,\lambda^\star,t),\qquad
\lambda(T)=\Phi_x(x^\star(T)).
```

状态从初值向前传播，协态从终端条件向后传播，两者通过最优控制条件耦合，形成两点边值问题。对于控制仿射系统 $`f=f_0(x)+G(x)u`$ ，若控制代价为 $`\frac12u^\top Ru`$ 且 $`R\succ0`$ ，驻值条件给出 $`u^\star=-R^{-1}G^\top\lambda`$ 。若没有二次控制代价而输入有界，最优输入可能落在边界，产生 bang-bang 控制；因此控制平滑性不是 PMP 自动带来的。

在仓储机器人机械臂的快速取放中，PMP 可解释某一时刻增加关节转矩如何通过未来状态影响终端抓取误差。路径约束、转矩边界和接触条件需要附加乘子及互补条件，切换点处还可能出现非光滑结构。PMP 只给出必要条件，求得的驻值轨迹可能是局部极小、极大或鞍点；模型可微性、可行初值和边值求解器的数值稳定性决定了它在工程上的实际可用性。

## 30.7 Bellman 最优性原理

Bellman 最优性原理指出：一条最优策略从任意中间状态开始的剩余部分，也必须对该剩余子问题最优。定义离散时间价值函数

```math
V_k(x)
=
\min_{u_k,\ldots,u_{N-1}}
\left[
\phi(x_N)+
\sum_{j=k}^{N-1}\ell_j(x_j,u_j)
\right],
```

则有递推关系

```math
V_k(x)
=
\min_u\left[
\ell_k(x,u)+V_{k+1}(f_k(x,u))
\right],
\qquad
V_N(x)=\phi(x).
```

等式右侧把一次决策的即时代价与下一状态的最优剩余代价相加。最小化得到策略 $`\pi_k^\star(x)`$ ，控制律为 $`u_k=\pi_k^\star(x_k)`$ 。与只给出一条开环输入序列相比，价值函数原则上定义了从整个状态域出发的反馈策略。

对仓储底盘而言，价值函数可以理解为“从当前位姿、速度和电量状态到达货架的最小剩余代价”。如果某次轮胎打滑使机器人偏离名义轨迹，只要当前状态仍在价值函数覆盖的区域，反馈策略就能重新选择动作。这个解释也说明了状态为何必须包含影响未来的充分信息；若相机遮挡历史或电机温度会影响后续能力，却未包含在状态中，Markov 假设便不成立。

Bellman 原理本身非常一般，但精确求解价值函数受到维数灾难限制。六轴机械臂仅关节位置和速度就有十二维，再叠加底盘与传感器状态，规则网格几乎不可行。它还假设模型和代价能够正确描述一步转移；在部分可观测环境中，严格状态应扩展为概率信念。LQR、iLQR 和 DDP 的核心，可以视为在特殊结构或局部邻域内让 Bellman 递推变得可计算。

<a id="ch30-sec8"></a>
## 30.8 Dynamic Programming

动态规划（Dynamic Programming，DP）是实现 Bellman 递推的一类计算方法。有限状态、有限动作情形下，可从终端时刻开始，对每个状态逐层计算

```math
Q_k(x,u)=\ell_k(x,u)+V_{k+1}(f_k(x,u)),
\qquad
V_k(x)=\min_u Q_k(x,u),
```

并保存最优动作 $`\pi_k^\star(x)=\arg\min_u Q_k(x,u)`$ 。这里的 $`Q_k`$ 是“当前采取动作 $`u`$ 、以后均最优”时的代价，不应与 LQR 中的状态权重矩阵 $`Q`$ 混淆。

在小规模离散模型上，DP 能处理非凸代价、离散模式和有界输入。例如可将仓库路口、通道占用和任务模式抽象成有限状态，用 DP 选择通行方向；但若把底盘连续位姿、机械臂关节和电机状态全部网格化，存储与计算量随状态维数指数增长。若每维取 $`M`$ 个节点，状态表规模约为 $`M^n`$ ，这就是维数灾难。

连续系统可采用插值、近似动态规划或局部函数近似，但插值误差会破坏精确递推，约束边界附近尤其敏感。DP 的全局性依赖于状态和动作覆盖、转移模型正确以及所有相关状态可观测。工程上常把任务级离散决策交给 DP，而把高维连续运动交给 LQR、轨迹优化或 MPC；这种分层并不自动全局最优，但能在算力与模型精度之间取得可实施的折中。

<a id="ch30-sec9"></a>
## 30.9 HJB 方程的基本思想

Hamilton–Jacobi–Bellman（HJB）方程是连续时间 Bellman 原理的微分形式。定义从时刻 $`t`$ 、状态 $`x`$ 出发的最优剩余代价

```math
V(x,t)=
\min_{u(\cdot)}
\left[
\Phi(x(T))+
\int_t^T\ell(x(\tau),u(\tau),\tau)\,d\tau
\right].
```

对一个短时间间隔展开，可得

```math
-\frac{\partial V}{\partial t}
=
\min_u
\left[
\ell(x,u,t)+
\nabla_x V(x,t)^\top f(x,u,t)
\right],
\qquad
V(x,T)=\Phi(x).
```

其中 $`\nabla_xV\in\mathbb{R}^n`$ 。方括号内正是以 $`\lambda=\nabla_xV`$ 构成的 Hamiltonian，因此 HJB 与 PMP 在光滑条件下相互连接：PMP 沿一条最优轨迹传播协态，HJB 则试图在整个状态—时间域求价值函数。若 $`V`$ 足够光滑，最优反馈由方程中的逐点最小化得到。

对底盘避障或无人机姿态恢复，HJB 理论上可直接产生状态反馈，并表达任意初始状态的最优剩余代价。然而高维偏微分方程难以网格求解，价值函数在切换面和障碍边界附近还可能不可微，此时需采用黏性解等更弱的概念。经典 HJB 不会绕过维数灾难；它的工程价值更多在于提供统一理论、验证低维问题，以及指导局部二次近似和价值函数学习。

<a id="ch30-sec10"></a>
## 30.10 Riccati 方程

当动力学线性、代价二次时，Bellman 递推保持二次结构。考虑离散系统

```math
x_{k+1}=A_kx_k+B_ku_k
```

及代价

```math
J=\frac12x_N^\top Q_fx_N+
\frac12\sum_{k=0}^{N-1}
\left(x_k^\top Q_kx_k+u_k^\top R_ku_k\right).
```

假设价值函数为 $`V_{k+1}(x)=\frac12x^\top P_{k+1}x`$ ，代入 Bellman 方程并对 $`u`$ 配方，可得

```math
K_k=
(R_k+B_k^\top P_{k+1}B_k)^{-1}
B_k^\top P_{k+1}A_k,
```

```math
P_k=
Q_k+A_k^\top P_{k+1}A_k
-
A_k^\top P_{k+1}B_k
(R_k+B_k^\top P_{k+1}B_k)^{-1}
B_k^\top P_{k+1}A_k,
```

终端条件为 $`P_N=Q_f`$ ，最优反馈为 $`u_k^\star=-K_kx_k`$ 。 $`P_k\in\mathbb{R}^{n\times n}`$ 表示未来代价的曲率， $`K_k\in\mathbb{R}^{m\times n}`$ 将状态映射为控制。

连续时间对应微分 Riccati 方程

```math
-\dot P
=
A^\top P+PA-PBR^{-1}B^\top P+Q,
\qquad
P(T)=Q_f.
```

无限时域、时不变问题在满足可稳定性与可检测性等条件时， $`P`$ 可收敛到代数 Riccati 方程的稳定化解。数值实现中通常调用可靠的 Riccati 或 Schur 分解算法，而不是显式计算矩阵逆；可通过线性方程求解获得增益。

Riccati 方程不仅是计算技巧，它表达了当前决策如何通过动力学影响全部未来代价。对底盘与机械臂耦合系统， $`P`$ 的非对角项可表示底盘误差与机械臂误差之间的未来耦合。其边界也很明确：标准递推假设无硬输入和状态约束，且要求相关矩阵维度一致、控制方向具有正定曲率；饱和后实际闭环不再是所求的无约束最优系统。

<a id="ch30-sec11"></a>
## 30.11 LQR

线性二次调节器（Linear Quadratic Regulator，LQR）针对线性系统与二次代价构造最优状态反馈。离散时不变系统

```math
x_{k+1}=Ax_k+Bu_k
```

在无限时域代价 $`\sum_{k=0}^\infty(x_k^\top Qx_k+u_k^\top Ru_k)`$ 下，若 $`(A,B)`$ 可稳定、 $`(Q^{1/2},A)`$ 可检测，且 $`Q\succeq0`$ 、 $`R\succ0`$ ，则稳定化 Riccati 解给出

```math
u_k=-Kx_k,\qquad
K=(R+B^\top PB)^{-1}B^\top PA.
```

闭环矩阵为 $`A_{\mathrm{cl}}=A-BK`$ 。离散系统要求其特征值位于单位圆内，连续系统则要求 $`A-BK`$ 的特征值实部为负。

例如将仓储底盘在直线匀速附近线性化，状态可取横向位置误差、航向误差及其变化率，控制为左右轮差动力矩；LQR 会同时抑制偏航和过大的轮端动作。对单个机械臂关节，也可用 $`x=[q-q^\star,\dot q]^\top`$ 、 $`u=\tau-\tau^\star`$ 设计局部调节器。若前一章的模型前馈抵消重力和参考加速度，LQR 可作为误差反馈，形成“前馈承担名义运动、反馈修正偏差”的结构。

LQR 的优势是计算稳定、参数含义清晰，并能同时处理多状态耦合；但它不是“调好 $`Q,R`$ 就必然安全”的配方。线性模型只在工作点附近有效，状态必须可测或可估计，执行器饱和会改变闭环动力学。LQR 也不显式处理关节限位、碰撞和轮胎摩擦锥。工程验证应包含闭环特征值、饱和范围、模型误差、采样延迟和状态估计噪声，而不能只比较名义仿真代价。

<a id="ch30-sec12"></a>
## 30.12 MIMO LQR

MIMO LQR 是多输入多输出系统上的 LQR，而非若干单回路控制器的简单并列。对于 $`x\in\mathbb{R}^n`$ 、 $`u\in\mathbb{R}^m`$ ，增益 $`K\in\mathbb{R}^{m\times n}`$ 的每一行通常同时依赖多个状态。六轴机械臂若以关节转矩为输入，则惯性矩阵、科氏项和末端任务使各关节耦合；移动操作机器人中，底盘运动还会改变机械臂基座，从而影响抓取误差。

完整矩阵权重可表达这种耦合。例如任务空间小误差满足 $`\delta p_e\approx J_e(q^\star)\delta q`$ ，其中 $`J_e\in\mathbb{R}^{d\times6}`$ 是末端任务 Jacobian。若希望惩罚末端误差 $`\delta p_e^\top W\delta p_e`$ ，可在关节状态代价中得到

```math
Q_q=J_e^\top WJ_e.
```

$`Q_q`$ 通常不是对角矩阵，这意味着某些关节误差组合比单个关节误差更重要。类似地， $`R`$ 的非对角项可描述共享电源或组合驱动动作的代价，但必须保持整体正定。

MIMO 设计要求状态和输入尺度合理，否则米、弧度、米每秒和安培的数值差异会造成病态矩阵。并非所有状态都必须单独可控，但所有不稳定模态必须可稳定；代价未观测到的不稳定模态会破坏无限时域结论。若只使用对角 $`Q,R`$ ，Riccati 解仍可产生耦合增益，但代价表达能力受限。对于接触切换、柔性传动和强饱和，多变量线性反馈只在选定模式与局部区域内成立。

<a id="ch30-sec13"></a>
## 30.13 Tracking LQR

调节问题以零状态或固定平衡点为目标，轨迹跟踪则围绕时变名义轨迹 $`(\bar x_k,\bar u_k)`$ 工作。名义轨迹应满足

```math
\bar x_{k+1}=f_k(\bar x_k,\bar u_k).
```

定义局部误差 $`\delta x_k=x_k-\bar x_k`$ 、 $`\delta u_k=u_k-\bar u_k`$ ，动力学一阶线性化为

```math
\delta x_{k+1}
\approx A_k\delta x_k+B_k\delta u_k,
\quad
A_k=\left.\frac{\partial f_k}{\partial x}\right|_{\bar x_k,\bar u_k},
\quad
B_k=\left.\frac{\partial f_k}{\partial u}\right|_{\bar x_k,\bar u_k}.
```

对时变 Riccati 方程反向递推可得 TVLQR 控制律

```math
u_k=\bar u_k-K_k\delta x_k.
```

仓储机器人执行“底盘接近货架—机械臂伸出—夹爪对准”的协同轨迹时， $`\bar u_k`$ 提供名义前馈， $`K_k`$ 根据每个阶段的局部动力学修正误差。相机更新较慢时，IMU 和编码器可在估计器中提供高频状态预测；控制器使用的是统一时刻的 $`\hat x_k`$ ，而不是未经时间对齐的原始测量。若估计偏差持续存在，单纯反馈可能留下稳态误差，可增广积分状态，但这会改变系统维度和可稳定性条件。

在流形状态上不能总用普通减法定义误差。底盘航向需进行角度归一化，三维姿态通常用 $`SO(3)`$ 上的对数映射形成局部切空间误差。Tracking LQR 的保证是局部的：名义轨迹必须动态可行，线性化误差必须足够小，反馈动作不能长期饱和。若参考轨迹穿过障碍物、超出关节极限或要求不可实现的加速度，TVLQR 无法把不合理参考变成可行运动。

<a id="ch30-sec14"></a>
## 30.14 iLQR

迭代 LQR（iterative LQR，iLQR）把 LQR 的局部二次求解嵌入非线性轨迹优化。给定一条名义控制序列 $`\{\bar u_k\}`$ ，先用非线性动力学前向滚动得到 $`\{\bar x_k\}`$ ；随后在轨迹附近线性化动力学、二次展开代价，并通过类似 Riccati 的反向递推计算控制修正

```math
\delta u_k=k_k+K_k\delta x_k,
```

其中 $`k_k\in\mathbb{R}^m`$ 是前馈搜索方向， $`K_k\in\mathbb{R}^{m\times n}`$ 是局部反馈增益。再用步长 $`\alpha\in(0,1]`$ 前向更新

```math
u_k^{\mathrm{new}}
=
\bar u_k+\alpha k_k+
K_k(x_k^{\mathrm{new}}-\bar x_k).
```

iLQR 的反向阶段对一步局部 $`Q`$ 函数作二次近似。若记价值函数导数为 $`V_x,V_{xx}`$ ，则在常见形式下

```math
Q_u=\ell_u+B^\top V_x',\qquad
Q_{uu}=\ell_{uu}+B^\top V_{xx}'B,
```

```math
Q_{ux}=\ell_{ux}+B^\top V_{xx}'A,
\qquad
k=-Q_{uu}^{-1}Q_u,\quad
K=-Q_{uu}^{-1}Q_{ux}.
```

撇号表示下一时刻的价值导数。为保证 $`Q_{uu}`$ 可正定求解，通常采用 Levenberg–Marquardt 型正则化；线搜索或信赖域用于检查真实非线性代价是否下降。

在仓储移动操作机器人中，iLQR 可联合优化底盘与机械臂动作，例如让底盘稍微侧移以减少机械臂接近奇异位形的程度。它需要一个尚可的初始控制序列，且通常处理平滑代价和可微动力学。标准 iLQR 对动力学只保留一阶导数，因此是局部算法，可能收敛到局部极小，也可能因碰撞代价非光滑、接触模式改变或初值过差而失败。输入限幅可以通过投影、控制受限反向步或重新参数化近似处理，但这些做法不等于一般硬约束优化的完整保证。

<a id="ch30-sec15"></a>
## 30.15 DDP

微分动态规划（Differential Dynamic Programming，DDP）与 iLQR 共享“前向滚动—反向局部动态规划—再前向更新”的结构，但 DDP 在局部 $`Q`$ 函数中进一步保留动力学的二阶导数。对离散动力学 $`x'=f(x,u)`$ ，例如

```math
Q_{xx}
=
\ell_{xx}
+
A^\top V_{xx}'A
+
\sum_{i=1}^{n}V_{x_i}'\,f_{xx}^{(i)},
```

其中 $`f_{xx}^{(i)}\in\mathbb{R}^{n\times n}`$ 是第 $`i`$ 个下一状态分量对当前状态的 Hessian。 $`Q_{ux}`$ 和 $`Q_{uu}`$ 中也分别含有 $`f_{ux}^{(i)}`$ 、 $`f_{uu}^{(i)}`$ 项。iLQR 通常省略这些动力学二阶项，因此也常被称为 Gauss–Newton 型 DDP。

二阶信息可以在非线性较强时改善局部模型和收敛速度。例如机械臂快速运动时，惯性耦合对关节状态具有明显非线性；无人机大角度机动中的旋转动力学也可能受益于完整 DDP。然而 Hessian 的计算、存储和收缩成本更高，自动微分虽能减少手工推导错误，却不能消除数值病态。若动力学来自带噪声辨识模型，二阶导数往往比一阶导数更不可靠，此时 iLQR 反而可能更稳健。

DDP 仍不是全局优化器。其局部二次模型要求轨迹附近具有足够光滑性， $`Q_{uu}`$ 需要通过正则化维持正定，前向更新还需接受准则。仓储抓取中的刚性碰撞、静摩擦切换和物体脱落会破坏光滑假设；可采用平滑接触模型或分模式优化，但所得解只对所选近似与模式有效。工程上应比较真实滚动代价、约束余量和模型外验证，而不能仅以二阶算法“收敛”作为成功标准。

<a id="ch30-sec16"></a>
## 30.16 Taylor、Jacobian 与 Hessian 在这里汇合

LQR、iLQR 和 DDP 的共同语言是局部 Taylor 展开。对轨迹附近的动力学，二阶展开可写为

```math
f(\bar x+\delta x,\bar u+\delta u)
\approx
f(\bar x,\bar u)
+
A\delta x+B\delta u
+
\frac12
\begin{bmatrix}\delta x\\\delta u\end{bmatrix}^{\top}
\nabla^2 f
\begin{bmatrix}\delta x\\\delta u\end{bmatrix},
```

其中 $`A=f_x\in\mathbb{R}^{n\times n}`$ 、 $`B=f_u\in\mathbb{R}^{n\times m}`$ ；由于 $`f`$ 是向量函数， $`\nabla^2 f`$ 实际是由 $`n`$ 个 Hessian 组成的三阶张量。iLQR 主要使用 $`A,B`$ ，DDP 还使用这些二阶张量与价值梯度的收缩结果。

标量代价的二阶展开则是

```math
\ell(\bar z+\delta z)
\approx
\ell(\bar z)
+
\ell_z^\top\delta z
+
\frac12\delta z^\top\ell_{zz}\delta z,
\qquad
z=\begin{bmatrix}x\\u\end{bmatrix}.
```

梯度决定局部下降方向，Hessian 描述曲率，Jacobian 则把状态与控制扰动传播到下一时刻。反向递推把这些局部导数通过 Bellman 结构聚合成“当前动作对全部未来代价”的导数，这正是从微积分、几何和优化到反馈控制的汇合点。

导数可以由解析推导、有限差分、自动微分或算法微分获得。有限差分实现简单，但步长过大会有截断误差，过小会受浮点消减影响；自动微分精度较高，却要求计算图中的动力学和代价可微。相机重投影残差、IMU 预积分状态和机械臂位姿误差还涉及流形坐标，应在一致的局部切空间内求导。实际部署前应做方向导数检查，并验证离散化、单位和坐标约定，否则一个符号或坐标系错误就可能使反向递推产生错误反馈。

Taylor 模型只在有限邻域内可信。线搜索、信赖域和正则化的作用不是让近似变成全局真理，而是限制每次更新不要离开有效区域。接近机械臂奇异位形、底盘轮胎打滑边界或相机视野边缘时，Jacobian 可能病态，Hessian 也可能不定；此时应缩小步长、改变参数化、增加约束处理，或切换到更适合非光滑和混合动力学的方法。

<a id="ch30-sec17"></a>
## 30.17 Bellman 如何连接最优控制与强化学习

最优控制和强化学习共享 Bellman 结构，只是在模型信息、数据来源和目标记号上常有差异。强化学习通常最大化回报，若改用最小化代价，则折扣无限时域 Bellman 方程为

```math
V^\star(x)
=
\min_u
\left[
\ell(x,u)+
\gamma\,\mathbb E\!\left[V^\star(x')\mid x,u\right]
\right],
\qquad 0\le\gamma<1,
```

相应的动作价值函数满足

```math
Q^\star(x,u)
=
\ell(x,u)+
\gamma\,\mathbb E\!\left[
\min_{u'}Q^\star(x',u')
\mid x,u
\right].
```

在确定性已知模型中，期望退化为 $`x'=f(x,u)`$ ，这就回到动态规划。LQR 用二次函数精确表示特殊线性系统的价值函数；iLQR/DDP 则沿名义轨迹构造局部二次价值近似；价值学习和策略学习尝试用参数化函数从数据中近似更大区域的价值或策略。

仓储机器人可以用已知动力学和安全约束完成底层转矩控制，再从运行数据学习货物质量变化、轮地摩擦或任务级代价。相机与 IMU 观测并不一定构成 Markov 状态，因此可使用估计器输出的信念状态，或用具有记忆的策略近似历史信息。模型式强化学习可辨识 $`f_\theta`$ 后进行规划，无模型方法则直接估计价值或策略；两者都不能自动消除分布外状态、感知误差和探索风险。

Bellman 残差小不等于真实机器人安全。函数近似、离线数据覆盖不足和模型偏差都可能使策略在未见状态上产生任意动作；折扣因子也改变了任务的时间偏好，并不只是数值技巧。对高功率电机、六轴机械臂和与人员共享空间的底盘，学习策略需要置于动作限幅、碰撞监测、备用控制器和可验证约束之下。最优控制提供模型结构、局部稳定反馈和可解释代价，强化学习提供从数据改善模型或价值近似的途径，二者更适合作为互补接口，而不是彼此替代。

## 本章小结

本章从“保持稳定”推进到“在动态约束下选择代价最小的行动”。动态系统定义可行轨迹，运行代价与终端代价定义任务偏好；变分法、PMP 和 HJB 分别从轨迹必要条件、协态传播和价值函数递推刻画同一个最优控制问题。在线性动力学与二次代价这一特殊结构下，价值函数保持二次形式，Riccati 方程由此产生 LQR、MIMO LQR 和时变跟踪反馈。

面对移动底盘与六轴机械臂的非线性耦合，iLQR 和 DDP 沿名义轨迹反复构造局部线性—二次模型，以前向滚动和反向 Bellman 递推更新控制序列。Taylor 展开、Jacobian、Hessian、几何误差和状态估计由此进入同一个计算链条。所有这些方法都依赖模型、可微性、局部近似和状态信息；标准形式不自动处理电机饱和、碰撞、关节极限、感知延迟或模型不确定性。

下一章将在有限时域优化的基础上加入滚动重规划：每个控制周期使用最新状态估计重新求解，并显式处理状态与输入约束。由此，LQR 可作为终端局部控制器或优化器内部结构，iLQR/DDP 可作为非线性求解机制，而模型预测控制则把这些工具组织成持续在线、面向约束的闭环决策框架。
