## 27.1 比例控制

比例控制根据当前误差立即产生控制作用。对标量被控量，令参考输入为 $`r(t)`$ 、测量输出为 $`y(t)`$ ，误差为 $`e(t)=r(t)-y(t)`$ ，比例控制律写成

```math
u(t)=u_{\mathrm{ff}}(t)+K_p e(t),
```

其中 $`u\in\mathbb{R}`$ 是执行器命令， $`u_{\mathrm{ff}}`$ 是由模型、重力补偿或期望加速度产生的前馈项， $`K_p`$ 的量纲为“输入单位/输出单位”。若省略前馈项，比例器只能通过形成非零误差来提供抵消负载所需的输入。例如仓储移动机器人的速度环需要持续输出电机转矩以克服滚动阻力；只有比例反馈时，稳态速度通常略低于命令速度，因为必须保留一个误差来产生该转矩。

设线性化对象的传递函数为 $`P(s)`$ ，单位负反馈下闭环传递函数为

```math
\frac{Y(s)}{R(s)}=\frac{K_pP(s)}{1+K_pP(s)}.
```

比例增益增大通常会提高低频环路增益、缩短响应时间并减小稳态误差，但“增益越大越好”并不成立。以一阶对象 $`P(s)=b/(\tau s+1)`$ 为例，闭环极点为 $`-(1+bK_p)/\tau`$ ，在 $`bK_p>-1`$ 时增大 $`K_p`$ 确实加快响应；若对象还包含机械柔性、计算延迟、相机处理延迟或未建模高频模态，则较大的增益会降低相位裕度，引起振荡甚至失稳。相机视觉伺服尤其受帧率和延迟限制，不能沿用高带宽电机电流环的比例增益。

对向量误差 $`e\in\mathbb{R}^m`$ ，比例律可写为 $`u=u_{\mathrm{ff}}+K_pe`$ ，其中 $`K_p\in\mathbb{R}^{p\times m}`$ 。六轴机械臂的关节位置控制常取对角矩阵，使每个关节近似独立；但在高速运动、重载或接近奇异构型时，关节之间通过惯性矩阵和几何雅可比显著耦合，简单对角比例器只能视为局部近似。在笛卡尔空间中，位置误差可以直接相减，姿态误差则应由 $`SO(3)`$ 上的对数映射或等价局部坐标构造，而不能无条件地对欧拉角逐分量相减。

比例控制结构简单、计算确定、易于建立安全边界，适合内环、阻尼充分且稳态偏差允许存在的对象。其适用前提是反馈符号正确、工作点附近对象增益方向已知、采样频率明显高于目标闭环带宽，并且执行器尚未长期饱和。它提供了最基本的误差校正机制，也暴露出两个随后需要处理的问题：恒值扰动造成的静差，以及提高增益时噪声、延迟和稳定裕度之间的冲突。

## 27.2 积分控制

积分控制累积历史误差，并根据误差面积产生控制输入。定义积分状态

```math
\dot{x}_I(t)=e(t),\qquad u_I(t)=K_i x_I(t),
```

则 $`x_I`$ 的量纲为“输出单位·秒”， $`K_i`$ 的量纲为“输入单位/(输出单位·秒)”。在闭环稳定且信号收敛的前提下，积分器会持续调整输入，直到恒定参考下的稳态误差趋于零。对仓储机器人底盘速度环，电池电压变化、地面坡度和载荷变化可近似为缓慢或恒值扰动，积分作用能自动补足克服这些扰动所需的电机转矩。

从模型角度看，积分器在原点引入一个极点，控制器为 $`C_I(s)=K_i/s`$ 。这使低频环路增益随频率降低而增大，并体现了内模原理：要无静差地跟踪常值信号、抑制常值扰动，闭环内部需要包含常值信号生成器，即位于 $`s=0`$ 的积分动态。该结论有明确条件：闭环必须保持内部稳定，执行器必须有能力提供所需稳态输入，而且对象在原点附近不能具有使这一结构不可稳定化的零极点特征。若参考是斜坡，仅含一个积分器通常仍会留下有限跟踪误差；继续增加积分阶次又会显著增加稳定性风险。

积分作用会增加相位滞后，使系统更容易产生超调和低频振荡。六轴机械臂关节若已通过重力模型提供前馈补偿，积分器只需修正摩擦、模型偏差和负载误差；若让积分器承担全部重力转矩，它会在启动阶段长时间累积，造成明显超调。积分还无法区分“误差尚未消除”和“执行器已无能力消除误差”：机械臂碰到货架、电机达到电流上限或底盘车轮打滑时，继续积分将形成 windup，必须使用第 27.11 节的抗饱和机制。

数字控制器通常按采样周期 $`T_s`$ 更新积分状态。最简单的前向矩形实现为

```math
x_I[k+1]=x_I[k]+T_s e[k],
```

梯形实现则为 $`x_I[k+1]=x_I[k]+\tfrac{T_s}{2}(e[k]+e[k-1])`$ 。后者对平滑信号更准确，但两者都要求时间戳可靠，并需要限制异常采样间隔造成的积分跳变。若积分对象是位置、姿态或地图坐标误差，还应先保证误差位于一致坐标系；例如移动底盘航向误差必须映射到 $`(-\pi,\pi]`$ 的局部分支，否则跨越角度边界会产生错误的大积分量。

## 27.3 微分控制

微分控制根据误差变化趋势产生提前校正：

```math
u_D(t)=K_d\dot e(t).
```

其中 $`K_d`$ 的量纲为“输入单位·秒/输出单位”。若误差正在快速减小，微分项会降低继续加速的控制作用；若误差快速增大，则会施加更强的反向校正。因此微分项常被解释为人工阻尼或趋势预测。在机械臂关节位置环中，若参考位置暂时固定，则 $`\dot e=-\dot q`$ ，控制律中的 $`-K_d\dot q`$ 正是与关节速度相反的阻尼转矩。

理想微分器 $`K_ds`$ 的高频增益无限大，不能直接用于真实传感器。编码器量化、IMU 振动、相机像素抖动都会被差分放大，因此工程上采用带限微分器，例如

```math
C_D(s)=K_d\frac{s}{1+s/\omega_f}
      =K_d\frac{\omega_f s}{s+\omega_f},
```

其中 $`\omega_f>0`$ 是滤波极点，单位为 $`\mathrm{rad/s}`$ 。在 $`\omega\ll\omega_f`$ 时，它近似理想微分；在高频处增益被限制为 $`K_d\omega_f`$ 。滤波截止频率必须高于希望提供相位超前的频段，又应低于传感器噪声、结构共振或混叠占主导的频段。这种选择依赖实际频谱，不存在适合所有机器人的固定比值。

为避免参考阶跃引起“微分冲击”，工程实现常对测量而不是对误差求导：

```math
u_D(t)=-K_d\dot y_f(t),
```

其中 $`y_f`$ 是经过适当滤波的测量。这样参考 $`r`$ 的不连续变化不会直接生成巨大控制脉冲。对移动底盘航向环，可使用陀螺仪角速度作为航向测量的导数信息，而不必对低频定位系统的航向做数值差分；但 IMU 零偏和安装振动仍需由估计器处理。对相机位姿误差，帧间差分同时包含目标运动、相机运动和视觉估计噪声，微分项通常只能放在低带宽外环，或改用融合后的速度状态。

微分作用改善阻尼的前提是导数估计方向正确、延迟足够小且目标模态可观测。若测量延迟接近闭环时间尺度，所谓“趋势”实际上是过去趋势，可能反而降低阻尼。微分也不能消除静差，更不能替代机械结构的真实阻尼、状态估计或输入约束处理；它只是利用局部动态信息塑造闭环瞬态。

## 27.4 PID

PID 将比例、积分和带限微分组合为一个误差反馈律。并联形式可写为

```math
u(t)=u_{\mathrm{ff}}(t)+K_pe(t)+K_i\int_0^t e(\tau)\,d\tau
+K_d\frac{d e(t)}{dt}.
```

在理想连续模型中，控制器传递函数为 $`C(s)=K_p+K_i/s+K_ds`$ 。也常使用 $`K_p(1+1/(T_is)+T_ds)`$ 的参数化，其中 $`K_i=K_p/T_i`$ 、 $`K_d=K_pT_d`$ 。不同工业控制器可能采用并联式、串联式或相互作用式参数定义，数值不能在未核对公式、单位和采样周期时直接复制。

实用的两自由度 PID 通常将参考权重与反馈作用分开：

```math
u=K_p(\beta r-y)+K_i x_I-K_d\dot y_f+u_{\mathrm{ff}},
\qquad
\dot x_I=r-y,
```

其中 $`\beta\in[0,1]`$ 是比例参考权重。积分项仍作用于完整跟踪误差，以保留常值参考的零静差能力；比例项通过 $`\beta`$ 降低参考阶跃造成的超调；微分项只对测量作用，以避免微分冲击。这种结构区分了“跟踪参考”和“抑制扰动”两类目标，通常比将三个环节机械地作用于同一误差信号更符合工程需求。

离散实现需要明确状态更新顺序、滤波器和饱和逻辑。一个典型周期包括：读取带时间戳的测量，构造几何一致的误差，更新微分滤波状态，根据抗饱和规则更新积分状态，计算未饱和命令 $`u_c[k]`$ ，再经过幅值限制、速率限制和执行器映射得到实际命令 $`u_a[k]`$ 。若只写出三个数值增益而不规定这些状态与非线性环节，PID 实现并不完整。采样抖动明显时，应使用实际 $`\Delta t_k`$ 更新积分和滤波，而不是假设固定周期。

在仓储移动操作机器人中，PID 是一种反馈律，不代表固定控制层级。电机驱动器可用 PI 控制电流，底盘可用 PI 控制轮速，机械臂关节可用带速度反馈的 PID 控制位置，视觉对准外环则可能用低带宽比例控制生成速度参考。这些回路通过串级连接，内环带宽通常应显著高于外环，使外环能够把内环近似为稳定、快速的一阶环节。若内外环带宽接近，分别独立调好的控制器组合后仍可能振荡。

PID 的适用基础是目标工作区间内可用低阶线性模型近似，输入输出关系相对固定，主要扰动位于积分和反馈可处理的频带内。强耦合、多约束、长预测时域、显著非最小相位或大范围姿态运动可能需要模型前馈、解耦、状态反馈或优化控制协同处理。PID 并非因简单而自动鲁棒，也不因存在积分和微分就自动获得零误差和良好阻尼；这些性质始终受闭环稳定性、噪声、延迟和执行器能力约束。

## 27.5 PID 的时域解释

时域设计直接关注上升时间、超调量、调节时间、稳态误差和控制峰值。对局部可近似为质量—阻尼系统的机械轴，

```math
m\ddot q+b\dot q=u+d,
```

采用位置 PD 控制 $`u=K_p(q_r-q)-K_d\dot q`$ ，在常值参考和忽略扰动时得到

```math
m\ddot e+(b+K_d)\dot e+K_pe=0.
```

由此可见， $`K_p`$ 主要提高等效刚度和自然频率， $`K_d`$ 增加等效阻尼。与标准二阶形式比较，有 $`\omega_n=\sqrt{K_p/m}`$ ， $`\zeta=(b+K_d)/(2\sqrt{mK_p})`$ 。该解释对机械臂单关节小范围运动很直观，但它假设惯量 $`m`$ 近似恒定、关节耦合和延迟可忽略；机械臂伸展并抓取重箱后惯量可能显著变化，原参数对应的 $`\omega_n`$ 与 $`\zeta`$ 也随之改变。

加入积分项后，闭环阶次至少增加一阶。对上述对象，理想 PID 的特征多项式为

```math
ms^3+(b+K_d)s^2+K_ps+K_i.
```

积分增益太小，消除静差缓慢；太大则可能形成慢振荡、增加超调，并使执行器在反向恢复时释放大量积分能量。虽然可以将三阶多项式与期望极点多项式比较来初选参数，但前提是模型准确、控制器零点影响可接受且未遗漏柔性模态。实际设计还必须检查控制输入峰值、速度和加速度限制，而不能只看输出曲线是否迅速到达参考值。

PID 的三个环节还对应不同时间尺度的信息：比例项响应“现在有多错”，积分项记录“过去累计错了多少”，微分项描述“误差正在如何变化”。这种解释有助于诊断仓储任务中的现象。底盘长期在斜坡上低于目标速度，说明需要稳态偏置或积分补偿；机械臂接近货位时反复摆动，可能意味着阻尼不足、微分估计延迟或比例增益过高；相机对准过程中偶发大命令，则可能来自视觉跳变被微分放大，而非真实运动趋势。

时域指标之间存在不可回避的权衡。缩短上升时间通常需要更大的控制作用和更高带宽，可能增加超调、噪声响应和饱和概率；减小超调可以降低参考权重、提高阻尼或平滑轨迹，但可能延长响应时间。对于移动机器人，参考不应总是理想阶跃：速度规划器和轨迹生成器可以限制加速度与加加速度，使控制器面对物理可实现的参考。控制设计与参考生成共同决定时域性能，不能要求反馈器弥补不可实现的轨迹。

## 27.6 PID 的频域解释

频域分析把控制器理解为对不同时间尺度信号的选择性放大。令环路传递函数为

```math
L(s)=P(s)C(s),
```

单位负反馈下的灵敏度函数和互补灵敏度函数分别为

```math
S(s)=\frac{1}{1+L(s)},\qquad
T(s)=\frac{L(s)}{1+L(s)},
```

且 $`S+T=1`$ 。输出扰动的抑制通常与 $`S`$ 有关，测量噪声传到输出的通道通常与 $`T`$ 有关。低频处希望 $`|L(j\omega)|`$ 大，使 $`|S|`$ 小，从而准确跟踪缓慢参考并抑制恒值或缓慢扰动；高频处希望 $`|L|`$ 小，使高频测量噪声和未建模结构不被闭环放大。

比例项大致在各频率提供恒定增益；积分项的幅值为 $`K_i/\omega`$ ，相位为 $`-90^\circ`$ ，主要提高低频增益；理想微分项的幅值为 $`K_d\omega`$ ，相位为 $`+90^\circ`$ ，在交越频率附近提供相位超前，但带限后在高频不再无限增长。因此 PID 可被看作一种低阶环路整形器：积分保证低频性能，比例设定总体增益，微分或超前部分恢复相位裕度。其目标不是让所有频率的增益都大，而是构造从低频高增益到高频低增益的合理过渡。

增益交越频率 $`\omega_c`$ 满足 $`|L(j\omega_c)|=1`$ 。相位裕度可写为 $`\phi_m=180^\circ+\angle L(j\omega_c)`$ ，增益裕度则描述相位达到 $`-180^\circ`$ 时还能容许多少增益增加。较大的裕度通常意味着对参数变化和延迟更有容忍度，但裕度并不能概括所有鲁棒性问题。例如对象在高频存在窄带柔性共振时，即使名义相位裕度良好，互补灵敏度仍可能出现尖峰；无人机机架振动和四足机器人腿部弹性就是典型情况。

频域解释依赖局部线性、近似时不变的模型。对仓储机器人，可在不同载荷和构型下通过物理模型或小信号辨识得到 $`P(j\omega)`$ ，再检查同一控制器是否保持足够裕度。数字系统还应把零阶保持、计算延迟和通信延迟计入模型；总延迟 $`\tau_d`$ 产生相位 $`-\omega\tau_d`$ ，频率越高损失越大。若相机回路总延迟为几十毫秒，其可实现带宽必然远低于电机电流环，不能仅通过增大 PID 增益跨越这一物理边界。

<a id="ch27-sec7"></a>
## 27.7 Root Locus

根轨迹研究当某个实参数变化时闭环极点在复平面中的运动。若控制器写为 $`C(s)=K C_0(s)`$ ，闭环特征方程为

```math
1+K P(s)C_0(s)=0.
```

根轨迹上的点 $`s`$ 满足角度条件 $`\angle P(s)C_0(s)=(2\ell+1)\pi`$ ，并由幅值条件 $`K=1/|P(s)C_0(s)|`$ 确定增益，其中 $`\ell`$ 为整数。轨迹从开环极点出发，随 $`K`$ 增大终止于开环零点或无穷远，因此控制器增加极点或零点会改变闭环极点可到达的区域。

对主导二阶响应，期望极点可由阻尼比和自然频率表示为

```math
s_{1,2}=-\zeta\omega_n
\pm j\omega_n\sqrt{1-\zeta^2}.
```

在根轨迹图上，固定阻尼比对应从原点出发的射线，固定自然频率对应圆弧。设计者可以先依据超调和调节时间选择期望区域，再检查单纯调整比例增益能否使主导极点进入该区域；若不能，则通过 lead 或 lag 补偿器重新塑造轨迹。对机械臂关节，根轨迹还能直观显示比例增益升高后某对柔性极点是否向虚轴靠近，从而解释“低速稳定、高增益振荡”的现象。

根轨迹并不只用于手工画图。工程软件可以根据模型计算分支、分离点和闭环极点，但解释仍需结合物理结构。离虚轴很远的极点通常衰减快，靠近虚轴的极点主导长时间响应；右半平面极点意味着线性闭环不稳定。然而“主导极点”近似要求其余模态足够快、相关残差不大，且控制器零点不会显著扭曲响应。若极点与零点仅在名义模型中近似相消，真实参数误差可能重新暴露慢模态或不稳定模态。

该方法最适合单输入单输出、低阶、有理、时不变模型。纯延迟需要近似后才能得到有限维根轨迹，而近似阶次会影响结果；多输入多输出系统也不能仅靠一条标量根轨迹描述方向性耦合。移动底盘左右轮速度可在对称条件下变换为纵向和转向两个近似独立通道，但载荷偏置、轮胎打滑和地面接触变化会破坏这一分解。根轨迹应作为局部设计与理解工具，并与频率响应、时域仿真和参数不确定性检查共同使用。

<a id="ch27-sec8"></a>
## 27.8 Lead Compensation

超前补偿器通过在目标频段提供正相位，增加相位裕度并提高可实现带宽。常用形式为

```math
C_{\mathrm{lead}}(s)
=K\frac{1+Ts}{1+\alpha Ts},
\qquad 0<\alpha<1,
```

其中零点位于 $`-1/T`$ ，极点位于 $`-1/(\alpha T)`$ ，极点频率高于零点频率。最大相位超前为

```math
\phi_{\max}
=\sin^{-1}\!\left(\frac{1-\alpha}{1+\alpha}\right),
\qquad
\omega_m=\frac{1}{T\sqrt{\alpha}},
```

其中 $`\omega_m`$ 是最大相位超前出现的频率。通常将 $`\omega_m`$ 放在期望交越频率附近，再结合补偿器幅值变化调整 $`K`$ 。

超前补偿在根轨迹上相当于加入一个零点和一个更靠左的极点，使部分轨迹向左移动；在频域上则在零点与极点之间提高幅值斜率并增加相位。机械臂关节存在惯性导致的相位下降时，适量超前可提高阻尼和跟踪速度。带限微分器本质上也具有类似的相位超前作用，因此 PID 中的微分环节可以看作一种受限的 lead 设计，而不是对数学导数的盲目逼近。

超前补偿的代价是提高中高频控制增益。在 $`\omega\gg1/(\alpha T)`$ 时，上述动态部分的增益趋于 $`1/\alpha`$ ，会放大编码器量化、IMU 振动以及机械柔性模态的影响。设计时必须检查控制灵敏度

```math
U(s)=-C(s)S(s)N(s)
```

对应的噪声到控制输入通道，其中 $`N`$ 表示测量噪声。即使输出曲线看似平滑，电机命令也可能含有高频抖动，导致驱动器发热、齿轮磨损或电池电流峰值增加。

Lead 适用于交越附近相位不足、对象模型在该频段可信且高频噪声仍有余量的情形。若相位损失主要来自大延迟，单纯超前只能在有限频段补偿，并会付出显著增益代价；若交越附近存在右半平面零点，提高带宽还受到非最小相位结构限制。相机闭环具有大延迟时，通常应降低外环带宽、改善时间同步或采用预测，而不是叠加多个超前环节强行追求电机级响应速度。

<a id="ch27-sec9"></a>
## 27.9 Lag Compensation

滞后补偿器主要提高低频相对于高频的增益，以改善稳态精度，同时尽量少改变交越附近的动态。常用形式为

```math
C_{\mathrm{lag}}(s)
=K\frac{1+Ts}{1+\beta Ts},
\qquad \beta>1.
```

其极点位于 $`-1/(\beta T)`$ ，零点位于 $`-1/T`$ ，极点更接近原点。动态部分的直流增益为 $`1`$ ，高频增益趋于 $`1/\beta`$ 。若同时把总体增益设为原来的 $`\beta`$ 倍，则低频环路增益可提高约 $`\beta`$ 倍，而交越频率以上的增益大致保持原水平。

为了减少额外相位滞后，lag 的极点和零点通常布置在期望交越频率以下，并保持一定频率间隔。它比纯积分器更温和：不会在所有低频都表现为无限增益，也不必在原点增加极点。对于底盘轮速环，若目标是减小缓慢负载变化引起的速度误差，而现有相位裕度不允许使用较强积分，lag 可以提供有限的低频增益提升。对于视觉对准外环，它也可改善缓慢偏差，但无法消除相机标定误差、遮挡或错误数据关联造成的系统性估计错误。

滞后网络会引入负相位，并可能使响应中出现更慢的尾部。若极点放得过近原点，扰动恢复时间会很长；若极点和零点靠近交越频率，则相位裕度可能显著下降。名义上的极零近似相消也不能被理解为动态完全不存在：参数变化、离散化和数值精度都会保留残余慢模态。对频繁启停的仓储机器人，过慢的补偿状态可能跨任务保留，因此还需规定任务切换时的状态重置或无扰切换策略。

Lag 适用于稳态性能不足而瞬态性能基本满意的局部线性系统。若恒值扰动必须严格实现零静差，积分内模通常更直接；若执行器持续饱和，提高低频增益不会创造额外控制能力；若误差来自状态估计偏置，则应先修正相机外参、IMU 零偏或轮径参数。控制器只能抑制反馈可见且执行器可影响的误差，不能替代诊断与标定。

<a id="ch27-sec10"></a>
## 27.10 Frequency Shaping

频率整形不是选择某个固定控制器模板，而是围绕闭环通道的性能要求塑造 $`L(s)=P(s)C(s)`$ 。常见目标包括：低频高环路增益以获得跟踪和扰动抑制；交越附近具有足够相位裕度和适中的幅值斜率；高频低增益以抑制测量噪声和未建模动态。PID、lead、lag、低通和陷波器都是实现这些目标的低阶构件。

若扰动 $`d`$ 加在对象输入、测量噪声为 $`n`$ ，则典型闭环关系为

```math
y=T r+P S d-T n,
```

而控制输入可表示为

```math
u=C S r-C S n-S d,
```

具体符号随框图约定而异，但核心通道由 $`S`$ 、 $`T`$ 、 $`PS`$ 和 $`CS`$ 描述。设计时不仅要看参考到输出的 $`T`$ ，还要同时检查扰动抑制、噪声传播和控制努力。仓储机器人底盘的地面阻力主要位于低频，编码器量化和齿槽转矩可能出现在较高频率；机械臂结构共振则可能形成窄带峰值。各类信号占据不同频带，正是频率整形可行的基础。

一个常用工程流程是先根据任务时间尺度选择目标交越频率，再评估该频率处的对象相位和不确定性；使用积分或 lag 建立低频增益，使用比例确定总体交越，必要时用 lead 增加相位裕度，用低通限制高频增益，用陷波器压制已确认且频率稳定的共振。陷波器不应被用来掩盖来源不明、随构型大幅漂移的振动。机械臂共振频率会随姿态和负载变化时，固定窄陷波可能失效，甚至在邻近频率产生不利相位变化。

频率指标还受基本限制约束。提高某一频段的扰动抑制通常会在其他频段增加灵敏度，常被概括为“水床效应”；右半平面零点、开环不稳定极点和延迟进一步限制可实现带宽。离散控制器的交越频率应明显低于奈奎斯特频率 $`\pi/T_s`$ ，并给采样保持、滤波和计算延迟留下余量。仅满足名义 Bode 图并不足够，还应在最轻与最重载荷、不同机械臂构型、电池电压及通信延迟下检查稳定裕度和峰值。

对多回路系统，频率整形还承担层级解耦的作用。电流环、速度环、位置环和视觉任务环应具有由内到外逐渐降低的带宽，具体间隔取决于模型、延迟与不确定性，而不是机械套用固定倍数。若六轴机械臂内层关节伺服带宽足够高，外层笛卡尔控制可以把它近似为速度或位置执行器；否则外层几何误差反馈会与内层动态相互作用，需要统一建模或进入下一章的多变量状态空间分析。

## 27.11 Anti-Windup

执行器饱和时，控制器计算的命令 $`u_c`$ 与实际施加的命令 $`u_a`$ 不再相同：

```math
u_a=\operatorname{sat}(u_c;u_{\min},u_{\max}).
```

若积分器仍按 $`\dot x_I=e`$ 累积，控制器内部状态会继续向不可实现的方向增长。待误差改变符号或系统退出饱和后，过大的积分状态仍维持原控制方向，导致恢复缓慢、严重超调甚至周期性振荡，这就是积分饱和或 windup。仓储机器人被货物阻挡、机械臂达到转矩上限、电机受电池电流限制以及底盘轮胎达到摩擦极限时都会出现该问题。

条件积分是一种简单方法：仅当执行器未饱和，或当前误差会推动命令离开饱和边界时，才更新积分状态。例如标量上饱和时，若 $`K_i e>0`$ 会进一步增大命令，则暂停积分；若 $`K_i e<0`$ 有助于退出饱和，则允许积分。该方法逻辑清晰，但对于多维耦合输入、同时存在幅值与速率限制的系统，简单逐分量判断未必反映真实可行方向。

反算抗饱和通过实际命令与未饱和命令之差修正积分状态：

```math
\dot x_I=e+K_{\mathrm{aw}}(u_a-u_c),
```

其中 $`K_{\mathrm{aw}}`$ 的维度应使右端各项与 $`\dot x_I`$ 一致。若采用 $`u_I=K_i x_I`$ ，也可直接对积分输出状态写出相应回跟方程。 $`u_c`$ 超过上限时， $`u_a-u_c<0`$ ，修正项会释放过量积分。 $`K_{\mathrm{aw}}`$ 太小，恢复仍慢；太大则可能与采样、量化和执行器内部限幅形成快速振荡。因此抗饱和回路本身也需要带宽设计，且应使用执行器实际接受或估计实际施加的命令，而非饱和前的软件变量。

工程中的“饱和”不限于静态上下限，还包括速度限制、加速度限制、电流热降额、共享电源约束和接触摩擦锥。机械臂六个关节同时动作时，驱动器可能因总线功率限制缩放所有命令；此时逐关节 anti-windup 无法完整描述耦合约束。更稳妥的接口是让约束分配模块返回实际可执行输入 $`u_a\in\mathbb{R}^p`$ ，控制器根据 $`u_a-u_c`$ 做一致的状态回跟。若系统进入安全停机、手动拖动或任务切换，还应采用积分冻结、状态重置或无扰切换，避免恢复自动控制时产生命令跳变。

Anti-windup 只能改善“命令不可实现”造成的控制器内部失配，不能让执行器突破物理极限。若维持目标所需的稳态转矩已超过上限，误差不可能被积分消除，应由规划器降低加速度、减小载荷、重新选择抓取姿态或进入故障状态。把长期不可达目标交给积分器处理，会掩盖真正的任务可行性问题。

## 27.12 工程调参

工程调参应从闭环接口和安全约束开始，而不是先反复修改三个增益。首先明确被控量、控制输入、符号、单位、坐标系、采样周期、传感器延迟、执行器幅值与速率限制，以及参考和扰动的典型频带。随后在安全工作点附近获得模型：可以来自动力学线性化，也可以通过小幅阶跃、扫频或闭环辨识得到。辨识激励必须避开碰撞、打滑和结构极限，并覆盖目标带宽附近，而不必追求对所有频率都精确的模型。

一种可复现的调参顺序是：

1. 暂停积分并采用低增益比例反馈，确认反馈方向、传感器极性和执行器映射正确。
2. 逐步增加 $`K_p`$ ，观察响应速度、振荡趋势、控制峰值及频率响应，确定稳定裕度而非只记录“临界振荡增益”。
3. 加入带滤波的微分或 lead，在目标交越附近增加阻尼；同步检查噪声、温升和未建模共振。
4. 从较小 $`K_i`$ 开始加入积分，使其主要处理慢扰动；验证稳态恢复、饱和和任务切换。
5. 配置 anti-windup、参考预滤波、速率限制和故障逻辑，在全部预期工况下复测。

经验整定或继电自整定可以提供初值，但通常隐含对象近似低阶、稳定、时不变且允许受控振荡等假设。对于携带易碎货物的机械臂、接近人员的移动底盘或可能失去升力的无人机，主动激发临界振荡并不安全。即使自动方法给出参数，也要根据闭环极点、裕度、噪声和约束重新验证。调参结果应包含控制器形式、单位、采样率、滤波参数和限幅配置，而不仅是 $`K_p,K_i,K_d`$ 三个数字。

仓储移动操作机器人适合采用串级调试。先在轮子悬空或受控台架上调电流环，再在地面调轮速环，随后调底盘线速度与角速度环，最后接入轨迹跟踪和相机定位外环。机械臂则先验证驱动器电流和速度接口，再调各关节位置环，最后测试笛卡尔轨迹与视觉对准。调外环时内环应保持固定，否则观察到的性能变化无法归因。每一级都应记录参考、测量、未饱和命令、实际命令、积分状态、时间戳和安全事件。

参数随工况变化明显时，可使用增益调度。例如机械臂根据构型和估计负载调整关节增益，底盘根据载荷与地面附着情况限制带宽。调度变量应可可靠测量或估计，参数表应在相邻区域平滑过渡，并在每个冻结工作点验证稳定性。冻结点稳定并不自动保证快速调度时稳定；必要时应限制参数变化率，或采用具有统一稳定性论证的设计。四足机器人在站立、摆腿和落足阶段动力学突变，更说明 PID 调度必须与接触状态机和估计置信度协同，而非独立运行。

最终验收需要覆盖名义性能之外的边界：最大与最小载荷、低电量、冷启动摩擦、传感器丢帧、通信抖动、参考突变、持续饱和、急停后恢复以及模型失配。时域上检查误差、超调、调节时间和输入峰值；频域上检查裕度、灵敏度峰值和共振；统计上则用多次运行评估噪声与环境变化。只有当参数在预定工作域内表现稳定、约束行为明确且故障模式可控时，调参才算完成。

<a id="ch27-sec13"></a>
## 27.13 经典控制今天为什么仍然重要

经典控制以输入输出、环路增益、极点零点和频率响应为核心语言。它不要求首先构建高维全状态模型，能够用少量参数回答一组直接的工程问题：误差为什么不消失，振荡来自哪个模态，带宽受什么限制，延迟损失多少相位，噪声为何进入电机命令，改变增益后稳定裕度如何变化。这些问题在电机、机械臂、移动底盘、相机云台和飞行器姿态内环中始终存在。

现代自主系统具有感知、估计、规划、优化和学习模块，但最终动作仍需通过有限带宽、有限功率的物理执行器实现。仓储机器人上层规划器可以给出无碰轨迹，状态估计器可以融合相机、编码器与 IMU，优化器可以分配速度和转矩；若底层闭环相位裕度不足、积分饱和或噪声放大，整机仍会振荡、偏离轨迹或触发保护。经典控制因此构成从抽象行动决策到可靠物理执行之间的基础接口。

经典方法也提供了其他控制范式的检验工具。状态反馈设计完成后仍可计算各输入输出通道的频率响应和灵敏度；模型预测控制落地时仍需分析采样、执行器内环和约束激活后的动态；学习控制策略部署前仍应经过带宽、增益、延迟和饱和测试。一个复杂控制器若不能解释其闭环极点、扰动通道和高频行为，就很难建立可验证的安全边界。

它的边界同样明确。单回路传递函数不擅长表达强多变量耦合、不可直接测量的内部状态、时变接触和复杂约束。机械臂在大范围构型变化下的惯性耦合，移动机器人侧滑状态，四足机器人浮动基座与接触力，以及无人机位置—姿态耦合，都需要更系统的状态空间表示。经典控制不是被这些方法取代，而是提供局部回路设计、频域鲁棒性和实现诊断的互补视角。

因此，成熟的自主系统通常不是在 PID、状态反馈和优化控制之间择一，而是分层组合：驱动器内部使用快速 PI，关节或姿态层使用 PID、lead 或状态反馈，上层使用几何控制、轨迹优化或模型预测控制，估计器则提供经过概率融合的状态与置信度。每一层都必须明确输入输出、带宽、假设与失效边界。经典控制的长期价值，正是在这些层之间提供一套可测量、可调试、可解释的动态语言。

## 本章小结

本章从比例、积分和微分三个基本反馈机制出发，建立了 PID 的连续与离散结构。比例项提供即时误差校正，积分项借助内部状态提高低频增益并消除可实现条件下的恒值静差，微分项通过带限趋势反馈增加阻尼。三者的有效性都依赖闭环稳定、模型工作区间、传感器质量、采样与延迟，以及执行器具有足够控制能力。

时域观点将控制器参数连接到上升时间、阻尼、超调、稳态误差和控制峰值；频域观点则通过 $`L`$ 、 $`S`$ 、 $`T`$ 、裕度和带宽揭示跟踪、扰动、噪声与鲁棒性之间的权衡。根轨迹说明增益与补偿器极零点如何移动闭环极点，lead、lag 和 frequency shaping 则把这种结构转化为可执行的环路设计方法。Anti-windup、参考整形、滤波、限幅和无扰切换表明，真实控制器不仅是一条代数公式，还包含必须显式设计的动态状态和非线性接口。

贯穿仓储移动操作机器人的例子说明，经典控制可以作用于电机电流、轮速、底盘运动、六轴机械臂关节和相机视觉外环，但不同回路具有不同带宽、噪声、延迟和耦合边界。调参必须以模型、日志、约束和工况验证为基础，不能把经验规则当作无条件有效的配方。

下一章将从输入输出回路进一步进入状态空间分析与状态反馈。届时，极点配置、可控性、可观性和多变量反馈会把本章的稳定性、动态响应及频率整形思想推广到包含内部状态和耦合通道的系统；本章形成的带宽、裕度、饱和与实现意识，仍将作为评价状态空间控制器能否可靠落地的基础。
