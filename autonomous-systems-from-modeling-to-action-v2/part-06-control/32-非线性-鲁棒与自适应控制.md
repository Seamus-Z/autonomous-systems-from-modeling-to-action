## 32.1 线性控制为什么会失效

线性控制并不是“错误的控制”，而是围绕给定工作点或参考轨迹建立的局部近似。对连续时间非线性系统
```math
\dot x=f(x,u),\qquad y=h(x,u),
```
在名义工作点 $`(x^\star,u^\star)`$ 附近令 $`\delta x=x-x^\star`$ 、 $`\delta u=u-u^\star`$ ，可得
```math
\delta\dot x=A\delta x+B\delta u+O(\|(\delta x,\delta u)\|^2),
```
其中 $`A=\left.\partial f/\partial x\right|_\star\in\mathbb R^{n\times n}`$ ， $`B=\left.\partial f/\partial u\right|_\star\in\mathbb R^{n\times m}`$ 。LQR、极点配置和局部线性 MPC 所使用的是前两项；被忽略的高阶项只有在状态、输入和时间尺度都处于线性化有效域时才足够小。因此，闭环线性模型稳定并不自动意味着原非线性系统能从任意初态收敛。

仓储移动操作机器人会以多种方式离开这个有效域。移动底盘高速转弯时，轮胎侧滑、驱动饱和和非完整约束使运动不再等同于固定姿态附近的线性模型；六轴机械臂跨越较大姿态范围时，惯性矩阵、科氏力和重力矩显著变化；抓取不同质量的货箱后，负载参数发生跳变；相机遮挡和 IMU 偏置又会使反馈状态与真实状态不一致。若控制器要求的轮电机电流超过上限，实际输入是
```math
u_{\mathrm{act}}=\mathrm{sat}(u_{\mathrm{cmd}}),
```
此时线性闭环矩阵 $`A-BK`$ 已不能完整描述系统，积分环节还可能因饱和产生 windup。

失效还可能来自结构而非幅值。例如差速底盘满足
```math
\dot p_x=v\cos\theta,\qquad
\dot p_y=v\sin\theta,\qquad
\dot\theta=\omega,
```
它在配置空间中是非线性的，并且不能通过光滑、时不变的静态状态反馈实现任意姿态的全局渐近稳定。机械臂关节角和无人机姿态则位于流形而非整个欧氏空间，直接相减会在角度回绕或姿态奇异点附近产生错误。接触切换、齿隙和静摩擦还会引入非光滑或混杂动力学，超出单一线性模型的假设。

因此，是否采用线性控制应由工作域和误差预算决定，而不是由模型形式决定。若机器人始终在一条缓慢轨迹附近运行、执行器有充分裕量且调度后的线性模型覆盖工作区，线性控制通常最简洁可靠；若存在大范围机动、强耦合、输入饱和、接触切换或显著参数变化，则需要非线性、鲁棒或自适应方法。它们也不能取消状态估计、约束处理和轨迹可行性检查，而是与前述概率估计、优化和 MPC 模块形成互补。

## 32.2 局部稳定与全局稳定

考虑自治闭环系统 $`\dot x=F(x)`$ ，并设 $`x_e`$ 为平衡点，即 $`F(x_e)=0`$ 。若对任意 $`\varepsilon>0`$ ，都存在 $`\delta>0`$ ，使 $`\|x(0)-x_e\|<\delta`$ 蕴含所有 $`t\ge 0`$ 上都有 $`\|x(t)-x_e\|<\varepsilon`$ ，则 $`x_e`$ 在 Lyapunov 意义下稳定；若进一步有 $`x(t)\to x_e`$ ，则称渐近稳定。上述性质只要求在某个邻域内成立时是局部稳定；若对状态空间内所有允许初态成立，并且解始终存在，则是全局稳定。指数稳定还要求存在 $`c,\lambda>0`$ ，使
```math
\|x(t)-x_e\|\le c e^{-\lambda t}\|x(0)-x_e\|.
```
指数界对采样、扰动分析和收敛时间估计尤其有用，但比渐近稳定更强。

吸引域 $`\mathcal R(x_e)`$ 是所有最终收敛到 $`x_e`$ 的初态集合。工程中“控制器稳定”通常不够，真正需要的是吸引域是否覆盖可到达的估计误差、路径偏差和负载变化。例如，仓储机器人因视觉重定位产生 $`0.5\,\mathrm m`$ 横向修正时，局部底盘控制器是否仍能恢复；机械臂抓箱后关节速度偏大时，是否会在收敛前触发力矩限幅或碰撞约束。即使理论吸引域很大，障碍物、关节限位、电流限幅等安全约束也会把可用吸引域缩小为其与可行集的交集。

全局结论还受状态空间拓扑限制。姿态属于 $`SO(3)`$ ，任何连续、时不变反馈都不能在不存在其他临界点的意义下实现单一姿态的全局渐近稳定；常见几何控制器得到的是“几乎全局”稳定，即除测度为零的特殊初态外均收敛。差速底盘的非完整约束也限制了光滑静态反馈。此时可采用时变控制、混杂切换或轨迹跟踪，而不能把局部坐标中的线性结论误称为全局结论。

稳定性分析还必须明确参考对象。对时变参考 $`x_r(t)`$ ，应研究误差 $`e=x\ominus x_r`$ 的非自治或增广系统，而非只考察固定平衡点；符号 $`\ominus`$ 表示与状态空间几何一致的误差运算。若相机/IMU 状态估计存在持续噪声，严格收敛到零通常不现实，更合理的结论是误差最终进入一个有界集合，或闭环满足输入到状态稳定性。局部、全局、几乎全局和最终有界是不同承诺，设计文档和验收指标应明确区分。

## 32.3 Lyapunov 方法

Lyapunov 方法不要求显式求解非线性微分方程，而是寻找一个沿闭环轨迹下降的标量函数。对平衡点平移后的系统 $`\dot x=F(x)`$ ，若存在连续可微函数 $`V:\mathcal D\to\mathbb R`$ ，满足
```math
V(0)=0,\qquad V(x)>0\ \ (x\ne0),\qquad
\dot V(x)=\nabla V(x)^\top F(x)\le0,
```
则原点稳定；若 $`\dot V(x)<0`$ ，通常可得渐近稳定。若 $`V`$ 径向无界，即 $`\|x\|\to\infty`$ 时 $`V(x)\to\infty`$ ，并且不等式在全空间成立，才有机会把局部结论提升为全局结论。 $`\dot V\le0`$ 只是半负定时，需要用不变集原理检查集合 $`\{\dot V=0\}`$ 中最大的闭环不变集，不能直接宣称状态收敛到原点。

Lyapunov 函数常对应能量、误差平方或优化代价。六轴机械臂动力学为
```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau+d,
```
其中 $`q\in\mathbb R^6`$ ， $`M(q)\succ0`$ ， $`\tau\in\mathbb R^6`$ 为关节力矩， $`d`$ 为外扰。对调节任务可选择
```math
V=\frac12\dot q^\top M(q)\dot q+U_e(q),
```
其中 $`U_e`$ 是在目标构型处取最小值的人工势能。利用机械臂结构性质 $`\dot M-2C`$ 为斜对称矩阵，适当的阻尼注入可使 $`\dot V=-\dot q^\top K_d\dot q\le0`$ 。这说明能量为何下降，也揭示了增大阻尼、补偿重力以及保持 $`M`$ 正定的工程意义。

面对估计误差和扰动，更实用的形式是输入到状态稳定性。若存在
```math
\alpha_1(\|x\|)\le V(x)\le\alpha_2(\|x\|),\qquad
\dot V\le-\alpha_3(\|x\|)+\sigma(\|d\|),
```
其中 $`\alpha_i`$ 为严格递增的比较函数， $`d`$ 可包含外力、建模误差和状态估计误差，则状态上界由初值衰减项和扰动幅值共同决定。仓储机器人通过狭窄货架通道时，这个界可用于把 IMU 偏置、地面不平度映射到横向跟踪误差，再与安全间隙比较。

Lyapunov 方法的困难不在验证求导，而在构造合适的 $`V`$ 。二次函数适合局部线性系统，机械系统能量适合保守结构，反步和自适应控制则在设计过程中递归构造复合函数。由数值优化或神经网络得到的候选函数，也必须在指定区域内验证正定性和导数条件。若存在饱和、采样延迟、接触切换或估计器跳变，应分析相应的离散、混杂或非光滑 Lyapunov 条件，不能直接套用光滑连续时间证明。

## 32.4 Feedback Linearization

反馈线性化通过非线性状态反馈抵消已知动力学，使输入—输出关系变为线性。对控制仿射系统
```math
\dot x=f(x)+G(x)u,\qquad y=h(x),
```
其中 $`x\in\mathbb R^n`$ 、 $`u\in\mathbb R^m`$ 、 $`y\in\mathbb R^p`$ ，反复对输出求导，直到输入显式出现。单输入系统若相对阶为 $`r`$ ，则
```math
y^{(r)}=L_f^r h(x)+L_gL_f^{r-1}h(x)\,u,
```
其中 $`L_fh=\nabla h^\top f`$ 是 Lie 导数。若解耦项 $`L_gL_f^{r-1}h(x)\ne0`$ ，令
```math
u=\frac{-L_f^rh(x)+v}{L_gL_f^{r-1}h(x)}
```
即可得到 $`y^{(r)}=v`$ ，再用线性反馈 $`v`$ 配置误差动态。多输入情形需要相应的解耦矩阵可逆。

机械臂的计算力矩控制是典型实例。令
```math
\tau=M(q)v+C(q,\dot q)\dot q+g(q),\qquad
v=\ddot q_d-K_d\dot e-K_pe,
```
其中 $`e=q-q_d`$ ，则理想模型下有
```math
\ddot e+K_d\dot e+K_pe=0.
```
若 $`K_p,K_d\in\mathbb R^{6\times6}`$ 为适当正定矩阵，六轴关节误差按设计的线性动态衰减。工程上，这种结构把动力学补偿与误差整形分离，适合模型较准、力矩接口开放且采样频率足够高的机械臂。

反馈线性化的核心边界是“可逆”和“内部稳定”。若总相对阶小于 $`n`$ ，输出被线性化后仍有不可见的内部状态，其在输出保持为零时的动态称为零动态；只有零动态稳定，所得系统才是最小相位的。差速底盘若选择不合适的车体中心位置作为输出，低速或零速附近可能出现奇异性；机械臂在接近运动学奇异位形时，任务空间解耦矩阵可能病态，控制力矩会被放大。

精确抵消还会放大模型误差。实际动力学写成 $`M=\hat M+\Delta M`$ 时，使用 $`\hat M`$ 的控制律不能得到精确的线性误差方程；负载突变、摩擦和柔性会成为残余扰动。因此应保留鲁棒反馈、力矩限幅和奇异性监测，并在必要时使用阻尼伪逆或局部切换。反馈线性化适用于模型结构可信、状态可观测且工作区避开奇异点的场景，而不是对任意非线性系统都有效的坐标技巧。

## 32.5 Backstepping

反步法适用于可写成严格反馈或近似严格反馈形式的系统。以二阶系统为例：
```math
\dot x_1=f_1(x_1)+g_1(x_1)x_2,\qquad
\dot x_2=f_2(x_1,x_2)+g_2(x_1,x_2)u.
```
设计时先把 $`x_2`$ 当作虚拟输入，为第一子系统选择期望值 $`x_2=\alpha_1(x_1)`$ ；再定义误差 $`z_2=x_2-\alpha_1(x_1)`$ ，通过真实输入 $`u`$ 使 $`z_2`$ 收敛。若第一步使用 $`V_1(x_1)`$ ，第二步通常构造
```math
V_2=V_1+\frac12z_2^2,
```
并选择 $`u`$ 使 $`\dot V_2`$ 负定。高阶系统按这一过程递归，因而得名“反步”。

仓储机器人轮电机可用这一结构理解。底盘速度控制器给出期望轮速 $`\omega_d`$ ，但真实执行变量是电机电流 $`i`$ ；机械部分与电气部分可近似写成
```math
J\dot\omega=-b\omega+k_t i-\tau_L,\qquad
L\dot i=-Ri-k_e\omega+v,
```
其中 $`v`$ 是驱动电压。先把电流 $`i`$ 视作虚拟控制，使轮速误差下降，再设计电压使实际电流跟踪虚拟电流。与简单串级 PID 相比，反步法显式考虑了两层动态耦合，并可给出复合 Lyapunov 证明。类似结构也出现在机械臂位置—速度—力矩级联以及无人机位置—姿态控制中。

反步法的代价是模型导数和表达式复杂度随阶次增加。虚拟控制 $`\alpha_i`$ 的时间导数会依赖前级状态及参考导数，形成所谓“复杂度爆炸”；动态面控制可用滤波器近似这些导数，但会引入滤波误差和新的时间尺度。若 $`g_i`$ 可能过零、输入方向未知，或者系统不能变换为严格反馈结构，标准反步推导便不成立。

实际实现还要处理饱和、噪声和未建模快动态。过大的递归增益会要求电机电流快速变化，激发齿轮弹性并放大编码器差分噪声；过慢则使底盘转弯和机械臂抓取响应不足。因此，反步控制的稳定证明应与执行器带宽、参考轨迹光滑性和状态估计误差共同审查。必要时可结合鲁棒项或自适应参数，但每增加一层机制，都应重新验证整体闭环而非简单叠加结论。

## 32.6 Sliding Mode

滑模控制通过设计一个低维滑模面，把闭环轨迹先驱动到该面，再沿面运动。对跟踪误差 $`e`$ ，常取
```math
s=\dot e+\Lambda e,
```
其中 $`\Lambda\succ0`$ ， $`s=0`$ 时误差满足稳定线性动态 $`\dot e=-\Lambda e`$ 。控制器令 Lyapunov 函数 $`V=\frac12s^\top s`$ 满足到达条件，例如
```math
\dot V=s^\top\dot s\le-\eta\|s\|_1,\qquad \eta>0.
```
实现上通常在等效控制之外加入 $`-\!K\mathrm{sgn}(s)`$ ，用不连续反馈克服有界扰动。

滑模对匹配扰动尤其有效。若系统为
```math
\dot x=f(x)+G(x)\bigl(u+d_m\bigr)+d_u,
```
则 $`d_m`$ 与控制输入通过同一通道进入，称为匹配扰动；只要已知其上界且控制权足够，切换增益可压制它。仓储机械臂的关节摩擦和一部分负载力矩可近似视为匹配扰动，而相机位姿误差、柔性连杆模态或底盘横向侧滑往往是非匹配扰动，不能仅靠增大切换增益消除。

理想符号函数要求无限快切换，数字控制器、电机驱动器和机械结构均无法实现，会产生抖振。常见工程替代是边界层
```math
\mathrm{sgn}(s)\ \longrightarrow\
\mathrm{sat}\!\left(\frac{s}{\phi}\right),
```
其中 $`\phi>0`$ 为边界层厚度。这样可降低电流尖峰和齿轮冲击，但只能保证 $`s`$ 进入与 $`\phi`$ 有关的邻域，而非精确到零。高阶滑模可在更高阶导数上实现连续控制，但需要更强的正则性、扰动导数界和可靠采样。

切换增益不是越大越好。增益应覆盖可信的扰动上界，同时受电机电流、温升、采样频率和传感器噪声限制；若上界估计过于保守，六轴机械臂会产生明显振动，货箱中的物品也可能受冲击。滑模适用于扰动通道清楚、执行器带宽高且允许小边界层误差的任务；在柔性、强延迟或非匹配扰动主导的系统中，应结合观测器、鲁棒优化或机械阻抗设计，而不能依赖单一切换项。

## 32.7 Geometric Control

几何控制直接在系统真实的配置空间上定义误差和反馈，而不是先选取可能奇异的局部坐标。移动底盘的位姿属于 $`SE(2)`$ ，机械臂末端位姿属于 $`SE(3)`$ ，无人机和刚体姿态属于 $`SO(3)`$ 。对 $`R,R_d\in SO(3)`$ ，有
```math
R^\top R=I,\qquad \det R=1.
```
常用姿态误差为
```math
e_R=\frac12\left(R_d^\top R-R^\top R_d\right)^\vee\in\mathbb R^3,
```
其中 $`(\cdot)^\vee`$ 将反对称矩阵映射为三维向量；角速度误差可写为 $`e_\Omega=\Omega-R^\top R_d\Omega_d`$ 。这些误差不依赖欧拉角，因此不会在俯仰角 $`\pm\pi/2`$ 处出现坐标奇异。

刚体姿态动力学满足
```math
J\dot\Omega+\Omega\times J\Omega=\tau,
```
其中 $`J\in\mathbb R^{3\times3}`$ 为正定惯量矩阵。几何控制可选择
```math
\tau=-k_Re_R-k_\Omega e_\Omega+\Omega\times J\Omega+\tau_{\mathrm{ff}},
```
其中 $`\tau_{\mathrm{ff}}`$ 补偿参考角加速度及坐标变换项。相应 Lyapunov 函数由姿态势能
```math
\Psi(R,R_d)=\frac12\mathrm{tr}(I-R_d^\top R)
```
和角动能误差组成。对仓储机械臂末端搬运易洒货箱的任务，这一表示可在大姿态变化中保持误差定义一致；对无人机，类似结构同时处理位置与姿态耦合。

移动操作机器人还可把底盘与机械臂统一描述为李群上的配置。底盘位姿 $`T_b\in SE(2)`$ 或嵌入 $`SE(3)`$ ，末端位姿为
```math
T_e=T_b\,T_{be}(q),
```
其中 $`T_{be}(q)`$ 是机械臂正运动学。误差可通过群差 $`T_d^{-1}T_e`$ 及其对数映射表达，再由伴随变换在不同坐标系之间传递速度和力。这与前述几何、状态估计中的位姿复合接口一致，避免把不同切空间中的向量直接相减。

几何方法不会自动解决所有全局问题。 $`SO(3)`$ 的拓扑意味着连续时不变反馈通常只能得到几乎全局稳定；对数映射在旋转角接近 $`\pi`$ 时也需谨慎。机械臂仍有运动学奇异、关节限位和碰撞约束，底盘仍有非完整约束。几何控制提供的是正确的状态空间和误差结构，性能与安全仍需结合动力学补偿、约束优化及混杂策略。

## 32.8 鲁棒性的含义

鲁棒性是闭环系统在模型、扰动和实现偏离名义条件时仍保持规定性质的能力。必须先说明“对什么不确定性、保持什么性质、在多大范围内”。鲁棒稳定性要求所有允许对象都稳定；鲁棒性能还要求跟踪误差、控制能量、峰值超调或安全距离满足上界。一个系统可以对质量变化保持稳定，却因误差过大而不具备可用性能，因此“没有发散”只是最低层的鲁棒性。

设真实闭环由不确定参数 $`\Delta\in\mathcal D`$ 决定，并以外部输入 $`w`$ 表示地面扰动、负载外力和传感器误差。鲁棒性能可写成
```math
\sup_{\Delta\in\mathcal D}\sup_{w\ne0}
\frac{\|z\|}{\|w\|}\le\gamma,
```
其中 $`z`$ 是加权跟踪误差、控制输入或其他性能输出， $`\gamma`$ 是允许增益。范数可以是 $`L_2`$ 、峰值范数或任务相关指标，不同选择表达不同工程风险。仓储机器人若重点防止货物摆动，可在 $`z`$ 中提高末端加速度权重；若重点防碰撞，则应直接监控横向偏差和最小间隙，而不能只看平均能量。

鲁棒性也可用裕度和不变集描述。在线性频域中常检查增益裕度、相位裕度和灵敏度峰值；在状态空间中，可寻找扰动下的鲁棒正不变集 $`\mathcal X_R`$ ，使
```math
x(0)\in\mathcal X_R,\quad d(t)\in\mathcal D
\ \Longrightarrow\ x(t)\in\mathcal X_R.
```
若该集合位于速度、关节和碰撞约束内部，就能为安全执行提供可验证余量。这与鲁棒 MPC 的约束收紧思想相连，但本章关注的反馈机制仍可独立于在线优化器存在。

鲁棒结论依赖不确定集合是否可信。把未知外力简单声明为“有界”并不能给出数值保证；界过小会导致失效，过大则得到保守甚至不可实现的控制器。概率模型给出高概率事件，最坏情形鲁棒模型覆盖确定集合，两者不能混用。实际系统通常需要用实验、辨识和故障分析构造分层边界，并把未覆盖的碰撞、通信中断和硬件故障交给安全监控与降级机制。

## 32.9 模型不确定性与扰动

不确定性可以按来源和数学结构分类。参数不确定性是质量、惯量、摩擦系数等数值未知；未建模动态包括电机电感、齿轮弹性和结构振动；外扰包括地面冲击、人员推碰和抓取接触力；传感器噪声与偏置通过反馈通道进入。对状态空间模型可写成
```math
\dot x=\bigl(A+\Delta A\bigr)x+\bigl(B+\Delta B\bigr)u+Ew,
```
其中 $`\Delta A,\Delta B`$ 可进一步表示为结构化参数块， $`w`$ 为外生扰动。保留结构通常比把一切合并为任意加性误差更少保守。

频域模型常使用加性或乘性不确定性：
```math
P=P_0+W_a\Delta_a,\qquad
P=P_0(1+W_m\Delta_m),
```
并约束 $`\|\Delta_a\|_\infty\le1`$ 或 $`\|\Delta_m\|_\infty\le1`$ 。加性形式适合未建模支路，乘性形式适合相对模型误差随频率增大的对象；权重 $`W_a,W_m`$ 描述各频段误差大小。电机低频参数可能较准，而齿轮柔性和采样延迟在高频显著，因此不确定权重通常随频率上升，不能用单一百分比覆盖所有动态。

仓储移动操作机器人中，同一现象可能以不同方式进入模型。抓取质量变化直接改变机械臂惯性矩阵和底盘制动距离，属于结构化参数变化；轮胎沾灰造成的滑移改变速度输入到实际位姿变化的映射；相机外参松动造成系统性观测偏差；IMU 零偏是随时间缓慢变化的估计状态。若把观测偏差误当作执行扰动，控制器可能持续施加错误补偿，因此应先明确误差是在过程模型、测量模型还是执行器通道中出现。

“总扰动”建模便于扰动观测器和滑模控制，但它有必要边界：总扰动必须具有足够平滑性或已知变化率，且其作用通道应可控制、可观测。高频接触冲击、时延、输入饱和和状态约束不能总被一个连续扰动项准确吸收。工程上应维护从物理来源到数学模型的误差地图，分别决定使用鲁棒反馈、在线估计、参数自适应、重新标定还是故障处理。

## 32.10 Sensitivity 与 Robustness

对负反馈系统，设对象为 $`P(s)`$ 、控制器为 $`K(s)`$ ，开环传递矩阵为 $`L(s)=P(s)K(s)`$ 。灵敏度函数和互补灵敏度函数定义为
```math
S(s)=(I+L(s))^{-1},\qquad
T(s)=L(s)(I+L(s))^{-1},
```
并满足 $`S+T=I`$ 。在常见反馈结构中，输出扰动到误差的传递由 $`S`$ 决定，测量噪声到输出的传递常与 $`T`$ 有关，对象乘性不确定性的鲁棒稳定也与 $`T`$ 相关。因此，低频希望 $`S`$ 小以获得良好跟踪和扰动抑制，高频希望 $`T`$ 小以避免放大相机、编码器和 IMU 噪声。

单输入系统可查看 $`|S(j\omega)|`$ 与 $`|T(j\omega)|`$ ，多输入系统则应检查最大奇异值
```math
\bar\sigma\bigl(S(j\omega)\bigr),\qquad
\bar\sigma\bigl(T(j\omega)\bigr),
```
因为不同方向之间可能强耦合。若乘性不确定性满足 $`P=P_0(I+W_m\Delta)`$ 且 $`\|\Delta\|_\infty\le1`$ ，一个常见的小增益条件是
```math
\|W_mT\|_\infty<1.
```
它说明在模型误差大的频段，闭环互补灵敏度必须足够小；但该条件依赖不确定结构和归一化方式，不能脱离模型直接使用。

灵敏度整形存在基本折中。对含不稳定极点、非最小相位零点或时延的系统，不可能在所有频率上同时令 $`S`$ 很小；降低一个频段的灵敏度往往会在另一频段形成峰值，即“水床效应”。仓储底盘若为提高低速路径精度而显著提高带宽，可能放大轮速量化噪声并激发车架振动；机械臂若过度压低低频误差，可能在结构柔性模态附近失去裕度。

频域灵敏度建立在线性时不变或局部冻结模型上。对大范围运动，可在不同姿态、负载和速度点计算模型族的 $`S,T`$ ，检查最坏工作点；对接触切换和强非线性，还需用时域 Lyapunov、增益界或仿真验证补充。灵敏度分析的工程价值在于把“增益太大”“噪声太强”转化为频率相关的闭环通道，而不是给非线性全局行为提供无条件证明。

## 32.11 H∞ 的基本思想

$`H_\infty`$ 控制把鲁棒性能表述为从外部输入 $`w`$ 到性能输出 $`z`$ 的最坏情形能量增益。对稳定闭环传递矩阵 $`T_{zw}(s)`$ ，
```math
\|T_{zw}\|_\infty
=\sup_{\omega}\bar\sigma\bigl(T_{zw}(j\omega)\bigr).
```
设计目标是寻找稳定化控制器 $`K`$ ，使
```math
\|T_{zw}\|_\infty<\gamma.
```
在零初值条件下，这意味着对所有有限能量输入都有
```math
\|z\|_2<\gamma\|w\|_2.
```
它不是假定某个概率分布后最小化平均代价，而是在给定通道和权重下限制最坏方向的放大。

广义对象把物理系统、权重和信号接口统一写成
```math
\begin{bmatrix}z\\y\end{bmatrix}
=
\begin{bmatrix}
P_{11}&P_{12}\\
P_{21}&P_{22}
\end{bmatrix}
\begin{bmatrix}w\\u\end{bmatrix},
\qquad u=Ky,
```
其中 $`y`$ 是控制器可测信号。混合灵敏度设计常令
```math
z=
\begin{bmatrix}
W_SS\\
W_UKS\\
W_TT
\end{bmatrix}w,
```
分别约束跟踪误差、控制努力和高频鲁棒性。对仓储底盘，可用 $`W_S`$ 强调低频横向误差，用 $`W_U`$ 限制轮电机电流，用 $`W_T`$ 抑制高频滑移和传感器噪声；六轴机械臂则可针对不同关节和末端方向设置矩阵权重。

$`H_\infty`$ 的关键设计工作通常是选择权重，而不是求解 Riccati 方程本身。权重过严会导致问题不可行、高阶控制器或过大执行需求；权重过松则虽有漂亮的 $`\gamma`$ ，却不对应任务指标。综合得到的控制器还可能具有较高阶数，需要降阶、离散化并重新验证。若系统随机械臂姿态和负载显著变化，可使用多模型、增益调度或线性参数变化方法，但调度过程本身也必须保持稳定。

该方法提供的是加权 $`L_2`$ 增益保证，不直接限制瞬时峰值，也不自动处理硬饱和、碰撞和状态约束。冲击虽持续时间短，却可能有很高峰值；输入饱和后闭环也不再是综合时的线性系统。因此， $`H_\infty`$ 适合模型误差可由频域权重覆盖、关心能量增益且系统近似线性的场景，并应与时域约束检查、抗饱和和安全监督配合。

## 32.12 Adaptive Control

自适应控制在闭环运行中调整控制器或模型参数，以应对未知但具有已知结构的动力学。典型假设是系统可对未知参数线性参数化：
```math
\dot x=f_0(x,u)+Y(x,u)\theta,
```
其中 $`\theta\in\mathbb R^p`$ 为未知常参数或缓慢变化参数， $`Y\in\mathbb R^{n\times p}`$ 为已知回归矩阵。控制器使用估计值 $`\hat\theta`$ ，并通过自适应律更新它。这里“线性参数化”指对参数线性，并不要求系统对状态线性。

机械臂动力学具有重要的线性参数化性质。对适当选择的参考速度 $`\dot q_r`$ 和参考加速度 $`\ddot q_r`$ ，可以写成
```math
M(q)\ddot q_r+C(q,\dot q)\dot q_r+g(q)
=Y(q,\dot q,\dot q_r,\ddot q_r)\theta.
```
令滑动误差 $`s=\dot q-\dot q_r`$ ，一种自适应控制结构为
```math
\tau=Y\hat\theta-K_ds,\qquad
\dot{\hat\theta}=-\Gamma Y^\top s,
```
其中 $`\Gamma\succ0`$ 是自适应增益。选择复合 Lyapunov 函数
```math
V=\frac12s^\top M(q)s+
\frac12\tilde\theta^\top\Gamma^{-1}\tilde\theta,
\qquad \tilde\theta=\hat\theta-\theta,
```
可在理想假设下得到 $`\dot V=-s^\top K_ds\le0`$ ，从而证明跟踪误差有界并趋向相应不变集。

状态跟踪收敛不等于参数估计收敛。要使 $`\hat\theta\to\theta`$ ，回归信号通常必须满足持续激励条件：存在 $`T,\alpha>0`$ ，使
```math
\int_t^{t+T}Y^\top(\tau)Y(\tau)\,d\tau\succeq\alpha I
```
对所有 $`t`$ 成立。仓储机械臂若长期只在很小范围内匀速搬运，数据不足以区分负载质量、质心和摩擦参数；控制误差可能已经很小，而参数仍不唯一。为辨识而主动激励又可能与货物安全和生产节拍冲突。

标准证明还常假设参数恒定、状态精确可测、执行器不饱和且未建模动态可忽略。现实中的编码器噪声、货物晃动和接触冲击会引起参数漂移，因此需要投影、死区、泄漏项等鲁棒修改。自适应控制适合结构已知而参数未知的情形；若连状态维度、接触模式或观测外参都不可信，单一参数自适应律不能替代模型重建、状态估计和故障诊断。

## 32.13 在线参数调整

在线参数调整必须同时考虑收敛理论、数据质量和数字实现。连续自适应律离散化后可写为
```math
\hat\theta_{k+1}
=\Pi_\Theta\!\left(
\hat\theta_k-h\Gamma\phi_k e_k
\right),
```
其中 $`h`$ 是采样周期， $`\phi_k\in\mathbb R^p`$ 为回归向量， $`e_k`$ 为标量预测或跟踪误差， $`\Pi_\Theta`$ 把估计投影到物理可行集合 $`\Theta`$ 。例如，抓取负载质量必须非负并受机械臂额定负载限制；惯量参数还需满足正定性和三角不等式。投影不仅防止数值发散，也避免不物理参数进入前馈补偿。

若重点是参数辨识，可使用带遗忘因子的递推最小二乘：
```math
K_k=\frac{P_{k-1}\phi_k}
{\lambda+\phi_k^\top P_{k-1}\phi_k},
```
```math
\hat\theta_k=\hat\theta_{k-1}
+K_k\bigl(y_k-\phi_k^\top\hat\theta_{k-1}\bigr),
```
```math
P_k=\lambda^{-1}
\left(P_{k-1}-K_k\phi_k^\top P_{k-1}\right),
```
其中 $`P_k\in\mathbb R^{p\times p}`$ 表示信息不足方向上的不确定程度， $`0<\lambda\le1`$ 为遗忘因子。 $`\lambda<1`$ 可跟踪缓慢变化参数，却也使噪声持续进入估计；缺少激励时， $`P_k`$ 还可能变得病态，需要协方差上界、正则化和条件数监测。

工程上不应让每个采样噪声都修改关键控制参数。常用措施包括：误差低于噪声尺度时停止更新；对回归量归一化；限制单周期参数变化率；只在接触模式、负载识别结果和传感器健康状态一致时启用更新；将快速稳定反馈与慢速参数更新分离。仓储机械臂可在抓取后通过腕部力矩和关节加速度估计负载，但在货箱碰撞货架或底盘急停期间冻结更新，以免把瞬态外力错误吸收到质量参数中。

在线调整还需要回退机制。每组新参数应带时间戳、适用工况、置信度和边界，超过创新阈值或触发电流、温度、跟踪误差限制时回退到经过验证的名义参数。相机外参和 IMU 偏置应由估计模块维护，并通过明确接口进入控制器，而不是与动力学参数混在同一更新律中。下一章讨论的采样、任务调度、时延和数值精度会直接改变自适应律的实际行为，因此连续时间证明必须转化为可执行的离散时间监控条件。

## 32.14 鲁棒、自适应与学习方法的区别

鲁棒控制、自适应控制与学习控制都处理“不完全知道系统”的问题，但它们对未知量的表达和承诺不同。鲁棒控制预先给定不确定集合 $`\mathcal D`$ ，寻找一个控制器使所有 $`\Delta\in\mathcal D`$ 都满足稳定或性能界；自适应控制假设未知量具有特定参数结构，并通过闭环数据更新 $`\hat\theta`$ ；学习方法则可使用更灵活的函数类，从数据中拟合动力学、价值函数、策略或残差。三者的差别不在是否使用数据，而在假设、更新对象以及可验证结论。

| 方法 | 未知量表示 | 主要目标 | 典型保证 | 主要边界 |
|---|---|---|---|---|
| 鲁棒控制 | 有界集合、频域权重或结构化扰动 | 覆盖最坏情形 | 集合内的稳定性或增益界 | 可能保守，依赖可信边界 |
| 自适应控制 | 已知结构中的未知参数 | 在线补偿参数变化 | 在激励和模型假设下的有界性、跟踪或参数收敛 | 对未建模动态和噪声敏感 |
| 学习方法 | 参数化函数、数据集或经验分布 | 提高预测或策略性能 | 常为统计、经验或局部保证 | 分布外行为和闭环稳定需额外验证 |

三类方法可以组合，但职责应清晰。例如，仓储机器人可用几何或反馈线性化控制器形成名义闭环，用鲁棒项覆盖有界摩擦和估计误差，用自适应律估计货箱质量，再让学习模型预测难以建模的轮胎滑移残差。若学习残差 $`\hat d_\psi(x,u)`$ 被加入模型，
```math
\dot x=f_{\mathrm{nom}}(x,u)+\hat d_\psi(x,u)+r,
```
则仍应为剩余误差 $`r`$ 给出可验证的界，并用安全过滤器、输入限幅或鲁棒不变集约束最终指令。预测准确率提高并不自动等价于闭环稳定。

选择方法时，应先问未知量是否有可靠结构和边界。参数范围明确、变化快但有最坏界时，鲁棒设计通常优先；结构明确且参数缓慢变化时，自适应控制能减少保守性；数据丰富而解析结构不足时，学习模型可改善性能，但必须处理分布漂移和验证覆盖。碰撞、断线、传感器失效等离散故障不应仅被归入连续扰动或训练数据，而应由故障检测、状态机和安全停机逻辑处理。

最终系统往往采用分层方案：最内层电机电流和机械稳定反馈具有确定的带宽与保护；中层底盘、机械臂和末端控制处理非线性与扰动；外层优化或学习模块生成参考和更新模型。越靠近执行器，越需要明确的时延、幅值和稳定裕度；越靠近策略层，越需要约束其输出进入已验证的可行域。方法之间不是相互替代，而是围绕同一状态空间、估计结果和安全约束建立可审计的接口。

## 本章小结

本章从局部线性化的有效域出发，说明了大范围运动、几何拓扑、执行器饱和、接触切换和模型变化为何会使线性闭环结论失效。局部、全局、几乎全局和最终有界描述了不同强度的稳定承诺；Lyapunov 方法则以能量或误差函数为主线，把反馈线性化、反步、滑模和自适应控制中的设计步骤统一为闭环耗散条件。几何控制进一步保证误差和反馈定义在 $`SO(3)`$ 、 $`SE(3)`$ 等真实状态空间上。

鲁棒控制关注给定不确定集合内的最坏情形，灵敏度函数与 $`H_\infty`$ 方法把扰动抑制、噪声放大和控制努力组织为频率相关的增益约束；自适应控制通过在线参数更新降低结构化参数误差，但其结论依赖持续激励、模型结构和数据质量。学习方法可以补充未知残差，却不能仅凭预测精度取代稳定性、约束和故障边界。对仓储移动操作机器人，合理架构通常是名义非线性控制、鲁棒安全余量、受约束的参数更新以及可监督的学习补偿共同工作。

这些控制律最终都要在数字硬件上以有限采样率、有限字长、通信时延和任务调度执行。连续时间中的负定导数、切换增益、带宽分离和参数更新速度，在离散实现后可能发生变化；饱和、时间戳错误和计算超时也会破坏理论假设。下一章将把本章的闭环机制连接到数字实时执行系统，讨论如何将数学控制器转化为具有确定时序、可监控状态和故障降级能力的软件与硬件闭环。
