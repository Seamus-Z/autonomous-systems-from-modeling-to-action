## 31.1 为什么最优控制要走向在线优化

上一章讨论的 LQR、iLQR 与 DDP 已经给出了从动态模型、代价函数到反馈控制律的系统路径。然而，真实自主系统很少工作在“模型准确、目标固定、没有约束、扰动已知”的理想环境中。仓储移动操作机器人既要沿货架通道行驶，又要控制六轴机械臂取放物品；底盘速度受电机能力限制，机械臂关节不能越界，相机可能临时检测到行人或托盘，地面摩擦也会随区域改变。若只离线计算一条最优轨迹，实际状态一旦偏离名义轨迹，原解便可能不再可行。

模型预测控制的核心思想，是把有限时域最优控制问题反复放到在线闭环中求解。在时刻 $`t`$ ，控制器以状态估计 $`\hat x_t\in\mathbb R^n`$ 为初值，预测未来 $`N`$ 步状态与输入，并求解

```math
\begin{aligned}
\min_{\{x_k,u_k\}} \quad &
\sum_{k=0}^{N-1}\ell_k(x_k,u_k)+V_f(x_N)\\
\text{s.t.}\quad &
x_0=\hat x_t,\\
&x_{k+1}=f_k(x_k,u_k),\\
&x_k\in\mathcal X_k,\qquad u_k\in\mathcal U_k,\\
&x_N\in\mathcal X_f .
\end{aligned}
```

其中， $`x_k\in\mathbb R^n`$ 是预测状态， $`u_k\in\mathbb R^m`$ 是预测输入， $`\ell_k`$ 是阶段代价， $`V_f`$ 是终端代价， $`\mathcal X_k`$ 、 $`\mathcal U_k`$ 和 $`\mathcal X_f`$ 分别表示状态、输入与终端约束集合。求得序列 $`u_0^\star,\ldots,u_{N-1}^\star`$ 后，只执行第一项 $`u_0^\star`$ ，下一采样时刻用新的估计状态重新求解。在线优化因此不是反馈的替代品，而是产生反馈动作的一种计算机制。

对仓储机器人而言，在线优化允许控制器把多个要求放在同一问题中：底盘跟踪通道中心线，机械臂末端保持货箱姿态，轮毂电机转矩不饱和，关节速度不超过安全阈值，并根据相机更新的障碍物位置修改未来运动。这种统一性是 MPC 的主要工程价值。但它依赖若干基本条件：预测模型在所用时域内具有足够可信度，状态估计误差可控，优化能够在采样周期内给出可接受解，而且约束本身应与执行器和环境的真实边界一致。MPC 不能消除建模误差、感知延迟或不可行任务；它只是使这些因素可以被明确地建模、权衡和监控。

## 31.2 Prediction Model

预测模型描述“若施加候选输入，系统未来会怎样演化”。离散时间的一般形式为

```math
x_{k+1}=f(x_k,u_k,w_k),\qquad
y_k=h(x_k,v_k),
```

其中 $`x_k\in\mathbb R^n`$ 、 $`u_k\in\mathbb R^m`$ 、 $`y_k\in\mathbb R^p`$ 分别是状态、输入和观测， $`w_k`$ 与 $`v_k`$ 分别表示过程扰动和测量噪声。MPC 通常以估计器输出的 $`\hat x_t`$ 或后验分布作为初值，而不是直接把相机像素、编码器读数或 IMU 原始数据作为优化状态。因此，它与前面章节中的状态估计接口是清晰的：估计器融合传感器形成当前状态，预测器则从该状态向未来展开。

模型必须与控制层级匹配。对差速移动底盘，可用采样周期 $`\Delta t`$ 下的运动学模型

```math
\begin{aligned}
p_{x,k+1}&=p_{x,k}+\Delta t\,v_k\cos\theta_k,\\
p_{y,k+1}&=p_{y,k}+\Delta t\,v_k\sin\theta_k,\\
\theta_{k+1}&=\theta_k+\Delta t\,\omega_k,
\end{aligned}
```

其中状态 $`x_k=[p_{x,k},p_{y,k},\theta_k]^\top\in\mathbb R^3`$ ，输入 $`u_k=[v_k,\omega_k]^\top\in\mathbb R^2`$ 。若优化目标涉及打滑、制动距离或电机转矩，则必须进一步加入轮速、底盘速度和驱动力学。六轴机械臂可取 $`x=[q^\top,\dot q^\top]^\top\in\mathbb R^{12}`$ ，输入为关节转矩 $`\tau\in\mathbb R^6`$ ，并使用

```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f=\tau+\tau_{\mathrm{ext}},
```

再通过数值积分构造离散预测。仅在低速且底层伺服足够快时，才可把关节速度或位置指令直接视为 MPC 输入。

工程上需要在保真度与计算量之间取舍。模型过于简单会产生系统性预测偏差，过于复杂则可能使在线求解超时。常见做法包括在名义轨迹附近线性化、用辨识得到的局部模型替代完整刚体动力学，或增广执行器动态。例如电机电流不能瞬时变化时，可把电流 $`i_k`$ 纳入状态，用 $`i_{k+1}=a_i i_k+b_i v_k`$ 表示电气动态。模型还应明确适用域：运动学底盘模型通常假设低速、轮地无明显侧滑；刚性机械臂模型忽略柔性与齿隙；相机预测若假定目标静止，则不适用于高速移动人员。预测模型是对控制相关机制的近似，而不是对物理世界的完整复制。

## 31.3 Prediction Horizon

预测时域决定控制器能“看多远”。若采样周期为 $`\Delta t`$ ，预测步数为 $`N`$ ，则对应的物理时长为 $`T=N\Delta t`$ 。时域太短，控制器只能处理眼前误差，可能来不及为弯道、制动或机械臂避障做准备；时域太长，则模型误差累积、决策变量增加，在线计算成本也会上升。因而 $`N`$ 并不是越大越好，而应覆盖系统的主要响应时间和关键约束出现之前的预见距离。

仓储底盘以速度 $`v`$ 接近通道尽头时，时域至少应覆盖制动和转向所需时间。若最大可用减速度为 $`a_{\max}>0`$ ，仅从连续时间近似看，停车时间约为 $`v/a_{\max}`$ ，停车距离约为 $`v^2/(2a_{\max})`$ 。如果 $`T`$ 远小于停车时间，控制器即使在当前时域内可行，也可能把系统带入未来无法停止的状态。机械臂抓取时，预测时域应覆盖接近、减速和接触前姿态调整；但若把整个仓库任务都纳入毫秒级转矩 MPC，计算和模型维护都不现实，应由上层规划提供较长尺度的参考。

预测时域与控制时域可以不同。设仅优化前 $`N_u\leq N`$ 步独立输入，而在后续保持 $`u_k=u_{N_u-1}`$ ，可以降低变量维度，但会限制可表达的控制序列。也可使用非均匀离散：近端步长小，以准确表达快速动态与紧迫约束；远端步长大，以较低成本获得较长预见。这要求离散模型和代价权重按实际时间间隔一致缩放，否则不同网格上的问题不再代表同一连续时间目标。

有限时域会造成“时域末端之后不存在”的假象，因此需要终端代价 $`V_f(x_N)`$ 、终端集合 $`\mathcal X_f`$ 或足够长的预测窗口来表达远期影响。在线性调节问题中，常取 $`V_f(x_N)=x_N^\top P x_N`$ ，其中 $`P\succeq0`$ 来自局部 LQR；终端集合则要求从 $`x_N`$ 出发存在局部控制律持续满足约束。稳定性和递归可行性结论通常依赖这些构造、模型无误差以及初始问题可行，不能仅凭“使用了滚动时域”自动获得。

<a id="ch31-sec4"></a>
## 31.4 Objective Function

目标函数把任务性能、控制消耗和风险偏好转化为可比较的标量。跟踪型 MPC 常用二次目标

```math
J=
\sum_{k=0}^{N-1}
\left[
(x_k-x_k^{\mathrm{ref}})^\top Q_k(x_k-x_k^{\mathrm{ref}})
+
(u_k-u_k^{\mathrm{ref}})^\top R_k(u_k-u_k^{\mathrm{ref}})
+
\Delta u_k^\top S_k\Delta u_k
\right]
+
(x_N-x_N^{\mathrm{ref}})^\top P(x_N-x_N^{\mathrm{ref}}),
```

其中 $`Q_k,P\in\mathbb R^{n\times n}`$ 为半正定矩阵， $`R_k\in\mathbb R^{m\times m}`$ 通常为正定矩阵， $`S_k\succeq0`$ ，且 $`\Delta u_k=u_k-u_{k-1}`$ 。第一项抑制状态跟踪误差，第二项限制输入偏离参考值或能耗，第三项抑制输入跳变，终端项近似时域之外的代价。

不同物理量的尺度必须被认真处理。底盘位置误差以米计，航向误差以弧度计，机械臂关节速度以弧度每秒计，电机转矩以牛顿米计；若直接使用单位矩阵，数值大小而非任务重要性会决定优化结果。可先用允许偏差 $`\bar e_i`$ 和典型输入 $`\bar u_j`$ 归一化，再设置无量纲权重，例如 $`Q_{ii}=w_i/\bar e_i^2`$ 。权重表达的是软性权衡，而安全边界通常应写成约束，不能只靠增大惩罚系数替代。

仓储移动操作任务可同时包含底盘路径误差、机械臂末端位姿误差和载荷平稳性。末端位姿代价可以写为

```math
\ell_{\mathrm{ee}}
=
\|p(q)-p^{\mathrm{ref}}\|_{W_p}^2
+
\|\operatorname{Log}(R_{\mathrm{ref}}^\top R(q))\|_{W_R}^2,
```

其中 $`p(q)\in\mathbb R^3`$ 和 $`R(q)\in SO(3)`$ 由正运动学得到， $`\operatorname{Log}:SO(3)\rightarrow\mathbb R^3`$ 给出局部旋转误差，记号 $`\|z\|_W^2=z^\top Wz`$ 。这种几何误差只在所选对数映射分支内具有局部光滑性，接近旋转奇异区域时应谨慎处理。

目标还可以加入能量、时间、视野或避障软代价，但多个目标的加权和并不自动表达严格优先级。例如相机需要始终看到抓取目标时，视野要求若属于任务必要条件，应建成约束或分层优化，而不只是一个可能被位置误差“买掉”的惩罚项。目标设计的边界在于：它只能比较模型中已表达的结果，无法补偿缺失状态、错误单位和未建模安全要求。

## 31.5 Input Constraint

输入约束直接描述执行器可以施加的命令集合。线性不等式常写为

```math
G_u u_k\leq g_u,
```

其中 $`G_u\in\mathbb R^{r_u\times m}`$ ， $`g_u\in\mathbb R^{r_u}`$ 。简单的上下界是 $`u_{\min}\leq u_k\leq u_{\max}`$ 。对差速底盘，输入可以是左右轮角速度，也可以是线速度和角速度；这两种坐标下的可行集合不同。若轮半径为 $`r`$ 、轮距为 $`b`$ ，则

```math
\omega_L=\frac{v-\frac{b}{2}\omega}{r},\qquad
\omega_R=\frac{v+\frac{b}{2}\omega}{r}.
```

轮速边界在 $`(v,\omega)`$ 平面中形成耦合多面体，而不是两个互不相关的盒约束。忽略这种耦合可能得到底盘层面看似合理、轮电机却无法执行的命令。

执行器还常受变化率和功率约束。输入变化率可写为

```math
\Delta u_{\min}\leq u_k-u_{k-1}\leq\Delta u_{\max},
```

其中 $`u_{-1}`$ 取上一控制周期实际施加的输入。六轴机械臂的关节转矩受电机电流、减速器能力和温度影响，固定的 $`\tau_{\min}\leq\tau_k\leq\tau_{\max}`$ 只是一阶近似；高速时还可能受反电动势限制，形成与关节速度相关的转矩包络。若底层驱动器存在电流环和限幅器，上层 MPC 应使用可被该接口实现的输入定义，而不能假定转矩瞬时、精确地到达。

硬输入约束通常不应被放松，因为超过电流、转矩或转速极限可能损坏硬件。然而，约束参数必须留出模型误差、通信延迟和低层跟踪误差的余量。过于乐观会频繁饱和，过于保守则浪费性能。输入约束也不能保证全部安全：即使每一步转矩均合法，累积温升、制动能量或载荷摆动仍可能越界，这些量需要通过增广状态或更高层的运行限制明确建模。

## 31.6 State Constraint

状态约束规定系统在预测过程中允许进入的区域，常写为

```math
G_xx_k\leq g_x
```

或更一般的非线性形式 $`c_j(x_k)\leq0`$ 。机械臂的关节位置、关节速度和工作空间范围属于典型状态约束；底盘可受通道边界、最小转弯空间和稳定速度限制。状态约束与输入约束的关键区别是：输入可以由当前控制器直接选择，而状态只能通过动力学间接改变。因此，当前状态接近边界且制动能力不足时，下一步状态约束可能根本无法满足。

障碍物约束通常由几何模型生成。若把底盘近似为半径 $`r_b`$ 的圆，把障碍物占据区域膨胀安全距离 $`r_s`$ ，则可要求机器人位置 $`p_k\in\mathbb R^2`$ 满足

```math
d(p_k,\mathcal O_k)\geq r_b+r_s,
```

其中 $`d(\cdot,\mathcal O_k)`$ 是到预测障碍区域 $`\mathcal O_k`$ 的距离。该约束一般是非凸的，因为可行空间可能分成从障碍物左右绕行的多个分支。对于机械臂，还要检查各连杆而不仅是末端执行器。相机检测得到的障碍位置带有不确定性时，安全距离应结合估计协方差、感知延迟和障碍运动模型设置，不能把单帧检测中心当作确定真值。

为了避免轻微预测误差导致优化完全不可行，部分状态约束可引入松弛变量 $`\epsilon_k\geq0`$ ：

```math
G_xx_k\leq g_x+\epsilon_k,\qquad
J_{\epsilon}=\rho_1\|\epsilon_k\|_1+\rho_2\|\epsilon_k\|_2^2.
```

大权重 $`\rho_1,\rho_2`$ 使违反约束代价高昂，并允许控制器报告“最小必要违反”。但软约束只适用于可以暂时退让的性能要求，例如通道中心偏差或舒适性限制。碰撞、机械硬限位等安全边界不能仅依赖有限惩罚，因为任何有限权重都可能在其他代价足够大时被优化器交换掉。

状态约束的另一个边界是离散采样。只在节点 $`x_k`$ 上无碰撞，并不保证节点之间的连续轨迹无碰撞，尤其在高速运动或较大 $`\Delta t`$ 下。工程上可缩短步长、检查插值轨迹、使用连续时间距离界，或对障碍进行额外膨胀。递归可行性同样不是自动成立的：今天存在一条满足有限时域约束的轨迹，不代表执行第一步后明天仍有可行轨迹，除非终端集合、鲁棒裕量或安全备份策略提供了相应保证。

<a id="ch31-sec7"></a>
## 31.7 Receding Horizon

滚动时域是 MPC 从有限时域优化转化为闭环控制的机制。每个控制周期依次执行：获取传感器数据；由滤波器或优化估计器形成 $`\hat x_t`$ ；更新参考轨迹、模型参数与障碍物集合；求解长度为 $`N`$ 的最优控制问题；发送第一项控制 $`u_0^\star`$ ；将预测序列平移，作为下一周期初值。其余预测输入不会被原样执行，而是用于评价当前动作的未来后果。

若用 $`\Pi_N(\hat x_t)`$ 表示有限时域优化器输出的首个动作，则闭环律可抽象为

```math
u_t=\Pi_N(\hat x_t,r_{t:t+N},\mathcal E_{t:t+N}),
```

其中 $`r_{t:t+N}`$ 是参考序列， $`\mathcal E_{t:t+N}`$ 表示环境与约束预测。尽管优化器每次给出一个开环序列，反复测量和重求解使首项动作成为当前估计状态的函数，因此形成反馈。仓储机器人若因地面接缝发生轻微侧滑，下一帧相机、轮速计和 IMU 融合后的位姿会改变，新的优化问题便会修正后续底盘速度；机械臂抓取载荷变化也会通过关节误差与扰动估计进入下一次求解。

滚动机制可以响应扰动，却不意味着能够修复任意扰动。若机器人已被推到约束外，或剩余距离小于物理停车距离，重新优化也无法创造不存在的可行动作。闭环性能还受估计延迟影响：优化完成时，初值 $`\hat x_t`$ 可能已经过时。常见处理是用已知控制把状态前推到预计执行时刻，或在预测模型中显式纳入计算和通信延迟。

滚动时域还可能带来短视行为，例如控制器不断把代价推到时域末端，而不真正完成任务。终端代价、终端约束和适当的任务进度变量用于抑制这种现象。理论上的稳定性与递归可行性通常要求模型精确、终端控制律可行、优化得到足够准确的解；实际系统还应配备求解超时、估计异常和约束冲突时的监控与安全动作。

<a id="ch31-sec8"></a>
## 31.8 Quadratic Programming

当预测模型线性、目标二次且约束为线性等式或不等式时，MPC 可写成二次规划（Quadratic Programming, QP）：

```math
\begin{aligned}
\min_z\quad &\frac12z^\top Hz+f^\top z\\
\text{s.t.}\quad &Az=b,\\
&Gz\leq h,
\end{aligned}
```

其中决策变量 $`z`$ 可以包含全部状态和输入， $`H=H^\top\succeq0`$ 时问题为凸 QP。若 $`H\succ0`$ 且可行集合非空，则最优解唯一。等式约束编码离散动力学和初值，不等式约束编码输入、状态及松弛变量边界。凸性意味着任意局部最优解也是全局最优解，但不意味着问题一定可行，也不意味着有限精度求解器一定在截止时间前返回足够准确的解。

QP 有稀疏形式和凝聚形式。稀疏形式保留 $`x_0,\ldots,x_N`$ 与 $`u_0,\ldots,u_{N-1}`$ ，动力学约束呈带状结构，适合利用时序稀疏性。凝聚形式通过递推消去状态，将预测堆叠成

```math
X=\mathcal A x_0+\mathcal B U,
```

其中 $`X\in\mathbb R^{Nn}`$ ， $`U\in\mathbb R^{Nm}`$ ， $`\mathcal A`$ 、 $`\mathcal B`$ 由系统矩阵构造。代入目标后得到只关于 $`U`$ 的 QP。凝聚减少变量数量，却可能让 Hessian 和约束矩阵变稠密；对于状态维度大的六轴机械臂，完全凝聚未必更快。

QP 求解器常基于活跃集法、内点法或一阶算子分裂法。活跃集法在相邻周期活跃约束变化较小时可有效利用热启动；内点法对大规模稀疏问题具有稳定的迭代结构；一阶方法单步便宜，但获得高精度可能需要更多迭代。选择应依据问题尺寸、条件数、所需精度和最坏计算时间，而不是只比较平均速度。变量缩放尤其重要：米、弧度、牛顿米和松弛惩罚相差多个数量级时，KKT 系统可能病态。

对仓储底盘的线性化跟踪问题，QP 可以在几十赫兹甚至更高频率运行；对机械臂，结构化稀疏求解通常比通用密集求解更有优势。工程验收不仅要检查目标值，还要检查原始残差、对偶残差、约束最大违反量和求解状态。一个标记为“已收敛”的数值解，只有在误差公差与硬件安全余量相容时才可执行。

## 31.9 Linear MPC

线性 MPC 使用线性或线性时变预测模型

```math
x_{k+1}=A_kx_k+B_ku_k+c_k,
```

其中 $`A_k\in\mathbb R^{n\times n}`$ 、 $`B_k\in\mathbb R^{n\times m}`$ 、 $`c_k\in\mathbb R^n`$ 。对于定常系统，矩阵可不随 $`k`$ 变化；对于沿参考轨迹线性化的系统，它们随预测步变化。设名义轨迹为 $`(\bar x_k,\bar u_k)`$ ，定义误差 $`\delta x_k=x_k-\bar x_k`$ 、 $`\delta u_k=u_k-\bar u_k`$ ，一阶近似为

```math
\delta x_{k+1}=A_k\delta x_k+B_k\delta u_k,
\qquad
A_k=\left.\frac{\partial f}{\partial x}\right|_{\bar x_k,\bar u_k},
\quad
B_k=\left.\frac{\partial f}{\partial u}\right|_{\bar x_k,\bar u_k}.
```

配合二次目标和多面体约束后，问题成为凸 QP。线性 MPC 的优势是计算结构清晰、求解器成熟，并且能够显式处理约束。仓储底盘沿缓弯通道运行时，可以围绕规划轨迹线性化运动学模型，优化横向误差、航向误差与速度；机械臂则可在某一抓取姿态附近使用离散线性动力学，控制小范围关节偏差。若工作点变化明显，应随参考轨迹更新 $`A_k,B_k`$ ，而不是长期使用单一固定模型。

线性化只在局部有效。底盘航向误差过大、轮胎明显侧滑，或机械臂远离线性化姿态时，一阶模型可能给出错误预测。可通过缩短采样周期、限制信赖区域、周期性重线性化或切换到非线性 MPC 缓解。若模型含仿射项 $`c_k`$ 或非零平衡输入，参考状态和参考输入还必须满足或近似满足动力学，否则控制器会持续补偿一个本可由参考生成阶段消除的残差。

稳定性设计通常借鉴 LQR。对无约束局部模型，可由离散代数 Riccati 方程得到 $`P`$ 和反馈增益 $`K`$ ，取终端代价 $`\delta x_N^\top P\delta x_N`$ ，并构造在 $`u=\bar u+K\delta x`$ 下正不变的终端集合。这样可以把有限时域末端与局部无限时域控制连接起来。但相关保证依赖线性模型、集合构造和约束假设；对时变参考、软约束或显著模型误差，必须重新分析而不能机械套用定常结论。

## 31.10 Nonlinear MPC

非线性 MPC（NMPC）直接保留非线性动力学、几何关系或约束：

```math
\begin{aligned}
\min_{\{x_k,u_k\}}\quad&
\sum_{k=0}^{N-1}\ell(x_k,u_k)+V_f(x_N)\\
\text{s.t.}\quad&
x_{k+1}=F_{\Delta t}(x_k,u_k),\\
&c(x_k,u_k)\leq0.
\end{aligned}
```

这里 $`F_{\Delta t}`$ 是连续动力学在时间步长 $`\Delta t`$ 下的离散流映射。它可由显式 Runge–Kutta、隐式积分或专门的刚体动力学离散方法得到。离散方式是模型的一部分：积分误差过大时，优化器可能利用数值模型中的虚假行为；高精度积分则增加函数和导数计算成本。

NMPC 适合非线性不可忽略的场景。移动底盘在狭窄通道中需要同时优化位置和航向，机械臂需要通过正运动学表达连杆避障与末端姿态，移动底盘和机械臂协同搬运时还存在明显耦合。对无人机，姿态位于 $`SO(3)`$ ，推力方向与平移动力学耦合，NMPC 的价值更为突出；但四元数必须处理单位范数和双覆盖，旋转矩阵则必须保持流形约束。状态空间中的几何结构不应被任意欧氏坐标替代。

非线性问题一般非凸，常用序列二次规划、内点法、直接多重射击或逐次凸化求解。以 SQP 为例，在当前轨迹附近线性化约束、二次近似拉格朗日函数，求一个 QP 步长，再更新名义轨迹。iLQR 和 DDP 也可看作利用动态结构求解局部轨迹优化的方式，但对一般不等式约束需要额外机制。由于非凸性，解依赖初值，算法可能收敛到局部最优，也可能在时限内未收敛。

工程上应为 NMPC 提供质量良好的参考轨迹和热启动，并限制每次迭代跨越的区域。仓储机器人绕货架选择左侧还是右侧属于离散拓扑决策，单次局部 NMPC 通常不擅长从差的初值中发现另一条绕行通道；这种选择更适合由上层规划器完成。NMPC 的边界因此很明确：它能精细优化给定局部运动族中的动态行为，但不能保证解决任意非凸全局规划问题。

## 31.11 实时优化

实时优化要求控制器在动作必须下发之前提供可用结果。若采样周期为 $`T_s`$ ，感知、估计、参考更新、优化、通信和执行器接口共同消耗该预算。设这些阶段的最坏时间分别为 $`T_{\mathrm{est}}`$ 、 $`T_{\mathrm{ref}}`$ 、 $`T_{\mathrm{opt}}`$ 和 $`T_{\mathrm{comm}}`$ ，至少应满足

```math
T_{\mathrm{est}}+T_{\mathrm{ref}}+T_{\mathrm{opt}}+T_{\mathrm{comm}}<T_s,
```

并保留操作系统抖动与异常分支余量。平均求解时间不足以证明实时性；偶发超时可能恰好发生在障碍物接近或电机饱和的关键时刻。

相邻控制周期的问题通常变化不大，因此可把上一周期解平移后作为热启动：

```math
u_k^{(0)}\leftarrow u_{k+1}^{\star},\qquad
u_{N-1}^{(0)}\leftarrow u_{N-1}^{\star}.
```

状态轨迹随后通过新初值重新积分，以减少动力学不一致。对 SQP 型 NMPC，可采用实时迭代策略：每周期只执行有限次线性化和 QP 更新，而不是等待完全收敛。这种做法依赖高采样率、良好热启动和缓慢变化的问题；若参考突然切换、感知结果跳变或当前轨迹远离可行域，一次迭代可能不足以产生可靠控制。

提升实时性的手段包括利用稀疏结构、预分配内存、自动生成导数、缩放变量、减少不必要状态、采用部分凝聚，以及将慢参数更新与快控制环分离。仓储移动操作机器人可让底盘局部 MPC 以较低频率更新速度轨迹，由电机速度环以更高频率执行；机械臂 NMPC 可生成关节转矩或速度参考，再由驱动器电流环闭合最快动态。多速率结构有效的前提是层间带宽分离合理，且上层模型已经反映下层闭环响应。

任何在线求解器都需要失败策略。控制器应区分最优、次优可接受、迭代上限、数值错误和不可行等状态，并检查候选解的约束残差。超时时可在验证安全后使用上一序列的下一项、局部稳定反馈或制动策略，但不能盲目重复陈旧命令。安全备份也必须考虑当前速度和制动能力；“停止”不是抽象指令，而是一条受动力学与障碍距离约束的轨迹。

<a id="ch31-sec12"></a>
## 31.12 模型误差与闭环反馈

MPC 的预测永远基于近似模型。仓储底盘可能因载荷和地面材质产生滚阻变化，机械臂抓取不同货物后惯量发生改变，电机存在死区与温漂，相机和 IMU 也会带来偏置、噪声与延迟。滚动反馈能不断修正状态偏差，却不能自动消除系统性的稳态误差。若模型持续低估阻力，控制器可能在每周期重复做出相似的错误预测。

一种常用方法是引入常值或慢变扰动状态：

```math
\begin{aligned}
x_{k+1}&=Ax_k+Bu_k+B_dd_k,\\
d_{k+1}&=d_k,\\
y_k&=Cx_k+C_dd_k+v_k,
\end{aligned}
```

其中 $`d_k\in\mathbb R^{n_d}`$ 表示未知偏置或等效扰动，由卡尔曼滤波、扩展滤波或移动时域估计器在线估计。控制目标再围绕满足增广稳态方程的 $`(x_s,u_s,d_s)`$ 构造，从而实现无静差跟踪。该方法要求扰动对输入输出的作用可辨识，并且“近似常值”的时间尺度相对控制环足够慢；快速冲击或结构错误不能被一个常值偏置完整表示。

对于有界误差，可把真实系统写成

```math
x_{k+1}=f(x_k,u_k)+w_k,\qquad w_k\in\mathcal W,
```

并通过约束收紧、管束 MPC 或不变集思想保留鲁棒余量。若不确定性来自概率估计，也可把碰撞概率或状态越界概率限制在给定水平，但概率约束只有在分布假设、相关性和尾部模型可信时才有意义。视觉感知中的漏检通常不是简单高斯噪声，因此不能只凭协方差膨胀宣称安全。

模型维护还需要残差监测。可比较观测到的下一状态与预测值 $`r_k=\hat x_{k+1}-f(\hat x_k,u_k)`$ ，跟踪其均值、协方差和工况依赖性。残差异常可能来自模型失配、传感器故障、执行器退化或时间同步错误，不能全部交给 MPC 权重调整。下一章将进一步讨论非线性、鲁棒与自适应控制；这里的接口是：MPC 提供显式的预测和约束框架，而鲁棒性与自适应机制规定如何在模型不确定时修正预测、收紧可行域并维持闭环性质。

<a id="ch31-sec13"></a>
## 31.13 MPC 与 LQR

LQR 与 MPC 共享相同的状态空间和二次性能指标。对离散线性系统

```math
x_{k+1}=Ax_k+Bu_k
```

和无限时域代价

```math
J=\sum_{k=0}^{\infty}(x_k^\top Qx_k+u_k^\top Ru_k),
```

在可稳定、可检测等标准条件下，LQR 得到线性反馈 $`u_k=Kx_k`$ ，其中 $`K`$ 由离散代数 Riccati 方程确定。若 MPC 不含约束，采用相同模型和代价，并令终端矩阵 $`P`$ 等于无限时域 Riccati 解，则有限时域动态规划在理想条件下也会给出相同的首项反馈。

两者的主要差异不是“最优”与“不最优”，而是问题结构。LQR 把无约束线性二次问题离线压缩为固定增益，在线计算极小；MPC 在线保留有限时域状态和输入，从而能够处理转矩饱和、关节限位、速度边界和时变参考。仓储底盘远离障碍且输入未饱和时，线性 MPC 的局部行为常接近 LQR；接近弯道或速度上限时，约束变为活跃，控制律转为分段仿射或更一般的非线性映射。

LQR 也为 MPC 提供终端设计和局部备份。可选择终端反馈 $`u=Kx`$ 、终端代价 $`x^\top Px`$ ，并构造集合

```math
\mathcal X_f=\{x\mid x\in\mathcal X,\ Kx\in\mathcal U,\ (A+BK)x\in\mathcal X_f\}.
```

若预测末端进入该集合，则存在一个已知局部策略继续满足约束。这个结构能在适当假设下建立稳定性和递归可行性，但终端集合可能保守，且对非线性、时变或受扰系统需要相应扩展。

因此，MPC 不应被理解为全面替代 LQR。对于高频电机电流环、小偏差姿态稳定或资源受限控制器，LQR 及其增益调度形式往往更合适；对于约束频繁活跃、参考随环境变化且需要预见的层级，MPC 更具优势。实际系统常把两者组合：MPC 负责较慢的受约束运动，LQR 或局部线性反馈负责快速稳定和求解失败时的短时接管。

<a id="ch31-sec14"></a>
## 31.14 MPC 与 Trajectory Optimization

轨迹优化与 MPC 在数学上都求解受动力学约束的有限时域优化问题。直接配点、多重射击、iLQR 和 DDP 都可以产生状态—输入轨迹

```math
\{x_0^\star,u_0^\star,\ldots,x_N^\star\}
```

以最小化任务代价。区别主要在使用方式：轨迹优化通常针对一个已知初值和任务离线或低频求解，并输出整条轨迹；MPC 则在每个采样周期重新设置初值，只执行第一项动作，并把优化嵌入反馈闭环。

二者可形成自然流水线。仓库任务规划器先确定货架、抓取点和通道拓扑；轨迹优化器根据完整非线性模型生成底盘与机械臂的动态可行名义轨迹；MPC 在执行时跟踪该轨迹，并根据最新状态、局部障碍和执行器边界调整未来若干步。名义轨迹为 NMPC 提供高质量热启动，也替它完成绕障侧别、抓取模式等较强的非凸决策。

从算法角度看，同一种求解方法既可用于轨迹优化，也可放入 MPC。iLQR 或 DDP 若在每周期以当前状态重求局部最优轨迹，并只施加第一项控制，就形成一种滚动时域控制器；SQP、多重射击和逐次凸化同样如此。因此，“MPC”更多描述闭环组织方式和持续重规划机制，而不是某一个特定数值算法。

边界在于计算频率和信息范围。离线轨迹优化可以用更长时域、更复杂碰撞模型和更多迭代，却无法及时利用执行中的新观测；MPC 能快速反馈，但通常只能处理局部时域和有限模型复杂度。若让短时域 MPC 独自承担全局通道选择，它可能陷入局部极小或无路可走；若只执行离线轨迹而没有反馈，微小误差又会累积。合理架构应让全局优化决定长期结构，让滚动优化负责局部动态一致性与约束处理。

<a id="ch31-sec15"></a>
## 31.15 MPC 为什么位于规划与控制的交界处

传统分层常把规划描述为“决定去哪里”，把控制描述为“保证到达那里”。MPC 同时包含两者的要素：它通过动力学和当前状态生成可执行控制，又在预测时域内选择未来状态、速度和局部路径。其解不是单纯的固定反馈增益，也不是只考虑几何连通性的路径，而是一段受模型、代价与约束共同决定的局部运动计划。

仓储移动操作机器人可以采用多层滚动结构。任务层决定取哪个货箱、送往哪个工位；全局规划层在仓库地图上选择通道与作业顺序；局部 MPC 根据相机更新的行人和托盘位置优化底盘速度与短期轨迹；机械臂 MPC 协调关节运动、末端姿态和连杆避障；最底层电机控制器跟踪电流、速度或转矩参考。不同层级的状态维度、采样周期和模型保真度不同，但接口应一致地表达参考、可行域、时间戳和不确定性。

这一交界可以用“参考不是命令，约束不是建议”来理解。上层给出的参考轨迹 $`r_{t:t+N}`$ 是期望行为，MPC 可在约束或扰动要求下偏离它；执行器边界和确认过的安全约束则定义不可随意交换的可行域。反过来，局部 MPC 若发现问题不可行，应把阻塞、最小停车距离或可达集合信息反馈给上层，而不是只返回一个数值失败标志。规划与控制由此形成双向接口，而非单向命令链。

MPC 也不能消除分层的必要性。全局任务包含离散决策、长时间依赖和地图拓扑，直接放入高频连续优化会形成规模巨大的混合整数或非凸问题；电机电流等快速动态又不适合由低频全局规划直接控制。只有在时间尺度、模型精度和计算资源允许时，某些层才适合合并。对无人机或四足机器人也是如此：NMPC 可以协调短期姿态、接触力和落脚运动，但长程航线、步态模式与任务逻辑通常仍需更高层处理。

因此，MPC 位于规划与控制交界处的真正原因，是它把“预测未来”和“立即反馈”放进了同一个循环。预测赋予控制器预见约束和任务后果的能力，滚动反馈则不断用真实状态纠正计划。其有效性建立在模型、估计、优化、几何环境和执行器接口的一致性上；任何一个接口失真，都可能使数学上的最优解失去工程意义。

## 本章小结

模型预测控制把有限时域最优控制嵌入反复测量、求解和执行的闭环。其基本链条是：由估计器提供当前状态，以离散预测模型展开未来，在预测时域内最小化阶段代价和终端代价，同时满足输入、状态与终端约束；求解后只执行第一项控制，并在下一周期根据新观测重新优化。线性模型、二次目标和线性约束形成 QP，适合成熟的实时数值方法；保留非线性动力学和几何约束则形成 NMPC，表达能力更强，但通常只能得到依赖初值的局部解。

仓储移动操作机器人展示了这一框架的多层价值：移动底盘可预见转弯、制动和通道边界，六轴机械臂可同时处理关节、转矩、末端位姿和连杆避障，电机约束规定真实可执行范围，相机与 IMU 则通过状态估计和环境更新闭合反馈。预测时域、权重、模型保真度和求解精度都必须与物理时间尺度匹配；软约束、热启动和失败策略能够改善可用性，却不能替代硬件边界、可行性分析与安全备份。

MPC 与 LQR 通过局部二次反馈、Riccati 终端代价和终端集合相连，与 iLQR、DDP 及一般轨迹优化通过有限时域动态优化相连。它之所以处于规划与控制的交界，是因为每次求解都产生一段局部计划，而滚动执行又把该计划变为反馈动作。下一章将在此基础上进一步处理非线性、参数变化和模型不确定性，讨论鲁棒裕量、自适应更新与闭环稳定性如何进入控制器设计。
