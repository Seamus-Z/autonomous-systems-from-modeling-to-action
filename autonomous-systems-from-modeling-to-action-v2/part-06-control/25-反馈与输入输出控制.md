## 25.1 开环与闭环

控制系统以期望目标为输入，通过执行器作用于动态对象，并使其输出表现出所需行为。沿用前文的状态空间接口，可将被控对象写成

```math
\dot{x}(t)=f\bigl(x(t),u(t),d(t)\bigr),\qquad
y(t)=h\bigl(x(t)\bigr)+n(t),
```

其中 $`x\in\mathbb{R}^n`$ 是状态， $`u\in\mathbb{R}^m`$ 是控制输入， $`d`$ 是进入动力学的扰动， $`y\in\mathbb{R}^p`$ 是可测输出， $`n`$ 是测量噪声。仓储移动操作机器人可同时包含底盘位姿与速度、六轴机械臂关节位置与速度、电机电流，以及相机或 IMU 的偏置状态；控制输入则可能是轮端电压、期望电流、关节力矩或更高层的速度命令。控制器究竟看到哪些变量，取决于传感器和状态估计器，而不一定等于完整状态 $`x`$ 。

开环控制按照时间、任务参数或规划结果直接生成输入，即 $`u(t)=\pi_{\mathrm{ol}}(r_{0:t},t)`$ ，执行过程中不利用当前输出对输入进行修正。例如，机器人根据标定模型向轮电机施加固定时长的电压，或机械臂按照离线逆动力学力矩序列抓取纸箱。开环的优点是结构简单，不会把传感噪声注入执行器；在模型准确、初始条件确定、环境重复且扰动很小时，它可以达到很高的可重复性。但轮胎打滑、载荷变化、电池电压下降或纸箱质量未知都会造成状态偏离，而开环没有识别并纠正这种偏离的机制。

闭环控制根据测量或估计结果生成输入：

```math
\hat{x}(t)=\mathcal{E}\bigl(y_{0:t},u_{0:t}\bigr),\qquad
u(t)=\pi\bigl(r(t),\hat{x}(t),t\bigr),
```

其中 $`\mathcal{E}`$ 是估计器， $`r`$ 是参考信号。底盘可用编码器、IMU 和相机融合得到的位姿闭环跟踪通道中心；机械臂可用编码器反馈修正关节误差；电流环则利用相电流测量快速调节电磁力矩。闭环能够响应未精确建模的变化，但并不天然稳定：错误的反馈符号、过大的增益、估计延迟、采样不足和执行器饱和都可能导致振荡甚至失稳。

开环与闭环也不是互斥的整机标签。一个仓储机器人通常同时具有开环任务调度、闭环底盘定位、闭环机械臂关节控制，以及前馈加反馈的电机控制。讨论某个系统是否闭环时，必须说明所考察的输入、输出和时间尺度。上层规划器以数秒为周期产生轨迹，下层电流环以数十微秒至数百微秒更新；对上层看似“立即实现”的速度命令，在电机层仍是具有动态、延迟和饱和的闭环过程。

## 25.2 Reference

参考信号（reference）是控制系统希望输出或状态遵循的目标，通常记为 $`r(t)\in\mathbb{R}^q`$ 。它不是抽象的“愿望”，而应是经过任务规划、路径规划和轨迹优化后形成的、带有坐标系、单位、时间参数和可行性语义的信号。第 24 章得到的离散轨迹可写为 $`\{x_k^\star,u_k^\star\}_{k=0}^{N}`$ ；进入控制层后，通常还要进行时间插值，形成 $`r(t)`$ 、 $`\dot r(t)`$ ，必要时包括 $`\ddot r(t)`$ 。若控制输出就是某个状态分量，可写成 $`y=Cx`$ 与 $`r=y^\star`$ ；若目标位于任务空间，则输出映射可能是非线性的，例如机械臂末端位姿 $`y=h(q)\in SE(3)`$ 。

仓储机器人的参考具有明显的层级结构。任务层给出“到货架 A、取箱、送到工位 B”；运动规划层将其变为底盘路径和机械臂无碰轨迹；底盘控制器接收平面位姿或线速度、角速度参考；关节控制器接收 $`q^\star,\dot q^\star,\ddot q^\star\in\mathbb{R}^6`$ ；电机内环再接收期望力矩或电流。若电机力矩常数为 $`K_t\in\mathbb{R}^{6\times6}`$ ，常用近似为 $`\tau^\star=K_t i^\star`$ 。这种逐层参考变换必须保持动力学可行性，不能把几何上连续但速度或加速度不连续的路径直接交给真实执行器。

参考也必须与输出空间相容。对欧氏位置可直接使用向量差，对角度则要处理周期性；对三维姿态不能把旋转矩阵逐元素相减后当作普通姿态误差。若移动底盘航向参考从 $`179^\circ`$ 变到 $`-179^\circ`$ ，正确目标是转动 $`2^\circ`$ ，而不是反向转动 $`358^\circ`$ 。类似地，机械臂末端位姿参考应通过群上的误差映射处理。参考的维数 $`q`$ 也不必等于控制输入维数 $`m`$ ：冗余机械臂可用多个关节自由度完成较低维的末端任务，欠驱动无人机则必须借助系统动态才能改变某些位置输出。

工程上还应区分“命令”与“可实现参考”。阶跃位置命令在数学上简洁，却隐含无限速度和加速度，不适用于有限力矩的底盘和机械臂。通常需要参考整形器，将原始命令 $`r_c`$ 转成满足速度、加速度、跃度及碰撞约束的 $`r`$ 。这一过程假设规划模型足以识别主要约束；若地面附着条件、抓取载荷或执行器温度发生变化，参考仍可能变得不可行，此时控制器应配合限幅、参考治理或重新规划，而不能仅靠增大反馈增益强行跟踪。

## 25.3 Error

误差（error）描述参考与实际输出之间的偏离。对同一欧氏向量空间中的信号，最基本的定义是

```math
e(t)=r(t)-y(t),\qquad e\in\mathbb{R}^p,
```

这里假设 $`r`$ 与 $`y`$ 维数、坐标系和单位一致。若控制器使用估计输出 $`\hat y`$ ，则实际计算的是 $`\hat e=r-\hat y`$ ，并有 $`\hat e=e-(\hat y-y)`$ ；因此，反馈看到的是控制误差与估计误差的叠加。编码器量化、视觉定位延迟和 IMU 偏置都会通过这一接口进入控制器，不能把状态估计与控制误差视为彼此无关的模块。

误差的定义必须尊重状态所在的几何空间。对移动底盘的平面位姿 $`T,T^\star\in SE(2)`$ ，可定义机体系误差

```math
e_T=\mathrm{Log}\!\left(T^{-1}T^\star\right)^\vee\in\mathbb{R}^3,
```

其中 $`\mathrm{Log}`$ 将群元素映射到李代数， $`(\cdot)^\vee`$ 再将矩阵表示转成坐标向量。对机械臂末端位姿 $`G,G^\star\in SE(3)`$ ，相同结构给出六维位置—姿态误差。左不变误差 $`(T^\star T^{-1})`$ 与右不变误差 $`(T^{-1}T^\star)`$ 表达在不同坐标系中；选择哪一种必须与雅可比矩阵、速度表示和控制律保持一致。在旋转接近 $`\pi`$ 时，对数映射还可能出现分支与数值不连续，需要限制工作域或采用连续姿态表示。

当误差包含不同单位时，不能仅凭数值大小比较。底盘的 $`0.1\,\mathrm{m}`$ 位置误差和 $`0.1\,\mathrm{rad}`$ 航向误差没有天然等价关系；机械臂的关节误差、速度误差与末端力误差也需按任务尺度加权。常用二次度量为

```math
\|e\|_Q^2=e^\mathsf{T}Qe,\qquad Q=Q^\mathsf{T}\succeq0,
```

其中 $`Q\in\mathbb{R}^{p\times p}`$ 编码单位归一化和任务优先级。 $`Q`$ 不是越大越好：它会与输入代价、噪声、约束及未建模动态共同决定闭环行为。若相机定位在货架遮挡时方差变大，固定高增益地追逐视觉误差可能使底盘抖动；更合理的做法是让估计器表达不确定性，并在控制设计中限制相应通道的带宽。

工程验收也不能只看瞬时误差。常见指标包括峰值误差 $`\|e\|_\infty`$ 、均方根误差、稳态误差以及积分绝对误差 $`\int_0^T\|e(t)\|\,dt`$ 。抓取任务还应关注末端速度和接触力，因为位置误差很小并不意味着接触安全。所有这些指标都建立在明确的任务区间和扰动条件上；超出传感器视场、执行器能力或控制器设计工作域后，误差指标本身不能保证安全。

## 25.4 Negative Feedback

负反馈（negative feedback）是把输出与参考进行比较，并让控制作用倾向于减小误差的机制。最简单的比例控制为

```math
u(t)=K e(t)=K\bigl(r(t)-y(t)\bigr),
```

其中 $`K\in\mathbb{R}^{m\times p}`$ 是反馈增益。对标量静态对象 $`y=Pu`$ 且 $`P>0`$ ，正的 $`K`$ 会使输出上升时误差下降，因而形成负反馈。这里“负”来自比较节点的符号，而不是要求控制输入数值为负。对多输入多输出系统，通道耦合使符号判断不再充分，必须考察矩阵闭环动态的特征值、频率响应或适当的稳定性条件。

在线性化工作点 $`(x_0,u_0)`$ 附近，令 $`\delta x=x-x_0`$ 、 $`\delta u=u-u_0`$ ，有

```math
\delta\dot x=A\delta x+B\delta u,\qquad
\delta y=C\delta x,
```

其中 $`A\in\mathbb{R}^{n\times n}`$ 、 $`B\in\mathbb{R}^{n\times m}`$ 、 $`C\in\mathbb{R}^{p\times n}`$ 。若采用状态反馈 $`\delta u=-K_x\delta x+K_r\delta r`$ ，闭环状态矩阵为 $`A-BK_x`$ 。负反馈能否稳定系统，取决于 $`(A,B)`$ 的可稳定性、估计误差动态、采样与延迟，而不是取决于控制律中是否写了一个负号。若某个不稳定模态不受执行器影响，任何该输入通道上的反馈都无法稳定它。

在仓储机器人中，电机电流环通过测得电流修正电压，速度环根据编码器速度修正期望力矩，底盘位姿环再根据定位结果修正速度命令。内环通常比外环快，从而使外环能把内环近似为一个响应较快的受控接口。六轴机械臂也可采用电流—速度—位置级联结构，但关节之间存在惯性和重力耦合，单关节负反馈只是一定工作范围内的近似；高速运动或重载抓取时，需要显式考虑耦合动力学。

提高增益通常能在低频减小误差，却也会放大高频测量噪声、激励结构柔性，并加剧饱和。若轮速命令超过地面附着极限，底盘打滑会改变实际对象；若机械臂力矩饱和，积分器继续累积则可能产生严重超调。因此负反馈的适用前提包括正确的反馈方向、足够的控制权、可接受的观测质量和延迟，以及对饱和、速率限制和模式切换的处理。它是一种闭环机制，而不是脱离对象动态后仍然有效的通用配方。

<a id="ch25-sec5"></a>
## 25.5 Tracking 与 Regulation

调节（regulation）要求系统在扰动和初始偏差存在时回到固定工作点，通常令 $`r(t)=r_0`$ ；跟踪（tracking）则要求输出随时间变化的参考 $`r(t)`$ 。二者可由同一误差 $`e=r-y`$ 描述，但对控制器的能力要求不同。底盘停靠充电桩后维持位姿、机械臂托住纸箱抵抗重力属于调节；底盘沿通道轨迹行驶、末端执行器随传送带上的箱体运动属于跟踪。

对线性系统

```math
\dot x=Ax+Bu,\qquad y=Cx,
```

固定参考的平衡点需满足

```math
0=Ax_{\mathrm{ss}}+Bu_{\mathrm{ss}},\qquad
r_0=Cx_{\mathrm{ss}}.
```

若这些方程无解，则该参考在当前执行器和结构下不可调节。例如非完整约束底盘不能在保持任意固定航向的同时产生横向静态速度；欠驱动无人机也不能独立指定任意姿态和三维加速度。即使方程有解，输入限幅也可能使平衡点在物理上不可达。控制器设计前应先检查可达性、稳态输入和安全约束。

跟踪变化参考时，系统不仅要消除当前误差，还要产生参考运动所需的速度、加速度和力。若只使用位置比例反馈，机械臂必须先产生位置误差才会生成维持载荷的力矩；对匀速或加速轨迹还可能存在持续滞后。积分作用可以消除某些恒定扰动下的稳态误差，前馈则可直接提供名义运动所需输入。更一般地，若希望对某一类参考实现零稳态误差，控制器需包含与该信号生成机制相匹配的内部模型：积分器对应常值信号，更高阶结构可对应斜坡或周期信号。

跟踪性能总是有频率和工作域边界。低速底盘可以精确跟随曲率平缓的路径，但过快变化的航向参考会受到轮胎附着、驱动器带宽和定位延迟限制；机械臂也不能在有限力矩下跟踪任意高频关节轨迹。参考整形、轨迹重新定时和约束控制往往比单纯提高增益更有效。工程上应分别报告调节时的恢复时间与稳态误差，以及跟踪时的相位滞后、峰值误差和输入裕度，避免用一个“跟踪精度”掩盖不同机制。

## 25.6 Disturbance Rejection

扰动抑制（disturbance rejection）是闭环系统降低外部或内部未知作用对受控输出影响的能力。扰动应按进入位置区分。在线性模型中可写为

```math
\dot x=Ax+Bu+Ew,\qquad
y=Cx+Du+v,
```

其中 $`w\in\mathbb{R}^{n_w}`$ 是过程扰动， $`E\in\mathbb{R}^{n\times n_w}`$ 描述其作用方向， $`v\in\mathbb{R}^{p}`$ 是测量噪声。还可以把执行器侧扰动写成对象实际接收 $`u+d_u`$ 。仓储底盘受到的地面坡度、轮胎摩擦变化和碰撞推力属于过程或输入扰动；机械臂抓取未知质量纸箱所增加的重力与惯性属于负载扰动；相机像素噪声和 IMU 高频噪声则属于测量噪声。

反馈抑制扰动的基本原因是：扰动使输出偏离参考，误差触发控制器产生反向修正。对低频恒定坡度，底盘速度环可增加轮端力矩以恢复速度；机械臂位置环可增加关节力矩以抵抗未知载荷。若控制器含积分状态

```math
\dot z=e,\qquad u=K_pe+K_iz,
```

则在闭环稳定、扰动为常值且不存在持续饱和等条件下，积分项可逐步生成抵消扰动的稳态输入。 $`z`$ 的维数通常与被积分的误差通道数一致。积分并不自动解决所有问题：输入饱和时需要抗积分饱和机制，测量偏置会被积分器误认为真实误差，而时变扰动可能超过积分环节的跟踪带宽。

扰动可抑制程度还受其方向与频率限制。若机械臂某方向上缺少足够力矩或接近奇异位形，反馈无法抵消该方向的外力；若底盘在低摩擦地面上已达到附着极限，继续增加电机电流只会加剧打滑。高频扰动可能位于执行器与采样带宽之外，柔性结构共振附近的高增益还会放大振动。对可测扰动，如称重传感器估计出的箱体质量或 IMU 测得的坡度，可采用扰动前馈；对不可直接测量但动态结构已知的扰动，可结合扰动观测器或状态扩张方法。

扰动抑制也不能与测量噪声抑制混为一谈。增强低频反馈通常有利于抵抗慢变载荷，却可能使控制输入更敏感于高频传感噪声。因此工程设计需要明确扰动谱、噪声谱、执行器能力和任务容差，而不是笼统追求“更强鲁棒性”。仓储场景中可按地面接缝、坡度变化、碰撞、载荷不确定性和定位跳变分别测试，因为它们进入系统的位置和所需对策并不相同。

<a id="ch25-sec7"></a>
## 25.7 Sensitivity

灵敏度（sensitivity）刻画闭环输出对对象变化、扰动或参考变化的响应程度。考虑单位负反馈系统，对象传递函数为 $`P(s)`$ ，控制器为 $`C(s)`$ ，开环环路传递函数定义为

```math
L(s)=P(s)C(s).
```

标量情形下，灵敏度函数和互补灵敏度函数分别为

```math
S(s)=\frac{1}{1+L(s)},\qquad
T(s)=\frac{L(s)}{1+L(s)},\qquad
S(s)+T(s)=1.
```

这里 $`s`$ 是拉普拉斯变量，公式建立在线性时不变模型、零初始条件和闭环良定义的假设上。 $`S`$ 常描述输出侧扰动或模型相对变化的影响， $`T`$ 常描述参考到输出的闭环响应以及某些测量噪声通道的影响。

若对象发生小的乘性变化 $`P\mapsto P+\delta P`$ ，在标量且扰动足够小时，有近似关系

```math
\frac{\delta T}{T}\approx S\,\frac{\delta P}{P}.
```

因此在 $`|L|\gg1`$ 的频段， $`|S|\ll1`$ ，闭环对对象参数变化不敏感。这解释了为什么同一底盘速度控制器能够容忍一定范围的纸箱载荷和电池电压变化，也解释了反馈为何能降低机械臂惯量建模误差的影响。但该结论只适用于闭环稳定、变化较小并且不改变系统结构的范围；轮胎从纯滚动转为严重打滑、夹爪从自由运动切换到刚性接触，都可能属于模型模式变化，不能仅靠局部灵敏度公式概括。

由于 $`S+T=1`$ ，无法在所有频率同时让二者都很小。控制通常希望低频 $`S`$ 小，以保证跟踪和慢扰动抑制；高频则希望 $`T`$ 小，以减少测量噪声和未建模快速动态的影响。这自然形成有限闭环带宽。相机定位更新较慢且有延迟，适合参与底盘低频位姿修正；编码器和 IMU 更新较快，可承担更高频的速度与姿态反馈。若强行让视觉环获得过高带宽，延迟带来的相位损失会破坏稳定裕度。

对多输入多输出系统， $`P,C,L,S,T`$ 都是矩阵，并有

```math
S(s)=\bigl(I+L(s)\bigr)^{-1},\qquad
T(s)=L(s)\bigl(I+L(s)\bigr)^{-1},
```

其中单位矩阵维数与反馈输出通道一致；矩阵乘法次序不可随意交换。工程上常考察最大奇异值 $`\bar\sigma(S(j\omega))`$ 和 $`\bar\sigma(T(j\omega))`$ ，以识别最不利输入方向。六轴机械臂在不同位形下耦合和条件数会显著变化，因此单通道增益曲线可能隐藏危险方向。灵敏度分析提供的是频域局部指标，仍需结合非线性工作域、饱和、采样和接触切换验证。

<a id="ch25-sec8"></a>
## 25.8 Feedforward

前馈（feedforward）根据参考、参考导数或可测扰动直接计算控制输入，不等待输出产生误差。其一般形式为

```math
u_{\mathrm{ff}}(t)=\Phi\bigl(r(t),\dot r(t),\ddot r(t),\hat d(t)\bigr),
```

其中 $`\Phi`$ 可以是静态增益、逆模型、优化器或学习模型， $`\hat d`$ 是可用的扰动估计。若静态对象满足 $`y=Pu`$ 且 $`P`$ 可逆，可取 $`u_{\mathrm{ff}}=P^{-1}r`$ ；对动态系统，前馈实质上试图求解“什么输入能产生所需轨迹”。它利用模型的预测能力，因而可在误差出现之前施加动作。

机械臂动力学是前馈最典型的例子：

```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f(q,\dot q)=\tau+\tau_{\mathrm{ext}},
```

其中 $`q,\dot q,\ddot q\in\mathbb{R}^6`$ ， $`M(q)\in\mathbb{R}^{6\times6}`$ 是正定惯性矩阵， $`C\dot q`$ 表示科氏与离心项， $`g\in\mathbb{R}^6`$ 是重力项， $`\tau_f`$ 是摩擦， $`\tau_{\mathrm{ext}}`$ 是外部作用。对规划轨迹 $`(q^\star,\dot q^\star,\ddot q^\star)`$ ，可用名义模型计算

```math
\tau_{\mathrm{ff}}
=\hat M(q^\star)\ddot q^\star
+\hat C(q^\star,\dot q^\star)\dot q^\star
+\hat g(q^\star)
+\hat\tau_f(q^\star,\dot q^\star).
```

重力补偿是令速度、加速度项为零后的特殊情况。抓取较重纸箱时，前馈可提前提供维持和加速载荷所需的力矩，从而减少必须由位置误差“换取”的控制作用。

移动底盘也可使用前馈。给定参考线速度 $`v^\star`$ 、角速度 $`\omega^\star`$ 及其导数，可通过运动学映射得到左右轮速，再利用电机反电动势、滚动阻力和名义质量模型计算电压或力矩。若 IMU 或地图已知通道坡度，还可增加坡度补偿。与反馈不同，前馈不会依据执行后的实际偏差自动修正，因此模型参数、初始状态和扰动估计的误差会直接留下残差。

动态逆并非总能安全实现。对象可能非最小相位、具有纯延迟、欠驱动、存在冗余或接近奇异；精确求逆还可能要求非因果信号或无限高频输入。机械臂雅可比接近奇异时，任务空间加速度的逆映射会产生巨大关节速度；底盘非完整约束也禁止任意瞬时横向运动。因此前馈应基于可行轨迹、正则化逆或受约束优化构造，并明确输入幅值、速率和模型有效域。它适合承担“已知且可预测”的主要作用，而不应被当作消除所有不确定性的手段。

<a id="ch25-sec9"></a>
## 25.9 模型前馈 + 反馈修正

高性能控制常采用两自由度结构：前馈负责实现名义运动，反馈负责修正实际系统相对名义模型的偏差。控制输入写为

```math
u=u_{\mathrm{ff}}+u_{\mathrm{fb}},\qquad
u_{\mathrm{fb}}=\mathcal{K}(e,\dot e,\hat x),
```

其中 $`u_{\mathrm{ff}}`$ 来自参考和模型， $`u_{\mathrm{fb}}`$ 来自测量或估计误差。两部分不是简单“各做一半”，而是在不同信息通道上分工：参考变化尚未造成误差时，只有前馈能提前作用；模型误差和未知扰动造成偏离后，反馈才根据实际结果修正。

对六轴机械臂，可采用计算力矩形式

```math
\tau=
\hat M(q)\left[\ddot q^\star+K_d(\dot q^\star-\dot q)+K_p(q^\star-q)\right]
+\hat C(q,\dot q)\dot q+\hat g(q),
```

其中 $`K_p,K_d\in\mathbb{R}^{6\times6}`$ 通常取正定矩阵。若名义模型准确且暂不考虑摩擦、扰动与饱和，误差动力学近似为

```math
\ddot e+K_d\dot e+K_pe=0.
```

这表明模型项试图抵消主要非线性，反馈项塑造残余误差动态。但该推导依赖 $`M(q)`$ 可逆、状态可测、模型误差较小且力矩未饱和；真实系统中还要考虑关节柔性、减速器间隙、离散采样和接触力。模型补偿过度时也可能放大参数误差，因此通常需要限幅、滤波和鲁棒性验证。

仓储移动操作机器人可以在多个层级复用这一结构。轨迹优化器给出底盘和机械臂的名义状态—输入序列，作为前馈；视觉、IMU 和编码器估计出的位姿误差进入反馈。底盘转弯时，前馈按曲率提前产生左右轮速差，反馈再修正轮径误差和局部打滑；机械臂取箱时，逆动力学预先提供重力及加速力矩，关节反馈修正纸箱质量不确定性。前馈还可减小反馈所需增益，从而降低噪声注入和结构振动风险。

两部分最终都要通过同一执行器，因此必须统一处理约束。若 $`\|u_{\mathrm{ff}}+u_{\mathrm{fb}}\|`$ 超过电机电流上限，不能假设反馈修正仍可完整实现。常见策略包括给反馈预留输入裕度、按任务优先级分配力矩、降低参考加速度，以及触发重新定时或重新规划。前馈模型和反馈控制器也应使用一致的坐标系、符号和时间戳；一个延迟的“正确前馈”可能比无前馈更差。该结构有效的边界是：名义模型能解释主要动态，反馈拥有足够剩余控制权，并且闭环稳定性在预期不确定性范围内成立。

<a id="ch25-sec10"></a>
## 25.10 为什么模型不需要完美

控制模型的任务不是逐原子复制真实机器人，而是保留与目标、时间尺度和稳定性有关的结构。设真实对象为名义模型与误差之和：

```math
P_{\mathrm{real}}(s)=P_0(s)+\Delta P(s),
```

或在非线性状态空间中写为

```math
\dot x=f_0(x,u)+\Delta f(x,u,d).
```

前馈和规划器使用 $`P_0`$ 或 $`f_0`$ 预测主要运动，反馈通过实际测量对 $`\Delta P`$ 、 $`\Delta f`$ 造成的可观测偏差进行修正。因此，模型只要在目标频段和工作域内足够准确，并保留惯性、延迟、输入方向、主要耦合及约束等关键性质，就可能支持良好控制。

以六轴机械臂为例，名义模型可准确描述连杆惯性和重力，却只粗略描述关节摩擦与纸箱质量。重力及惯性前馈已经消除了大部分可预测负担，反馈则补偿剩余力矩误差。对移动底盘，差速运动学模型忽略小幅轮胎变形仍可用于低速通道跟踪，定位反馈会修正累计偏差。这样的简化成立于低速、附着良好、侧滑有限的范围；在湿滑地面高速转弯时，侧向轮胎动力学成为主导因素，原模型不再只是“略有误差”，而是遗漏了决定性机制。

模型不完美不等于模型可以错误。控制输入方向、相对阶次、不稳定模态、显著延迟和非最小相位零点若建模错误，反馈设计可能从根本上失效。被忽略动态若位于闭环带宽以内，也不能简单交给反馈处理。例如柔性机械臂的结构模态位于高增益频段时，刚体模型控制器可能激励共振；视觉处理延迟若接近底盘位姿环的特征时间，忽略它会显著降低相位裕度。模型简化必须根据频率、工况和任务风险进行，而不是根据方程是否方便。

可用一个残差观点理解模型精度要求。若名义前馈产生 $`u_{\mathrm{ff}}`$ 后，剩余等效扰动为 $`d_{\mathrm{res}}`$ ，则反馈只需在其带宽和输入裕度允许的范围内抑制 $`d_{\mathrm{res}}`$ 。模型越好，残差通常越小，系统可以使用更低反馈增益；模型较粗时，则需要更大的反馈权限和更保守的参考。若残差导致执行器持续饱和、状态离开估计器有效域或触发接触模式变化，反馈就无法维持原有保证。因而“模型不需要完美”的准确含义是：模型误差必须落在闭环鲁棒性能够覆盖的集合中。

工程上应通过辨识、仿真和实机试验逐步确定这一集合。仓储机器人可在空载、典型载荷和最大许可载荷下测试；对底盘改变地面摩擦和电池电量，对机械臂改变姿态和速度，对相机与 IMU 注入延迟、丢帧和偏置。若性能不足，应判断问题来自名义模型、估计、反馈带宽、执行器约束还是参考不可行，而不是盲目增加模型复杂度。模型复杂度只有在能改善预测、稳定裕度、约束处理或故障诊断时才具有工程价值。

<a id="ch25-sec11"></a>
## 25.11 闭环传递函数

闭环传递函数把参考、扰动和噪声到输出或控制输入的关系显式写出，是分析跟踪、扰动抑制和噪声放大的统一工具。考虑线性时不变、零初始条件下的单位负反馈系统：

```math
u(s)=C(s)\bigl(r(s)-y_m(s)\bigr),\qquad
y_m(s)=y(s)+n(s),
```

```math
y(s)=P(s)\bigl(u(s)+d_i(s)\bigr)+d_o(s),
```

其中 $`P`$ 是对象， $`C`$ 是控制器， $`d_i`$ 是输入侧扰动， $`d_o`$ 是输出侧扰动， $`n`$ 是测量噪声。标量系统中令 $`L=PC`$ 、 $`S=(1+L)^{-1}`$ 、 $`T=L(1+L)^{-1}`$ ，整理可得

```math
y
=Tr+PS\,d_i+S\,d_o-Tn.
```

该式清楚表明：参考通过 $`T`$ 到达输出；输出侧扰动受 $`S`$ 抑制；输入侧扰动还要经过对象 $`P`$ ；测量噪声则通过 $`-T`$ 进入输出。若只说“高增益减小误差”，就遗漏了高频噪声通道和对象动态对输入扰动的影响。

控制输入同样需要分析。由上述关系可得

```math
u
=CS\,r-CS\,d_o-CS\,n-T\,d_i.
```

即使输出误差很小，控制输入也可能很大。仓储底盘在视觉定位噪声下若出现快速轮速抖动，输出轨迹短时间内可能仍然平滑，但电机电流、轮胎磨损和能耗已经恶化；机械臂也可能以高频关节力矩维持表面上的低位置误差。因此闭环设计不能只考察 $`r\to y`$ ，还应检查 $`r,d,n\to u`$ 的峰值、频谱及饱和风险。

若加入参考前馈滤波器 $`F(s)`$ ，采用

```math
u=C(r-y)+F r,
```

则参考到输出的传递函数变为

```math
\frac{y}{r}=\frac{P(C+F)}{1+PC},
```

而由反馈环决定的特征方程仍为 $`1+PC=0`$ 。这体现了两自由度设计：在不改变主要反馈稳定机制的前提下， $`F`$ 可改善名义参考响应。但若前馈导致输入饱和，真实系统会变为非线性，以上分离不再严格成立；若 $`F`$ 包含不稳定或非因果的对象逆，也不能直接实现。

对多输入多输出系统，需保留矩阵顺序。若 $`u=C(r-y)`$ 、 $`y=Pu`$ ，则

```math
y=(I+PC)^{-1}PC\,r,
```

而从误差到控制输入的相关表达式可能包含 $`(I+CP)^{-1}`$ 。虽然在维数相容时存在恒等关系，但不能把 $`PC`$ 与 $`CP`$ 当作可交换标量。六轴机械臂的关节耦合、移动底盘与机械臂协同引起的基座反作用，都要求关注通道方向、奇异值和内部状态，而不能只逐元素查看传递函数。

最后，闭环传递函数存在且外部输入输出有界，并不自动等价于所有内部状态稳定。控制器与对象之间可能发生不稳定极零相消，使某个输入输出通道看似正常，而内部状态持续增长。真正的闭环分析应检查内部稳定性、因果性、适定性以及不确定性下的稳定裕度；对采样控制还应使用离散域变量 $`z`$ 并显式考虑保持器、计算延迟和多速率接口。下一章将在这些闭环关系之上研究极点、时间响应、频率响应和经典稳定性指标，把“反馈如何连接”进一步落实为“闭环动态究竟如何变化”。

## 本章小结

本章以状态空间对象、估计输出和任务参考为接口，建立了输入输出控制的基本语言。开环依靠预先计算的输入，闭环则利用测量或估计结果持续修正；参考必须具有明确的空间、单位、时间参数与可行性，误差定义必须尊重欧氏空间、角度周期性和 $`SE(2)`$ 、 $`SE(3)`$ 的几何结构。负反馈能够降低偏差，却只有在反馈方向、控制权、观测质量、延迟和饱和均得到妥善处理时才可能稳定有效。

调节关注固定工作点，跟踪关注时变参考，扰动抑制则关注未知作用到输出的传播。灵敏度函数 $`S`$ 与互补灵敏度函数 $`T`$ 揭示了低频跟踪、扰动抑制、高频噪声和未建模动态之间不可消除的权衡。前馈利用模型提前生成名义输入，反馈修正模型误差和未知扰动；仓储移动操作机器人的底盘、六轴机械臂和电机内环都可采用这种分工，但必须统一处理坐标、时间尺度和执行器约束。

模型不必覆盖所有物理细节，却必须在目标工作域和频段中保留主导动态、输入方向、延迟、耦合与约束。闭环传递函数进一步把参考、输入扰动、输出扰动和测量噪声映射到输出及控制输入，为定量分析提供了统一结构。下一章将从这些结构出发，研究闭环极点、瞬态响应、频率特性和稳定裕度，从而把反馈机制转化为可计算、可验证的动态性能结论。
