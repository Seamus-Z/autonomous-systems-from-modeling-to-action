## 29.1 为什么反馈不应该做所有工作

反馈控制根据误差采取行动。若参考状态为 $`x_d`$ 、估计状态为 $`\hat x`$ ，最基本的状态反馈可写成 $`u_{\mathrm{fb}}=K(x_d-\hat x)`$ 。这种结构具有纠正未知扰动和模型偏差的能力，却必须先“看见误差”才能产生作用。当机器人承受已知重力、按照已知加速度运动，或搬运质量大致已知的货箱时，若仍让反馈承担全部控制量，就意味着系统必须以持续的位置偏差、速度偏差或积分累积来换取所需力矩。提高增益虽然能减小误差，却会同时放大相机、编码器和 IMU 的估计噪声，增加电机饱和、结构振动、接触冲击以及离散采样不稳定的风险。

对具有 $`n`$ 个广义坐标的刚性机器人，常用动力学模型为
```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+f(\dot q)=S^\top\tau+J_c(q)^\top\lambda ,
```
其中 $`q,\dot q,\ddot q\in\mathbb R^n`$ ， $`M(q)\in\mathbb R^{n\times n}`$ 是正定质量矩阵， $`C\dot q`$ 表示科氏与离心项， $`g\in\mathbb R^n`$ 是重力广义力， $`f`$ 是摩擦等非保守项； $`\tau\in\mathbb R^m`$ 为 $`m`$ 个执行器的输入， $`S\in\mathbb R^{m\times n}`$ 是驱动选择矩阵， $`J_c^\top\lambda`$ 是接触力产生的广义力。固定基座六轴机械臂通常有 $`m=n=6`$ 、 $`S=I`$ ；移动操作机器人的底盘可能受非完整约束，浮动基四足机器人则通常有 $`m<n`$ 。因此，“给每个自由度配置一个独立高增益控制器”只在充分驱动、耦合较弱且工作范围有限时才近似成立。

模型前馈的基本分工是
```math
\tau=\tau_{\mathrm{ff}}+\tau_{\mathrm{fb}},
```
其中 $`\tau_{\mathrm{ff}}`$ 预测实现期望运动本来需要的力矩， $`\tau_{\mathrm{fb}}`$ 修正初始误差、建模误差和外部扰动。仓储移动操作机器人在伸臂取箱时，可由模型预先补偿臂重、夹具和额定载荷，由反馈处理货箱质量偏差与底盘微振；底盘沿直线加速时，也可前馈近似的轮端惯性力和滚阻，再由轮速闭环抑制地面变化。这样做不是用模型替代反馈，而是避免把可预测部分变成误差之后再处理。

这一思想依赖若干边界：状态估计与参考轨迹必须在同一时间基准和坐标系中；轨迹至少具有模型所需的可微阶数；执行器应有足够带宽和力矩裕量；接触模式不能与模型假设冲突。模型错误过大时，前馈可能比零前馈更差，因此工程上要设置力矩、功率、速度和变化率限制，并保留反馈与安全监控。反馈负责鲁棒性，模型负责结构化预测，二者的权衡贯穿本章。

## 29.2 重力补偿

重力补偿是最简单也最常用的模型前馈。对静止或低速机械臂，忽略惯性、速度项和摩擦后有
```math
\tau_g(q)=g(q).
```
若采用电机侧命令，还需根据减速比和传动效率映射力矩。例如对关节力矩 $`\tau_g`$ 、对角减速比矩阵 $`N`$ 和近似效率矩阵 $`\eta`$ ，电机力矩可按具体传动约定写成 $`\tau_m\approx (N^\top)^{-1}\eta^{-1}\tau_g`$ 。这里必须核对控制器接口究竟接收电机电流、电机轴力矩还是减速器输出力矩；单位或方向约定错误会使“补偿”变成重力放大。

机械臂重力项可由势能 $`V(q)`$ 求得：
```math
g(q)=\frac{\partial V(q)}{\partial q},\qquad
V(q)=\sum_{i=1}^{N_b}m_i\,g_0^\top p_{c_i}(q),
```
其中 $`N_b`$ 为刚体数量， $`m_i`$ 是第 $`i`$ 个连杆质量， $`p_{c_i}\in\mathbb R^3`$ 是其质心在世界坐标系中的位置， $`g_0\in\mathbb R^3`$ 为重力加速度向量。仓储机械臂夹起货箱后，应把货箱视为末端附加刚体；若载荷质量为 $`m_L`$ 、末端到载荷质心的雅可比为 $`J_{v,L}\in\mathbb R^{3\times n}`$ ，其重力贡献可写成
```math
\tau_{g,L}=J_{v,L}(q)^\top m_L g_0.
```
这也说明，载荷质心偏差可能同时引入关节力矩偏差，尤其在机械臂水平伸展时最明显。

重力补偿常与低增益位置反馈组合：
```math
\tau=g(\hat q)+K_p(q_d-\hat q)-K_d\hat{\dot q},
```
其中 $`K_p,K_d\in\mathbb R^{n\times n}`$ 通常取正定对角矩阵。静止参考下，准确的 $`g(\hat q)`$ 提供主要支撑力矩，反馈只需形成期望刚度与阻尼。相较仅用 PD，这能显著降低稳态下垂，并避免依赖积分项长期积累。实际系统中，关节编码器给出 $`q`$ ，底盘或安装面的姿态则可能来自 IMU；若机械臂基座因坡面倾斜，必须先把世界重力方向变换到模型基坐标系，否则计算出的 $`g(q)`$ 会带有系统偏差。

重力补偿并不补偿加速运动、摩擦、线缆拖曳和接触力，也不保证机械臂可以安全“失重”拖动。模型中的质量、质心和零位偏差会形成残余力矩，静摩擦还会造成滞回。工程上通常对载荷类别进行参数标定，对低速段加入平滑摩擦补偿，并限制补偿比例；在人机共域或碰撞风险较高时，不能仅凭低位置误差判断安全，还需监测关节力矩、电机电流、末端力和动能。

## 29.3 逆动力学前馈

当期望轨迹包含明显速度和加速度时，重力补偿可推广为逆动力学前馈。对充分驱动、无显式接触的机器人，给定期望轨迹 $`(q_d,\dot q_d,\ddot q_d)`$ ，名义前馈为
```math
\tau_{\mathrm{ff}}
=M(q_d)\ddot q_d+C(q_d,\dot q_d)\dot q_d+g(q_d)+f(\dot q_d).
```
右侧各项维度均为 $`\mathbb R^n`$ 。它回答的是“若系统恰好处于期望轨迹上，实现期望加速度需要多大力矩”，而不负责把偏离轨迹的实际状态拉回。因此开环逆动力学通常与反馈共同使用，而不是单独执行。

在仓储机器人取放流程中，轨迹规划器应输出时间一致的 $`q_d,\dot q_d,\ddot q_d`$ 。若只给离散位置点，再通过差分获得速度和加速度，高频量化噪声会直接进入力矩命令；更稳妥的方法是使用满足速度、加速度和跃度约束的样条或时间参数化轨迹。六轴机械臂快速抬升货箱时， $`M\ddot q_d`$ 体现连杆与载荷惯性， $`C\dot q_d`$ 体现关节耦合， $`g`$ 提供静态支撑。对移动底盘，类似思想可用于由期望纵向加速度计算轮端驱动力，但轮胎打滑、地面坡度和非完整约束必须在底盘模型中显式处理。

实际实现常采用“期望量与实测量混合”的形式：
```math
\tau_{\mathrm{ff}}
=M(\hat q)\ddot q_d+C(\hat q,\hat{\dot q})\dot q_d+g(\hat q)+\hat f(\dot q_d).
```
用 $`\hat q`$ 计算当前构型下的质量矩阵和重力项，可以减少轨迹误差导致的模型失配；但不同软件库对 $`C(q,\dot q)\dot q`$ 的定义、符号和速度参数约定并不完全相同，不能机械拼接。递归牛顿—欧拉算法能够以与刚体数量近似线性相关的计算量直接求取逆动力学力矩，适合高频控制；显式构造全部矩阵则更便于分析和多任务优化。

逆动力学前馈成立的关键假设包括刚体模型可用、驱动充分、接触模式已知以及力矩能被执行器近似实现。齿隙、柔性、温度相关摩擦和电流环动态通常未被刚体模型覆盖；不确定接触下，直接施加自由空间逆动力学可能产生冲击。所有前馈命令都应经过力矩与力矩变化率约束，并进行反饱和处理。若某关节饱和，整条轨迹的动力学一致性已被破坏，此时仅裁剪单个力矩往往不够，还应降低轨迹速度或重新进行时间参数化。

## 29.4 Computed Torque Control

Computed Torque Control，通常译为计算力矩控制，把逆动力学与误差反馈组合起来。对充分驱动机械臂，定义关节误差
```math
e=q_d-q,\qquad \dot e=\dot q_d-\dot q,
```
并构造虚拟加速度
```math
v=\ddot q_d+K_d\dot e+K_p e.
```
控制律为
```math
\tau=M(q)v+C(q,\dot q)\dot q+g(q),
```
其中 $`K_p,K_d\in\mathbb R^{n\times n}`$ 为正定增益矩阵。若模型精确、状态可测且没有饱和，把该控制律代入动力学后得到
```math
\ddot e+K_d\dot e+K_p e=0.
```
原本非线性且耦合的机械臂误差动力学因而变成设计者指定的线性二阶系统。

当增益取对角形式时，第 $`i`$ 个关节可按期望自然频率 $`\omega_{n,i}`$ 和阻尼比 $`\zeta_i`$ 选择
```math
K_{p,i}=\omega_{n,i}^2,\qquad
K_{d,i}=2\zeta_i\omega_{n,i}.
```
这里的 $`K_p`$ 、 $`K_d`$ 位于“加速度层”，量纲分别为 $`\mathrm{s}^{-2}`$ 和 $`\mathrm{s}^{-1}`$ ，与直接力矩 PD 中的刚度、阻尼量纲不同。仓储六轴机械臂在搬运货箱时，可根据最柔弱关节、减速器允许力矩和载荷变化选择带宽；高带宽并不自动带来高精度，因为未建模柔性、编码器滤波延迟和内层电流环会限制可实现的闭环频率。

模型不精确时，实际误差方程包含扰动。以 $`\hat M,\hat C,\hat g`$ 表示控制器模型，可概括为
```math
\ddot e+K_d\dot e+K_p e=d(q,\dot q,t),
```
其中 $`d`$ 汇集参数误差、摩擦、外力和执行误差。稳定的名义误差系统会对有界扰动呈现有界响应，但这并不等价于任意模型误差下都稳定。质量矩阵估计必须保持正定，速度估计需要适度滤波，积分补偿若用于消除恒定偏差，则必须配置反积分饱和。

计算力矩尤其适合固定基、充分驱动、自由空间运动且动力学参数较可信的机械臂。对差速底盘、无人机平移方向或浮动基四足机器人，输入不能直接指定全部广义加速度，不能照搬 $`M^{-1}`$ 抵消全部动力学；它们还要满足非完整约束、推力方向约束或接触约束。此时应在可控子空间内进行动态补偿，或通过约束优化求解可实现的力矩与接触力。

## 29.5 Feedback Linearization

反馈线性化是计算力矩控制的更一般形式。考虑控制仿射非线性系统
```math
\dot x=f(x)+G(x)u,\qquad y=h(x),
```
其中 $`x\in\mathbb R^n`$ 、 $`u\in\mathbb R^m`$ 、 $`y\in\mathbb R^p`$ 。若对输出连续求导，直到输入显式出现，可得到
```math
y^{(r)}=b(x)+A(x)u,
```
其中 $`r`$ 是标量输出的相对阶；多输出系统对应相对阶向量， $`A(x)`$ 为解耦矩阵。当 $`A(x)`$ 在工作区域内方阵且可逆时，选择
```math
u=A(x)^{-1}\bigl(v-b(x)\bigr)
```
即可使输入—输出关系成为 $`y^{(r)}=v`$ ，再利用线性反馈选择 $`v`$ 。计算力矩控制正是机械系统以 $`q`$ 为输出、相对阶为二时的反馈线性化。

“抵消非线性”只是一种局部结构结论。首先， $`A(x)`$ 可能在奇异构型退化，例如机械臂任务输出的雅可比失去秩；其次，若所有输出相对阶之和小于状态维数，系统还存在未直接线性化的内部动态。令输出及其导数保持为零后得到的动态称为零动态，只有当它稳定时，输入—输出线性化才不会以隐藏状态发散为代价换取输出跟踪。移动机器人侧向位置、无人机位置与姿态之间的耦合都体现了这一边界：输出选得不当，可能要求系统产生不可实现的瞬时侧向力或姿态。

仓储差速底盘的运动学可写成
```math
\dot x_b=v\cos\theta,\qquad
\dot y_b=v\sin\theta,\qquad
\dot\theta=\omega ,
```
输入为 $`u=[v,\omega]^\top`$ 。若直接把 $`(x_b,y_b)`$ 作为输出，其瞬时输入映射只有沿车体前向的平移能力，无法像全向质点那样独立指定二维速度。工程上可跟踪位于车体前方的虚拟点，或采用满足非完整结构的轨迹控制器，而不是强行对底盘质心位置做全线性化。类似地，六轴机械臂在腕部奇异位形附近不能可靠地把任意六维末端速度映射为有限关节速度。

反馈线性化依赖光滑、足够准确的模型以及可靠的状态估计，并会把模型误差直接带入补偿通道。它适合结构清晰、工作区域避开奇异点、执行器带宽足够的系统；不适用于未经处理的输入饱和、开关接触和强未建模动态。工程实现应检查解耦矩阵条件数，采用阻尼逆或任务降级策略，并让安全约束优先于精确抵消。

## 29.6 关节空间控制

关节空间控制以 $`q_d(t)\in\mathbb R^n`$ 为参考，直接调节每个关节的位置、速度或力矩。最常见的力矩级结构为
```math
\tau=\tau_{\mathrm{ff}}
+K_p(q_d-\hat q)
+K_d(\dot q_d-\hat{\dot q})
+K_i z,
\qquad
\dot z=q_d-\hat q ,
```
其中 $`K_p,K_d,K_i\in\mathbb R^{n\times n}`$ 。前馈可选为重力补偿或完整逆动力学；比例项形成恢复力矩，微分项提供阻尼，积分项补偿缓慢的恒值偏差。积分并非总是需要，尤其在接触、饱和或模式切换时，积累的 $`z`$ 可能导致突然的大力矩，因而必须限幅、泄漏或反算回退。

真实机械臂通常采用级联架构：外层轨迹或位置环输出期望速度、力矩，内层电流环驱动电机。若电机电流为 $`i\in\mathbb R^n`$ 、力矩常数矩阵为 $`K_t`$ ，则电机力矩近似为 $`\tau_m=K_t i`$ ；减速器再把它映射到关节侧。模型前馈必须与内层接口匹配，不能在位置命令接口上假定能够瞬时施加关节力矩。速度估计 $`\hat{\dot q}`$ 常由编码器差分与低通滤波获得，滤波会引入相位滞后，因此微分增益和截止频率应联合设计，而不能单独追求平滑。

关节空间的优势是参考和约束清晰，容易施加关节角、速度、加速度和力矩限制，也便于利用第 28 章的局部状态空间分析。在平衡点附近令状态误差为 $`\delta x=[\delta q^\top,\delta\dot q^\top]^\top`$ ，可线性化为
```math
\delta\dot x=A\delta x+B\delta\tau .
```
关节 PD、极点配置或状态反馈都可在这一接口上设计。仓储机械臂执行已离线规划且避障完成的取放轨迹时，关节空间控制通常稳定、计算量小；移动底盘的轮速环也可视为电机或车轮关节空间控制，由上层底盘控制器生成左右轮参考。

它的局限是任务误差被间接处理。相同的关节误差在不同构型下可能对应截然不同的末端位置误差；对冗余机械臂，给定末端任务并不唯一决定 $`q_d`$ ；接触操作关心的通常是笛卡尔方向上的力与柔顺性，而不是每个关节独立的刚度。因此关节空间控制适合作为可靠的内层执行接口，但上层仍需通过运动学、优化或任务空间控制生成一致参考。高齿比、强摩擦机械臂的关节力矩命令也不等于末端实际力，必要时应结合电流、关节力矩传感器和末端六维力传感器进行估计。

## 29.7 Jacobian Transpose Control

雅可比转置控制利用虚功原理，把任务空间中的期望广义力映射到关节力矩。若末端微分运动满足
```math
\dot x=J(q)\dot q,
```
其中 $`x\in\mathbb R^p`$ 是任务坐标、 $`J\in\mathbb R^{p\times n}`$ ，则虚功一致性
```math
\tau^\top\delta q=F^\top\delta x
```
给出
```math
\tau=J(q)^\top F.
```
这里 $`F\in\mathbb R^p`$ 是与任务坐标共轭的力或力矩。对三维位置任务， $`F`$ 的单位为牛顿；对六维位姿任务，它通常是由力和力矩组成的 wrench，坐标系与排列顺序必须明确。

一个典型控制律是
```math
F_d=K_x e_x+D_x\dot e_x,\qquad
\tau=J^\top F_d+g(q),
```
其中 $`e_x=x_d-x`$ ， $`K_x,D_x\in\mathbb R^{p\times p}`$ 分别表示任务空间刚度和阻尼。仓储机械臂抓取货箱把手时，可对末端位置设置较高刚度，对接近货架法向设置较低刚度，从而减小定位误差引起的碰撞； $`J^\top F_d`$ 将这些方向性要求转成六个关节的力矩。重力补偿使任务反馈不必同时承担臂重。

对于姿态，不能在大范围内直接把欧拉角相减。若期望和当前旋转为 $`R_d,R\in SO(3)`$ ，可使用
```math
e_R=\frac{1}{2}\bigl(R_d^\top R-R^\top R_d\bigr)^\vee\in\mathbb R^3,
```
或使用对数映射定义局部旋转误差，再与角速度误差组成六维任务误差。误差向量、雅可比和 wrench 必须在同一空间坐标系或机体坐标系表达；否则 $`J^\top F`$ 虽维度正确，物理方向却不一致。接近旋转角 $`\pi`$ 时，局部姿态误差存在表示边界，控制器应避免把它当作全局无奇异坐标。

雅可比转置不需要求 $`J^{-1}`$ ，因而比直接运动学求逆更容易在非方阵情况下使用，但它并不自动消除动力学耦合，也不意味着末端闭环具有精确的 $`K_x,D_x`$ 。在奇异位形附近，某些任务方向无法产生有效运动，控制力可能转化为很大的关节内力或缓慢响应。它适合中低带宽、模型要求较低的任务吸引和柔顺控制；若要求构型无关的任务加速度或惯性整形，则需要进一步使用任务空间动力学。

<a id="ch29-sec8"></a>
## 29.8 任务空间控制

任务空间控制直接围绕机器人要完成的几何任务定义误差。设任务映射为
```math
x=\phi(q),\qquad
\dot x=J(q)\dot q,\qquad
\ddot x=J(q)\ddot q+\dot J(q,\dot q)\dot q ,
```
其中 $`x\in\mathbb R^p`$ 可以是夹爪位置、位姿、相机视线误差或多个任务量的组合。仓储机器人把货箱放入货格时，真正重要的是货箱相对货架的位姿，而非某一组特定关节角；相机估计的货架位姿和机械臂正运动学必须先通过统一的坐标变换链表达在一致参考系中。

在速度层，可令
```math
\dot q_d=J^\#\bigl(\dot x_d+K_x e_x\bigr)
+\bigl(I-J^\#J\bigr)\dot q_0 ,
```
其中 $`J^\#\in\mathbb R^{n\times p}`$ 是广义逆， $`\dot q_0`$ 是零空间参考。对满行秩 $`J`$ ，Moore–Penrose 右逆为 $`J^\#=J^\top(JJ^\top)^{-1}`$ ；靠近奇异点时常使用阻尼最小二乘
```math
J^\#_\mu=J^\top(JJ^\top+\mu^2I)^{-1},
```
其中 $`\mu>0`$ 是阻尼系数。零空间项可用于远离关节限位、改善可操作度或收拢肘部，但阻尼逆下的“零空间”只是近似的，次任务仍可能轻微扰动主任务。

在加速度层，可选择
```math
\ddot x^\star=\ddot x_d+K_d(\dot x_d-\dot x)+K_p e_x
```
并求解
```math
J\ddot q=\ddot x^\star-\dot J\dot q.
```
若同时存在关节限位、速度限幅、碰撞距离和底盘约束，更一般的做法是把 $`\ddot q`$ 或 $`\dot q`$ 作为优化变量，在满足硬约束的前提下最小化任务残差。移动操作机器人可把底盘与机械臂坐标组成统一的 $`q`$ ，从而让底盘提前移动以减少机械臂伸展；但差速底盘的非完整约束必须加入可行速度集合，不能把底盘横向速度当作独立变量。

任务空间控制主要描述运动学关系，不自动说明需要多少力矩，也不自动处理质量分布。相机测量通常存在延迟与遮挡，IMU 姿态存在偏置，任务误差因而应由估计器提供带时间戳的 $`\hat x`$ ，而不是混用不同时间的原始测量。其适用条件是任务映射可微、局部秩满足要求且参考轨迹可实现；在奇异点、任务冲突或接触模式改变时，应降低任务维数、重新排序优先级或转入力与阻抗控制。

<a id="ch29-sec9"></a>
## 29.9 Operational Space Control

Operational Space Control 通常译为操作空间控制。它不只把末端误差映射到关节，而是显式推导任务坐标中的动力学。先考虑无约束、充分驱动系统
```math
M(q)\ddot q+h(q,\dot q)=\tau,
```
其中 $`h=C\dot q+g+f`$ 。对满行秩任务雅可比 $`J\in\mathbb R^{p\times n}`$ ，定义任务空间惯量
```math
\Lambda(q)=\bigl(JM^{-1}J^\top\bigr)^{-1}\in\mathbb R^{p\times p}.
```
$`\Lambda`$ 描述机器人沿不同任务方向表现出的等效惯量：同一夹爪在水平和竖直方向、机械臂收拢和伸展构型下，等效质量通常不同。

结合 $`\ddot x=J\ddot q+\dot J\dot q`$ ，可将任务动力学整理为
```math
\Lambda(q)\ddot x+\mu(q,\dot q)+p(q)=F,
```
其中 $`\mu`$ 汇集任务空间速度相关项， $`p`$ 为任务空间重力项， $`F\in\mathbb R^p`$ 是任务 wrench。选择
```math
F=\Lambda\ddot x^\star+\mu+p,\qquad
\tau=J^\top F
```
可在模型准确时实现 $`\ddot x=\ddot x^\star`$ 。于是不同构型下可以获得较一致的任务响应，而不像简单的 $`J^\top`$ PD 那样随惯量变化显著。对仓储机械臂，这有助于让夹爪载货与空载、近身与远伸时保持相近的末端跟踪特性，但载荷模型必须及时更新。

冗余系统中常用动力学一致广义逆
```math
J_M^\#=M^{-1}J^\top\Lambda
```
及相应零空间投影
```math
N=I-J_M^\#J.
```
控制力矩可写成
```math
\tau=J^\top F+N^\top\tau_0,
```
其中 $`\tau_0`$ 用于关节限位回避、姿态偏好或内部阻尼。所谓“动力学一致”是指理想模型下零空间力矩不改变主任务加速度；若 $`M`$ 错误、任务雅可比降秩或执行器饱和，这种解耦会被破坏。多层任务还要明确优先级，不能仅把多个力矩相加后假设它们互不干扰。

对于移动操作机器人、四足机器人或存在接触的机械臂，需要把驱动选择矩阵、接触约束 $`J_c\ddot q+\dot J_c\dot q=0`$ 和摩擦锥共同纳入求解。此时 $`\Lambda`$ 的简单公式可能不再适用，通常要在约束允许的子空间内计算投影，或通过二次规划同时求 $`\ddot q,\tau,\lambda`$ 。操作空间控制的边界因此十分明确：它是基于模型的局部动力学整形，不是自动满足奇异性、接触可行性、力矩限幅和碰撞约束的万能接口。

<a id="ch29-sec10"></a>
## 29.10 力控制与阻抗控制

当机器人与环境接触时，位置误差不再只是跟踪问题，还会通过环境刚度转化为接触力。若沿货架法向的定位误差仅为数毫米，而货架和夹具都很硬，纯高增益位置控制仍可能产生很大冲击。力控制直接调节测得或估计的接触 wrench。以标量方向为例，可采用
```math
u_f=K_f(F_d-\hat F)+K_{if}\int(F_d-\hat F)\,dt ,
```
再把 $`u_f`$ 解释为期望速度、位移修正或任务力。六维情形中 $`F_d,\hat F\in\mathbb R^6`$ ，必须把传感器读数补偿零偏、工具重力和惯性，并变换到控制坐标系。

混合位置—力控制把任务方向分成互补子空间。令选择矩阵 $`S_f\in\mathbb R^{p\times p}`$ 表示力控方向，则 $`S_x=I-S_f`$ 表示位置控方向，可构造
```math
F_c=S_xF_{\mathrm{motion}}+S_fF_{\mathrm{force}}.
```
例如夹爪擦拭货箱表面时，切向跟踪位置，法向保持接触力；插入货格时，可沿插入方向控制运动，在横向保持柔顺。该分解依赖接触法向估计和稳定接触假设；若接触尚未建立、法向快速变化或发生滑动，固定选择矩阵可能失效，控制器必须包含接触检测与模式切换。

阻抗控制不要求误差严格为零，而是规定运动与外力之间的期望动态：
```math
M_d\ddot e+D_d\dot e+K_d e=F_{\mathrm{ext}},
```
其中 $`e=x-x_d\in\mathbb R^p`$ ， $`M_d,D_d,K_d\in\mathbb R^{p\times p}`$ 分别为期望惯量、阻尼和刚度，通常取对称正定或半正定矩阵。若机器人能直接控制力矩，可利用逆动力学或操作空间控制实现该关系；若设备只有位置接口，则可采用导纳控制，以测得外力驱动一个虚拟质量—弹簧—阻尼器，生成新的位置参考。阻抗控制适合力矩源、低摩擦机械臂，导纳控制更常见于高刚度位置伺服平台，但两者都会受到采样延迟、传感器噪声和执行器带宽限制。

接触稳定性取决于机器人、控制器和环境的共同动力学。高刚度环境、低采样率和通信延迟会显著缩小可稳定阻抗范围；简单提高阻尼也可能因噪声微分而注入能量。工程上应限制最大接触力和能量，设置接近、触碰、稳定接触与脱离等状态机，并在碰撞时优先触发安全停机。对未知货箱质量、软包装或人员意外接触，较低刚度和适当阻尼能提高容错性，但会降低定位精度；这是物理交互中的性能—鲁棒性权衡，而非参数调节可以完全消除的矛盾。

<a id="ch29-sec11"></a>
## 29.11 模型前馈 + 反馈：建模与控制的桥梁

模型前馈把状态空间模型、刚体几何、参数估计和执行器模型转化为可实施的控制量，反馈则封闭真实系统与模型之间的差距。一个统一的控制接口可写成
```math
u=\mathrm{sat}_{\mathcal U}
\left(
u_{\mathrm{ff}}(x_d,\dot x_d,\ddot x_d,\hat\theta)
+
u_{\mathrm{fb}}(\hat x,x_d)
\right),
```
其中 $`\hat x`$ 是状态估计， $`\hat\theta`$ 是质量、质心、摩擦或电机常数等参数估计， $`\mathcal U`$ 表示输入、功率与变化率可行集。前馈来自预测模型，反馈可采用 PD、状态反馈、任务空间反馈或阻抗结构，饱和算子提醒我们最终命令必须服从硬件边界。

对仓储移动操作机器人，这一链条可以具体分层：相机估计货架和货箱位姿，IMU 与轮编码器估计底盘状态，关节编码器提供机械臂构型；轨迹模块生成底盘和机械臂的时间参数化参考；逆动力学计算移动、抬臂和载荷所需的名义输入；关节或任务空间反馈修正误差；接触后切换到力或阻抗控制；电流环最终把命令转为电机转矩。每层都应明确坐标系、单位、采样率、时间戳和不确定度，否则再准确的单个模型也无法组成一致系统。

工程调试宜遵循由静到动、由自由空间到接触的顺序。首先校验关节方向、电机力矩符号和急停；随后验证重力补偿及不同构型下的静态残差；再以低速轨迹检查速度项和惯性项；之后逐步加入反馈并扩大带宽；最后才在受控条件下测试接触。可以记录模型力矩 $`\tau_{\mathrm{ff}}`$ 、反馈力矩 $`\tau_{\mathrm{fb}}`$ 、饱和标志和跟踪残差。若长期由反馈承担大部分稳定负载，通常意味着模型、载荷识别或坐标变换存在问题；若前馈主导且误差突然增大，则应检查接触变化、状态估计延迟和执行器饱和。

模型前馈也不能脱离鲁棒性和可行性分析。参数可通过离线辨识或在线估计更新，但快速自适应可能把未建模接触误认为参数变化；摩擦补偿可能在零速附近引入极限环；精确动力学抵消可能降低系统原有的被动性。因而实际控制器应保留稳定的名义反馈，限制参数更新范围，并用残差检测、约束投影和降级模式管理模型失效。控制的目标不是证明模型永远正确，而是在模型有效的区域利用它，在不确定性增大时仍保持可预测的退化行为。

## 本章小结

本章从“反馈不应承担全部工作”出发，建立了模型前馈与反馈协同的控制主线。重力补偿处理静态可预测负载，逆动力学前馈进一步加入惯性和速度耦合，计算力矩与反馈线性化则利用模型把局部非线性误差动力学整形成较易设计的形式。关节空间控制提供可靠的执行接口，雅可比转置和任务空间控制把控制目标提升到末端几何任务，操作空间控制进一步显式处理任务方向上的惯量与动力学耦合；进入接触后，力控制、混合控制与阻抗控制用受控交互替代盲目的高刚度位置跟踪。

所有这些方法都有共同边界：模型只在给定坐标、参数、接触模式和带宽范围内有效；奇异性、欠驱动、饱和、延迟与未建模柔性不会因代数抵消而消失。因此，机器人控制应被理解为模型预测、状态估计、误差反馈、约束管理和安全降级的组合。下一章将在这一接口上进一步引入性能指标与有限时域优化，从局部线性二次调节扩展到 iLQR 和 DDP，使“选择一个可用反馈律”推进为“在动力学和代价之间系统地优化行动”。
