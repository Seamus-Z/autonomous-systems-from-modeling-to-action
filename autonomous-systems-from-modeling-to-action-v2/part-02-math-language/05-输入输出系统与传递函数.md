自主系统通过传感器获得信息，通过执行器作用于物理世界。无论底层对象是电机、机械臂关节、无人机姿态还是移动机器人速度环，一个最直接的问题都是：

> 给系统施加某种输入之后，我们关心的输出将怎样变化？

本章建立输入—输出系统的基本语言，并以一台差速移动机器人的单轮驱动模块作为贯穿实例。电机端电压记为 $`u(t)`$ ，车轮角速度记为 $`y(t)=\omega(t)`$ 。我们将从信号、线性时不变系统、冲激响应与卷积出发，引入 Laplace 变换和传递函数，再讨论极点、零点、典型动态以及这种表示的能力边界。

输入—输出表示并不试图描述系统内部的一切。它主动隐藏部分内部变量，以换取对响应、稳定性、带宽和反馈设计更直接的理解。这种取舍将自然连接 Chapter 6 的状态空间表示，并在 Chapter 26 的经典控制分析以及 Chapter 27 的 PID 控制中再次出现。

## 5.1 信号与系统

信号（signal）是随某个自变量变化的信息载体。在动态系统中，这个自变量通常是时间。连续时间信号写成

```math
u:\mathbb{R}\rightarrow\mathbb{R}^{m},\qquad
y:\mathbb{R}\rightarrow\mathbb{R}^{p},
```

其中 $`u(t)\in\mathbb{R}^{m}`$ 是输入， $`y(t)\in\mathbb{R}^{p}`$ 是输出， $`m`$ 和 $`p`$ 分别表示输入与输出通道数。数字控制器处理的离散时间信号则写成 $`u[k]`$ 和 $`y[k]`$ ，其中 $`k\in\mathbb{Z}`$ 是采样序号。本章主要讨论连续时间系统；离散时间中的 $`Z`$ 变换和差分方程具有相应结构，但不能把 $`s`$ 域公式不加转换地直接用于离散系统。

系统（system）是从输入信号到输出信号的映射：

```math
y=\mathcal{S}[u].
```

这里的 $`\mathcal{S}`$ 可以表示微分方程、机械结构、电路、软件滤波器，甚至由实验数据辨识出的黑箱模型。系统还可能依赖初始状态 $`x(0)`$ 、参数 $`\theta`$ 和外部扰动 $`d(t)`$ ，更完整地可写为

```math
y(t)=\mathcal{S}\bigl(u(\cdot),d(\cdot),x(0),\theta;t\bigr).
```

这说明“同样的输入是否产生同样的输出”不能脱离初始条件和工作环境讨论。把扰动忽略并不意味着扰动不存在，只意味着当前模型没有显式表示它。

贯穿本章的单轮驱动模块由直流电机和车轮组成。其常见模型为

```math
L\dot i(t)+Ri(t)+k_e\omega(t)=u(t),
```

```math
J\dot\omega(t)+b\omega(t)=k_t i(t)-\tau_L(t),
```

其中 $`i`$ 为电枢电流， $`L`$ 和 $`R`$ 分别为电感与电阻， $`k_e`$ 为反电动势系数， $`J`$ 为等效转动惯量， $`b`$ 为黏性阻尼， $`k_t`$ 为转矩常数， $`\tau_L`$ 为负载转矩。若选择 $`u`$ 为电压、 $`\omega`$ 为输出，那么电流 $`i`$ 是内部变量，负载转矩是扰动。工程建模的第一步并不是写公式，而是明确哪些量被定义为输入、输出、内部变量和扰动。

常用测试信号包括单位阶跃 $`1(t)`$ 、单位冲激 $`\delta(t)`$ 、斜坡和正弦信号。它们不是为了模拟所有真实命令，而是为了用标准化激励揭示系统性质。例如速度命令突变近似对应阶跃，路面瞬时撞击可近似为短时脉冲，周期性机械振动则适合用正弦信号分析。实际执行器具有幅值、速率和带宽限制，因此理想冲激与无限快阶跃是分析工具，而不是可直接施加到硬件上的命令。

## 5.2 输入—输出视角

输入—输出视角只关心外部可访问端口之间的关系。对于单输入单输出（single-input single-output, SISO）系统，我们研究一个输入 $`u`$ 如何产生一个输出 $`y`$ ；对于多输入多输出（multiple-input multiple-output, MIMO）系统，则研究向量输入与向量输出之间的耦合。例如差速机器人有左右轮两个电压输入，也可有左右轮速、车体线速度和角速度等多个输出。

这种视角的优势是接口明确。假设电机驱动器已经封装好，我们未必需要在上层导航控制中持续计算绕组电流、磁通和齿轮接触力，而可以把模块看成

```math
u(t)\longmapsto \omega(t).
```

只要输入—输出模型在所关心的工作范围和频率范围内足够准确，上层就能分析命令跟踪速度、稳态误差、振荡和噪声放大。模块化设计、频率响应测试和经典反馈控制都依赖这种端口抽象。

输入—输出关系仍然具有动态记忆。静态映射写成 $`y(t)=g(u(t))`$ ，当前输出只取决于当前输入；动态系统则通常依赖整个历史：

```math
y(t)=\mathcal{F}\bigl(u(\tau),\ \tau\le t\bigr).
```

电机断电后车轮不会瞬间停下，正是因为惯量保存了过去输入的影响。一个系统若在时刻 $`t`$ 的输出只依赖 $`\tau\le t`$ 的输入，则称为因果系统（causal system）。真实在线控制装置必须因果；依赖未来输入的非因果运算只能用于离线数据处理或借助已知参考轨迹实现。

需要警惕的是，相同的端口描述不保证内部结构相同。两个电机模块可能对常见电压测试给出几乎相同的轮速响应，但一个内部电流受到良好限制，另一个却接近热失效。输入—输出等价只针对选定端口与实验范围成立，不能自动推出内部安全性、能量分布或故障模式相同。

## 5.3 线性与时不变性

系统 $`\mathcal{S}`$ 若满足叠加原理，就称为线性系统（linear system）。对任意输入 $`u_1,u_2`$ 和标量 $`a,b`$ ，要求

```math
\mathcal{S}[a u_1+b u_2]
=a\mathcal{S}[u_1]+b\mathcal{S}[u_2].
```

它同时包含可加性与齐次性，并隐含零输入在零初始条件下产生零输出。若关系中存在常数偏置，例如 $`y=Ku+c`$ ，则它是仿射映射而非严格线性映射。工程中通常先减去平衡点：

```math
\delta u=u-u^\ast,\qquad
\delta y=y-y^\ast,
```

再研究增量之间的近似线性关系 $`\delta y\approx G\,\delta u`$ 。

时不变性（time invariance）表示系统规律不随绝对时间改变。令延时算子满足 $`u_\tau(t)=u(t-\tau)`$ 。若

```math
\mathcal{S}[u(t-\tau)]
=y(t-\tau),
```

则系统时不变。换言之，今天施加某个输入波形与明天施加同样波形，除时间平移外应得到相同响应。电阻随温度变化、电池电压下降、轮胎磨损、载荷改变或控制器按时间调度参数，都会使严格时不变假设失效。

同时具有线性与时不变性的系统称为线性时不变系统（linear time-invariant, LTI）。本章传递函数理论主要针对 LTI 系统。直流电机方程在参数 $`L,R,J,b,k_e,k_t`$ 为常数，且不考虑饱和、死区、库仑摩擦和齿隙时，是一个 LTI 模型。真实电机显然不是全局线性的：电压和电流有上限，摩擦在低速附近不光滑，驱动器还可能包含保护逻辑。因此更准确的说法是：LTI 模型在给定工作点、幅值和频率范围内有效。

Chapter 4 中的非线性模型可在平衡点附近通过一阶 Taylor 展开得到局部线性模型。对

```math
\dot x=f(x,u),\qquad y=g(x,u),
```

在平衡点 $`(x^\ast,u^\ast)`$ 满足 $`f(x^\ast,u^\ast)=0`$ 时，有

```math
\delta\dot x=A\delta x+B\delta u,\qquad
\delta y=C\delta x+D\delta u,
```

其中 $`A,B,C,D`$ 是相应 Jacobian 在工作点处的值。局部线性化不是把非线性系统“变成了线性系统”，而是给出小扰动范围内的近似；工作点变化较大时应重新线性化，或改用后续章节中的非线性方法。

## 5.4 冲激响应与卷积

单位冲激 $`\delta(t)`$ 不是普通有限值函数，而是一种广义函数，满足

```math
\delta(t)=0\quad(t\ne0),\qquad
\int_{-\infty}^{\infty}\delta(t)\,dt=1,
```

以及抽样性质

```math
\int_{-\infty}^{\infty}f(\tau)\delta(t-\tau)\,d\tau=f(t).
```

一个连续时间 LTI 系统在零初始条件下对单位冲激的输出称为冲激响应（impulse response），记为 $`h(t)`$ 。冲激响应包含该系统全部零状态输入—输出信息。

任意输入都可以形式化地分解为连续排列的移位冲激：

```math
u(t)=\int_{-\infty}^{\infty}u(\tau)\delta(t-\tau)\,d\tau.
```

利用线性与时不变性，输出为卷积（convolution）

```math
y(t)=(h*u)(t)
=\int_{-\infty}^{\infty}h(t-\tau)u(\tau)\,d\tau.
```

若系统因果，则 $`h(t)=0`$ 对所有 $`t<0`$ 成立；若输入也从 $`t=0`$ 开始，卷积可写为

```math
y(t)=\int_0^t h(t-\tau)u(\tau)\,d\tau.
```

这个公式揭示了动态系统的“记忆核”：过去时刻 $`\tau`$ 的输入，以权重 $`h(t-\tau)`$ 影响当前输出。对轮速系统，若 $`h(t)`$ 衰减很快，旧电压对当前轮速的影响很快消失；若衰减缓慢，系统具有较长记忆。若存在直接通道 $`D`$ ，冲激响应中还会包含 $`D\delta(t)`$ ，表示输入可瞬时影响输出。

对因果连续时间 LTI 系统，若

```math
\int_0^\infty |h(t)|\,dt<\infty,
```

则系统是有界输入—有界输出稳定的，即 BIBO 稳定（bounded-input bounded-output stable）：任意有界输入产生有界输出。这个判据针对外部输入—输出性质。它与内部状态是否稳定有关，但两者并非在所有非最小实现中自动等价，尤其当不稳定内部模态被输入—输出通道隐藏时更应谨慎。

真实硬件无法产生理想 $`\delta(t)`$ ，因为它要求无限幅值和零持续时间。工程测试会使用持续时间很短、面积已知的脉冲，或通过扫频、伪随机二进制序列等安全激励估计响应。脉冲过窄会触发执行器带宽与采样限制，过强则可能造成电流冲击，因此“冲激响应可完整描述系统”是理论结论，不等于必须用理想冲激做实验。

## 5.5 Laplace 变换

Laplace 变换把时域中的微分和卷积转换为复变量 $`s`$ 域中的代数运算。对定义在 $`t\ge0`$ 的信号 $`f(t)`$ ，单边 Laplace 变换写为

```math
F(s)=\mathcal{L}\{f(t)\}
=\int_0^\infty f(t)e^{-st}\,dt,
\qquad s=\sigma+j\omega.
```

其中 $`\sigma`$ 描述指数加权， $`\omega`$ 描述正弦振荡频率， $`j^2=-1`$ 。变换只在积分收敛的 $`s`$ 区域内成立，这一区域称为收敛域。只写代数表达式而忽略收敛域，有时会把具有不同因果性或稳定性的信号混为一谈。

Laplace 变换最重要的性质之一是导数变换：

```math
\mathcal{L}\{\dot f(t)\}=sF(s)-f(0^-),
```

```math
\mathcal{L}\{\ddot f(t)\}
=s^2F(s)-sf(0^-)-\dot f(0^-).
```

因此微分方程可变为关于 $`s`$ 的代数方程。卷积则满足

```math
\mathcal{L}\{h*u\}=H(s)U(s).
```

时域中需要积分整个历史的卷积，在 $`s`$ 域中变成普通乘法，这正是传递函数便于分析和模块连接的根本原因。

若令 $`\sigma=0`$ ，则 $`s=j\omega`$ 对应稳态正弦频率轴。因而 Laplace 变换同时连接瞬态响应与频率响应。不过，只有当 $`j\omega`$ 位于收敛域内时，直接代入 $`s=j\omega`$ 才有明确意义。稳定系统通常满足这一条件；不稳定系统仍可具有形式上的传递函数，却不能把所有稳态正弦解释照搬过来。

Laplace 变换不是“把真实系统搬到另一个世界”，而是一种表示工具。初始条件、因果性和收敛性不会因为进入 $`s`$ 域而消失。尤其在定义传递函数时通常设初始条件为零；若系统启动时车轮已经转动，则完整输出还包含初始状态引起的零输入响应，不能只计算 $`G(s)U(s)`$ 。

<a id="ch5-sec6"></a>
## 5.6 从微分方程到传递函数

对零初始条件的 LTI 系统，传递函数（transfer function）定义为输出 Laplace 变换与输入 Laplace 变换之比：

```math
G(s)=\frac{Y(s)}{U(s)}.
```

更本质地说， $`G(s)`$ 是冲激响应的 Laplace 变换：

```math
G(s)=\mathcal{L}\{h(t)\}.
```

传递函数只描述零状态响应，而不是任意初始条件下的全部运动。对 MIMO 系统，传递函数变为传递矩阵

```math
Y(s)=G(s)U(s),\qquad
G(s)\in\mathbb{C}^{p\times m},
```

其中元素 $`G_{ij}(s)`$ 表示第 $`j`$ 个输入到第 $`i`$ 个输出的通道。

考虑常系数微分方程

```math
a_n y^{(n)}+\cdots+a_1\dot y+a_0y
=b_m u^{(m)}+\cdots+b_1\dot u+b_0u.
```

在零初始条件下进行 Laplace 变换，可得

```math
\left(a_ns^n+\cdots+a_1s+a_0\right)Y(s)
=
\left(b_ms^m+\cdots+b_1s+b_0\right)U(s),
```

因此

```math
G(s)=
\frac{b_ms^m+\cdots+b_1s+b_0}
{a_ns^n+\cdots+a_1s+a_0}.
```

对于有限维因果物理系统，通常要求传递函数是正常的（proper），即分子次数不高于分母次数；若严格低于，则称严格正常（strictly proper）。不正常传递函数意味着高频增益无限增长，往往包含理想微分器，需要额外动态或带宽限制才能物理实现。

对单轮电机模型，令负载扰动 $`\tau_L=0`$ ，并取零初始条件。Laplace 变换后有

```math
(Ls+R)I(s)+k_e\Omega(s)=U(s),
```

```math
(Js+b)\Omega(s)=k_t I(s).
```

消去 $`I(s)`$ ，得到从电压到角速度的传递函数

```math
G_{\omega u}(s)
=\frac{\Omega(s)}{U(s)}
=
\frac{k_t}
{(Ls+R)(Js+b)+k_ek_t}.
```

展开分母：

```math
G_{\omega u}(s)
=
\frac{k_t}
{LJ s^2+(Lb+RJ)s+(Rb+k_ek_t)}.
```

若输出改为车轮角位置 $`\theta`$ ，由于 $`\Omega(s)=s\Theta(s)`$ 在零初始条件下成立，因此

```math
G_{\theta u}(s)=\frac{1}{s}G_{\omega u}(s).
```

同一个物理对象因输出选择不同而具有不同传递函数，甚至会多出一个原点极点。这说明“系统的传递函数”必须连同输入和输出定义一起说明。

<a id="ch5-sec7"></a>
## 5.7 极点（Pole）

对于有理传递函数

```math
G(s)=\frac{N(s)}{D(s)},
```

使 $`D(s)=0`$ 且未被分子约去的复数 $`p_i`$ 称为极点（pole）。若分母可因式分解，则

```math
D(s)=a_n\prod_{i=1}^{n}(s-p_i).
```

极点决定系统自然响应中的指数模态。实极点 $`p=-a`$ 对应 $`e^{-at}`$ ；共轭复极点 $`p=\sigma\pm j\omega_d`$ 对应带指数包络 $`e^{\sigma t}`$ 的振荡。

对有限维、因果、有理的连续时间传递函数，在不存在隐藏不稳定模态等问题时，所有极点满足

```math
\operatorname{Re}(p_i)<0
```

意味着 BIBO 稳定。右半平面极点导致响应指数增长；位于虚轴上的单极点通常产生不衰减响应，而重复虚轴极点还会造成多项式增长。原点极点 $`p=0`$ 表示积分环节，例如从角速度到角位置的关系 $`1/s`$ 。积分器对阶跃输入会产生斜坡输出，因此本身不是 BIBO 稳定的，但在闭环中常用于消除稳态误差。

电机轮速传递函数的极点由

```math
LJ s^2+(Lb+RJ)s+(Rb+k_ek_t)=0
```

决定。电气电感和机械惯量共同形成两个动态模态。当电气时间常数 $`L/R`$ 远小于机械时间尺度时，其中一个极点通常位于更靠左的位置并快速衰减，另一个极点主导可见轮速响应。这为后续的一阶近似提供依据。

极点不是模型参数列表的另一种写法，而是系统时间尺度和振荡特征的压缩表达。不过，传递函数中的极点只反映所选输入—输出通道可见的模态。若某个内部不稳定模态既不受该输入激励，也不被该输出观测，它可能不会出现在化简后的传递函数中。因此，不能仅凭某一个通道的极点就断言整个设备内部安全稳定；Chapter 6 的状态空间表示将更直接地讨论内部模态。

<a id="ch5-sec8"></a>
## 5.8 零点（Zero）

使传递函数分子为零且未与分母约去的复数 $`z_i`$ 称为零点（zero）：

```math
N(s)=b_m\prod_{i=1}^{m}(s-z_i).
```

极点主要决定系统有哪些自然动态，零点则描述不同动态通道如何在输出端组合和抵消。零点会显著改变瞬态形状、相位和可实现的闭环性能，即使它不直接决定开环系统是否 BIBO 稳定。

若零点位于左半平面，系统通常称为最小相位系统的一部分；若存在右半平面零点，则系统是非最小相位（non-minimum-phase）的。右半平面零点常导致逆响应：阶跃输入施加后，输出先向最终目标的反方向移动，再转向稳态值。例如某些轮式机器人若输出选为离质心较远处的横向位移，转向输入可能先因车体转动几何关系产生反向局部运动。此类零点还限制跟踪带宽：控制器不能在不付出巨大控制量、超调或鲁棒性代价的情况下任意加快响应。

纯电压到理想电机轮速的模型

```math
G_{\omega u}(s)
=
\frac{k_t}
{LJ s^2+(Lb+RJ)s+(Rb+k_ek_t)}
```

没有有限零点，因为分子是常数。但若加入传感器滤波、柔性传动、多位置测量或前馈通道，零点就可能出现。零点因此不仅属于“被控对象”，也可能由传感器位置、执行器位置和输出定义共同产生。

极零相消需要特别谨慎。形式上，

```math
G(s)=\frac{s-a}{(s-a)(s+b)}
=\frac{1}{s+b},
```

但若 $`a>0`$ ，被约去的是右半平面不稳定模态。精确数学模型中它从输入—输出表达式消失，真实系统中微小参数误差却会使相消不完全，留下危险的不稳定动态。工程设计不应依赖对不稳定极点或弱阻尼极点的精确相消。

<a id="ch5-sec9"></a>
## 5.9 一阶与二阶动态系统

标准一阶系统写为

```math
G(s)=\frac{K}{\tau s+1},
\qquad \tau>0,
```

其中 $`K`$ 是静态增益， $`\tau`$ 是时间常数。对单位阶跃输入，零初始条件下的响应为

```math
y(t)=K\left(1-e^{-t/\tau}\right),\qquad t\ge0.
```

在 $`t=\tau`$ 时，输出达到最终值的约 $`63.2\%`$ ；在 $`3\tau`$ 和 $`4\tau`$ 时分别达到约 $`95.0\%`$ 和 $`98.2\%`$ 。因此时间常数给出响应快慢的直接尺度，但“稳定时间等于 $`4\tau`$ ”只是采用约 $`2\%`$ 误差带时的经验值。

若电机电感动态远快于机械动态，可近似令 $`L\dot i\approx0`$ ，于是

```math
i\approx\frac{u-k_e\omega}{R}.
```

代入机械方程并令 $`\tau_L=0`$ ，得到

```math
RJ\dot\omega+(Rb+k_ek_t)\omega=k_tu,
```

因此

```math
G_{\omega u}(s)
\approx
\frac{K}{\tau s+1},
```

其中

```math
K=\frac{k_t}{Rb+k_ek_t},\qquad
\tau=\frac{RJ}{Rb+k_ek_t}.
```

这个近似清楚揭示了轮速稳态增益和机械响应时间，但它不能用于分析高频电流变化，也不适合设计接近电气极点频率的高速控制器。

标准二阶系统写为

```math
G(s)=
\frac{\omega_n^2}
{s^2+2\zeta\omega_ns+\omega_n^2},
```

其中 $`\omega_n>0`$ 是无阻尼自然频率，单位为 $`\mathrm{rad/s}`$ ； $`\zeta\ge0`$ 是无量纲阻尼比。其极点为

```math
p_{1,2}
=-\zeta\omega_n
\pm\omega_n\sqrt{\zeta^2-1}.
```

当 $`0<\zeta<1`$ 时系统欠阻尼，极点为共轭复数，阻尼振荡频率为

```math
\omega_d=\omega_n\sqrt{1-\zeta^2}.
```

当 $`\zeta=1`$ 时为临界阻尼； $`\zeta>1`$ 时为过阻尼； $`\zeta=0`$ 时理想系统持续振荡。

对无零点、单位静态增益的欠阻尼二阶系统，阶跃响应的峰值时间和百分比超调量分别为

```math
t_p=\frac{\pi}{\omega_n\sqrt{1-\zeta^2}},
```

```math
M_p=100\%
\exp\left(
-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}
\right).
```

采用 $`2\%`$ 误差带时，常用近似稳定时间

```math
t_s\approx\frac{4}{\zeta\omega_n}.
```

这些公式假设标准二阶形式、欠阻尼、无额外零点且初始条件为零。若系统存在显著零点、饱和或高阶模态，直接套用会产生误导。对机器人轮速环而言，提高闭环自然频率通常能加快响应，但电流限制、采样频率、传感器噪声和未建模柔性会给可实现速度设置上限。

<a id="ch5-sec10"></a>
## 5.10 高阶系统与主导动态

真实自主系统通常高于二阶。电机包含电气和机械动态，齿轮与轮胎具有柔性，驱动器包含滤波和延迟，车体运动又与地面接触耦合。一般有理传递函数可写成

```math
G(s)=K
\frac{\prod_{j=1}^{m}(s-z_j)}
{\prod_{i=1}^{n}(s-p_i)}.
```

若极点互异，部分分式展开可表示为

```math
G(s)=D+\sum_{i=1}^{n}\frac{r_i}{s-p_i},
```

其中 $`r_i`$ 是留数（residue）。时域响应中的每个模态不仅由极点位置决定，还由留数决定。一个极点即使衰减较慢，如果其留数对当前输入—输出通道极小，也可能在测量中不显著；反之，一个不算最慢但留数很大的模态可能主导短期响应。

所谓主导动态，是在所关心时间尺度和频率范围内决定主要输出行为的少数模态。通常，靠近虚轴的稳定极点衰减较慢，更可能成为主导极点；远在左半平面的极点衰减很快，可在低频模型中忽略。例如电机的电气极点比机械极点快一个数量级以上时，轮速通道可近似为一阶系统。但“快五倍或十倍即可忽略”只是经验规则，仍需检查零点、留数、控制带宽和所需精度。

降阶时应比较原模型与近似模型的阶跃响应和频率响应，并明确有效范围。若轮速控制器带宽已经接近被忽略的电气极点，原本“很快”的动态就不再可忽略。类似地，轮胎柔性在低速导航中可能不重要，在高速运动或崎岖路面上却会成为主要振荡源。模型阶数不是越低越好，也不是越高越真实；合适的模型应保留对当前决策有影响的动态。

时间延迟也是高阶系统中常见而特殊的因素。纯延迟 $`T>0`$ 的传递函数为

```math
G_d(s)=e^{-sT},
```

它不是有限阶有理函数，幅值不变但引入相位滞后 $`-\omega T`$ 。通信、计算、传感器曝光和零阶保持都会产生延迟。可用 Padé 近似把延迟写成有限阶有理模型，例如一阶近似

```math
e^{-sT}\approx
\frac{1-\frac{T}{2}s}
{1+\frac{T}{2}s},
```

但该近似引入右半平面零点，只应在目标频段内使用，不能把近似模型在所有频率上的行为当作真实延迟。

<a id="ch5-sec11"></a>
## 5.11 传递函数能告诉我们什么

传递函数首先能告诉我们零初始条件下，某个输入—输出通道的动态响应。由极点可以判断主要时间尺度、衰减速度和振荡趋势；由零点可以判断响应整形、相位特性和逆响应；由低频增益

```math
G(0)=\lim_{s\to0}G(s)
```

可以在极限存在时得到常值输入对应的稳态增益。例如电机轮速模型的直流增益为

```math
G_{\omega u}(0)
=
\frac{k_t}{Rb+k_ek_t},
```

它表示在线性模型和无负载假设下，稳态轮速与恒定电压之比。

令 $`s=j\omega`$ 可得到频率响应

```math
G(j\omega)
=
|G(j\omega)|e^{j\angle G(j\omega)}.
```

幅值 $`|G(j\omega)|`$ 表示各频率输入被放大或衰减的程度，相位 $`\angle G(j\omega)`$ 表示输出相对输入的相位偏移。对轮速模块，低频电压主要改变平均轮速，而高频电压变化会受到电感和惯量抑制。频率响应因此能回答“系统能跟随多快的命令”“哪些振动会被放大”“传感器噪声可能怎样进入输出”等问题。

传递函数还特别适合模块连接。若两个因果 LTI 模块串联，

```math
G_{\mathrm{series}}(s)=G_2(s)G_1(s).
```

若并联后输出相加，

```math
G_{\mathrm{parallel}}(s)=G_1(s)+G_2(s).
```

在标准负反馈结构中，若被控对象为 $`G(s)`$ 、控制器为 $`C(s)`$ ，开环传递函数为

```math
L(s)=C(s)G(s),
```

从参考输入到输出的闭环传递函数为

```math
T(s)=\frac{L(s)}{1+L(s)}.
```

灵敏度函数则为

```math
S(s)=\frac{1}{1+L(s)},
\qquad S(s)+T(s)=1.
```

这两个函数直接连接跟踪、扰动抑制、噪声传递与鲁棒性，是经典控制的核心对象。

对 MIMO 系统，单个元素的极点和增益仍可分析，但通道之间存在方向性耦合，不能仅查看若干标量曲线就完整判断性能。传递矩阵的秩、零点以及频率相关的奇异值会更有意义。差速机器人的左右轮通道看似对称，车体线速度与角速度却由两轮组合产生；若只独立分析单轮而忽略车体耦合，上层运动性能可能与预测不符。

<a id="ch5-sec12"></a>
## 5.12 传递函数不能告诉我们什么

传递函数不会显式告诉我们系统内部状态是什么。电机的 $`G_{\omega u}(s)`$ 给出电压到轮速的关系，但不直接显示电流 $`i(t)`$ 。即使轮速完全满足指标，电流也可能暂时超过驱动器上限。温度、磁通、齿轮扭转和电池荷电状态等内部变量若未被选作输出，就不会自动出现在这个通道的传递函数中。

传递函数也不能单独表达任意初始条件。完整线性系统响应通常分为

```math
y(t)=y_{\mathrm{zi}}(t)+y_{\mathrm{zs}}(t),
```

其中 $`y_{\mathrm{zi}}`$ 是由初始状态产生的零输入响应， $`y_{\mathrm{zs}}`$ 是由外部输入产生的零状态响应。关系 $`Y(s)=G(s)U(s)`$ 只覆盖后者。机器人在斜坡上启动、车轮已有初速度或柔性机构中储存了弹性能量时，忽略初始状态会低估瞬态风险。

标准传递函数主要描述固定参数下的 LTI 动态，不能直接处理饱和、死区、碰撞、接触切换、逻辑模式和强非线性。例如电机电压满足

```math
|u(t)|\le u_{\max},
```

电流满足

```math
|i(t)|\le i_{\max},
```

这些约束不会因为写出 $`G(s)`$ 就自动进入分析。线性模型预测的控制输入可能在数学上有效，却在硬件上被截断，进而造成积分饱和、响应变慢甚至失稳。工作点变化、载荷变化和轮胎打滑也会使固定传递函数失准。

传递函数还不能仅凭一个化简后的通道保证内部稳定性、可控性或可观性。极零相消可能隐藏内部模态，不同内部实现也可能具有相同传递函数。传递函数描述的是外部行为等价类，而不是唯一物理结构。要回答“哪些内部状态能被输入影响”“哪些状态能由传感器重建”“初始状态如何演化”等问题，需要 Chapter 6 的状态空间语言。

最后，模型精确并不等于环境确定。传递函数中的参数可能有误差，外部扰动可能未知，传感器也含有噪声。一个名义模型

```math
G(s;\theta_0)
```

只代表参数 $`\theta_0`$ 下的近似对象。工程上必须同时考虑参数集合、未建模高频动态、延迟和测量误差。把实验曲线拟合得非常精细，却没有验证模型在不同载荷、速度和温度下是否仍成立，是常见误区。

<a id="ch5-sec13"></a>
## 5.13 输入输出表示为什么自然走向经典控制

控制的任务是选择输入，使输出按照目标变化并抵抗扰动。输入—输出表示正好把这一任务写成端口之间的关系。对机器人轮速环，设参考轮速为 $`r`$ ，实际轮速为 $`y`$ ，误差为

```math
e(s)=R(s)-Y(s),
```

控制器生成电压命令

```math
U(s)=C(s)E(s),
```

被控对象满足

```math
Y(s)=G(s)U(s).
```

联立可得

```math
\frac{Y(s)}{R(s)}
=
\frac{C(s)G(s)}
{1+C(s)G(s)}.
```

于是闭环极点是特征方程

```math
1+C(s)G(s)=0
```

的根。控制器设计因而可以理解为：通过改变环路传递函数 $`L=C G`$ ，重新塑造闭环极点、频率响应和稳态误差。

这一结构自然产生经典控制的三类问题。第一，时域上关心上升时间、超调量、稳定时间和稳态误差；第二，复平面上关心控制增益变化时闭环极点怎样移动，即根轨迹；第三，频域上关心增益、相位、带宽以及稳定裕度，即 Bode 图和 Nyquist 分析。Chapter 26 将在本章概念之上系统讨论这些工具，Chapter 27 则进一步研究 PID 控制器如何用比例、积分和微分环节塑造响应。

输入—输出方法之所以适合工程现场，还因为对象模型可由实验直接辨识。即使不知道电机的每个内部参数，也能施加安全测试信号并测量轮速，从而估计一阶或二阶模型。随后可在频域比较名义模型与真实设备，设计控制器，再进行闭环验证。这条路线特别适合模块化执行器和 SISO 内环。

但经典控制并不是状态空间方法的对立面。对线性状态空间模型

```math
\dot x=Ax+Bu,\qquad
y=Cx+Du,
```

在零初始条件下，其传递矩阵为

```math
G(s)=C(sI-A)^{-1}B+D.
```

这条公式说明，两种表示描述的是同一类线性动态的不同侧面：传递函数强调外部端口、频率与响应；状态空间强调内部状态、初始条件和多变量结构。自主系统通常同时需要二者——底层执行器环适合使用输入—输出工具，上层估计、预测和多变量控制则往往需要显式状态。

贯穿本章的单轮驱动例子也体现了这一接口。若只需设计轮速内环，可用 $`G_{\omega u}(s)`$ 分析响应并配置控制器；若还要估计电流、限制轮胎力、融合编码器与惯性测量，或联合控制左右轮和车体姿态，就应回到以 $`i,\omega`$ 等变量组成的状态模型。好的工程方法不是固定偏爱某种表示，而是根据问题选择能暴露关键结构、同时隐藏无关细节的表示。

## 本章小结

本章从信号与系统出发，建立了连续时间 LTI 输入—输出系统的主线：

```math
\text{微分方程}
\longrightarrow
\text{冲激响应与卷积}
\longrightarrow
\text{Laplace 变换}
\longrightarrow
\text{传递函数}
\longrightarrow
\text{极点、零点与动态响应}.
```

对 LTI 系统，冲激响应 $`h(t)`$ 完整描述零状态输入—输出关系，任意输入响应由卷积 $`y=h*u`$ 得到；Laplace 变换把卷积变成乘法，进而得到 $`Y=GU`$ 。极点揭示自然模态、稳定性和时间尺度，零点决定通道组合、相位与逆响应。一阶、二阶和主导动态近似则把高阶模型压缩成可直接解释的工程指标。

以移动机器人的单轮驱动模块为例，我们从电气—机械微分方程推导了电压到轮速的传递函数，并看到输出选择、快速电气动态、负载扰动和执行器约束如何影响模型解释。传递函数擅长回答跟踪速度、稳态增益、频率响应和反馈连接问题，却不会自动给出内部状态、任意初始条件、非线性约束或隐藏模态。

下一章将把内部状态重新放回模型，建立状态空间表示。届时，电机电流与轮速不再只是被消去的中间变量，而会组成状态向量；传递函数

```math
G(s)=C(sI-A)^{-1}B+D
```

将成为输入—输出表示与状态空间表示之间的桥梁。
