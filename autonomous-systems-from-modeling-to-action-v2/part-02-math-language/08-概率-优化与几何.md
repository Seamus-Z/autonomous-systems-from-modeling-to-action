自主系统必须同时处理三类问题：世界具有不确定性，行动需要在约束下作出选择，而位置、姿态和运动又发生在具有特定结构的几何空间中。概率论回答“系统知道什么以及有多确定”，优化理论回答“在可行选择中应当采取什么行动”，几何则回答“状态和运动究竟存在于什么空间、应如何表示”。

本章以一台在仓库中执行取放任务的移动机械臂为贯穿例子。机器人由移动底盘、六自由度机械臂、相机和激光雷达组成。它需要估计自身位姿与货物位置，规划无碰撞轨迹，并在执行过程中根据新观测修正行动。这个例子将说明：概率、优化与几何不是三个彼此独立的工具箱，而是同一闭环中的三个侧面。

## 8.1 随机变量与概率分布

随机变量（Random Variable）不是一个“随机变化的符号”，而是把随机试验结果映射为数值的函数。离散随机变量 $`X`$ 由概率质量函数（Probability Mass Function, PMF）

```math
p_X(x)=\Pr(X=x),\qquad \sum_x p_X(x)=1
```

描述；连续随机变量则由概率密度函数（Probability Density Function, PDF）描述：

```math
p_X(x)\ge 0,\qquad \int_{\mathcal X}p_X(x)\,dx=1.
```

连续情形中，单点概率通常为零，即 $`\Pr(X=x)=0`$ ，真正具有概率意义的是区间积分：

```math
\Pr(a\le X\le b)=\int_a^b p_X(x)\,dx.
```

因此，“密度值为 2”并不意味着概率超过 1；密度具有量纲，其数值还会随坐标尺度改变。

自主系统通常使用随机向量 $`x\in\mathbb R^n`$ 表示状态、噪声或未知参数。多元高斯分布（Multivariate Gaussian Distribution）写为

```math
x\sim\mathcal N(\mu,\Sigma),
```

其密度为

```math
p(x)=\frac{1}{(2\pi)^{n/2}|\Sigma|^{1/2}}
\exp\left[-\frac12(x-\mu)^\mathsf T\Sigma^{-1}(x-\mu)\right].
```

其中 $`\mu\in\mathbb R^n`$ 是均值， $`\Sigma\in\mathbb R^{n\times n}`$ 是对称半正定协方差矩阵；若要求存在普通密度，则通常假设 $`\Sigma\succ0`$ 。指数中的二次型是马氏距离（Mahalanobis Distance）的平方，它按各方向的不确定性对误差进行归一化。

在移动机械臂中，编码器误差、相机像素噪声和轮胎打滑都可以建模为随机变量。例如测量模型可写成

```math
z_k=h(x_k)+v_k,\qquad v_k\sim\mathcal N(0,R_k),
```

其中 $`x_k\in\mathbb R^n`$ 是时刻 $`k`$ 的状态， $`z_k\in\mathbb R^m`$ 是观测， $`h`$ 是观测函数， $`R_k\in\mathbb R^{m\times m}`$ 是测量噪声协方差。高斯分布计算方便，但它并非“不确定性”的同义词：遮挡导致的多峰分布、接触模式的不连续变化和严重离群点通常不能由单个高斯分布充分表达。

## 8.2 期望、方差与协方差

期望（Expectation）描述随机变量在概率意义下的平均位置。对连续随机向量 $`x`$ ，

```math
\mu=\mathbb E[x]=\int_{\mathcal X}x\,p(x)\,dx.
```

对标量随机变量 $`X`$ ，方差（Variance）为

```math
\mathrm{Var}(X)
=\mathbb E[(X-\mathbb E[X])^2]
=\mathbb E[X^2]-\mathbb E[X]^2.
```

标准差 $`\sigma=\sqrt{\mathrm{Var}(X)}`$ 与 $`X`$ 具有相同单位，因而比方差更容易直接解释。期望只描述中心，不描述分布形状；两个分布可以具有相同的期望和方差，却具有完全不同的尾部与多峰结构。

对 $`x\in\mathbb R^n`$ ，协方差（Covariance）矩阵定义为

```math
\Sigma_x=\mathbb E\!\left[(x-\mu_x)(x-\mu_x)^\mathsf T\right].
```

其第 $`i`$ 个对角元素是 $`x_i`$ 的方差，非对角元素

```math
(\Sigma_x)_{ij}
=\mathbb E[(x_i-\mu_i)(x_j-\mu_j)]
```

描述两个分量的线性相关程度。归一化后的相关系数为

```math
\rho_{ij}=\frac{(\Sigma_x)_{ij}}{\sigma_i\sigma_j},
\qquad -1\le \rho_{ij}\le 1.
```

零协方差只表示不存在线性相关，一般不能推出统计独立；只有在联合高斯等特定条件下，这一推论才成立。

若 $`y=Ax+b`$ ，其中 $`A\in\mathbb R^{m\times n}`$ ，则

```math
\mathbb E[y]=A\mu_x+b,\qquad
\Sigma_y=A\Sigma_xA^\mathsf T.
```

对非线性变换 $`y=f(x)`$ ，在 $`\mu_x`$ 附近用雅可比矩阵 $`J_f=\left.\frac{\partial f}{\partial x}\right|_{\mu_x}`$ 线性化，可得一阶近似

```math
\Sigma_y\approx J_f\Sigma_xJ_f^\mathsf T.
```

仓库机器人把相机中的货物位置变换到机械臂基座坐标系时，均值要经过坐标变换，协方差也必须同步传播。只变换位置而保留原协方差，会把错误的不确定性方向交给后续规划器。还应注意单位和尺度：位置—姿态联合协方差中的米与弧度不能不加解释地直接比较，其权重必须来自传感器模型、几何线性化或明确的工程尺度。

## 8.3 条件概率

条件概率（Conditional Probability）描述在获得额外信息之后，事件或随机变量的概率如何改变。若 $`\Pr(B)>0`$ ，则

```math
\Pr(A\mid B)=\frac{\Pr(A\cap B)}{\Pr(B)}.
```

对连续随机变量，相应关系写成

```math
p(x\mid y)=\frac{p(x,y)}{p(y)},
\qquad p(y)>0.
```

联合分布可以由条件分布分解：

```math
p(x,y)=p(x\mid y)p(y)=p(y\mid x)p(x).
```

边缘化（Marginalization）则通过消去不关心的变量得到边缘分布：

```math
p(x)=\int p(x,y)\,dy.
```

随机变量 $`x`$ 与 $`y`$ 独立，当且仅当 $`p(x,y)=p(x)p(y)`$ ，此时 $`p(x\mid y)=p(x)`$ 。条件独立则是“给定第三个变量后独立”，例如

```math
p(z_k\mid x_k,z_{1:k-1})=p(z_k\mid x_k)
```

表示在当前状态 $`x_k`$ 已知时，当前传感器观测 $`z_k`$ 与历史观测 $`z_{1:k-1}`$ 条件独立。这类假设不是符号技巧，而是滤波与图模型能够分解计算的结构基础。

在移动机械臂中， $`p(z_k\mid x_k)`$ 是传感器模型：假设机器人处于位姿 $`x_k`$ ，看到观测 $`z_k`$ 的可能性有多大。与之不同， $`p(x_k\mid z_k)`$ 是获得观测后对状态的判断。二者不能直接互换。例如，相机“在货物存在时容易检测到货物”并不等于“检测到目标时它一定是货物”，因为后者还取决于货物出现的先验频率和误检概率。

条件模型的边界来自其假设。轮速误差可能因地面材质连续数秒保持相关，相机误差也可能因标定偏差产生系统性相关。如果仍假设各时刻噪声独立，算法通常会重复计算同一信息，得到过度自信的协方差。工程上应区分随机白噪声、时间相关噪声和固定但未知的系统偏差。

## 8.4 Bayes 公式

Bayes 公式把先验知识与新观测结合起来：

```math
p(x\mid z)
=\frac{p(z\mid x)p(x)}{p(z)}
=\frac{p(z\mid x)p(x)}
{\int p(z\mid x')p(x')\,dx'}.
```

其中 $`p(x)`$ 是先验（Prior）， $`p(z\mid x)`$ 是似然（Likelihood）， $`p(x\mid z)`$ 是后验（Posterior），分母 $`p(z)`$ 称为证据或边缘似然。对固定观测 $`z`$ ，分母与 $`x`$ 无关，因此常写成

```math
p(x\mid z)\propto p(z\mid x)p(x).
```

比例式适合求最优点，但若要比较模型、计算概率或继续进行严格的边缘化，归一化常数不能永久忽略。

动态系统中的 Bayes 递推包括预测和更新。设状态转移模型为 $`p(x_k\mid x_{k-1},u_{k-1})`$ ，其中 $`u_{k-1}`$ 是控制输入，则预测分布为

```math
p(x_k\mid z_{1:k-1},u_{0:k-1})
=
\int p(x_k\mid x_{k-1},u_{k-1})
p(x_{k-1}\mid z_{1:k-1},u_{0:k-2})
\,dx_{k-1}.
```

获得新观测 $`z_k`$ 后，

```math
p(x_k\mid z_{1:k},u_{0:k-1})
\propto
p(z_k\mid x_k)\,
p(x_k\mid z_{1:k-1},u_{0:k-1}).
```

这就是递归状态估计的概率骨架；不同滤波算法的主要差别在于如何表示分布以及如何近似积分。

仓库机器人运动时，轮速计和动力学模型提供预测，相机与激光雷达提供更新。若货架遮挡导致视觉观测不可靠，似然应更宽或采用更合适的鲁棒模型，而不是让算法“盲目信任相机”。Bayes 公式不会自动纠正错误模型：若先验排除了真实状态，或似然严重失配，形式正确的推理仍会产生错误结论。因此，概率推理的质量由模型、数据关联和数值表示共同决定。

## 8.5 最大似然与最大后验

最大似然估计（Maximum Likelihood Estimation, MLE）把观测数据 $`D`$ 视为已知，把参数 $`\theta\in\mathbb R^p`$ 视为待估变量：

```math
\hat\theta_{\mathrm{ML}}
=\arg\max_\theta p(D\mid\theta).
```

似然是关于参数 $`\theta`$ 的函数，但它不是“参数的概率分布”，因为通常没有对 $`\theta`$ 归一化。为避免大量概率相乘造成数值下溢，实际计算常最大化对数似然：

```math
\hat\theta_{\mathrm{ML}}
=\arg\max_\theta \log p(D\mid\theta).
```

若观测独立，则联合对数似然是各项对数似然之和。

假设观测模型为

```math
y_i=f(x_i;\theta)+\varepsilon_i,\qquad
\varepsilon_i\sim\mathcal N(0,R_i),
```

且各次误差条件独立，则负对数似然除去与 $`\theta`$ 无关的常数后为

```math
-\log p(D\mid\theta)
=
\frac12\sum_i r_i(\theta)^\mathsf T
R_i^{-1}r_i(\theta),
```

其中 $`r_i(\theta)=y_i-f(x_i;\theta)\in\mathbb R^{m_i}`$ 。因此，高斯噪声假设下的最大似然估计等价于加权最小二乘。权重 $`R_i^{-1}`$ 不是随意的调参系数，而是观测精度在概率模型中的表达。

最大后验估计（Maximum A Posteriori Estimation, MAP）进一步引入参数先验：

```math
\hat\theta_{\mathrm{MAP}}
=\arg\max_\theta p(\theta\mid D)
=\arg\min_\theta
\left[-\log p(D\mid\theta)-\log p(\theta)\right].
```

若 $`p(\theta)=\mathcal N(\theta_0,\Sigma_0)`$ ，则先验贡献为

```math
\frac12(\theta-\theta_0)^\mathsf T
\Sigma_0^{-1}(\theta-\theta_0).
```

这说明常见的二次正则化可以解释为高斯先验。仓库机器人标定相机外参时，可用历史标定值作为先验，用当前观测作为似然；数据充分时似然占主导，数据稀少时先验可抑制不合理漂移。

MLE 与 MAP 都给出点估计，不等于完整后验分布。点估计还可能受到不可辨识性、多峰似然、局部极值和离群点影响。增加正则项也不必然提高真实性：过强先验会压制有效数据。工程上必须检查残差、参数敏感性和可辨识方向，而不能只看优化器是否“成功收敛”。

<a id="ch8-sec6"></a>
## 8.6 什么是优化问题

优化（Optimization）是在候选集合中寻找使目标最优的决策。一般形式为

```math
\begin{aligned}
\min_{z\in\mathbb R^n}\quad & f(z)\\
\text{s.t.}\quad & z\in\mathcal F,
\end{aligned}
```

其中 $`z`$ 是决策变量， $`f:\mathbb R^n\to\mathbb R`$ 是目标函数， $`\mathcal F`$ 是可行域。最大化问题可通过最小化 $`-f`$ 转换为相同形式。优化的输出不只应包含一个数值解，还应说明该解是否可行、是局部还是全局最优，以及终止条件和数值误差是什么。

仓库机器人的轨迹规划可以把未来 $`N`$ 个时刻的状态和控制量共同作为决策变量：

```math
z=(x_0,u_0,x_1,u_1,\ldots,x_N).
```

若 $`x_k\in\mathbb R^{n_x}`$ 、 $`u_k\in\mathbb R^{n_u}`$ ，则直接转录后的决策维度约为 $`(N+1)n_x+Nn_u`$ 。优化器不是凭空“生成动作”，而是在由动力学、碰撞条件和执行器能力限定的候选轨迹中作出权衡。

必须区分优化模型与求解算法。问题本身由变量、目标和约束定义；梯度下降、二次规划、序列二次规划和内点法只是求解手段。同一个物理任务可以有不同的数学表述，而不同表述会显著改变数值条件、稀疏结构和收敛性质。一个算法返回结果，也不代表原问题存在唯一解，更不代表该结果在真实系统上安全可执行。

## 8.7 目标函数与约束

有限时域最优控制的典型目标为

```math
J=\phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k),
```

其中 $`\ell`$ 是阶段代价， $`\phi`$ 是终端代价。对仓库机器人，可取

```math
\ell(x_k,u_k)
=
(x_k-x_k^{\mathrm{ref}})^\mathsf TQ(x_k-x_k^{\mathrm{ref}})
+u_k^\mathsf TRu_k,
```

其中 $`Q\succeq0`$ 、 $`R\succ0`$ 。第一项惩罚偏离参考轨迹，第二项抑制过大的控制输入。矩阵元素应结合变量单位、允许误差和任务风险设定；未经尺度归一化就直接比较米、弧度和牛·米，容易使某类误差在数值上无意中支配优化。

典型约束包括

```math
x_{k+1}=F(x_k,u_k),
```

```math
x_{\min}\le x_k\le x_{\max},\qquad
u_{\min}\le u_k\le u_{\max},
```

以及障碍物安全距离

```math
d(q_k,\mathcal O)\ge d_{\mathrm{safe}}.
```

动力学是等式约束，状态、输入和安全距离通常是不等式约束。若使用标准形式 $`g(z)\le0`$ ，最后一项应写为

```math
g_{\mathrm{obs}}(q_k)
=d_{\mathrm{safe}}-d(q_k,\mathcal O)\le0.
```

统一符号方向十分重要，否则乘子符号和 KKT 条件容易写反。

硬约束必须严格满足，适用于执行器极限、几何不可穿透等要求；软约束则允许以代价换取有限违反。例如引入松弛变量 $`s_k\ge0`$ ：

```math
g(z)\le s_k,\qquad
J_{\mathrm{soft}}=J+\rho\sum_k s_k^2.
```

软化可以避免因模型误差导致问题完全不可行，但不应把真正的安全边界随意改成软约束。惩罚系数过小会容忍危险违反，过大则可能导致病态数值问题。工程实现应同时报告目标值、最大约束违反量和求解时间，而不是只报告代价下降。

## 8.8 梯度与 Hessian

对可微标量函数 $`f:\mathbb R^n\to\mathbb R`$ ，梯度（Gradient）为

```math
\nabla f(x)=
\begin{bmatrix}
\frac{\partial f}{\partial x_1}&\cdots&
\frac{\partial f}{\partial x_n}
\end{bmatrix}^{\mathsf T}\in\mathbb R^n.
```

在欧氏空间和标准内积下，梯度给出局部上升最快的方向，因此 $`-\nabla f`$ 是下降方向。Hessian 矩阵为

```math
H(x)=\nabla^2f(x)\in\mathbb R^{n\times n},
\qquad
H_{ij}=\frac{\partial^2f}{\partial x_i\partial x_j},
```

它描述局部曲率。若二阶偏导连续，则 Hessian 对称。

二阶 Taylor 展开为

```math
f(x+\Delta x)\approx
f(x)+\nabla f(x)^\mathsf T\Delta x
+\frac12\Delta x^\mathsf TH(x)\Delta x.
```

令该局部二次模型的梯度为零，可得到 Newton 步

```math
H(x)\Delta x=-\nabla f(x).
```

若 $`H\succ0`$ ，该步是局部二次模型的唯一极小点；若 Hessian 不定，Newton 方向可能反而上升，因而需要阻尼、线搜索或信赖域机制。实际计算通常求解线性方程，而不是显式计算 $`H^{-1}`$ 。

对非线性最小二乘

```math
f(x)=\frac12\sum_i\|r_i(x)\|_{W_i}^2,
\qquad
\|r\|_W^2=r^\mathsf TWr,
```

设 $`J_i=\frac{\partial r_i}{\partial x}`$ ，则

```math
\nabla f=\sum_iJ_i^\mathsf TW_ir_i,
```

```math
\nabla^2f
=\sum_i\left(J_i^\mathsf TW_iJ_i
+\sum_j (W_ir_i)_j\nabla^2r_{i,j}\right).
```

Gauss–Newton 方法忽略残差的二阶项，用 $`J^\mathsf TWJ`$ 近似 Hessian；当残差较小或模型近似线性时通常有效。仓库机器人的位姿估计、标定和轨迹拟合常具有这一结构。数值微分实现简单但受步长和尺度影响；解析微分与自动微分通常更准确。若变量位于旋转流形上，导数还必须相对于局部切空间定义，不能直接把旋转矩阵的九个元素当成彼此独立的欧氏变量。

<a id="ch8-sec9"></a>
## 8.9 Lagrange 乘子

考虑仅含等式约束的问题：

```math
\min_x f(x)
\quad\text{s.t.}\quad h(x)=0,
```

其中 $`x\in\mathbb R^n`$ ， $`h:\mathbb R^n\to\mathbb R^m`$ 。定义 Lagrange 函数

```math
\mathcal L(x,\nu)=f(x)+\nu^\mathsf Th(x),
```

其中 $`\nu\in\mathbb R^m`$ 是 Lagrange 乘子。若约束 Jacobian

```math
J_h(x)=\frac{\partial h}{\partial x}\in\mathbb R^{m\times n}
```

在候选点具有适当的满秩性质，则一阶必要条件为

```math
\nabla f(x^\star)+J_h(x^\star)^\mathsf T\nu^\star=0,
\qquad
h(x^\star)=0.
```

几何上，可行方向 $`\delta x`$ 满足 $`J_h\delta x=0`$ 。在约束极值点，目标梯度不能沿任何可行方向继续下降，因此它必须位于约束法向量张成的空间内。乘子给出了各约束法向量组合的系数。若约束退化或梯度线性相关，乘子可能不唯一，简单的一阶条件也可能失去判别力。

乘子还具有灵敏度解释。若约束写为 $`h(x)=b`$ ，在正则条件下，最优值对 $`b`$ 的局部变化率与乘子相关；具体符号取决于 Lagrange 函数采用 $`h(x)-b`$ 还是 $`b-h(x)`$ 。因此乘子常被称为影子价格（Shadow Price）：它衡量稍微放宽某项约束能够改善多少目标值。

在机器人轨迹优化中，离散动力学

```math
x_{k+1}-F(x_k,u_k)=0
```

对应一组乘子。这些乘子在最优控制中与协态变量密切相关。约束动力学中的接触力也会以类似乘子出现，但二者不能不加区分：优化乘子首先是约束最优性条件中的对偶变量，只有在特定物理建模和符号约定下，才可解释为实际约束力。

<a id="ch8-sec10"></a>
## 8.10 KKT 条件

对一般约束问题

```math
\begin{aligned}
\min_x\quad & f(x)\\
\text{s.t.}\quad & g_i(x)\le0,\quad i=1,\ldots,m,\\
& h_j(x)=0,\quad j=1,\ldots,p,
\end{aligned}
```

定义

```math
\mathcal L(x,\lambda,\nu)
=f(x)+\sum_{i=1}^m\lambda_i g_i(x)
+\sum_{j=1}^p\nu_j h_j(x).
```

Karush–Kuhn–Tucker 条件（KKT Conditions）包括：

```math
\nabla_x\mathcal L(x^\star,\lambda^\star,\nu^\star)=0
```

即驻点条件；

```math
g_i(x^\star)\le0,\qquad h_j(x^\star)=0
```

即原始可行性；

```math
\lambda_i^\star\ge0
```

即对偶可行性；以及

```math
\lambda_i^\star g_i(x^\star)=0
```

即互补松弛。

若 $`g_i(x^\star)<0`$ ，该约束未激活，互补松弛要求 $`\lambda_i^\star=0`$ ；若 $`\lambda_i^\star>0`$ ，则必有 $`g_i(x^\star)=0`$ ，说明约束恰好顶住最优解。反过来，激活约束的乘子仍可能为零，因此“激活”不等同于“对最优目标具有非零边际影响”。

在满足适当约束资格条件时，KKT 是局部最优的一阶必要条件；对于凸目标、凸不等式约束和仿射等式约束，在适当正则条件下，它也可成为全局最优的充分条件。对非凸问题，满足 KKT 可能只是局部极小点、极大点或鞍点，不能据此宣称全局最优。

仓库机器人靠近货架时，安全距离约束可能激活，其乘子反映继续靠近对目标的局部影响；当电机力矩达到上限时，输入约束乘子也会变为非零。QP、序列二次规划和模型预测控制中的许多线性方程组，实质上是在数值求解 KKT 系统。工程上还需检查约束缩放：以毫米表示的距离约束和以牛·米表示的力矩约束若尺度悬殊，会使 KKT 系统病态。

<a id="ch8-sec11"></a>
## 8.11 凸优化与非凸优化

集合 $`\mathcal C\subseteq\mathbb R^n`$ 若满足：对任意 $`x,y\in\mathcal C`$ 和 $`\alpha\in[0,1]`$ ，

```math
\alpha x+(1-\alpha)y\in\mathcal C,
```

则称为凸集（Convex Set）。函数 $`f`$ 在凸域上若满足

```math
f(\alpha x+(1-\alpha)y)
\le
\alpha f(x)+(1-\alpha)f(y),
```

则称为凸函数（Convex Function）。若 $`f`$ 二阶可微，凸域内

```math
\nabla^2f(x)\succeq0
```

是凸性的等价判据。凸优化要求目标函数凸、等式约束仿射，并且由 $`g_i(x)\le0`$ 定义的各不等式函数 $`g_i`$ 为凸函数。

凸优化最重要的性质是局部最优点也是全局最优点。严格凸目标在凸可行域上至多有一个最优解，但非严格凸问题仍可能存在一组全局最优解。线性规划和具有 $`H\succeq0`$ 的二次规划

```math
\min_z\ \frac12z^\mathsf THz+c^\mathsf Tz
\quad\text{s.t.}\quad Az=b,\; Gz\le d
```

都是典型凸问题。

机器人问题通常天然非凸：旋转空间不是普通欧氏凸集，机械臂正运动学是非线性的，障碍物外部区域往往非凸，不同绕障路径属于不同同伦类别，接触模式还引入离散选择。非凸问题中，初始化可能决定最终落入哪个局部解。算法返回“收敛”通常只表示一阶残差足够小，而不是找到了全局最优。

常用工程策略包括局部线性化、序列凸优化、多初值、信赖域、采样与优化结合，以及把部分离散决策显式写成混合整数问题。对仓库机器人，可先由全局路径搜索决定绕过货架的拓扑路线，再用连续轨迹优化改善平滑性和动力学可行性。把非凸问题近似成凸问题可以提高效率，但近似范围、碰撞检查和最终可行性必须单独验证。

<a id="ch8-sec12"></a>
## 8.12 坐标、几何空间与流形

几何对象与其坐标表示不是同一事物。一个空间点、刚体姿态或机械臂构型客观存在，而坐标只是相对于某个参考系和参数化方式给出的数字。同一个向量 $`v`$ 在坐标系 $`A`$ 与 $`B`$ 中分别写作 $`{}^Av`$ 和 $`{}^Bv`$ ，两者数值可能不同，但表示的是同一几何对象。坐标变换必须同时作用于状态、速度、力和不确定性，且其变换规律并不总相同。

机器人构型的集合称为构型空间（Configuration Space）。六个转动关节组成的机械臂，其局部关节坐标常写为

```math
q=(q_1,\ldots,q_6),
```

但若关节角按 $`2\pi`$ 周期识别，则每个转动关节更准确地位于圆周 $`S^1`$ 上，而不是无限直线 $`\mathbb R`$ 上。移动机械臂的整体构型可以概念性地写成

```math
\mathcal Q=SE(2)\times (S^1)^6,
```

其中 $`SE(2)`$ 表示平面刚体位姿。末端执行器所在的任务空间则通常与 $`SE(3)`$ 有关。构型空间与任务空间通过正运动学映射联系，但二者维度、约束和奇异性不同。

流形（Manifold）是在每个局部邻域内看起来像欧氏空间、但整体可能具有弯曲或拓扑结构的空间。对流形 $`\mathcal M`$ 上一点 $`x`$ ，局部速度和微小扰动位于切空间 $`T_x\mathcal M`$ 。坐标图把局部邻域映射到 $`\mathbb R^n`$ ，使微积分和数值算法可以在局部坐标中进行。不同坐标图可能存在奇异点，因此“参数化失效”不一定表示物理姿态本身奇异。

几何结构直接影响误差定义。例如角度误差不能在所有情况下用普通减法处理， $`179^\circ`$ 与 $`-179^\circ`$ 的实际差值应接近 $`2^\circ`$ ，而不是 $`358^\circ`$ 。姿态均值和协方差也不应机械地对旋转矩阵元素做欧氏平均；更合理的做法是在某个参考姿态的切空间中定义局部误差。忽略流形结构往往在小范围内暂时有效，却会在大角度、闭环累计或接近参数化奇异点时产生明显错误。

<a id="ch8-sec13"></a>
## 8.13 李群（Lie Group）与李代数（Lie Algebra）的基本思想

李群（Lie Group）同时具有群结构和光滑流形结构。群结构允许组合、单位元和求逆，流形结构允许定义连续运动与导数。三维旋转群为

```math
SO(3)=\{R\in\mathbb R^{3\times3}\mid
R^\mathsf TR=I,\ \det R=1\}.
```

其中群运算是矩阵乘法，单位元为 $`I`$ ，逆元为 $`R^{-1}=R^\mathsf T`$ 。刚体位姿群为

```math
SE(3)=
\left\{
T=
\begin{bmatrix}
R&p\\
0&1
\end{bmatrix}
\ \middle|\ 
R\in SO(3),\ p\in\mathbb R^3
\right\}.
```

位姿复合由矩阵乘法完成，但 $`SE(3)`$ 一般不可交换，即 $`T_1T_2\ne T_2T_1`$ 。

李代数（Lie Algebra）是李群在单位元处的切空间。对 $`SO(3)`$ ，其李代数

```math
\mathfrak{so}(3)=
\{\Omega\in\mathbb R^{3\times3}\mid \Omega^\mathsf T=-\Omega\}
```

由反对称矩阵组成。对 $`\omega=[\omega_1,\omega_2,\omega_3]^\mathsf T\in\mathbb R^3`$ ，帽算子定义为

```math
\omega^\wedge=
\begin{bmatrix}
0&-\omega_3&\omega_2\\
\omega_3&0&-\omega_1\\
-\omega_2&\omega_1&0
\end{bmatrix},
```

并满足 $`\omega^\wedge v=\omega\times v`$ 。指数映射把局部增量映射回群：

```math
R=\exp(\omega^\wedge),
```

对 $`\theta=\|\omega\|`$ 可写成 Rodrigues 公式

```math
\exp(\omega^\wedge)
=
I+\frac{\sin\theta}{\theta}\omega^\wedge
+\frac{1-\cos\theta}{\theta^2}(\omega^\wedge)^2.
```

当 $`\theta\to0`$ 时，应使用级数展开避免数值消减误差。

对 $`SE(3)`$ ，令运动增量 $`\xi=[\rho^\mathsf T,\phi^\mathsf T]^\mathsf T\in\mathbb R^6`$ ，其矩阵形式可写为

```math
\xi^\wedge=
\begin{bmatrix}
\phi^\wedge&\rho\\
0&0
\end{bmatrix},
\qquad
T=\exp(\xi^\wedge).
```

于是优化器可以在六维切空间中计算小增量，再通过指数映射更新位姿。例如左扰动和右扰动分别写为

```math
T_{\mathrm{new}}=\exp(\delta\xi^\wedge)T,
\qquad
T_{\mathrm{new}}=T\exp(\delta\xi^\wedge).
```

两种约定都正确，但对应不同参考坐标、Jacobian 和协方差定义，不能在同一推导中混用。伴随映射（Adjoint Map）用于在不同坐标表达之间变换运动增量：

```math
\mathrm{Ad}_T=
\begin{bmatrix}
R&p^\wedge R\\
0&R
\end{bmatrix},
```

这里采用 $`\xi=[\rho;\phi]`$ 的排列约定；若线速度与角速度顺序相反，矩阵块结构也会相应改变。

仓库机器人抓取货物时，相机观测、底盘位姿、机械臂末端位姿都通过 $`SE(3)`$ 变换链组合。李群形式能保持旋转矩阵正交性，并使局部线性化与优化更新具有清晰几何意义。但指数与对数映射并非全局一一对应，旋转接近 $`\pi`$ 时对数映射可能出现分支和数值敏感性。李群工具解决的是表示与局部运算结构，不会自动消除传感器噪声、运动学奇异或优化非凸性。

<a id="ch8-sec14"></a>
## 8.14 动力学、概率、优化：全书三条横向数学主线

动力学描述世界如何随时间变化。连续系统通常写为

```math
\dot x=f(x,u,w,t),
```

离散系统写为

```math
x_{k+1}=F(x_k,u_k,w_k),
```

其中 $`x`$ 是状态， $`u`$ 是控制输入， $`w`$ 是过程扰动。动力学不仅用于仿真，还规定哪些未来轨迹在物理上可达。Chapter 9 之后的建模、估计、规划与控制方法都会反复使用这一状态转移接口。

概率描述系统对状态、扰动和参数知道多少。给定控制与观测，自主系统维护信念状态（Belief State）

```math
b_k(x)=p(x_k=x\mid z_{1:k},u_{0:k-1}).
```

若用高斯近似，则信念可以由 $`(\mu_k,\Sigma_k)`$ 表示；若分布多峰，则可能需要粒子、混合模型或其他更丰富的表示。概率模型使机器人不仅报告“货物在这里”，还能够表达“货物可能在这些位置，以及各自可信程度”。

优化把目标、动力学和约束组合成行动问题。若忽略不确定性，可写为

```math
\min_{x_{0:N},u_{0:N-1}}
\phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k)
```

并满足离散动力学和安全约束。若显式考虑随机性，则目标可能变为期望风险

```math
\min_\pi\ 
\mathbb E\!\left[
\phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k)
\right],
```

其中 $`\pi`$ 是从信息或信念到动作的策略，而不再只是固定的开环输入序列。还可以加入机会约束（Chance Constraint）：

```math
\Pr\!\left(d(x_k,\mathcal O)\ge d_{\mathrm{safe}}\right)
\ge 1-\epsilon,
```

其中 $`\epsilon\in(0,1)`$ 是允许的风险上界。

三条主线在仓库移动机械臂中形成完整闭环：

1. 动力学根据当前状态和控制预测底盘与机械臂如何运动；
2. 概率推理融合轮速计、激光雷达和相机，更新机器人与货物的状态信念；
3. 优化根据当前信念、任务目标和安全约束生成轨迹与控制；
4. 几何结构保证位置、姿态、速度和不确定性在正确空间中组合；
5. 新动作改变真实世界，新观测再次进入估计过程。

一种常见工程简化是“先取状态估计均值，再按确定性模型优化”，即确定性等价近似。它计算高效，但会忽略控制对未来信息质量的影响，也可能低估低概率高损失事件。例如机器人为看清被遮挡货物而主动改变视角，本质上同时追求运动目标和信息增益，不能完全分解为独立的“先估计、后控制”。是否需要联合处理，取决于不确定性大小、任务风险和实时计算预算。

概率、优化和几何还共享同一局部计算结构：在流形切空间中定义误差，用 Jacobian 线性化模型，用协方差或信息矩阵加权残差，再通过 Newton、Gauss–Newton 或约束优化求解增量。理解这一共同结构，可以把状态估计、系统辨识、轨迹优化和模型预测控制看成不同信息流与约束结构下的统一计算问题，而不是互不相关的算法集合。

## 本章小结

本章建立了自主系统中三类关键数学语言。随机变量、分布、期望和协方差用于描述不确定性；条件概率和 Bayes 公式用于根据观测更新知识；最大似然与最大后验把统计推断转化为可计算的优化问题。目标函数、约束、梯度、Hessian、Lagrange 乘子和 KKT 条件给出了从问题建模到数值求解的一条完整链路，而凸性决定了局部解与全局解之间能够建立多强的保证。

几何部分强调：状态不是任意数字数组，位置、角度和刚体姿态存在于具有特定结构的空间中。流形提供局部欧氏化的语言，李群与李代数则把位姿复合、局部增量和微分运算统一起来。概率分布和优化增量若定义在错误的空间中，即使代数形式看似正确，也可能产生不可执行或不一致的结果。

贯穿全章的移动机械臂表明，完整闭环可压缩为一句话：动力学给出可达未来，概率表达对当前与未来的认知，优化在几何与物理约束下选择行动。下一章将以这些对象为接口，进一步进入系统模型的组织与推导：状态如何选取、动力学如何形成、噪声如何进入模型，以及这些模型如何服务于后续估计、规划和控制。
