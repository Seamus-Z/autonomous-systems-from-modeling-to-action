## 23.1 为什么碰撞自由不等于可执行

几何规划回答的是“机器人能否沿某条形状穿过环境”，动力学可行规划还要回答“机器人能否在有限时间内、依靠实际执行器沿该形状运动”。设机器人的构型为 $`q\in\mathcal Q`$ ，第 22 章得到的碰撞自由路径可以写成连续映射
```math
q:[0,1]\rightarrow\mathcal Q,\qquad q(s)\in\mathcal Q_{\mathrm{free}},
```
其中 $`s`$ 只是路径参数，并不代表时间。要把路径变成轨迹，必须选择单调非减的时间标定 $`s(t)`$ ，得到 $`q(t)=q(s(t))`$ 。这时速度、加速度分别为
```math
\dot q=q'(s)\dot s,\qquad
\ddot q=q''(s)\dot s^2+q'(s)\ddot s.
```
因此，同一条几何路径可以对应许多不同的运动；其中有些满足速度、加速度和执行器限制，有些则没有任何可行的时间标定。

仓储移动操作机器人提供了直接例子。二维栅格上的最短路径可能在货架拐角处包含折线尖点，而移动底盘若以非零速度通过尖点，就需要瞬时改变速度方向，对应无穷大的横向加速度。机械臂在构型空间中的直线也可能靠近运动学奇异位形，使末端的有限笛卡尔速度要求关节速度急剧增大。即使速度和加速度表面上可接受，满载机械臂伸出时的重力矩也可能超过关节电机额定转矩；底盘急转时还可能因轮地摩擦不足而侧滑，或因载荷重心偏移而倾覆。碰撞检测只排除了几何交叠，没有排除这些失效模式。

更完整的可执行性由系统动力学定义。连续时间模型通常写为
```math
\dot x=f(x,u),\qquad x(t)\in\mathcal X,\quad u(t)\in\mathcal U,
```
其中状态 $`x\in\mathbb R^n`$ 包含决定未来演化所需的变量，例如底盘位姿与速度、六轴机械臂关节角与关节速度；输入 $`u\in\mathbb R^m`$ 可以是轮端转矩、关节转矩、电机电流或低层速度指令。可行轨迹必须同时满足初始条件、动力学方程、状态约束、输入约束、碰撞约束和目标条件。若相机与 IMU 的估计误差不可忽略，还要给碰撞边界留出安全裕量，而不能把估计值当作精确真值。

动力学可行也不是“真实系统一定成功”的同义词。它总是相对于一个模型、参数范围和离散精度而言：刚体模型可能忽略轮胎变形，额定电机模型可能忽略温升降额，静态障碍物模型可能忽略人员运动。工程上应把规划结果理解为在明确假设下的名义可行解，再由反馈控制、在线估计、约束收紧和重规划处理有限扰动。动力学规划因此位于几何规划与控制之间：它把“存在一条路”推进为“存在一种受约束的时间演化”。

## 23.2 速度约束

速度约束限制状态变化的快慢，常写为
```math
\dot q_{\min}(q)\le \dot q\le \dot q_{\max}(q),
```
或更一般地写为 $`g_v(q,\dot q)\le 0`$ 。对于 $`d`$ 个自由度， $`q,\dot q\in\mathbb R^d`$ ；逐分量上下界适合关节和独立驱动轴，而范数约束 $`\|J(q)\dot q\|_2\le v_{\max}`$ 适合限制由雅可比矩阵 $`J(q)`$ 映射得到的末端线速度。速度边界可能依赖构型、载荷和运行模式，例如机械臂在人员附近采用较低速度，在接近奇异位形时也应降低末端速度要求。

对给定几何路径 $`q(s)`$ ，速度约束可转化为对路径速率 $`\dot s`$ 的限制。由 $`\dot q=q'(s)\dot s`$ ，第 $`i`$ 个关节满足
```math
\dot q_{i,\min}\le q_i'(s)\dot s\le \dot q_{i,\max}.
```
在规定 $`\dot s\ge 0`$ 时，每个非零的 $`q_i'(s)`$ 都给出一个关于 $`\dot s`$ 的区间，所有区间的交集才是该路径位置上的允许速率。若交集为空，说明即使暂时不考虑加速度和输入，这条路径也无法以指定方向通过；若 $`q_i'(s)=0`$ ，对应关节的速度约束在该点不限制 $`\dot s`$ ，但仍可能通过加速度项产生影响。

移动底盘的速度约束通常不是单一的平移速度上限。对差速底盘，若左右轮角速度为 $`\omega_L,\omega_R`$ ，轮半径为 $`r`$ ，轮距为 $`b`$ ，则理想无滑动关系为
```math
v=\frac r2(\omega_R+\omega_L),\qquad
\omega=\frac r b(\omega_R-\omega_L),
```
其中 $`v`$ 是车体纵向速度， $`\omega`$ 是偏航角速度。因此轮速矩形约束 $`|\omega_L|,|\omega_R|\le\omega_{\max}`$ 在 $`(v,\omega)`$ 平面中形成一个菱形可行域，而不是两个互不相关的上下界。仓储机器人若以最大线速度行驶，就不能同时实现最大转向角速度。六轴机械臂也有类似耦合：末端速度由 $`J(q)\dot q`$ 决定，不能仅凭末端速度上限判断每个关节是否可行。

速度约束适用于伺服器能较准确跟踪速度指令、且瞬态动力学不是主要瓶颈的情形，但它不能替代加速度和转矩约束。把任意路径“整体放慢”通常能够缓解速度限制，却未必能解决重力矩、静摩擦、坡道保持或最小飞行速度等问题。对需要在规定时间窗内完成拣选的机器人，过度放慢还会违反任务时限。因而速度约束既是安全边界，也是时序资源约束，必须与后续的加速度、输入和任务调度共同处理。

## 23.3 加速度约束

加速度约束描述速度能够以多快的速率改变，常写为
```math
\ddot q_{\min}(q,\dot q)\le \ddot q\le \ddot q_{\max}(q,\dot q),
```
其中 $`\ddot q\in\mathbb R^d`$ 。对沿几何路径的运动，
```math
\ddot q=q''(s)\dot s^2+q'(s)\ddot s.
```
第一项是由路径曲率与当前速率产生的加速度，第二项是沿路径加速或减速产生的加速度。即使 $`\dot s`$ 保持不变，只要路径弯曲， $`q''(s)\dot s^2`$ 也不会消失；这正是尖锐拐角不能以非零速度无代价通过的数学原因。

对平面底盘沿曲率为 $`\kappa`$ 的路径行驶，法向加速度近似为
```math
a_\perp=v^2\kappa.
```
若轮地摩擦或载荷稳定性给出 $`|a_\perp|\le a_{\perp,\max}`$ ，则弯道速度必须满足
```math
|v|\le \sqrt{\frac{a_{\perp,\max}}{|\kappa|}}.
```
仓储移动操作机器人在机械臂收拢时允许较大的横向加速度，而抓取高处周转箱并伸臂运输时，重心升高、支撑多边形内的稳定裕量减小， $`a_{\perp,\max}`$ 应相应降低。这里的上界依赖载荷质量、重心、地面附着系数和底盘姿态，不能永久固定为一个与任务无关的常数。

机械臂的加速度边界既来自电机能力，也来自被搬物体和结构安全。过大的关节加速度会放大惯性力，引起末端物品滑移、减速器冲击和视觉图像运动模糊。若相机安装在腕部，曝光期间的角加速度还会降低特征跟踪质量；若 IMU 用于状态估计，强振动可能使模型噪声假设失效。在许多系统中还要限制跃度 $`j=\dddot q`$ ，以避免加速度命令不连续。加速度有界并不自动意味着跃度有界，因此分段常加速度轨迹虽然动力学上可能可行，却可能不适合直接发送给真实伺服器。

加速度约束只有在所采用的坐标和模型层级明确时才有意义。关节加速度上限、末端笛卡尔加速度上限和底盘车体系加速度上限不能直接混用，它们通过雅可比矩阵及其导数联系：
```math
\ddot p=J(q)\ddot q+\dot J(q,\dot q)\dot q,
```
其中 $`p`$ 是末端任务空间坐标。靠近奇异位形时，满足笛卡尔加速度要求可能需要很大的关节加速度。工程上必须说明限制施加在哪个空间、参数是否随载荷变化，以及是否已经包含控制跟踪和估计延迟所需的裕量。

## 23.4 输入约束

输入约束直接限制执行器能够施加的作用。机械系统常用二阶动力学
```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+d(q,\dot q)=B(q)u,
```
其中 $`M(q)\in\mathbb R^{d\times d}`$ 是质量矩阵， $`C(q,\dot q)\dot q`$ 表示科里奥利与离心项， $`g(q)\in\mathbb R^d`$ 是重力项， $`d`$ 汇总摩擦及其他已建模作用， $`B(q)\in\mathbb R^{d\times m}`$ 是输入映射， $`u\in\mathbb R^m`$ 是控制输入。全驱动六轴机械臂通常有 $`m=d=6`$ 且 $`B`$ 可逆；无人机和带被动关节的机构则可能欠驱动，不能独立指定所有广义加速度。

最简单的输入集合是盒约束
```math
\mathcal U=\{u\mid u_{\min}\le u\le u_{\max}\},
```
但真实电机的可用转矩经常依赖转速、电压、温度和持续时间。以直流电机的简化模型为例，
```math
\tau=k_t i,\qquad V=Ri+k_e\omega,
```
其中 $`\tau`$ 为转矩， $`i`$ 为电流， $`V`$ 为端电压， $`\omega`$ 为电机角速度， $`R`$ 为电阻， $`k_t,k_e`$ 分别为转矩与反电动势常数。电流限制约束转矩，电压限制使高速时可用转矩下降，热限制又区分短时峰值与持续输出。规划若只采用恒定额定转矩上限，可能生成短时间仿真可行、连续搬运时却过热降额的轨迹。

输入约束与加速度约束不能简单互换。由动力学可知，在给定 $`(q,\dot q)`$ 时，输入集合通过
```math
\ddot q=M(q)^{-1}\!\left(B(q)u-C(q,\dot q)\dot q-g(q)-d(q,\dot q)\right)
```
映射成状态相关的可行加速度集合。六轴机械臂水平伸展并托举重物时，大部分肩关节转矩已经用于抵消重力，可供加速的余量很小；同一关节在垂直下垂构型中则可能拥有更大余量。移动底盘在平地和坡道上的可用纵向加速度也不同。由此可见，一个与状态无关的 $`\ddot q_{\max}`$ 只能是保守近似，不能表达全部执行器物理。

还要区分“命令输入”和“物理输入”。若规划器输出轮速而底层控制器实际通过电流闭环产生轮端转矩，那么轮速不是任意可瞬时设定的物理控制量。将它作为输入需要假设底层速度环足够快、误差有界且不发生饱和；否则应把轮速纳入状态，把转矩或加速度作为规划输入。输入模型越接近硬件，预测越可靠，但计算代价和参数辨识要求也越高。工程上应选择与规划时域、动态强度和低层接口相匹配的模型，而不是一味追求最高复杂度。

## 23.5 非完整约束

非完整约束是对允许瞬时速度方向的约束，但它通常不能积分成仅关于构型的位置约束。其 Pfaff 形式为
```math
A(q)\dot q=0,
```
其中 $`A(q)\in\mathbb R^{k\times d}`$ ，每一行排除一个不可实现的瞬时速度分量。若约束能够化为 $`h(q)=0`$ ，它就是完整约束；若不能，则称为非完整约束。非完整并不意味着某个位置永远不可达，而是意味着到达该位置必须通过一系列受限方向上的运动组合。

对平面差速底盘，构型为 $`q=(x,y,\theta)^\top`$ ，理想纯滚动、无侧滑条件为
```math
-\sin\theta\,\dot x+\cos\theta\,\dot y=0.
```
它禁止车体横向瞬时速度。等价的控制模型为
```math
\dot x=v\cos\theta,\qquad
\dot y=v\sin\theta,\qquad
\dot\theta=\omega,
```
其中控制量为纵向速度 $`v`$ 和角速度 $`\omega`$ 。底盘能够通过前进、转向、倒车等动作到达横向位置，却不能像全向平台那样立即侧移。因此，在二维占据栅格中连接两个位置的直线段，若没有同时规定可实现的朝向演化，就不一定是可执行路径。

非完整约束会改变局部连接器、距离度量和采样规划的扩展方式。欧氏距离接近的两个状态可能需要较长机动才能相连，例如窄巷中同一位置但朝向相反的两种底盘状态。规划器若用直线插值连接它们，会在插值过程中产生横向滑动。适合的局部运动应来自满足约束的运动原语、解析曲线或动力学前向仿真。对允许前进和倒车且曲率受限的车辆，可使用相应的曲率受限曲线作为近似连接；对只允许前进的系统，可达集合会进一步不对称。

非完整模型也有适用边界。差速底盘的无侧滑假设在低速、平整且附着良好的仓库地面上较合理，但急转、湿滑地面或轮胎变形会造成偏离。四足机器人在稳定落足阶段可近似受接触约束，但换足会引入离散模式切换；无人机不受轮式非完整约束，却因推力方向和姿态动力学而欠驱动。机械臂关节通常不具有同类非完整运动学约束，但移动底盘与机械臂组成联合系统后，底盘约束仍会限制整体构型速度。规划模型必须对应具体运动机制，不能把“机器人”统一简化为可在任意方向平移的质点。

<a id="ch23-sec6"></a>
## 23.6 状态空间中的规划

几何规划通常在构型空间 $`\mathcal Q`$ 中搜索，而动力学规划在状态空间 $`\mathcal X`$ 中搜索。对于二阶机械系统，典型状态为
```math
x=
\begin{bmatrix}
q\\ \dot q
\end{bmatrix}\in\mathbb R^{2d},
\qquad
\dot x=
\begin{bmatrix}
\dot q\\ f_q(q,\dot q,u)
\end{bmatrix}.
```
仓储移动操作机器人若联合规划底盘与六轴机械臂，可令 $`q=(x_b,y_b,\theta_b,q_1,\ldots,q_6)`$ ，并加入相应速度。状态维数随之显著增加，但这是区分“在货架前静止”和“以高速冲向货架”的必要代价：两者构型相同，未来可行运动却完全不同。

障碍物约束也要从构型空间提升到状态空间。静态环境中的几何碰撞仍主要由 $`q`$ 决定，可写成 $`q\in\mathcal Q_{\mathrm{free}}`$ ；速度、稳定性、电机温度和电池状态等约束则依赖完整状态。于是
```math
\mathcal X_{\mathrm{free}}
=
\{x\mid q(x)\in\mathcal Q_{\mathrm{free}},\ g_x(x)\le 0\}.
```
目标通常是状态集合 $`\mathcal X_{\mathrm{goal}}`$ ，而不是单一位姿。例如机器人到达拣选工位时不仅要位姿误差小，还应满足 $`|\dot q|\le\varepsilon_v`$ ，否则它只是高速穿过目标区域。若机械臂要立即执行视觉抓取，目标集合还可能要求相机朝向、关节奇异性指标和振动水平满足阈值。

离散时间实现把动力学写为
```math
x_{k+1}=F_{\Delta t}(x_k,u_k),
```
其中 $`F_{\Delta t}`$ 是在时间步长 $`\Delta t`$ 内对连续动力学积分得到的转移映射。一个有限时域规划问题可表述为寻找状态—输入序列，使其满足
```math
x_0=x_{\mathrm{init}},\quad
x_{k+1}=F_{\Delta t}(x_k,u_k),\quad
x_k\in\mathcal X_{\mathrm{free}},\quad
u_k\in\mathcal U,\quad
x_N\in\mathcal X_{\mathrm{goal}}.
```
若还考虑性能，可最小化 $`J=\phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k)\Delta t`$ ，其中 $`\ell`$ 可组合时间、能耗、离障碍距离和动作平滑度， $`\phi`$ 为终端代价。可行性与最优性应分开：首先要找到满足全部约束的轨迹，然后才有资格比较代价。

状态空间规划依赖马尔可夫假设，即当前状态包含预测未来所需的信息。若电机温度、柔性变形或载荷摆动会显著影响未来，却未被纳入状态，模型就不再闭合。相机与 IMU 提供的通常是状态估计 $`\hat x`$ 及协方差 $`P`$ ，不是精确状态；名义规划可在 $`\hat x`$ 上运行，但应通过障碍膨胀、约束收紧或概率安全条件处理不确定性。若必须直接规划信念分布，则问题进入更高维的信念空间规划，本章方法只能作为其确定性或名义内核。

## 23.7 Forward Simulation

前向仿真是从当前状态和候选输入出发，按照动力学预测未来状态的过程。给定 $`x_0`$ 、分段常值输入 $`u(t)=u_k`$ 以及持续时间 $`\Delta t`$ ，状态传播写为
```math
x_{k+1}=\Phi_{\Delta t}(x_k,u_k)
=x_k+\int_{0}^{\Delta t}f(x(t),u_k)\,dt.
```
一般情况下积分没有闭式解，需要数值积分。显式欧拉法使用 $`x_{k+1}=x_k+\Delta t f(x_k,u_k)`$ ，计算便宜但误差较大；四阶 Runge–Kutta 法通过多个中间斜率提高精度，适合较平滑的动力学。含刚性接触、强阻尼或高速电机动态时，可能需要更稳定的积分方法。

动力学规划中的一次扩展通常由“采样控制—选择持续时间—前向传播—检查约束”组成。对差速底盘，可以采样 $`(v,\omega)`$ 或轮端转矩；对六轴机械臂，可以采样关节转矩向量；然后从树节点状态开始仿真若干步，得到一段状态轨迹和终点。只有整段轨迹都满足输入、速度、稳定性与碰撞约束，扩展才有效。检查终点无碰撞并不足够，因为机器人可能在两个离散时刻之间穿过货架。工程上应采用足够密的中间检查、连续碰撞检测，或依据最大速度和几何间隙自适应选择步长。

时间步长同时影响正确性和搜索效率。过大的 $`\Delta t`$ 会掩盖快速动态、漏检碰撞，并使控制采样产生粗糙的可达集合；过小则增加积分和碰撞检测成本，树的每次扩展距离也可能过短。可根据系统时间常数、最大角速度、障碍物尺度和控制更新周期设定上界。例如底盘在窄货架通道中应采用比开阔区更细的碰撞检查；机械臂靠近障碍物或奇异位形时也应缩短积分步长。数值积分误差本身应小于规划预留的安全裕量，否则“可行”只反映离散器误差。

前向仿真的可信度受模型误差限制。轮地摩擦、负载质量和电机常数不精确时，可对多个参数样本传播，或用有界扰动模型
```math
\dot x=f(x,u)+w,\qquad w\in\mathcal W
```
估计可达管，而不是只保留单条名义轨迹。更轻量的做法是降低使用上限、扩大障碍物并缩短开环执行时间。前向仿真不是现实的替代品；它是把动力学约束嵌入搜索的计算接口，其结果仍要由状态估计和反馈控制持续校正。

<a id="ch23-sec8"></a>
## 23.8 Kinodynamic RRT

Kinodynamic RRT 将第 22 章的快速探索随机树扩展到受动力学约束的状态空间。树中每个节点存储状态 $`x`$ ，每条边存储一段控制 $`u(t)`$ 、持续时间和前向仿真得到的轨迹。一次基本迭代可以概括为：

1. 在状态空间或目标区域采样 $`x_{\mathrm{rand}}`$ ；
2. 从树中选择一个候选节点 $`x_{\mathrm{near}}`$ ；
3. 采样若干控制及持续时间，并从 $`x_{\mathrm{near}}`$ 前向仿真；
4. 选取约束可行且最接近 $`x_{\mathrm{rand}}`$ 的传播结果；
5. 将新状态、控制和轨迹加入树，直至进入目标集合或耗尽预算。

这里最困难的环节往往不是随机采样，而是“近”的定义和可达方向。状态距离可以写成加权形式
```math
d(x_1,x_2)^2
=(q_1-q_2)^\top W_q(q_1-q_2)
+(\dot q_1-\dot q_2)^\top W_v(\dot q_1-\dot q_2),
```
其中 $`W_q,W_v`$ 为半正定权重矩阵，用于统一位置、角度和速度的量纲。然而该距离未必反映真实到达时间：非完整或欠驱动系统的可达性具有方向性，从 $`x_1`$ 到 $`x_2`$ 的代价可能不同于反向代价。可用线性化系统的局部可控性度量、近似最优控制代价或离线学习的到达时间改进节点选择，但这些近似也只在相应模型和局部范围内可靠。

对仓储机器人，可为底盘采样有限的 $`(v,\omega)`$ 组合与持续时间，例如直行、缓转、急转和制动；机械臂则可使用经过限幅的关节加速度或转矩原语。与在高维输入空间完全均匀采样相比，运动原语能显著提高有效扩展比例，但会限制搜索所能表达的轨迹。目标偏置可让一部分样本落在拣选工位的目标状态集合中；控制持续时间也应兼顾开阔区快速探索和狭窄区精细机动。若底盘与机械臂强耦合，例如伸臂状态会改变稳定性，就不能始终把二者独立规划后再拼接。

Kinodynamic RRT 的理论性质取决于控制采样、传播器、状态度量和系统可控性等条件。对满足一定正则性且局部可达的系统，随机控制传播可以获得概率完备性的相应结果，即存在具有正安全裕量的可行轨迹时，采样次数增加会提高找到解的概率；这不意味着有限时间内保证成功，也不保证原始 RRT 渐近最优。窄通道、目标状态速度要求严格、输入维数高或可行轨迹裕量接近零时，算法仍可能极其缓慢。若需要持续改善代价，可采用带重连或批处理思想的动力学变体，但其有效性依赖能否构造可靠的局部连接或代价下界。

实际系统还需要对树边进行复核和执行管理。找到目标后，应重新以更精细积分、连续碰撞检测和完整执行器模型验证整条轨迹，并进行时间参数平滑。执行时只应下发有限前缀，根据相机、编码器和 IMU 更新的状态重新定位或重规划。RRT 树给出的是开环候选轨迹，不是抵抗轮滑、负载误差和人员闯入的反馈策略；忽略这一边界，会把搜索成功错误地等同于任务成功。

<a id="ch23-sec9"></a>
## 23.9 Differential Flatness

微分平坦性是一种利用少量输出及其有限阶导数参数化系统状态和输入的结构性质。对系统 $`\dot x=f(x,u)`$ ，若存在平坦输出 $`y\in\mathbb R^m`$ ，使得
```math
x=\alpha(y,\dot y,\ldots,y^{(r)}),\qquad
u=\beta(y,\dot y,\ldots,y^{(r+1)}),
```
则称系统在相应区域内微分平坦。这里平坦输出的维数通常等于输入维数 $`m`$ ， $`\alpha`$ 和 $`\beta`$ 是代数映射。规划时可先设计较低维且光滑的 $`y(t)`$ ，再重构完整状态和控制，从而绕开逐时刻显式积分动力学的部分困难。

差速底盘的运动学模型在非零速度区间可用平面位置 $`y=(x,y)`$ 作为平坦输出。令
```math
v=\sqrt{\dot x^2+\dot y^2},\qquad
\theta=\operatorname{atan2}(\dot y,\dot x),
```
并可由二阶导数得到
```math
\omega=\dot\theta
=\frac{\dot x\ddot y-\dot y\ddot x}{\dot x^2+\dot y^2}.
```
因此，只要规划一条具有足够连续导数的平面曲线，就能恢复底盘朝向、线速度和角速度。速度、角速度与加速度约束可转化为对输出导数的约束。仓储通道中的中心线可以先表示为分段多项式或样条，再通过调整时间和控制点满足曲率与轮速限制。

这一参数化存在明确边界。当 $`\dot x=\dot y=0`$ 时，朝向公式和 $`\omega`$ 的分母出现奇异性；机器人原地转向也不能由仅含位置的普通光滑曲线直接表达。工程上需要分段处理静止、原地转向与平移模式，或选择其他局部参数化。若进一步加入轮胎侧滑、轮端转矩动态、电机电流和载荷摆动，简单运动学平坦模型未必仍然有效。微分平坦性是系统结构，不是任意非线性系统都具备的通用技巧；六轴刚性机械臂的完整转矩动力学也不能在所有情况下简单地以末端位姿作为全局平坦输出。

平坦性对无人机尤其有代表性：在常见刚体模型和非退化推力条件下，位置与偏航角可作为一组平坦输出，姿态、总推力和角速度可由其高阶导数恢复。这解释了为何无人机轨迹常通过分段多项式并最小化高阶导数来生成。对仓储移动操作机器人，平坦参数化更适合作为局部轨迹生成器或搜索中的动力学连接器：几何规划给出通道拓扑，平坦输出曲线负责生成光滑、可重构的运动，再由完整动力学和输入约束复核。若重构后的转矩、稳定性或碰撞约束不满足，就必须修改输出轨迹，而不能仅凭“系统平坦”宣称可执行。

<a id="ch23-sec10"></a>
## 23.10 规划与控制开始融合的地方

当规划显式包含状态、输入和动力学时，它已经与最优控制共享同一数学骨架。有限时域问题可写为
```math
\begin{aligned}
\min_{\{x_k,u_k\}}\quad&
\phi(x_N)+\sum_{k=0}^{N-1}\ell(x_k,u_k)\\
\text{s.t.}\quad&
x_{k+1}=F_{\Delta t}(x_k,u_k),\\
&x_k\in\mathcal X_{\mathrm{free}},\quad u_k\in\mathcal U,\\
&x_0=\hat x,\quad x_N\in\mathcal X_{\mathrm{goal}}.
\end{aligned}
```
规划侧关注跨越障碍、选择拓扑通道和到达远期目标，控制侧关注根据实时误差修正输入；二者的差异更多体现在时域、信息更新频率和求解方法，而不是问题变量本身。Kinodynamic RRT 通过采样构造可行状态—控制序列，下一章的轨迹优化则会直接调整这些变量以降低代价和约束违反。

开环轨迹必须配合反馈才能执行。设规划得到名义轨迹 $`(x^\star(t),u^\star(t))`$ ，实际控制可写为
```math
u(t)=u^\star(t)+K(t)\bigl(\hat x(t)-x^\star(t)\bigr),
```
其中 $`K(t)`$ 是时变反馈增益， $`\hat x`$ 来自编码器、相机和 IMU 的状态估计。反馈会使实际状态分布在名义轨迹周围的一个“管”内，因此规划时不能让名义机器人贴着障碍物或输入饱和边界运动。若能估计跟踪误差集合 $`\mathcal E`$ ，可把允许的名义状态收紧为
```math
x^\star(t)\in\mathcal X_{\mathrm{safe}}\ominus\mathcal E,
```
其中 $`\ominus`$ 表示 Pontryagin 差。其含义是：对任意允许误差，真实状态仍留在安全集合中。

滚动时域方法进一步模糊了规划与控制的界线。系统每次以最新估计 $`\hat x_k`$ 为初始状态，求解一段有限时域轨迹，只执行第一个控制或短前缀，然后重新估计并求解。这种模型预测控制式机制能够处理缓慢模型偏差和新出现的障碍物，但并不自动保证全局可达：短时域优化可能被局部极小值困住，也可能看不到货架尽头的死路。因此常用全局几何或采样规划器提供通道、参考轨迹或终端区域，再由局部动力学优化器和反馈控制器跟踪。全局层负责“走哪边”，局部层负责“当前怎样安全地走”。

仓储移动操作机器人的完整接口可以分为几个闭环层次：任务层给出货位、抓取和交付目标；几何规划层排除不可穿越的通道；动力学规划层生成满足底盘、机械臂和电机约束的状态—输入轨迹；局部控制层处理轮滑、关节摩擦和载荷误差；估计层持续融合相机、编码器与 IMU；安全监控层独立检查急停距离、人员侵入和执行器故障。若人员突然进入通道，控制器只能在当前制动能力允许的范围内响应，所以规划器必须提前保证停止距离和可避让空间，而不能把所有安全责任推给反馈。

这种融合仍有必要边界。规划模型若过于粗糙，控制器可能没有足够输入余量补偿误差；规划模型若过于复杂，在线求解又可能错过实时期限。合理设计不是让规划器复制全部硬件细节，而是保留会改变可达性、约束活跃性和安全裕量的动态，并把高频、局部且可稳定补偿的效应交给控制器。下一章将在这一状态—输入表示上进一步研究轨迹优化：如何把一条初始可行或近似可行的运动，转化为更平滑、更省时、更节能且具有约束裕量的轨迹。

## 本章小结

动力学可行规划把几何路径提升为带时间、状态和输入的受约束运动。碰撞自由路径只说明构型能够穿过环境；要成为可执行轨迹，还必须满足速度、加速度、执行器输入、非完整运动学和状态目标等条件。速度决定状态变化的速率，加速度联系路径曲率与时间标定，输入约束通过动力学形成状态相关的可行加速度集合，非完整约束则限制系统能够瞬时运动的方向。

在算法上，规划空间由构型空间扩展为状态空间，系统转移通过前向仿真获得。Kinodynamic RRT 以控制传播代替任意直线连接，能够搜索满足动力学的轨迹，但其效率和理论性质依赖状态度量、控制采样、局部可达性与数值精度。微分平坦性在具备相应结构时，可把部分系统的状态和输入重构问题转化为平坦输出曲线设计，但必须处理奇异点、模型层级和额外约束。

贯穿仓储移动操作机器人的主线表明，可行性总是相对于模型、估计精度和安全裕量而言。规划提供名义状态—输入轨迹，反馈控制与在线估计负责在扰动下维持执行，重规划负责响应环境变化。由此，动力学规划成为几何搜索与最优控制的接口；下一章将以本章定义的状态、输入、动力学和约束为基础，讨论如何通过轨迹优化系统地改善可行解。
