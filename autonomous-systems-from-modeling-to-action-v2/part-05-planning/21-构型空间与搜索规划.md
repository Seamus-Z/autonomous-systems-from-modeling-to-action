## 21.1 规划到底决定什么

规划的任务，是在当前状态估计、目标描述、环境模型和系统约束之间，构造一项关于未来的可执行决策。这里的“决策”可能是一条几何路径、一条带时间参数的轨迹，也可能是随着观测变化而改变动作的策略。若机器人状态记为 $`x\in\mathcal X`$ ，控制输入为 $`u\in\mathcal U`$ ，环境信息为 $`m`$ ，目标为 $`\mathcal G`$ ，则规划器可抽象为
```math
\Pi:(\hat x_0,\Sigma_0,m,\mathcal G)\mapsto \xi,
```
其中 $`\hat x_0`$ 与 $`\Sigma_0`$ 分别来自状态估计模块，表示当前状态均值及协方差； $`\xi`$ 是规划结果。几何规划中的 $`\xi`$ 常是一条构型路径，动态规划中的 $`\xi`$ 可以是一条状态—控制轨迹，而不确定性显著时，它还可能是反馈策略。规划并不直接保证电机准确跟踪，也不负责从相机和 IMU 原始数据中恢复状态；它处于估计与控制之间，把“机器人在哪里、环境是什么样”变成“接下来应朝哪里运动”。

以仓储移动操作机器人为例，高层任务“从货架 A 取出料箱并送到工作台 B”至少会分解为若干规划决策：移动底盘在货架通道中的通行路线、底盘停止位姿、六轴机械臂避开货架隔板的关节路径，以及抓取后携物返回时的新碰撞几何。底盘规划可在 $`\mathrm{SE}(2)`$ 上进行，机械臂规划通常在六维关节空间中进行；若把底盘和机械臂联合规划，构型维数可达到 $`3+6=9`$ 。电机电流、关节速度与制动距离通常由后续轨迹生成和控制层处理，但若它们决定某段路径能否安全执行，就必须以速度、加速度或动力学约束的形式反馈到规划问题中。

一个规划结果至少应区分**可行性**与**最优性**。可行解 $`\xi`$ 必须满足边界条件和约束，
```math
\xi\in\mathcal F,
```
其中 $`\mathcal F`$ 是所有合法未来运动组成的集合；最优规划则进一步求解
```math
\xi^\star=\arg\min_{\xi\in\mathcal F}J(\xi),
```
代价 $`J`$ 可以综合路程、时间、能耗、风险与操作余量。工程上通常先保证安全可行，再在有限计算预算内改善代价。规划算法的保证依赖于模型假设：地图是否静态、障碍是否已知、状态是否可观测、执行误差是否有界。若仓库中有人突然进入通道，基于静态地图得到的最短路不再是无条件有效的承诺，系统还需要在线感知、局部重规划和安全控制共同闭环。

<a id="ch21-sec2"></a>
## 21.2 起点、目标与约束

规划问题首先要明确起点与目标。起点通常不是理想的精确点，而是估计得到的构型 $`\hat q_s`$ ，必要时还带有不确定性 $`\Sigma_q`$ 。目标既可以是单一构型 $`q_g`$ ，也可以是目标集合 $`\mathcal Q_g\subseteq\mathcal C`$ 。对于六轴机械臂，“末端到达料箱把手位姿”并不唯一决定六个关节角；更自然的目标是
```math
\mathcal Q_g=\left\{q\in\mathcal C\mid
d_{\mathrm{SE}(3)}\!\left(T_{WE}(q),T_{WE}^{\mathrm{des}}\right)\le \varepsilon,\;
q\in\mathcal Q_{\mathrm{valid}}
\right\},
```
其中 $`T_{WE}(q)\in\mathrm{SE}(3)`$ 是由正运动学得到的末端位姿， $`d_{\mathrm{SE}(3)}`$ 是兼顾平移和旋转的位姿误差度量， $`\varepsilon`$ 是任务容差。目标集合允许规划器在多个逆运动学解中选择碰撞余量更大或路径更短的一个。

约束决定了问题的真实类型。几何约束包括障碍物、关节限位和闭链关系；运动学约束包括轮式底盘的非完整约束；动力学约束则涉及质量、力矩、摩擦和接触。一般连续时间模型可写为
```math
\dot x(t)=f(x(t),u(t)),\qquad
x(t)\in\mathcal X_{\mathrm{free}},\quad
u(t)\in\mathcal U,\quad
g(x(t),u(t))\le 0.
```
这里 $`x\in\mathbb R^n`$ 是状态，可能同时包含构型 $`q`$ 与速度 $`\dot q`$ ； $`u\in\mathbb R^m`$ 是电机转矩、轮速命令或推力； $`g`$ 汇总速度、加速度、力矩和安全距离等不等式。若只检查 $`q(t)`$ 是否无碰撞，就是几何路径规划；若还要求状态满足 $`f`$ ，则属于运动动力学规划，不能把几何最短路直接视为可执行轨迹。

仓储底盘可近似为差速模型
```math
\dot x=v\cos\theta,\qquad
\dot y=v\sin\theta,\qquad
\dot\theta=\omega,
```
因此它不能瞬时横移。若仅在二维占据栅格上允许向任意相邻单元移动，所得路径可能穿越位置上可达、姿态和曲率上却不可执行的狭窄区域。类似地，机械臂关节路径即使无碰撞，也可能要求电机产生超过上限的转矩。简化约束能够降低计算量，但其适用边界必须明确：只有当后续轨迹参数化和控制器确实能把几何路径转化为满足硬件极限的运动时，这种分层规划才成立。

不确定性也应被视为约束的一部分。若底盘定位误差近似服从 $`\mathcal N(\hat q,\Sigma_q)`$ ，可以通过膨胀障碍物、缩小可行通道或施加概率约束
```math
\Pr\!\left(q(t)\in\mathcal C_{\mathrm{free}}\right)\ge 1-\delta
```
来限制碰撞风险，其中 $`\delta`$ 是允许的风险水平。但协方差只在估计模型和分布假设成立时有意义；动态遮挡、错误数据关联或地图漂移可能造成非高斯误差。安全系统不能仅凭一个名义概率约束替代急停、速度限制与在线障碍检测。

## 21.3 Path 与 Trajectory

路径（path）描述“经过哪些构型”，不规定“何时经过”。一条构型路径可定义为连续映射
```math
p:[0,1]\rightarrow\mathcal C,\qquad
p(0)=q_s,\quad p(1)\in\mathcal Q_g,
```
其中参数 $`s\in[0,1]`$ 只表示路径进度，并非物理时间。若对所有 $`s`$ 都有 $`p(s)\in\mathcal C_{\mathrm{free}}`$ ，则它在几何上无碰撞。路径长度可写成
```math
L[p]=\int_0^1\sqrt{p'(s)^\mathsf T W(p(s))p'(s)}\,ds,
```
其中 $`W\in\mathbb R^{d\times d}`$ 是正定度量矩阵， $`d=\dim\mathcal C`$ 。 $`W`$ 用于平衡不同自由度的尺度，例如不能直接把底盘的一米平移与机械臂的一弧度转动当作相同代价。

轨迹（trajectory）则显式依赖时间：
```math
q:[0,T]\rightarrow\mathcal C,\qquad
\dot q(t),\ddot q(t)\ \text{按需要存在并有界}.
```
路径可通过单调时间标定 $`s(t)`$ 转化为轨迹 $`q(t)=p(s(t))`$ ，并有
```math
\dot q=p'(s)\dot s,\qquad
\ddot q=p''(s)\dot s^2+p'(s)\ddot s.
```
因此同一条路径可以快走或慢走，但路径曲率、关节速度上限和动力学约束会共同限制 $`\dot s`$ 与 $`\ddot s`$ 。仓储机械臂绕过货架立柱的关节路径可能完全相同，而空载和抓取重箱时必须采用不同的时间参数，因为负载改变了惯量、重力矩和允许制动距离。

这种区分具有明确的工程意义。搜索规划通常先在构型空间求离散路径，再进行平滑与时间参数化，最后交给底盘速度控制器或关节伺服器跟踪。相机和 IMU 持续更新状态估计，执行层根据估计偏差修正运动；如果偏差超过路径走廊的容许范围，则应触发减速或重规划。几何路径规划适用于环境近似静态、系统低速、路径能够被后处理成可行轨迹的场景。对于高速无人机、跳跃四足机器人或需要精确控制接触力的操作，时间与动力学从一开始就是核心变量，单纯的无碰撞路径并不足够。

此外，路径最短不等于轨迹最快。贴近障碍物的折线路径虽然几何长度小，却可能因曲率过大而需要频繁减速；稍长但平滑、宽裕的通道反而具有更短执行时间和更高鲁棒性。因此工程代价常写成
```math
J=\alpha L+\beta T+\gamma E+\eta R,
```
其中 $`L`$ 、 $`T`$ 、 $`E`$ 、 $`R`$ 分别表示长度、时间、能耗与风险，系数应具有一致量纲或经过归一化。权重反映任务偏好，而不是算法自动发现的客观真理；改变货物脆弱程度、剩余电量或人机共存等级时，权重和约束也应随之改变。

## 21.4 工作空间与构型空间

工作空间描述机器人实体所处的物理空间，通常是二维或三维欧氏空间；构型空间（configuration space，简称 C-space）则由完整确定机器人几何姿态所需的广义坐标组成，记为 $`\mathcal C`$ 。对于平面全向底盘，构型可写为 $`q=(x,y,\theta)\in\mathrm{SE}(2)`$ ；对于六轴转动关节机械臂， $`q=(q_1,\ldots,q_6)`$ ，若各关节可连续旋转，则局部结构类似六维环面 $`\mathbb T^6`$ ，若有关节限位，则是该空间的受限子集。联合移动操作机器人可写为
```math
q=(x_b,y_b,\theta_b,q_1,\ldots,q_6)\in \mathrm{SE}(2)\times\mathcal Q_{\mathrm{arm}}.
```
构型维数等于独立自由度数，而不是机器人在工作空间中占据的几何维数。

正运动学把构型映射到机器人各刚体的工作空间位姿。对第 $`i`$ 个连杆，
```math
T_{Wi}=F_i(q)\in\mathrm{SE}(3),
```
其占据区域可记为 $`\mathcal A_i(q)\subset\mathbb R^3`$ 。规划并不是只移动末端点，而是要求所有连杆、底盘外壳、传感器支架以及已抓取物体在运动过程中均合法。机械臂末端在笛卡尔空间画一条直线时，中间连杆可能扫过货架；反之，关节空间中的简单插值也可能使末端大幅绕行。工作空间适合表达货架、墙面和抓取位姿，构型空间适合表达机器人整体运动和关节限位，两者通过运动学映射相连而不能互相替代。

构型空间还带有拓扑和度量结构。角度 $`\theta`$ 与 $`\theta+2\pi`$ 表示同一姿态，因此角度差应使用
```math
\Delta\theta=\mathrm{wrap}(\theta_2-\theta_1)\in(-\pi,\pi],
```
而不能直接作普通实数减法。对联合构型，可采用加权距离
```math
d(q_a,q_b)=
\sqrt{
w_p\|\Delta p_b\|_2^2+
w_\theta\Delta\theta_b^2+
\sum_{i=1}^{6}w_i\Delta q_i^2
}.
```
权重可依据最大速度、典型运动范围或能耗尺度设置。若忽略周期性和单位差异，最近邻、启发函数和路径长度都会产生系统性偏差。

构型空间方法的代价是维数增长。若每个自由度离散为 $`k`$ 个值， $`d`$ 维空间最多产生 $`k^d`$ 个网格点；六轴机械臂按每轴 $`100`$ 个角度采样就有 $`10^{12}`$ 种组合，联合底盘后更加不可枚举。这就是维数灾难。低维、规则环境适合显式栅格与搜索；高维机械臂通常需要利用稀疏图、分层规划或下一章讨论的采样方法。构型空间仍然是统一语言，但不意味着所有构型空间都应被均匀离散。

## 21.5 障碍构型空间

工作空间障碍物记为 $`\mathcal O\subset\mathbb R^2`$ 或 $`\mathbb R^3`$ ，机器人在构型 $`q`$ 时占据的区域记为 $`\mathcal A(q)`$ 。障碍构型空间定义为
```math
\mathcal C_{\mathrm{obs}}
=
\left\{
q\in\mathcal C\mid
\mathcal A(q)\cap\mathcal O\neq\varnothing
\right\}.
```
它把“具有体积的机器人与障碍物相交”转化为“构型点落入禁止区域”。若有多个连杆和多个障碍物，则
```math
\mathcal C_{\mathrm{obs}}
=
\bigcup_{i,j}
\left\{
q\mid \mathcal A_i(q)\cap\mathcal O_j\neq\varnothing
\right\},
```
还应并入机器人自碰撞、关节限位和其他非法构型。一个工作空间中的简单矩形货架，在机械臂六维构型空间中可能形成弯曲且难以显式表示的高维区域。

对平移但不旋转的刚体，障碍构型空间可以用 Minkowski 和构造。设机器人局部形状为 $`\mathcal A`$ ，参考点位置为 $`p`$ ，则
```math
\mathcal C_{\mathrm{obs}}=\mathcal O\oplus(-\mathcal A),
```
其中 $`\oplus`$ 表示 Minkowski 和， $`-\mathcal A=\{-a\mid a\in\mathcal A\}`$ 。工程上这等价于按机器人外形膨胀障碍物，然后把机器人参考点视为质点。仓储底盘若近似圆盘，只需把货架边界向外膨胀底盘半径；若还要考虑定位误差和跟踪误差，可进一步增加安全裕量 $`r_{\mathrm{safe}}`$ 。但矩形底盘在不同朝向下的有效膨胀不同，若始终用外接圆，会更保守并可能错误地判定窄通道不可通过。

抓取会改变 $`\mathcal C_{\mathrm{obs}}`$ 。机械臂抓住料箱后，占据区域应改为
```math
\mathcal A_{\mathrm{carry}}(q)
=
\mathcal A_{\mathrm{robot}}(q)\cup
T_{WO}(q)\mathcal A_{\mathrm{object}},
```
其中 $`T_{WO}(q)`$ 是被抓物体相对世界的位姿。若规划器仍使用空载机械臂模型，手臂本体虽然不碰货架，料箱却可能撞上隔板。相机支架、线缆和末端工具也需要按风险等级建模；不重要的小结构可通过安全包络近似，而不能在没有误差界的情况下任意忽略。

障碍构型空间依赖地图、标定和状态估计的正确性。静态、已知且刚性的障碍允许离线预处理；移动人员、叉车和摆动物体则使其成为随时间变化的集合 $`\mathcal C_{\mathrm{obs}}(t)`$ 。仅在静态 C-space 中找到路径，不能保证未来时刻无碰撞。对动态障碍需要加入时间维、预测模型或反应式安全层，而且预测范围越远，不确定性通常越大。

<a id="ch21-sec6"></a>
## 21.6 自由空间

自由构型空间定义为合法构型的集合：
```math
\mathcal C_{\mathrm{free}}
=
\mathcal C\setminus\mathcal C_{\mathrm{obs}},
```
并隐含关节限位、闭链约束和任务约束等条件。几何路径规划的基本问题是：给定 $`q_s\in\mathcal C_{\mathrm{free}}`$ 与目标集合 $`\mathcal Q_g\subseteq\mathcal C_{\mathrm{free}}`$ ，是否存在连续路径 $`p`$ ，使
```math
p(0)=q_s,\qquad p(1)\in\mathcal Q_g,\qquad
p(s)\in\mathcal C_{\mathrm{free}},\ \forall s\in[0,1]?
```
其本质是判断起点与某个目标构型是否位于自由空间的同一连通分量。障碍物不只是增加代价，还可能从拓扑上切断可达性。

仓储通道展示了自由空间“宽度”的重要性。底盘中心线可以穿过某条窄缝，并不表示真实系统能稳定通过。定义构型到障碍的间隙
```math
\rho(q)=\inf_{q'\in\mathcal C_{\mathrm{obs}}}d(q,q'),
```
路径最小间隙为 $`\rho_{\min}[p]=\min_s\rho(p(s))`$ 。可在代价中加入风险项，例如
```math
J_{\mathrm{clear}}[p]
=
\int_0^1\frac{1}{\rho(p(s))+\epsilon}\,ds,
```
其中 $`\epsilon>0`$ 防止数值发散。这样搜索会在路程与安全余量之间折中，而不是无条件贴着货架走。对机械臂，较大构型空间间隙也常意味着对关节跟踪误差和标定误差更鲁棒。

自由空间通常只是在名义模型下定义的。若构型误差集合为 $`\mathcal E`$ ，一种鲁棒做法是要求
```math
q\oplus\mathcal E\subseteq\mathcal C_{\mathrm{free}},
```
即机器人可能出现的全部实际构型都保持合法。等价地，可以把障碍构型空间按误差界膨胀。该方法假设误差具有可信的有界集合；若只知道协方差，则可依据置信椭球近似，但这给出的是概率意义而非绝对保证。安全裕量过小会提高碰撞风险，过大则可能人为封闭本来可通行的空间。

还需区分几何自由与动态可达。四足机器人站立时某个机身位姿可能无碰撞，却未必存在保持平衡和接触约束的动作到达它；无人机在障碍间的某个位置也可能因速度过高而无法及时制动。因此 $`\mathcal C_{\mathrm{free}}`$ 是几何规划的基础，却不自动等于可控状态集合。若速度、接触或动力学不可忽略，应在状态空间 $`\mathcal X`$ 中定义安全集合，并使用相应的运动动力学规划方法。

<a id="ch21-sec7"></a>
## 21.7 碰撞检测

碰撞检测是判断某个构型或一段运动是否合法的计算过程。对单个构型 $`q`$ ，离散碰撞检测返回
```math
\mathrm{Collision}(q)=
\begin{cases}
1,&\exists i,j:\mathcal A_i(q)\cap\mathcal O_j\neq\varnothing,\\
0,&\text{其他}.
\end{cases}
```
完整检测包括机器人与环境碰撞、自碰撞、已抓物体碰撞，以及按任务定义的禁入区域。典型实现先做宽阶段，用轴对齐包围盒、空间哈希或包围体层次结构快速排除相距较远的几何体，再在窄阶段使用凸体距离、三角网格相交或符号距离函数精确判断。

规划器更常需要验证一条边，而不是一个端点。设局部连接为 $`q(\tau)`$ ， $`\tau\in[0,1]`$ ，连续碰撞检测要验证
```math
q(\tau)\in\mathcal C_{\mathrm{free}},\qquad\forall\tau\in[0,1].
```
简单实现以步长 $`\Delta\tau`$ 采样，但如果机器人在两个样本之间穿过薄障碍，就会发生漏检。保守步长可依据几何运动上界确定：若机器人表面点的最大位移不超过当前距离下界，则该区间安全。实际系统也可使用扫掠体、保守推进或专门的连续碰撞算法。采样越密计算越贵，越疏则风险越高，必须根据最小障碍尺度、关节运动引起的连杆位移和安全等级设定。

对六轴机械臂，关节空间中的小变化并不一定对应工作空间中的小位移。局部有
```math
\delta x_i\approx J_i(q)\,\delta q,
```
其中 $`J_i(q)\in\mathbb R^{6\times6}`$ 是第 $`i`$ 个连杆或特征点的几何雅可比。靠近长臂末端的点可能因基座关节的小角度变化而移动很远，因此边验证分辨率不能只按 $`\|\delta q\|`$ 固定设置。仓储机器人抓取长料箱后，这种杠杆效应更明显，应把载荷几何加入扫掠范围计算。

碰撞模型本身也有边界。三角网格可能存在孔洞，传感器地图具有体素分辨率，机械臂标定和底盘定位存在误差，柔性线缆更难精确建模。因此“检测为无碰撞”只表示在当前模型、数值容差和检测分辨率下未发现相交。工程系统通常结合几何膨胀、最小距离阈值、低速通过窄区、实时相机监测和硬件急停，避免把单次离线检测当作绝对安全证明。

<a id="ch21-sec8"></a>
## 21.8 连续空间如何离散成图

搜索算法作用于图，而机器人运动发生在连续空间。离散化的目标是构造图
```math
G=(V,E),
```
其中节点 $`v\in V`$ 代表一个自由构型或一个自由区域，边 $`(u,v)\in E`$ 代表可由局部运动连接的两个节点。边必须经过碰撞检测，边权 $`c(u,v)\ge 0`$ 可表示距离、时间、能耗或风险。起点和目标可以直接对应节点，也可以通过临时连接边接入图中。这样，连续规划问题被近似成从 $`v_s`$ 到目标节点集合 $`V_g`$ 的图搜索问题。

对二维仓储底盘，最常见的是占据栅格。每个自由栅格中心作为节点，可采用四邻域或八邻域连接；若边长为 $`r`$ ，水平和竖直边代价可设为 $`r`$ ，对角边代价设为 $`\sqrt2r`$ 。若必须考虑朝向，可使用状态格
```math
v=(i,j,k),\qquad
x=ir,\ y=jr,\ \theta=k\Delta\theta,
```
并用符合底盘运动学的运动基元连接节点，而不是任意改变姿态。对于差速底盘，运动基元可由若干固定的 $`(v,\omega)`$ 在短时间内积分得到；这样图上的边更接近可执行运动，但状态数也随朝向离散数量增长。

离散化分辨率决定计算量与表达能力。设第 $`l`$ 个自由度划分为 $`N_l`$ 个取值，则节点数上界为
```math
|V|\le\prod_{l=1}^{d}N_l.
```
缩小网格间距可以表达更窄的通道，却以指数速度增加高维空间的节点数。固定分辨率图通常只能提供**分辨率完备性**：如果在该离散图上存在连接，完备搜索会找到它；如果连续空间存在路径但通道比网格尺度更窄，图上仍可能不存在解。因而“搜索失败”可能表示真正不可达，也可能只是离散化过粗。

工程上还可使用导航网格、可见图、距离变换图或预先构造的路线网络。仓库通道结构规则时，可将通道中心线与交叉口压缩为稀疏拓扑图，再在局部栅格中精化；机械臂高维关节空间则很少适合均匀网格。离散图还应随地图变化更新：相机发现临时托盘堵塞通道后，可以将受影响节点和边置为无效并重新搜索。图模型假设边的有效性和代价在搜索期间足够稳定；如果环境快速变化，则需要增量搜索、时空图或在线局部规划，而不是反复执行静态最短路后盲目跟踪。

<a id="ch21-sec9"></a>
## 21.9 BFS

广度优先搜索（breadth-first search，BFS）按从起点出发的边数逐层扩展节点。算法维护先进先出队列、已访问集合和父节点映射：先将 $`v_s`$ 入队，每次取出队首节点 $`u`$ ，检查其未访问邻居 $`v`$ ，记录 $`\mathrm{parent}(v)=u`$ 后入队；首次访问目标时，可沿父节点反向恢复路径。若图中所有边代价相同，BFS 找到的路径具有最少边数，等价于最小总代价。

令层数 $`d(v)`$ 表示起点到节点 $`v`$ 的最少边数，则 BFS 的扩展顺序满足非递减的 $`d(v)`$ 。在单位边权下，每次从第 $`k`$ 层生成的未访问节点必然属于第 $`k+1`$ 层，因此目标第一次被发现时，不可能还存在边数更少但尚未处理的路径。使用邻接表时，其时间复杂度为
```math
O(|V|+|E|),
```
空间复杂度为 $`O(|V|)`$ 。这一结论假设图可有限表示，并且节点判重正确；在隐式生成的巨大图中，内存往往先于计算时间成为限制。

在四邻域、每步代价均为一的仓储栅格中，BFS 可以求最少栅格步数路线，适合验证连通性或构造距离层。它也可用于相机生成的局部二值占据图，在较小窗口内快速寻找绕障方向。但八邻域中对角移动的物理长度为 $`\sqrt2`$ 倍，若仍把所有边视为单位代价，BFS 优化的是步数而非真实距离；加入地面坡度、拥堵风险或转向代价后，边权更不相同，BFS 不再保证所需意义下的最优。

BFS 的适用边界因此很清楚：非负且完全相同的边代价、可承受的图规模，以及不需要利用目标方向信息。它通常会向所有方向均匀扩张，在大地图上访问大量与目标无关的区域。BFS 是理解搜索完备性和层次扩展的基线，但对于有权图应使用 Dijkstra，对于已知目标且可构造启发函数的情形则可使用 A*。

<a id="ch21-sec10"></a>
## 21.10 Dijkstra

Dijkstra 算法求解非负边权图上的单源最短路径。对每个节点维护暂定距离
```math
g(v)=\text{当前已知的从 }v_s\text{ 到 }v\text{ 的最小代价},
```
初始化 $`g(v_s)=0`$ ，其余为 $`+\infty`$ 。算法使用按 $`g`$ 排序的优先队列，每次取出 $`g`$ 最小的节点 $`u`$ ，并对每条出边执行松弛：
```math
\text{若 }g(u)+c(u,v)<g(v),\quad
g(v)\leftarrow g(u)+c(u,v),
```
同时更新父节点。目标节点从优先队列中以最小键值正式弹出时，即可终止并恢复最优路径。

算法正确性的核心是边权满足 $`c(u,v)\ge0`$ 。当 $`u`$ 是尚未确定节点中 $`g`$ 最小者时，任何经其他未确定节点再到达 $`u`$ 的路径都不会更便宜，因此 $`g(u)`$ 已是最优值。若存在负边权，这一论证失效，已经确定的节点可能后来被改善。机器人规划中的距离、时间和能耗通常非负，风险奖励若被建模为负数则可能破坏条件；更稳妥的做法是重构为非负代价，或选择适合负权问题的其他算法。采用二叉堆和邻接表时，典型复杂度为
```math
O\big((|V|+|E|)\log|V|\big).
```

仓储底盘可把边代价设计为
```math
c(u,v)=
\alpha\,\ell(u,v)+
\beta\,t_{\mathrm{turn}}(u,v)+
\gamma\,r(u,v),
```
其中 $`\ell`$ 是边长度， $`t_{\mathrm{turn}}`$ 是转向或速度调整代价， $`r`$ 是贴近货架、通过人流区或低质量地图区域的风险项。只要各项组合后非负，Dijkstra 就能找到离散图上的最小总代价路径。它还能一次性计算起点到所有可达节点的距离场，适用于多目标选择，例如比较多个可用工作台或多个机械臂停靠位。

Dijkstra 的最优性只针对给定图和给定边权。离散图遗漏连续空间中的通道时，图上的最优不等于连续问题的最优；边权若只估算长度，也不会自动优化执行时间。算法还会以代价波前向四周扩展，即使目标方向已知，也可能处理大量无关节点。A* 通过加入对剩余代价的估计，把这种无方向的波前转化为朝目标集中的搜索。

<a id="ch21-sec11"></a>
## 21.11 A*

A* 为每个节点定义评价函数
```math
f(v)=g(v)+h(v),
```
其中 $`g(v)`$ 是从起点到 $`v`$ 的当前已知代价， $`h(v)`$ 是从 $`v`$ 到目标的剩余代价估计。算法每次从优先队列中选择 $`f`$ 最小的节点扩展，并使用与 Dijkstra 相同的松弛操作。若 $`h(v)=0`$ ，A* 就退化为 Dijkstra；若 $`h`$ 能准确反映目标方向，搜索会集中在可能构成优质路径的区域。

设真实最优剩余代价为
```math
h^\star(v)=\min_{\pi:v\leadsto V_g}\sum_{(i,j)\in\pi}c(i,j).
```
若启发函数满足可采纳性
```math
0\le h(v)\le h^\star(v),
```
则它从不高估未来代价。在有限图、非负边权和正确实现的条件下，树搜索形式的 A* 可据此保证最优；对会重复到达同一节点的图搜索，更常要求一致性
```math
h(u)\le c(u,v)+h(v)
```
对每条边成立。一致性相当于启发函数满足图上的三角不等式，使沿路径的 $`f`$ 值不下降，并允许节点弹出后直接关闭。若仅可采纳但不一致，实现应允许重新打开已关闭节点，否则可能失去最优性。

在二维八邻域栅格中，若边权仅为几何长度，可使用对角距离
```math
h(v)=
r\left[
\max(|\Delta i|,|\Delta j|)
+(\sqrt2-1)\min(|\Delta i|,|\Delta j|)
\right].
```
它等于忽略障碍时的最短八邻域距离，因此不会超过含障碍情况下的真实代价。对联合移动操作机器人，简单欧氏距离可能难以同时处理底盘平移、朝向和六个关节；可用与边权相容的加权距离下界，或在简化问题上预计算代价到达图。启发函数必须下界真实边代价，而不是仅凭几何直觉选取。

A* 的完备性和最优性同样受问题边界约束。有限图、正的最小边代价和至少一条可行路径时，标准 A* 能找到解；无限图或零代价环需要额外条件。它的最坏情况仍可能扩展指数数量的节点，并不能消除高维构型空间的维数灾难。工程上还会使用加权 A*
```math
f(v)=g(v)+w\,h(v),\qquad w>1,
```
以更快获得可行路径，但此时通常放弃严格最优性；在合适条件下可以得到次优界。实时仓储系统可以先用较大 $`w`$ 快速出路，再在剩余时间内降低权重改善路径，但任何性能承诺都必须与所用变体的具体条件一致。

<a id="ch21-sec12"></a>
## 21.12 Heuristic

启发函数（heuristic）不是随意的“朝目标猜测”，而是对最优未来代价 $`h^\star(v)`$ 的可计算近似。设计它的基本方法，是把原问题放松为一个更容易求解的问题：删除障碍、忽略部分约束、降低维数或允许更强的运动能力。因为放松问题的可行路径集合更大，其最优代价通常不高于原问题，从而自然得到可采纳下界。例如在占据栅格中忽略障碍后的欧氏距离
```math
h(v)=\|p(v)-p_g\|_2
```
是以路径长度为边权时的下界；若边代价按时间计，并且底盘最大平移速度为 $`v_{\max}`$ ，则
```math
h(v)=\frac{\|p(v)-p_g\|_2}{v_{\max}}
```
是理想条件下的最短时间下界。

启发函数必须与状态、边权和运动模型匹配。差速底盘若必须在目标处达到指定朝向，可组合平移与旋转的下界，例如
```math
h(v)=\max\left(
\frac{\|p-p_g\|_2}{v_{\max}},
\frac{|\mathrm{wrap}(\theta-\theta_g)|}{\omega_{\max}}
\right).
```
取最大值是因为平移和旋转可能同时发生；若直接求和，则在允许同时运动的模型下可能高估真实时间。机械臂可使用关节速度界构造
```math
h(q)=\max_i\frac{|\mathrm{wrap}(q_i-q_{g,i})|}{\dot q_{i,\max}},
```
但这只适用于目标关节构型已知且各关节能够并行运动的简化模型。若目标是末端位姿集合，应对候选逆运动学解取最小值，或者使用可证明的工作空间下界。

更强的启发函数常来自预计算。仓库布局大体固定时，可从目标工作台在静态二维地图上反向执行 Dijkstra，得到忽略临时障碍和机械臂姿态后的距离表 $`D_{\mathrm{static}}(x,y)`$ ，并将其作为高维搜索的启发项。模式数据库也可只保留部分关节，精确求解低维子问题，再把其代价作为原问题下界。多个可采纳启发函数 $`h_1,\ldots,h_k`$ 可以组合为
```math
h(v)=\max_i h_i(v),
```
该结果仍不超过 $`h^\star(v)`$ ，且通常比任意单个下界更有信息；直接相加则只有在各代价部分互不重叠等额外条件下才安全。

启发函数越接近 $`h^\star`$ ，通常扩展节点越少，但计算每次 $`h`$ 的成本也越高。若计算一个复杂启发值所需时间超过它节省的搜索时间，整体性能反而下降。地图更新还可能使预计算距离失效：删除约束后得到的旧距离通常仍可作为下界，但若边权尺度或运动模型改变，就需重新验证。工程设计应同时测量节点扩展数、启发计算时间、内存和重规划延迟，而不能仅凭“更准确”判断启发函数更好。

<a id="ch21-sec13"></a>
## 21.13 从搜索理解“未来代价”

图搜索可以从动态规划的角度理解。对任意节点 $`v`$ ，最优未来代价满足 Bellman 最优性方程
```math
V^\star(v)=
\begin{cases}
0,&v\in V_g,\\[2mm]
\displaystyle\min_{u\in\mathrm{Succ}(v)}
\left[c(v,u)+V^\star(u)\right],&v\notin V_g.
\end{cases}
```
其中 $`V^\star(v)`$ 就是从 $`v`$ 到目标的真实最小代价，也即上一节的 $`h^\star(v)`$ 。这条递推说明，一条全局最优路径的任意后缀也必须是相应子问题的最优路径。Dijkstra 通过有序传播逐渐确定代价，A* 则利用启发函数近似尚未计算出的 $`V^\star`$ ，优先扩展“已经付出的代价加上预计未来代价”较小的节点。

从这一视角看， $`g`$ 与 $`h`$ 分别对应过去和未来：
```math
f(v)=
\underbrace{g(v)}_{\text{已发生、可精确累计}}
+
\underbrace{h(v)}_{\text{尚未发生、需要估计}}.
```
只按 $`g`$ 搜索是 Dijkstra，它对未来没有方向性偏好；只贪心选择 $`h`$ 最小的节点，则可能为了表面上接近目标而走入死胡同。A* 在二者之间保持结构化平衡。仓储底盘面对 U 形货架时，贪心搜索可能持续靠近隔墙另一侧的目标，而 $`g+h`$ 会在确认绕行代价更优后选择远离目标的出口。这里的“未来代价”不是神秘直觉，而是由模型、边权和可证明下界共同定义的量。

如果环境、状态或目标发生变化，未来代价也会变化。相机检测到通道被托盘封锁后，相关边代价可设为无穷大；IMU 与轮速融合发现底盘位姿偏离原路径后，当前节点和 $`g`$ 的起点需要更新；抓取料箱后，机器人碰撞几何变化，原有图边可能失效。实际系统因此常采用滚动方式：执行一小段、更新估计与地图、重新评估剩余路径。重规划不是承认先前规划“错误”，而是对信息集变化作出的条件更新。

搜索方法的边界也由价值函数的表示方式决定。离散图可以明确枚举节点并精确累计边代价，但高维连续构型空间无法穷举；动态障碍还要求价值函数依赖时间，不确定性下则可能依赖信念状态 $`b(x)`$ 。下一步需要回答的问题是：当均匀离散过于昂贵时，能否只在连续自由空间中选择有限而有代表性的构型，并通过局部连接逐步建立可搜索结构。采样规划正是沿着这一接口展开：构型空间、自由空间、碰撞检测、边代价和目标集合保持不变，改变的是图从“预先规则离散”转为“按样本逐步生成”。

## 本章小结

本章从规划所决定的对象出发，区分了几何路径、时间轨迹与反馈策略，并把起点、目标集合、环境模型及运动约束统一写成可行性与最优性问题。工作空间用于描述货架、料箱和机器人实体，构型空间则以一个点表示完整机器人姿态；障碍构型空间把几何碰撞转化为禁止构型，自由空间中的连通性决定名义几何可达性。碰撞检测负责验证节点和边，但其结论始终依赖几何模型、检测分辨率及估计误差，必须结合安全裕量与在线感知解释。

将连续自由空间离散为带权图后，BFS、Dijkstra 与 A* 分别对应单位边权搜索、非负边权最短路和启发式最短路。启发函数是对最优未来代价的下界近似，其有效性依赖可采纳性、一致性及与边权模型的匹配。Bellman 方程进一步揭示了搜索的共同结构：当前位置的决策由一步代价与后续最优代价共同决定。

规则栅格在低维仓储导航中直观而有效，但节点数量会随构型维数指数增长，难以直接覆盖六轴机械臂或移动操作机器人的联合空间。下一章将在相同的构型空间与碰撞检测接口上，用采样生成稀疏图或树，讨论如何在高维连续自由空间中寻找可行路径，以及概率完备性、连接策略和采样偏置如何改变规划性能。
