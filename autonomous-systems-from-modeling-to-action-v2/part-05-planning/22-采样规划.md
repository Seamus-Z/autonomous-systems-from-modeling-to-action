## 22.1 为什么高维空间需要采样

上一章把机器人运动规划表述为构型空间中的可达性问题。设机器人的构型为 $`q\in\mathcal C`$ ，障碍物诱导出的碰撞区域为 $`\mathcal C_{\mathrm{obs}}`$ ，自由空间为

```math
\mathcal C_{\mathrm{free}}=\mathcal C\setminus\mathcal C_{\mathrm{obs}}.
```

规划器需要寻找连续路径 $`\sigma:[0,1]\rightarrow\mathcal C_{\mathrm{free}}`$ ，满足 $`\sigma(0)=q_{\mathrm{start}}`$ 、 $`\sigma(1)\in\mathcal X_{\mathrm{goal}}`$ 。这里 $`\mathcal X_{\mathrm{goal}}`$ 可以是单个目标构型，也可以是由末端位姿、抓取约束或容差定义的目标集合。对仓储移动操作机器人，若移动底盘采用平面位姿 $`(x,y,\theta)`$ ，六轴机械臂采用关节角 $`(q_1,\ldots,q_6)`$ ，则联合构型至少是九维变量；再加入升降轴、夹爪开度或可动货架状态后，维度还会继续增加。

规则网格在低维空间中直观有效，但其规模随维数呈指数增长。若每一维离散为 $`m`$ 个取值， $`d`$ 维网格包含 $`m^d`$ 个节点。即使每维只有 $`100`$ 个离散点，九维底盘—机械臂空间也需要 $`10^{18}`$ 个节点，显然无法显式建立。更重要的是，碰撞边界通常由复杂几何体的相交关系隐式定义，很难得到 $`\mathcal C_{\mathrm{obs}}`$ 的闭式表达。采样规划因此采用另一种信息获取方式：不完整地枚举空间，而是在若干构型上调用碰撞检测器，并用局部连接器检验相邻样本之间是否存在短的无碰路径。

设从分布 $`\mu`$ 中得到样本 $`q_i\sim\mu`$ ，采样规划器通常只需要三个基本接口：`Sample` 产生候选构型，`CollisionFree` 判断点或短路径是否碰撞，`Nearest/Near` 根据度量选择邻居。构型间距离可写为

```math
d_W(q,q')=\sqrt{(q-q')^\mathsf T W(q-q')},
```

其中 $`W\in\mathbb R^{d\times d}`$ 为正定权重矩阵。对含角度的构型，差值应取相应流形上的最短角差；对底盘与机械臂联合空间， $`W`$ 还需平衡米、弧度以及各关节对机器人几何包络的不同影响。该度量不只是实现细节：它决定“最近邻”、扩展方向和局部连接概率，因而会改变搜索效率。

采样方法的优势是避免显式构造高维自由空间，并能直接复用精确或近似的几何碰撞检测模块；其代价是解具有随机性，有限时间内找不到路径并不等价于路径不存在。它尤其适用于高维、几何复杂、可进行局部插值连接的问题，而不天然适用于强动力学约束、极窄通道或必须严格证明不可达的任务。仓库中的开阔通道和货架前操作区通常适合采样搜索，但插入料箱缝隙、穿过狭窄门洞时，采样分布与局部规划器将成为决定性因素。

## 22.2 Probabilistic Roadmap

Probabilistic Roadmap，简称 PRM，是一种先构建自由空间拓扑近似、再处理查询的多查询规划方法。其路图为图 $`G=(V,E)`$ ：顶点集合 $`V\subset\mathcal C_{\mathrm{free}}`$ 由无碰样本构成；若两个顶点足够接近，且局部规划器能够在它们之间构造无碰路径，则加入边 $`(q_i,q_j)\in E`$ 。对于新的起点和目标，规划器把它们连接到路图，再使用 Dijkstra 或 A* 搜索图路径。PRM 的核心不是重建自由空间的精确边界，而是以随机样本和局部边近似其连通结构。

典型构建过程是：采样 $`q_{\mathrm{rand}}`$ ，拒绝碰撞样本，将其加入 $`V`$ ；查询其 $`k`$ 个最近邻或半径 $`r_n`$ 内的邻居；对每个邻居调用局部规划器。最简单的局部路径是在坐标或流形上插值，

```math
q(s)=\mathrm{Interp}(q_i,q_j;s),\qquad s\in[0,1],
```

并沿路径执行离散或连续碰撞检测。边代价可取加权长度

```math
c(q_i,q_j)=\int_0^1
\sqrt{\dot q(s)^\mathsf T W\dot q(s)}\,\mathrm ds,
```

也可加入与障碍物距离、关节限位裕量或操作姿态有关的代价。离散碰撞检测的步长必须与机器人几何尺度和最小安全间隙相容，否则端点均无碰并不能保证边内部无碰；连续碰撞检测更可靠，但计算代价通常更高。

PRM 特别适合环境大体固定、查询频繁的场景。例如仓库货架布局在一个班次内保持不变，而机器人需要反复从不同通道口移动到不同拣选位。离线阶段可为底盘或机械臂工作区建立稠密路图，在线阶段只连接当前估计起点与目标。工程上常采用 Lazy PRM：先按距离加入候选边，只有当图搜索选中的路径实际使用某条边时才做昂贵的碰撞检测；若边无效，则删除该边并重新搜索。该策略在碰撞检测远贵于图搜索、而大量边永远不会被访问时很有效。

PRM 的适用前提是环境在路图生命周期内近似静态，局部连接器能在邻近构型间提供有意义的可行性判断，且采样能够覆盖相关自由空间。动态出现的托盘、人员或叉车会使已验证边失效，因此路图必须支持边的失效标记、局部修复或按环境版本重建。若机器人动力学使直线插值不可执行，几何 PRM 中的边只能视为路径候选，不能直接当作控制轨迹；若任务约束把可行构型限制在低维流形上，直接在环境空间均匀采样还可能以概率一错过该流形，需要使用约束采样或投影方法。

## 22.3 RRT

Rapidly-exploring Random Tree，简称 RRT，是一种从已知起点增量扩展搜索树的单查询方法。树 $`T=(V,E)`$ 初始仅含 $`q_{\mathrm{start}}`$ 。每次迭代采样 $`q_{\mathrm{rand}}`$ ，找到

```math
q_{\mathrm{near}}
=\arg\min_{q\in V} d(q,q_{\mathrm{rand}}),
```

再用扩展算子生成

```math
q_{\mathrm{new}}
=\mathrm{Steer}(q_{\mathrm{near}},q_{\mathrm{rand}},\eta),
```

其中 $`\eta>0`$ 是最大扩展尺度。若从 $`q_{\mathrm{near}}`$ 到 $`q_{\mathrm{new}}`$ 的局部路径无碰，则将新顶点和相应边加入树。当新节点进入目标集合，或可由局部规划器连接到目标时，沿父指针回溯得到一条路径。

RRT 的快速探索来自隐含的 Voronoi 偏置。树中位于未探索区域边界的节点往往拥有较大的 Voronoi 区域，因此均匀随机样本更可能把这些节点选为最近邻，树会自然向空旷区域伸展，而不必显式计算探索前沿。扩展尺度 $`\eta`$ 控制局部性：过大时，一次边验证容易跨越障碍物或窄通道；过小时，树节点数量和最近邻查询成本迅速增加。对平面移动底盘，可在 $`SE(2)`$ 上插值并处理航向角周期性；对六轴机械臂，应同时检查连杆与货架、料箱以及机器人自身的碰撞。

仓储拣选的一次性查询很适合 RRT。例如机器人已经停在货架前，需要从当前折叠姿态移动到某个抓取预备姿态。规划器可在六维关节空间中生长一棵树，并把末端接近方向满足容差的逆运动学解作为目标集合。若目标区域很小，常以概率 $`p_{\mathrm{goal}}`$ 直接选择目标样本，以概率 $`1-p_{\mathrm{goal}}`$ 做全局采样；这种目标偏置提高了收敛速度，但 $`p_{\mathrm{goal}}`$ 过大时会让树反复撞向同一障碍物。双向 RRT 则从起点和目标分别生长两棵树并尝试连接，通常能显著缩短高维几何问题的首次解时间。

基本 RRT 追求尽快找到任意可行路径，而不是优质路径。早期随机扩展形成的分支会永久决定节点的父子关系，因此所得路径常有折线多、长度大、离障碍物过近等问题。路径捷径化和样条平滑可以改善结果，但每次替换都必须重新验证碰撞，且平滑后仍不自动满足速度、加速度或力矩限制。RRT 的理论与工程效果还依赖最近邻度量、采样支持集、局部连接器和碰撞检测分辨率；在非完整底盘、无人机或四足机器人上，简单构型直线通常不是可执行运动，需要把 `Steer` 替换为满足系统运动约束的传播过程。

## 22.4 RRT*

RRT* 在 RRT 的增量探索基础上加入“择优父节点”和“重连”，使树能够随着样本增加持续改善路径代价。生成无碰的 $`q_{\mathrm{new}}`$ 后，算法不一定直接把 $`q_{\mathrm{near}}`$ 作为父节点，而是在邻域

```math
X_{\mathrm{near}}
=\{q\in V:d(q,q_{\mathrm{new}})\le r_n\}
```

中选择使累计代价最小的节点：

```math
q_{\mathrm{parent}}
=\arg\min_{q\in X_{\mathrm{near}}}
\left[J(q)+c(q,q_{\mathrm{new}})\right],
```

其中 $`J(q)`$ 是从起点到 $`q`$ 的树上代价， $`c`$ 是局部边代价。加入新节点后，算法还检查是否可通过 $`q_{\mathrm{new}}`$ 降低邻居的累计代价；若可以且新边无碰，就修改该邻居的父节点，并更新其后代代价。

在 $`d`$ 维欧氏型自由空间中，常用邻域半径具有形式

```math
r_n=\min\left\{\eta,\,
\gamma\left(\frac{\log n}{n}\right)^{1/d}\right\},
```

其中 $`n=|V|`$ ， $`\gamma>0`$ 是与自由空间体积、维数和理论下界有关的常数。也可以使用随 $`n`$ 增长的近邻数量 $`k_n=k_0\log n`$ 。邻域过小会失去足够的重连机会，过大则会导致大量局部连接和碰撞检测。高维时 $`(\log n/n)^{1/d}`$ 下降很慢，这表明理论上合适的邻域可能包含许多候选点，也解释了高维 RRT* 的计算压力。

对仓储移动操作机器人，可以把代价定义为联合路径长度、安全裕量和动作偏好的组合：

```math
J(\sigma)=
\int_0^1
\left(
\|\dot\sigma(s)\|_W
+\lambda\,\phi\!\left(\delta(\sigma(s))\right)
\right)\mathrm ds,
```

其中 $`\delta(q)`$ 是机器人在构型 $`q`$ 下与障碍物的最小距离， $`\phi`$ 是在距离较小时增大的惩罚函数， $`\lambda\ge 0`$ 为权重。这样，RRT* 不仅会缩短机械臂关节运动，还可能逐步把路径从货架边缘推向更安全的区域。若实际任务关心执行时间或电机能耗，几何长度只能作为代理代价；在没有时间参数化和动力学模型时，不能把它直接解释为最短时间或最低能耗。

RRT* 的改进是渐进的：第一次解通常不比 RRT 更快，真正优势出现在允许持续计算并反复优化时。它要求边代价具有适当的可加性和连续性，局部连接必须可验证，重连后的子树代价必须一致更新。若环境突然变化，旧树中的部分边会失效，理论上的单调改进不再成立；若最优路径贴着障碍边界、通过零宽通道或依赖不连续接触模式，标准渐近最优结论也可能不适用。工程系统因此通常同时设置首次解时限、优化时限和安全裕量，而不是无限等待理论极限。

## 22.5 概率完备性

概率完备性描述的是“存在可行解时，随机规划器最终发现解”的概率性质。设规划器在使用 $`n`$ 个样本后失败的事件为 $`F_n`$ 。若对问题类中的每个可行实例都有

```math
\lim_{n\rightarrow\infty}\Pr(F_n)=0,
```

则称该规划器在相应假设下概率完备。它不同于确定性完备：有限次采样失败不能证明问题不可行；它也不保证在给定的一秒或一万个样本内一定成功。该概念回答的是样本数趋于无穷时的极限行为，而不是实时系统中的最坏情况时限。

常见证明思路要求存在一条具有正间隙的参考路径 $`\sigma^\star`$ 。若存在 $`\delta>0`$ ，使路径上的每个构型都与碰撞区域至少相距 $`\delta`$ ，则可沿路径放置有限个相互重叠的小球 $`B_1,\ldots,B_m\subset\mathcal C_{\mathrm{free}}`$ 。若采样分布在每个球中都具有正概率，独立采样最终命中所有小球的概率趋近于一；若局部规划器能够连接相邻球中的样本，PRM 或 RRT 就有机会构造完整路径。对单个体积为 $`\nu_i>0`$ 、采样概率为 $`p_i>0`$ 的区域， $`n`$ 次独立采样均未命中的概率为

```math
(1-p_i)^n\le e^{-np_i},
```

这给出了失败概率随样本数下降的基本机制。

这些结论依赖若干不能省略的条件：采样分布必须在相关自由空间上具有充分支持，碰撞检测和局部连接判断必须正确，参考解通常需要正的鲁棒间隙，样本之间还要按合适尺度建立连接。若路径只能穿过零测度集合，例如两个障碍物恰好相切形成的零宽通道，连续分布直接采中该集合的概率为零。若末端必须精确落在由等式约束定义的低维流形上，直接在整个关节—任务空间中均匀采样也可能永远无法满足约束，此时必须显式在目标流形采样、用逆运动学生成目标构型，或把样本投影到约束流形。

在仓库工程中，概率完备性意味着：若移动底盘到货架前存在具有安全余量的通道，并且采样、度量与连接器覆盖该通道，那么增加规划时间原则上会提高成功概率。它并不保证狭窄的托盘间隙能在任务时限内被发现，也不补偿错误地图、未观测叉车或碰撞模型偏差。实际系统应记录失败原因并区分“预算耗尽”“目标逆解不存在”“已知图中不可连通”和“碰撞校验失败”；不能把随机规划器超时直接上报为物理不可达。

<a id="ch22-sec6"></a>
## 22.6 渐近最优性

渐近最优性比概率完备性更强。令 $`J_n`$ 是规划器使用 $`n`$ 个样本后得到的最佳可行路径代价， $`J^\star`$ 是允许路径集合中的最优代价。若

```math
\Pr\!\left(
\lim_{n\rightarrow\infty}J_n=J^\star
\right)=1,
```

则称规划器具有渐近最优性。概率完备只要求最终找到某条路径，而渐近最优要求最佳已知解最终逼近全局最优值。PRM*、RRT* 以及满足相应连接尺度条件的算法具有此类性质；基本 RRT 通常会以非零概率长期保留次优树结构，因此不具备同样的保证。

这一性质依赖代价与几何结构的相容性。通常要求路径代价非负、可按边分解，并对小的路径扰动不过度敏感；自由空间和最优解还需满足适当的正则性或可由具有正间隙的路径序列逼近。以长度代价为例，

```math
J(\sigma)=\int_0^1 \|\dot\sigma(s)\|_W\,\mathrm ds
```

在分段光滑路径上定义良好。若代价包含“只要碰到某一精确接触点就立刻减少一个常数”之类的不连续项，邻近样本对最优路径的逼近未必带来代价逼近。类似地，若最优解必须沿障碍物边界滑动，而任何有正间隙的替代路径都显著更差，标准证明条件需要重新检查。

渐近最优不等于有限预算下优越。高维空间中，获得第一条路径、验证邻边和维护最近邻结构都需要时间；在仓储机器人只有数百毫秒进行局部重规划时，一个快速 RRT 加路径后处理可能比尚未充分重连的 RRT* 给出更好的实际结果。若允许机器人在执行前持续优化数秒，RRT* 才更可能把机械臂路径从冗长绕行逐步缩短。工程评价因此应绘制“代价—时间”曲线，而不能只比较算法名称或最终理论极限。

此外，最优性只相对于所选模型、可行集和代价函数成立。若 $`W`$ 低估了肩关节电机负担，关节空间最短路径可能造成较高峰值力矩；若安全距离仅作为软惩罚，最优路径可能仍过于靠近货架；若地图来自相机和 IMU 融合估计，状态与障碍位置的不确定性未进入模型，所谓最优也只是名义模型下的最优。设计者必须先明确优化对象，再讨论收敛到什么意义下的最优解。

## 22.7 采样策略

最基础的策略是在有界构型域中独立均匀采样。它结构简单、覆盖无偏，便于建立概率完备和渐近最优结论，但在有效自由空间很小或通道很窄时效率低。更一般地，可从密度 $`p(q)`$ 采样；为了保留覆盖性质，通常要求相关开放区域上的概率质量不为零。工程中常把多种分布混合：

```math
p(q)=\alpha_0p_{\mathrm{uniform}}(q)
+\alpha_1p_{\mathrm{goal}}(q)
+\alpha_2p_{\mathrm{task}}(q),
\qquad
\alpha_i\ge 0,\quad \sum_i\alpha_i=1.
```

其中均匀分量保证全局探索，目标分量提高连接目标集合的机会，任务分量则利用货架、抓取姿态或历史查询的先验。只要 $`\alpha_0>0`$ 且均匀分量覆盖所需区域，偏置策略一般不会完全排除未预见通道。

窄通道可使用障碍物附近采样、桥测试或高斯采样。桥测试先采两个碰撞构型 $`q_a,q_b`$ ，若其中点或流形中间构型 $`q_m`$ 无碰，则 $`q_m`$ 可能位于狭窄自由通道中。这类方法利用“通道附近碰撞体积大、自由体积小”的几何特征，但会增加无效碰撞查询，也可能在复杂非凸几何中产生误导。对仓库移动底盘，可在门洞、货架端部和托盘间隙附近提高采样密度；对机械臂，则可在末端接近走廊对应的逆运动学解附近采样，而不能只在笛卡尔空间靠近目标就假定整条机械臂无碰。

找到一条当前最佳路径后，可以限制后续采样到有可能改进代价的区域。以欧氏路径长度为例，若起点与目标间距离为 $`c_{\min}`$ ，当前最佳代价为 $`c_{\mathrm{best}}`$ ，则任何能改进解的点 $`q`$ 必须满足

```math
\|q-q_{\mathrm{start}}\|
+\|q-q_{\mathrm{goal}}\|
<c_{\mathrm{best}},
```

对应一个以起点和目标为焦点的长椭球体。Informed RRT* 直接在该区域采样，避免探索不可能产生更短路径的远处空间。该几何结论依赖欧氏型可加长度；对于带障碍风险、非对称运动代价或多个目标构型的情形，启发区域必须重新推导，不能机械套用椭球。

采样还应尊重构型空间的几何与约束。旋转应在 $`SO(2)`$ 或 $`SO(3)`$ 上按合适测度采样，而不是对冗余参数随意均匀取值；闭链、末端接触和固定抓取等式 $`h(q)=0`$ 定义了低维约束流形，可先采样环境空间再通过迭代

```math
q_{k+1}=q_k-J_h(q_k)^\dagger h(q_k)
```

投影，其中 $`J_h\in\mathbb R^{m\times d}`$ 是约束雅可比矩阵， $`J_h^\dagger`$ 为广义逆。投影只在局部正则、初值足够近且雅可比秩合适时可靠，并可能收敛到错误分支或越过关节限位。学习型采样器可以利用历史拣选数据，但应与保底分布混合，并监测环境变化下的分布偏移，避免把经验偏置误当成无条件保证。

<a id="ch22-sec8"></a>
## 22.8 高维机器人规划

移动操作机器人的构型空间通常是多个流形和区间的乘积。对全向或可近似全向的平面底盘与六轴机械臂，可写为

```math
\mathcal C
=SE(2)\times\mathbb T^6,
\qquad
q=(x,y,\theta,q_1,\ldots,q_6),
```

其中 $`\mathbb T^6`$ 表示六个周期关节的乘积；若部分关节有限位，则相应分量应视为受限区间而非完整圆周。规划中的障碍包括底盘与货架碰撞、机械臂与环境碰撞、自碰撞、关节限位以及抓持料箱后的扩大几何包络。一次碰撞查询需要通过正运动学把所有连杆放置到工作空间，因此其成本常高于样本生成和最近邻查询。

高维规划不能只靠增加样本数，还需要利用问题结构。一个常见分解是先规划底盘到可操作区域，再在若干候选底盘位姿上求机械臂逆运动学和关节路径；另一种方式是在九维联合空间中直接规划，使底盘微调与手臂绕障协同发生。前者计算量小，但可能因过早固定底盘而丢失可行解；后者更完整，却面临更严重的维数灾难。可采用分层策略：先在 $`SE(2)`$ 中生成若干底盘走廊和停靠候选，再以这些结果为偏置在联合空间搜索，同时保留少量全局联合采样，以降低分解错误造成的不完备风险。

联合度量应体现不同变量对机器人几何运动的影响。例如可定义

```math
d^2(q,q')
=w_p\|(x,y)-(x',y')\|^2
+w_\theta\,\Delta\theta^2
+\sum_{i=1}^{6}w_i\,\Delta q_i^2.
```

权重可以依据典型运动尺度设置，也可以用机械臂雅可比近似关节变化引起的末端或连杆位移。固定权重仍只是局部近似：机械臂在伸展姿态时，肩关节微小转动引起的扫掠体积远大于腕关节同量转动；接近奇异位形时，任务空间与关节空间的尺度关系也会恶化。因此，最近邻度量可以用于高效索引，但边验证必须回到完整几何模型，不能以“小距离”代替“安全可连”。

感知与估计通过状态接口进入规划。相机提供货架、料箱和人员的几何观测，IMU 与轮式里程计帮助估计底盘位姿，关节编码器给出机械臂状态。规划器实际接收的是估计量 $`\hat q`$ 、地图 $`\hat{\mathcal M}`$ 及其时间戳，而不是真实状态。若估计协方差为 $`\Sigma_q\in\mathbb R^{d\times d}`$ ，可以根据不确定性扩大障碍物或提高安全间隙，例如要求名义距离满足

```math
\delta(\hat q)\ge \delta_{\min}+\kappa\,\sigma_\delta,
```

其中 $`\sigma_\delta`$ 是由状态与地图不确定性传播得到的距离标准差， $`\kappa`$ 对应保守程度。该近似需要局部线性化和近似高斯假设；在遮挡、多峰定位或未知障碍物情况下，单一协方差不足以表达真实风险。

最终，采样规划器输出的是离散节点与局部边组成的路径。执行前通常还要做捷径化、连续碰撞复核、时间参数化和控制跟踪验证。机械臂路径必须满足电机速度、加速度和力矩能力，移动底盘路径还需符合转向或非完整约束；抓持料箱后，质量、惯量和质心变化会影响可执行性。高维几何规划最有价值的角色，是在复杂拓扑中发现候选通道，而不是单独承担从感知到电机命令的全部责任。

<a id="ch22-sec9"></a>
## 22.9 纯几何规划的能力边界

纯几何规划把边的可行性主要定义为构型连续、满足静态约束且不发生碰撞。它能够回答“机器人形状是否能从这里绕到那里”，却通常不回答“机器人能否按给定时间、速度和控制能力完成运动”。设一般动力系统为

```math
\dot x=f(x,u),\qquad
x\in\mathcal X,\quad u\in\mathcal U,
```

其中状态 $`x`$ 可能同时包含构型 $`q`$ 和速度 $`\dot q`$ 。几何规划只在 $`\mathcal C`$ 中寻找 $`\sigma(s)`$ ，并未保证存在时间标定 $`s(t)`$ 和控制 $`u(t)`$ ，使 $`q(t)=\sigma(s(t))`$ 满足上述动力学、输入限制和状态限制。因而无碰路径可能要求移动底盘瞬时侧移、无人机在零速度下急转，或机械臂电机产生超过额定值的力矩。

对于某些系统，几何路径与时间参数化可以分层处理。若机械臂沿给定路径 $`q=\sigma(s)`$ 运动，则

```math
\dot q=\sigma'(s)\dot s,\qquad
\ddot q=\sigma''(s)\dot s^2+\sigma'(s)\ddot s.
```

把它们代入速度、加速度和力矩约束，可求解允许的 $`\dot s`$ 与 $`\ddot s`$ 区域。若路径曲率适中、动力学约束有余量，这种“先路径、后时间”的方法有效且工程成熟；但若任何时间标定都无法满足约束，后处理不能挽救该几何路径。高速移动、强惯性、欠驱动无人机以及需要动态跨越的四足机器人，更需要在状态空间中同时考虑运动与控制。

静态构型空间也不能完整描述时间变化障碍。仓库中的人员、叉车和其他机器人使碰撞关系依赖时间，需写成 $`\mathcal C_{\mathrm{obs}}(t)`$ 。单纯绕开它们的当前观测位置可能导致未来相撞；把时间作为额外维度可以表达时空走廊，但还必须使用运动预测、交互假设和不确定性模型。若障碍物行为会响应机器人，固定预测轨迹本身也可能失效。类似地，定位误差、相机遮挡和接触模型误差意味着“名义无碰”不等于实际安全，安全监控、在线重规划和低层保护仍不可缺少。

几何碰撞模型还难以处理接触丰富任务。抓取、推箱、开门和插入都涉及接触模式、摩擦锥、作用力与物体状态变化。将接触一律视为碰撞会排除必要动作，将其一律允许又会产生不可执行方案。对仓储机器人，移动到抓取预备位姿可由本章方法有效处理，而夹爪闭合、料箱脱离货架、负载下回撤则需要把接触、动力学和控制约束纳入模型。采样规划在这里仍可作为全局探索框架，但其节点应扩展到状态或模式，边应由动力学传播、轨迹优化或可验证控制器生成。

因此，纯几何采样规划的正确定位是：在复杂高维自由空间中高效发现连通关系与候选路径，并为后续模块提供拓扑上合理的初值。它的结论成立于地图、机器人几何、构型约束和局部连接假设之下，不应被解释为执行层面的无条件可达。下一章将把规划变量从构型路径推进到状态—控制轨迹，研究速度、加速度、非完整约束和动力学可行性如何改变采样、扩展与最优性问题。

## 本章小结

本章从高维构型空间的指数复杂度出发，说明了采样规划为何以随机样本、最近邻查询、局部连接和碰撞检测替代规则网格。PRM 通过可复用路图近似自由空间的连通结构，适合静态环境中的多次查询；RRT 借助 Voronoi 偏置快速探索，适合尽快求得单次查询的可行解；RRT* 通过择优父节点和重连持续降低路径代价。概率完备性描述样本增加时发现可行解的概率趋近于一，渐近最优性则进一步要求最佳路径代价逼近全局最优值，两者都依赖采样支持、正间隙、局部连接和代价正则性等明确假设。

采样分布决定有限预算下的实际效率。均匀采样提供全局覆盖，目标偏置、窄通道采样、任务先验和启发式子集采样提高局部效率，但偏置不应完全移除保底覆盖。对仓储移动操作机器人，还必须正确处理 $`SE(2)`$ 、关节流形、逆运动学目标集合、自碰撞以及底盘—机械臂耦合，并把相机、IMU、编码器和地图估计的不确定性转化为合理的安全裕量。

本章方法主要解决几何通道发现问题。离散无碰路径仍需平滑、连续复核、时间参数化和闭环执行验证；当移动底盘具有非完整约束、机械臂受电机力矩限制，或任务涉及无人机惯性、四足动态运动与接触切换时，构型空间中的直线连接不再代表可执行运动。下一章将以状态空间模型 $`\dot x=f(x,u)`$ 为接口，把动力学、控制输入和时间纳入采样规划，建立从几何可行到动力学可行的进一步连接。
