# SUMMARY

# 《从模型到行动：自主系统的统一方法》

> 真实世界 → 系统 → 物理规律 → 微分方程 → **状态空间** → 系统分析 → 估计 → 规划 → 控制 → 执行 → 学习 → 再回到真实世界
>
> 学习（Learning）横跨各层，反馈（Feedback）将整个系统连接成闭环。状态空间是统一接口。
